# 用户设置基础

设置属于客户端本地偏好，与内容包、剧本存档、Core 世界状态和规则随机无关。当前仅提供 `San9.Client.Godot.Settings` 下的不可变 `UserSettings` 和显式 `UserSettingsStore.Load/Save`；尚未接入启动流程、设置窗口或播放消费者，不表示选项已经影响游戏。

| 设置 | 取值 | 首版默认 |
| --- | --- | --- |
| MusicEnabled | 开／关 | 开 |
| SoundEnabled | 开／关 | 开 |
| MoviesEnabled | 开／关，仅影片 | 开 |
| MessageSpeed | Normal／Fast／Pause，对应普通／快／暂停 | Normal |
| ProgressReport | Detailed／Summary／Off，对应详细／要约／OFF | Detailed |

默认值是本次基础实现的明确选择，不声称已核对原作编译默认值。原作选项及标签证据见[RE-0065](../research/findings/RE-SAN9PK-0065.md)。枚举以英文名称序列化，不继承原作配置整数编码。影片不控制地图或战斗动画；讯息速度的等待／跳过方式、进行记录的过滤规则待对应模块接入时核对，不将 OFF 解释为删除存档记录或关闭模拟录像。

正式接入时，客户端装配层将 `user://user-settings.json` 经 Godot `ProjectSettings.GlobalizePath` 转成绝对路径，再创建存储对象；存储本身只用 .NET 文件 API，可以脱离引擎测试。调用方持有当前设置，负责何时应用、保存及显示失败，不在每次读取时访问磁盘，不在存储层创建全局单例或自动覆盖用户配置。

正式接入采用以下读写时机，当前尚未实现这些调用方行为：启动读取一次，此后消费者读取内存设置，切换剧本或读取存档不重新加载；设置窗口编辑独立草稿，确认／应用时先保存，成功后发布当前设置，取消丢弃草稿。读取失败时提示并使用内存默认值，保留原文件；保存失败时保留草稿供重试，不发布新设置或显示成功。不依赖退出时保存，也不在播放声音或显示消息时读取磁盘。

文件采用 UTF-8、格式版本 1 和完整必填字段。文件不存在时返回默认值且不创建文件；损坏、字段缺失、非法枚举、未知字段和不支持版本明确报错，保留原文件。读取与写入权限错误交由调用方处理。保存先校验，在同目录写临时文件并刷新后替换目标，失败清理本次临时文件。当前仅支持一个客户端写入者，不承诺多实例合并。未来格式变化显式处理，不以缺字段默认为成功掩盖损坏。

测试覆盖独立读取、全部枚举往返、替换保存、缺文件、损坏和非法值、失败不覆盖已有值及临时文件清理。没有设置 UI，当前不涉及画面验收。
