# 开局专项：剧本载入、确认新局与首旬准备

本页集中维护散落的开局结论、重制接入状态与待核对项。核对基线：2026-09-25，繁中 PK 1.0.1；其他版本差异单列。原始地址、编号门、实验与反编译证据仍保留在各 RE，不在此复制。

**研究事实不自动成为采用决定。** “已接入”仅指表中列明的行为；“缺口”指相对原作的已确认差异，不表示本次已授权实现。本文不宣称穷尽全部开局事件，也不是新一轮画面验收记录。

## 一、生命周期与顺序

```text
启动工作剧本（编辑工作数据，不是进入游戏）
  → 选择正式剧本：重置、重新载入、可选人物／物品覆盖
  → 运行时派生初始化：日期标志、归属、引用、地图占用等
  → 玩家选择与新局设置确认
  → 一次性新局处理
  → 首旬准备及各自满足门槛的周期／事件处理
  → 首次玩家交互
```

一次性新局处理的原作顺序为：自创人物初始化 → 扩展物品整理 → 自创君主城市兵役转化／增兵 → 虚拟人物与势力关系初始化（仅虚拟）→ 蓬莱／倭隐藏 → 异民族身份、兵力及人物出生年 → 难度与显式额外补偿 → 城市固定兵法追加 → 后续收尾、配置保存及可选人物编辑缓冲覆盖。部分收尾调用仍未完整解释，不把这个概览当作完整操作清单。[载入证据](../research/findings/RE-SAN9PK-0140.md)、[确认新局证据](../research/findings/RE-SAN9PK-0174.md)。

**读档是另一条路径。** 恢复保存的世界与推进边界，不重新发放开局资源、不重掷人物、不重置出生年，也不重复首旬准备。重制 `SimulationEngine` 的 `New` 边界执行人物登场初始化和 `ResolutionPipeline.Prepare`，恢复边界不重复执行这一分支。

## 三、异民族新局初始化

### 电脑异民族开局加兵

190 年转换包保留乌丸、羌、山越、南蛮各 100000 基础驻兵。会话创建新世界时，Core 向活动电脑异民族的君主所属城市追加 200000，受兵力容量限制；驻地不合格时按城市 ID 稳定选择所属城市，无城市则不发放。普通开局四城各成为 300000，兵役人口与士气不变；读档不重复。

倭城同为 100000，但处于休眠；隐藏步骤在先，**不能据此给休眠倭直接加兵**，也不能把后续蓬莱探索奖励提前到新局。玩家选择倭的激活应使用创作的初始资源，不等同于完成探索事件。

### 异民族人物出生年

25 名相关人物由 Importer 转换开局年龄定义：五位首领为 34，其余为 19。新世界按“开局年 − 年龄差”解析出生年，190 年分别为 156 与 171。普通人物保留固定出生年；固定年份与相对年龄互斥，存档仅保存解析后的运行时出生年。

该规则不受玩家选择、当前归属或休眠影响。原作列传资源身份只在版本 Importer 中解释，共享内容允许独立创作相对开局年的出生定义。样本与核对方法见 [RE-0174 补充核对](../research/findings/RE-SAN9PK-0174.md#新局初始化补充核对2026-09-25)。

## 四、新局设置：一次性效果与持续规则分开

### 初级／高级与显式补偿

- 初级将合格的非玩家、非异民族势力初始资金和兵粮乘以 1.2；高级乘以 1.4。账户资金／兵粮有上限，不是每旬收入倍率。
- 高级另给合格的非玩家、非异民族城市增加 10000 兵。
- 高级设置的五个额外输入分别是资金、兵粮、内政增量、兵力、士气；普通默认路径均为 0。额外兵力等分支的对象筛选并不完全等同于上述难度分支，不能合并成一个“电脑补偿”条件。
- 电脑战斗强度百分比是另一个世界字段；另有独立的人物编辑缓冲应用开关，不能混作第六种资源补偿。
- 高级下自动工作等待减半、尝试预算和军事候选差异是持续 AI 规则，不是开局一次性写值；等待减半也不代表整个工作周期减半。

来源与完整筛选条件见 [RE-0174](../research/findings/RE-SAN9PK-0174.md)。默认值已闭合，不推断所有特殊入口或修改后的配置也恒为零。

### 史实／虚拟

虚拟新局随机化包括义理、野心、性格、寿命档、相性；重设忠诚表、亲代与血缘根；按人物身份调整在野／未发现位置或未登场相关地点。它**不重掷统率、武力、智力、政治和兵法**，也不把所有在职人物换到随机势力。寿命档不是死亡年龄。

势力关系重设为中立值，不意味着清除联盟等其他外交标志。持续的连携关系加成及事件准入另有模式判断，不能概括为“虚拟禁止连携／全部历史事件”。繁中 PK 1.0.1 的虚拟称帝限制与日版 1.3 不同；重制已采用虚拟可称帝，不据繁中样本反向撤销产品选择。详见 [RE-0174](../research/findings/RE-SAN9PK-0174.md)。

## 五、首旬准备不是开局奖励包

| 项目 | 已确认边界 |
| --- | --- |
| 俸禄 | 首次交互前可能已经支付；既有动态样本中董卓 27 笔共 444，资金由 9520 变为 9076 |
| 商人与粮价 | 属普通旬处理，重制 `EconomicCycle` 已在 `XunUpdate` 接入刷新 |
| 联盟期限 | 距开局须大于 0，首次准备不扣一期 |
| 季度资金、七月粮食 | 距开局至少 30 日，且满足各自日期／外层门槛；不能因一月／七月开局就自动发放 |
| 人物、伤兵、请求、内政标志、在野迁移、官职请求 | 普通旬处理链包含相应步骤，各自资格与时间门独立，不能断言首次全部产生变化 |
| 月／季／年事件与更新 | 有独立选择器、状态和准入；日期符合不等于必定触发，尚未穷尽首旬审计 |

重制 `EconomicCycle` 在 `XunUpdate` 处理俸禄、商人与粮价，在 `BeforeDailyCommands` 处理粮食消耗；季度人口与收入由距开局至少 30 日门控制。这里只确认这条基础路径，不据此宣称原作全部周期逻辑等价。证据见 [RE-0011](../research/findings/RE-SAN9PK-0011.md)、[RE-0157](../research/findings/RE-SAN9PK-0157.md) 与 [RE-0174](../research/findings/RE-SAN9PK-0174.md)。

非兵役人口与兵役人口从剧本分别导入；信息界面的“人口”为两者之和，“兵役人口”单列后者。字段定义见 [BEH-IMPORT-0003](../specs/behavior/BEH-IMPORT-0003-scenario-city-records.md)。

## 六、后续核对与实现边界

1. 异民族加兵与人物出生年已接入；实际开局画面待验收。
2. 逐项核对难度和虚拟设置的数据入口、确认阶段写值及持续消费者，分别记录采用与未采用项。
3. 对照载入派生清单核对归属、引用与占用，补齐自创人物、扩展物品、编辑覆盖及倭隐藏例外的接入审计。
4. 继续核对首次交互前的事件与周期顺序；既有俸禄样本不是全部剧本、模式的完备验收。
5. 自创君主增兵保持明确排除；统一人物规则尚未决定，不借本次整理重新引入。

工程归属遵循现有约定：版本特有的原始身份及固定表由 Importer 转为可创作语义；依赖玩家选择和设置的一次性处理由会话组织、领域规则执行；周期处理留在推进管线；读档恢复保存状态。不要为本次清单另造平行初始化框架。内容与会话入口见[客户端内容](client-content.md)、[运行时架构](runtime-state.md)。
