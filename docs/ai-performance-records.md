## 共用测量口径

- 环境：.NET 10.0.4 x64 Release JIT，Windows 10.0.26200、12逻辑处理器；190年完整内容（94据点／700人物）、初级、全自动。同机顺序独立运行，不与测试并发；各节另列种子、旬数和版本。
- 整旬只累计连续会话`Apply`，含规划、公共命令与日期推进，不含构建、初始化、恢复副本、比较、重放和输出。工作分项含公共提交及响应，不含批前准备；P95用向上取整的最近秩。
- 尝试含空计划／公共拒绝，不等于成功提交；外层路线请求与底层搜索分别计数。首旬与后续世界不同，不视作同局面的冷暖对照。
- 单组测量不保证统计稳定加速或跨设备性能；轨迹不同不能作为同工作量加速比。只在说明逐字节／哈希一致时主张同轨迹。
- 证据路径相对仓库根目录，均为忽略的本地产物，不保证其他机器可用。除明确契约变更外复用内容包。
