# 粗格导航设计

- 状态：已采用，2026-09-27。
- 行为与验收以[行军规格](behavior/BEH-WAR-0001-movement-and-command-lifecycle.md)为准；实测与性能限制见[寻路验收](../docs/pathfinding-verification.md)。
- 原作证据：[RE-0136](../research/findings/RE-SAN9PK-0136.md#原作寻路全链总览与差异清单2026-09-27)、[RE-0179](../research/findings/RE-SAN9PK-0179.md)。

## 选择与边界

采用粗格四向A*、细步执行和有界端点接驳。地图地形按粗格定义，领域位置、占地和射程仍使用细坐标。每条粗边逐步验证完整占地；任意坐标与合法入口通过3×3粗格窗口接驳。当前200×200地图的全局搜索容量由1,000,000细节点降为40,000粗节点，端点工作区最多225节点。容量减少96%不代表耗时或总内存同比降低。

用户明确接受：粗格中心路线可能漏掉细空间窄通路，本次不补齐，不以细空间完备性或全局最短路作为验收门槛。不增加全图细格兜底、扩窗重试或地点例外。端点接驳只服务于精确位置和到达条件。

原作粗图与局部细图均为四邻接，显示插值可以斜行。重制保留确定性同价贴线，暂不采用原作连线附近的强折扣，避免改变绕险权衡。规划软费用与实际步费分离；同方部队允许重叠，出征在合法来源中心立即创建，纯水阵形等中心不合法的情况在创建时选择合法入口。

每次每日移动重新规划，只保存自动前瞻点和对应真实目标几何。玩家中继、等待日数与自动前瞻各自独立；完整路径、失败次数、阻挡快照和重试退避均不持久化。前瞻用于缩短后续搜索距离，不替代真实到达谓词。协议拒绝旧状态格式，不保留旧导航执行分支。

## 职责与性能

Simulation统一按身份、外交、方针和设施语义生成占用快照，供预览、命令验证、移动与预计到达使用。搜索直接接收完整快照，只理解硬阻挡和非负软费用；旧的局部窗口占用回调已删除。

Core维护粗图搜索与有界端点接驳，按实际细步消费预算；Rendering绘制路线和旗子，客户端输入与动画不修改领域位置。本次没有新增每日行军插值。

仅保留不可变地形数据、水陆地图视图和可复用搜索工作区。对象分桶每次查询重填，端点费用每个窗口重算；线程工作区独占租用，归还后不持有地图。未保留区域图、引导LRU或全图细格缓存。诊断只记录工作量，不影响结果。

2026-09-27核对190年转换包：地图200×200，28种阵形均为3×3细单位；94个据点中心均位于粗格中心。据点占地为50个5×5、36个3×3、2个1×3、3个1×5、3个3×1；工作物定义含6项1×3／3×1和1项3×3。这支持选择粗格为主的导航模型，但不能证明窄通路或较大Mod阵形的连通性，不能把这些尺寸写成Core限制。

## 未采用的方案

| 方案 | 取舍理由 |
| --- | --- |
| 全部位置改为粗格、整格跳行 | 会粗化速度、接近距离、港口入口和部队占地。 |
| 全局粗图加一般化局部避障 | 要处理粗细连通差异、失败重规划；当前已接受窄通路限制。 |
| 保留全图细格并增加层级与缓存 | 延续旧实现的主要复杂度。 |
| 八邻接或任意角度搜索 | 改变穿角与距离规则，同价贴线已经可以形成斜向阶梯。 |
| 流场或群体转向 | 需要共享目标或连续碰撞体系，目前按日结算且各队目标不同，没有测量证据要求引入。 |

现代实现的参考思路是优先缩小搜索图；采用普通A*和优先队列，不预先引入更复杂的导航体系。路线质量、持续负载和完整会话成本分别验证；历史基准与当前外交软避让规则不同，不能直接据此宣称整体提速倍数。
