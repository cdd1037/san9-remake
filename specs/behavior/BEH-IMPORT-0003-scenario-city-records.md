## 适用范围

本规格约束繁中 PK 1.0.1.0 正式剧本 `city` chunk 的记录边界、已确认字段和输入校验。输入必须先通过 [BEH-IMPORT-0001](BEH-IMPORT-0001-source-container-validation.md)。

本规格不定义城市名称文本、州域显示名称、坐标到道路拓扑的映射、其他版本对两个保留字段的可能解释、城市武将列表或城市属性的运行时变化公式。原作在剧本载入后对势力君主城市执行的兵役转化与增兵属于新局初始化，不属于 `city` chunk 解析；证据见 [RE-SAN9PK-0061](../../research/findings/RE-SAN9PK-0061.md)。

## 原作基线

`city` chunk 包含 50 项，每项 56 字节：

| 偏移 | 类型 | 字段 | 已确认约束 |
| --- | --- | --- | --- |
| `0x00` | `u32` | city flags | bit 0 表示常驻商人；正式剧本没有其他置位 |
| `0x04` | `u32` | population | 非兵役人口；不大于 1,000,000 |
| `0x08` | `u32` | draft population | 兵役人口；不大于 500,000 |
| `0x0C` | `u32` | soldiers | 城市士兵；不大于 500,000 |
| `0x10` | `u16` | serialized id | 等于记录序号 |
| `0x12` | `u16` | auxiliary id 1 | 等于记录序号；不进入领域模型 |
| `0x14` | `u16` | auxiliary id 2 | 等于记录序号；不进入领域模型 |
| `0x16` | `u16` | area code | 0–14，对应 15 项州域表 |
| `0x18` | `u16` | reserved 1 | 20 个正式剧本均为 0；本构建载入后不读取、不写入存档 |
| `0x1A` | `u16` | reserved 2 | 20 个正式剧本均为 0；本构建载入后不读取、不写入存档 |
| `0x1C` | `u16` | force code | 0–49；`0xFFFF` 表示无所属势力 |
| `0x1E` | `u16` | public order | 民心，0–1,000 |
| `0x20` | `u16` | max income | 最大收益，0–1,000 |
| `0x22` | `u16` | max harvest | 最大收获，0–1,000 |
| `0x24` | `u16` | income | 当前收益，不大于最大收益 |
| `0x26` | `u16` | harvest | 当前收获，不大于最大收获 |
| `0x28` | `u16` | durability | 当前耐久，不大于最大耐久 |
| `0x2A` | `u16` | max durability | 最大耐久，不大于 1,500 |
| `0x2C` | `u16` | x | 地图横坐标，0–199 |
| `0x2E` | `u16` | y | 地图纵坐标，0–199 |
| `0x30` | `u16` | terrain code | 城市外观特征代码 0–2；黑盒显示为中原都市、南方都市、北方都市；建筑组合分组映射为 `2→0`、`0→1`、`1→2` |
| `0x32` | 6 字节 | tactic flags | 41 位兵法标志；bit 39/40 分别为落石和射台 |

原程序以记录位置建立两个运行时对象 ID，不依赖文件中的三个编号字段；正式输入仍要求三个编号一致。州域代码和势力代码分别经过 15 项、50 项访问器转换为运行时引用。士兵载入路径使用 500,000 上限。

城市坐标是建筑视觉与占用几何的中心锚点；完整占用区不由坐标字段单独编码，而由 `squa` 方格的 `ZoneCode` 和 flags 表达。已验证实例中，洛阳 `city[15]` 的 `(89,64)` 对应 5×5、共 25 格 `ZoneCode=15`；据点则以 `50 + bldgId` 编码，例如带方港 `bldg[0]` 的 `(184,26)` 对应 3×3、共 9 格 `ZoneCode=50`。方格地形和过渡属性与对象占用保持正交。

## 重制行为

导入器必须保留全部字段，包括两个剧本保留字段和完整 48 位原始兵法位集。`0xFFFF` 势力代码必须映射为空值。

转换到现代内容模型时，两个辅助 ID 可以丢弃；两个保留字段不得进入玩法逻辑。常驻商人、落石和射台以显式布尔派生值提供，原始标志仍须保留。流动商人的当前在场状态属于运行时状态，不得从剧本 `city` 记录虚构第二个输入字段。若后续支持其他原版构建，必须重新调查该构建对保留字段的处理，不能沿用本版本结论。

未知城市标志、越界人口/兵力、编号不一致、非法引用、当前值超过最大值、越界坐标、非法城市外观特征或 41 位之外的兵法标志必须拒绝整个 `city` chunk。

## 状态与不变量

- 输入与前置条件：已通过 `BEH-IMPORT-0001` 的完整剧本流，位置在文件起点。
- 状态变化：无；只生成 50 项只读记录。
- 始终成立的不变量：返回顺序等于文件顺序；每项完整消费 56 字节。
- 失败行为：抛出格式错误，不截断、钳制或猜测字段。

## 示例与边界

- 190 年剧本记录 0：人口 58,000、兵役 7,000、士兵 8,000、民心 200、坐标 `(164, 17)`、城市外观特征代码 2。
- force code 为 `0xFFFF`：解析为空所属势力。
- tactic bit 39：`HasRockfall = true`。
- tactic bit 40：`HasArrowPlatform = true`。
- income 大于 max income：拒绝整个列表。
