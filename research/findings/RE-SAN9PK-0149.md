## 调查动机与边界

`RE-SAN9PK-0133` 已闭合培养记录的触发、激活、九旬状态和最终归属，但只摘要了“触发人物、导师、策略、当前能力/熟练度和随机流共同决定结果”，没有展开玩家机制文章所需的生成与成长公式。本批回查既有已命名函数、静态系数表和事件分派器，补齐初始人物、初始兵法、四轮能力、熟练度及事件优先顺序。

本批不读取工作区外的原版编辑器、存档或资源文本，不给未读取的本地化事件台词强行命名。地址与内部字段仅留在本记录；玩家文章使用业务术语和公式。

## 头像、性别、年龄与姓名

`initialize_trainee_identity_and_birth_year(0x408C40)` 从头像号 `786..835` 中随机选择尚未占用的一项。头像组内序号 `0..34` 写男性，`35..49` 写女性。年龄由头像子组决定：

| 头像组内序号 | 生成年龄 |
| --- | --- |
| `0..4`、`35..36` | `15..17` |
| `5..9`、`37..40` | `18..20` |
| `10..21`、`41..44` | `21..24` |
| `22..31`、`45..48` | `25..29` |
| `32..34` | `30..32` |
| `49` | `30` |

随后写 `birth_year = current_year + 1 - generated_age`。因此旧摘要中的总范围 `15..30` 应纠正为 `15..32`。

`sub_408D90` 从 104 个姓资源和按性别分开的名资源随机组合，拒绝与既有人物重名及长度不在 `1..10` 的结果。函数末尾还按姓资源索引写一项静态字段，但本批没有闭合该字段的玩家语义，故不作命名。

## 四项初始能力与上限

令触发人物对应的统率、武力、智力、政治为 `T`，`rnd(N)` 返回 `0..N-1`，整数除法向零截断。`initialize_trainee_abilities_and_caps(0x4086A0)` 分别执行：

```text
统率初值 = 35 + rnd((T统率 - 50) / 3 + 20)
武力初值 = 35 + rnd((T武力 - 50) / 3 + 20)
智力初值 = 30 + rnd((T智力 - 50) / 3 + 25)
政治初值 = 30 + rnd((T政治 - 50) / 3 + 25)

单项上限 = min(70 + max(0, (T - 74) / 6) + rnd(30), 100)
```

四项各自独立取随机数并保存独立上限。初值写基础能力后再重算当前有效能力；培养轮增长不得越过对应上限。

## 相性、义理、野心与性格

`initialize_trainee_traits_from_promoter(0x408AB0)` 实际参考触发人物所在势力的君主：

- 相性：80% 取 `leader_affinity - rnd(21) + 10` 并按 150 环归一化，20% 取 `rnd(150)`；
- 义理：50% 取 `clamp(trigger_righteousness - rnd(5) + 2, 0, 15)`，50% 取 `rnd(16)`；
- 野心：50% 取 `clamp(trigger_ambition - rnd(5) + 2, 0, 15)`，50% 取 `rnd(16)`；
- 性格：50% 直接继承触发人物性格，50% 取 `rnd(4)`。

这也纠正了旧摘要把相性笼统写成“触发人物附近”的表达：相性的邻近中心是触发人物所属势力君主，义理、野心和性格才直接参考触发人物。

## 初始兵法、熟练度与精通

令 `L = 候选当前统率 + 候选当前智力`。`initialize_trainee_tactics_from_trigger(0x40A900)` 的强制初始兵法如下：

| 触发码 | 强制结果 |
| --- | --- |
| `1` 消灭势力 | 无强制兵法 |
| `2` 占领城市 | 30% 直接给兵法 `19` |
| `3` 捕获人物 | 无强制兵法 |
| `4` | 兵法 `0` |
| `5` | `0`；若 `L>=120` 再给 `1` |
| `6` | 与码 `5` 相同；当前样本在 `L>=150` 仍未写兵法 `2` |
| `7` | 兵法 `3` |
| `8` | `3`；若 `L>=120` 再给 `4` |
| `9` | `3`；`L>=120` 给到 `4`；`L>=150` 给到 `5` |
| `10` | 兵法 `6` |
| `11` | `6`；若 `L>=120` 再给 `7` |
| `12` | `6`；`L>=120` 给到 `7`；`L>=150` 给到 `8` |
| `13` | 兵法 `9` |
| `14` | `9`；若 `L>=120` 再给 `10` |
| `15` | `9`；`L>=120` 给到 `10`；`L>=150` 给到 `11` |

之后还枚举兵法 `0..30` 中除 `0/3/6/9/12/16/20/24/27/28` 外的未习得项：关联触发人物会该兵法时，候选以 `min(50, 候选当前智力)%` 习得；否则仍有 `10%`。每项按存储顺序独立消费培养随机流。

每项已知兵法再向对应类别熟练度追加：

```text
单项追加量 = floor(兵法习得门槛 / 3) + rnd(50)
类别熟练度 = min(当前类别熟练度 + 单项追加量, 1000)
```

候选已经会任一类别的兵法时，该类别精通位置位。除此之外还按能力合计随机追加精通类别：

```text
武系追加次数 = min(5, (武力 + 统率 - 100) / 20 + 2)
谋略系追加次数 = min(3, (智力 + 政治 - 80) / 20)
```

武系每次从类别 `0..5` 随机，谋略系每次从 `6..8` 随机；抽取可重复，所以“次数”不保证得到相同数量的不同精通类别。

## 教学状态与三种策略

培养记录 `+0x13C` 为策略：`0` 均衡、`1` 严格、`2` 躬亲；`+0x13D` 为教学评价状态 `0..4`，数值越大不等同于旬号。初始化时均衡/严格把评价写为 `1`，躬亲写为 `2`。事件可继续改写评价。

四轮能力成长使用下列倍率 `M`：

| 轮次 | 评价 | 均衡 | 严格 | 躬亲 |
| --- | ---: | ---: | ---: | ---: |
| 第1轮 | 0/1/2/3/4 | 150/120/100/80/0 | 160/130/110/90/0 | 150/120/100/80/0 |
| 第2、3轮 | 0/1/2/3/4 | 155/125/105/85/0 | 155/125/105/85/0 | 150/120/100/80/0 |
| 第4轮 | 0/1/2/3/4 | 150/120/100/80/0 | 155/125/105/85/0 | 155/125/105/85/0 |

策略不是一个单独的固定加成：它与当前评价、所在轮次共同查表。

## 四轮能力成长公式

令导师四维为 `A0..A3`，总和 `S`，候选剩余上限分别为 `cap-current`：

```text
B = 3 + Σ max(1, floor(Ai / 24))
R = max(0, 11 - B)
U = 26 - B + R
G = B + floor(M * rnd(U) / 100)

pre_i = floor(Ai * G / S)
```

机器随后做一次余数检查；若 `G - pre_政治 - pre_智力 - pre_武力 != pre_统率`，四项 `pre_i` 都加 `1`。最后每项增长受候选该项剩余上限截断并写回。

因此导师四维不仅影响总增长基数，也按其四维比例分配本轮增长；策略只通过倍率表改变随机部分。评价状态 `4` 令倍率为零，但 `B` 这部分仍存在，不能把表中零误读为整轮绝对零成长。

## 四轮熟练度成长公式

每轮先按策略与评价确定训练的不同类别数，向上取整后最多四类：

| 评价 | 均衡 | 严格 | 躬亲 |
| ---: | ---: | ---: | ---: |
| `0` | 3 | 2 | 4 |
| `1` | 3 | 2 | 4 |
| `2` | 2 | 1 | 3 |
| `3` | 2 | 1 | 3 |
| `4` | 0 | 0 | 0 |

候选类别还受导师性格过滤：

- 莽撞 `0`：全部未到 1000 的类别；
- 刚胆 `1`：只有候选尚未掌握任何兵法时，全部未满类别才可入选；
- 冷静 `2`：候选已精通且尚未掌握该类最高阶兵法的类别；
- 慎重 `3`：候选尚未掌握该类最高阶兵法，且导师或候选至少掌握该类一项兵法的类别。

系统从合格类别中用全局随机流抽取互不重复的类别。令当前熟练度为 `P`，候选该类精通位为 `E`（0或1）：

```text
武系类别 0..5：Q = floor((导师统率 + 导师武力) / 2) + rnd(20)
谋略类别 6..8：Q = floor((导师智力 + 导师政治) / 2) + rnd(20)
D = floor((50 - isqrt(P)) * Q / 100)
本轮熟练度增加 = floor((2 + E) * D / 2)
```

精通者以系数 `3/2` 替代未精通者的 `2/2`。熟练度越高，`50-isqrt(P)` 越小，单轮增量随之下降。

## 事件调度、延时、暂停与换导师

每旬先处理暂停返回和导师有效性，再按以下优先级尝试事件：

1. 倒计时为 `8/5/2`、未暂停、事件史少于三项时，依固定顺序尝试特殊事件族；
2. 若本旬尚无事件，依次尝试三个兵法教学事件 `25..27`；
3. 若仍无事件，再依次尝试关系、能力差、年龄/性别、策略和评价相关事件 `1..4、15..24`；
4. 同一旬命中前项后不继续改试后项；
5. 事件结算后才进入倒计时 `8/6/4/2` 的常规成长，因此事件对暂停位、倒计时或评价的写回可以影响本旬成长。

三项兵法教学事件的机器边界为：

- `25`：候选仍有未学兵法时，概率基数为均衡 `35`、严格 `30`、躬亲 `45`；
- `26`：从 `0..30` 中排除 `0/3/6/9/12/16/20/24/27/28`，再取导师与候选都不会的兵法；门槛为 `max(0,(候选当前智力-25)/3)%`。命中后候选必定习得所选兵法，导师再以独立 `50%` 同步习得，并结算相应成长；
- `27`：从导师会而候选不会的兵法中选择，概率由策略基数、评价基数和导师智力 `/10` 相加；事件直接授予并追加对应成长。

特殊与表现事件的主要资格和概率按分派顺序为：

- `5`：只在倒计时 `2` 的特殊窗口；令 `Delta` 为当前四维总和减去初始化四维总和，概率门为 `max(0,70-Delta)%`，通过后还要求至少两项距离各自上限严格超过 `10`；命中后倒计时 `+3`；
- `6`：倒计时不是 `8/0`、历史无 `6/7`；按人物存储顺序取得首名有效的同势力非导师人物，仅当此人某项能力高出当前导师 `10` 以上时，才以 `2*(8-countdown)` 投骰，成功可进入换导师；失败不改试后续人物；
- `8`：倒计时不是 `8/0`、历史无 `8`；同样只取首名有效的同势力非导师人物，并比较导师最高能力所在项；对方该项更高时，阈值为 `min(10,2*差值)`，成功进入重选；
- `9`：倒计时不是 `8/0`、评价不为 `4`、历史无 `9/10/12/13`；阈值为严格方针 `10` 加相性距离 `/7`，其他方针不加前项；成功置暂停；
- `11`：历史无 `11` 且倒计时非零；阈值 `10-countdown`，成功置暂停；
- `12`：历史无 `9/10/12/13` 且倒计时不是 `8/0`；阈值 `10-countdown`，成功置暂停；
- `14`：历史无 `14`、倒计时至少 `3`、严格方针、评价至少 `2`，导师智力/政治低于 `70`、性格码不大于 `1`；阈值 `max(10, affinity_distance/2)`，结果可使导师或候选伤势加一；
- `15`：评价至少 `2`，先以导师四维总和高于学生的平均差为门，再以 `max(5,(导师智力-70)/3+5)` 投骰；
- `16`：评价不大于 `2`、导师武力低于 `30`；阈值 `(50-导师智力)/3`；
- `17`：非严格方针、评价至少 `2`；阈值 `85-affinity_distance/8`；
- `18`：非严格方针、评价小于 `2`；阈值 `max(1,affinity_distance/7)`；
- `19`：内部进度大于 `10`，师生至少两项能力差小于 `10`，再投 `20%`；
- `20`：先按导师四项超过 `85` 的部分求平均阈值，再要求导师至少两项高出学生 `40`；
- `1/2`：事件史未满三项、师生异性；由相性距离和学生年龄构造第一门，并另过 `25%` 门；评价分别排除 `0/4`；
- `3`：事件史未满三项、倒计时非零、评价不为 `0/4`；阈值最多 `5`，严格方针直接把该门推到 `5`；
- `21/22`：严格方针下各自 `10%`，分别要求评价不为 `0/4`；
- `23`：评价不大于 `1` 时 `10%`，评价数值加一；
- `4/24`：事件 `4` 在评价不大于 `2` 且历史未有 `4` 时走 `10%`；事件 `24` 在评价至少 `2` 时走 `10%`并令评价数值减一。

其中 `15..22` 的效果分支没有直接写能力、兵法、评价、倒计时或暂停位；本批不依据台词猜测额外数值。

事件 `1..4` 会把评价分别写到 `0`、`4`、随机 `0/4`、`3`。事件 `5` 把倒计时加 `3` 并置一次性标志；事件 `6..8` 可进入导师/策略重选；事件 `9/11/12` 会置暂停位；事件 `14` 可使导师或候选受伤；事件 `23` 把评价数值加一，事件 `24` 把评价数值减一。`15..22` 在当前机器分支只显示相应表现消息，不直接写能力、兵法、评价或暂停位。

暂停位为 `+0x13F bit 1`。暂停期间旬倒计时不减。每旬返回满足任一条件即可：

```text
rnd(100) < 5 * 当前倒计时
或
rnd(100) < 2 * 记录字段(+0x70) + 10
```

返回后清暂停位，并重新核对导师。导师死亡、成为俘虏或已不在同一势力时，原导师引用清空并进入导师/策略重选。

## 随机流边界

培养并非只使用一条随机流：

- 姓名、头像、年龄和部分熟练度类别抽取使用全局随机流；
- 初值、上限、相性/性格、激活、成长及事件大量使用培养专用确定性随机流；
- 培养专用流每次调用按计数器轮换读取候选四项能力作为种子输入的一部分。

因此，其他系统的随机消费未必影响所有培养结果，但会影响使用全局随机流的头像、姓名和部分类别选择；不能把整个培养过程概括成一颗独立且完全隔离的随机种子。

## 纠错、事实与剩余边界

- 纠错事实：生成年龄总范围为 `15..32`；相性邻近中心是触发人物所属势力君主，不是触发人物本人。
- 新增事实：初始能力/上限、初始兵法、策略倍率、四轮能力、四轮熟练度、事件优先级、延时、暂停返回和导师失效路径均来自当前项目主数据库控制流、静态表和写回。
- 中置信度边界：事件代码与效果已按机器写回闭合，但本批没有读取本地化资源，故不为代码 `1..27` 登记玩家显示事件名或逐句台词。
- 本批没有修改程序字节；后续经用户确认，将下述证据同步到项目主数据库。

## IDA 同步与回读验证

## 结论

小兵培养不是笼统的“导师加随机成长”。候选在触发时已经由头像组、触发人物、势力君主和触发码生成完整基础；激活后，策略、评价、导师四维与性格通过两套不同公式分别控制四维和熟练度；事件又按固定优先级在成长前改写评价、倒计时、暂停、导师和兵法。上述关系足以支撑一篇不依赖主观配对表的完整玩家机制介绍。
