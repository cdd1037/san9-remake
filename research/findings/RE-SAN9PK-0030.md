# RE-SAN9PK-0030：疆界线开关、边缘掩码与地图标记资源

- 状态：开关链与疆界线片段生成链已确认；重制版的具体渲染实现仍待设计
- 日期：2026-08-19
- 结论类型：IDA 直接证据；资源归属为代码交叉引用后的高置信度推断
- 置信度：高（消息映射、命令分发、状态字段、组 41、边缘资源选择）；中高（组 41 的产品语义为疆界线）
- 关联记录：`RE-SAN9PK-0026`

## 1. 结论

游戏里的“疆界线”不是在消息文本中定义的。消息 `08430` 只负责右上角地图工具按钮的 hover 提示：

```text
08430：可切换是否显示疆界线。
```

实际链路是：

```text
08430
  -> map toolbar tooltip table 0x660F70（第 5 个按钮）
  -> control command 1004
  -> CMainmapView::toggle_map_overlay 0x52BA90
  -> set_map_display_mode 0x521940
  -> state field CSan9MapView +0x118
  -> show/hide visual-object group 41
```

疆界线片段的生成链是：

```text
map square refresh 0x521370
  -> update_square_edge_visuals 0x5191D0
  -> choose resource variant 10794..10805
  -> create visual object 0x51ECE0
  -> object group = 41
```

## 2. 08430 如何连接到开关

`0x5269E0` 的 hover 处理函数先计算当前工具按钮索引，再读取 `0x660F60 + index * 4` 的消息号。该表第 5 项位于 `0x660F70`，值为 `8430`，因此 `08430` 对应按钮索引 4。

`0x52BA90` 对按钮命令 `1004` 的分支读取地图显示状态 `0x533D70`，将 `0` 与 `1` 互换，再调用 `0x521940`。所以按钮的点击行为不是直接绘制，而是切换地图视图状态。

## 3. 显示状态与可见对象组

`0x533D70` 读取 `CSan9MapView + 0x118`；`0x534340` 写入该字段并触发全局地图更新。

`0x521940` 的行为如下：

| 新状态 | 行为 | 直接证据 |
| ---: | --- | --- |
| 1 | 调用 `0x51CE10`，筛选 `value[7] == 41` 的视觉对象，并对这些对象执行管理器操作 `+0x14(..., 1)` | `0x51CE10`、`0x5B9820`、`0x5B94F0` |
| 0 | 调用 `0x521900`，扩大当前地图区域后进入 `0x521370` 重算/刷新 | `0x521900`、`0x521370` |

因此，组 41 是当前样本中被“疆界线开关”专门控制的地图视觉层。由于代码没有给这个组留下可读名称，称其为“疆界线组”属于基于唯一消费者和生成链的高置信度推断。

## 4. 疆界线片段如何生成

`0x5191D0` 是关键函数。它对 4 个方向逐项处理：

1. 从当前方格数据和邻接数据中读取边缘/势力掩码。
2. 根据当前方向是否存在边界，以及两侧关系，计算 `n2 = 0/1/2` 的片段变体。
3. 按另一组掩码选择资源基址：
   - `10794 + n2` 或 `10797 + n2`
   - `10800 + n2` 或 `10803 + n2`
4. 通过 `0x51E140` 获取资源对象。
5. 通过 `0x51ECE0` 创建视觉对象，参数中明确写入：
   - 图层/资源对象：上一步结果
   - 绘制层级：`2000`
   - 对象标志：`0x10000000`
   - 对象组：`41`
   - 所属方格：当前 `CSquareData`

`0x51B940` 的资源注册表把 `G_MapMkr.s9` 注册为资源号 `10794`。因此，10794–10805 是 `G_MapMkr.s9` 这组地图标记资源的变体；代码负责按方格边界掩码选择方向/形状，资源文件负责提供最终的图形片段。

这里的“边界”不是按城市之间画一条几何线，而是按地图方格逐边生成片段：当相邻方格的势力/地形关系满足条件时，才为对应方向创建组 41 的视觉对象。

## 5. 刷新时机

地图区域变化或疆界状态关闭时，`0x521370` 会扫描受影响的方格及邻接方格，并调用 `0x5191D0` 更新每格的边缘视觉对象。`0x522040` 也会在地图视图刷新后处理组 41 对象：对越出当前可见矩形的对象执行隐藏，并把组 41 对象的方格坐标转换到屏幕坐标后判断可见性。

## 6. 事实、推断与待验证

### 已确认事实

- `08430` 是地图工具栏第 5 个按钮的 hover 消息。
- 点击命令为 `1004`，它切换 `CSan9MapView +0x118` 的 `0/1` 状态。
- 状态 1 显示对象组 41，状态 0 触发地图区域刷新。
- `0x5191D0` 按方格边缘掩码选择 `10794..10805` 的资源变体，并以组 41 创建视觉对象。
- 资源号 `10794` 的注册名是 `G_MapMkr.s9`。

### 高置信度推断

- 对象组 41 就是疆界线视觉层。
- `G_MapMkr.s9` 的 10794–10805 变体是疆界线的方向/连接片段；代码中的 `n2` 和掩码逻辑负责组合这些片段。

### 待验证

- 10794–10805 每一个资源号对应的具体方向、端点和颜色。
- `a3/a4/a5` 三个掩码的字段级名称，以及它们从势力数据到 `CSquareData` 的完整来源。
- 重制版是否保留逐格片段模型，还是改为按势力区域边界提取连续折线。
