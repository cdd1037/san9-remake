# 军事外交与移动规则补齐验收

2026-09-13。本轮按用户要求暂停后续G08功能，处理本对话已确认而现有军事规则未接入的行为。依据[RE-0119](../research/findings/RE-SAN9PK-0119.md)、[RE-0136](../research/findings/RE-SAN9PK-0136.md)；产品约定见[普通战斗](../specs/behavior/BEH-WAR-0004-normal-combat.md)和[移动生命周期](../specs/behavior/BEH-WAR-0001-movement-and-command-lifecycle.md)。

## 已接入

- 明确攻击不再被联盟身份直接禁止。出征、改令、整编附带攻击在关系≥60或联盟保护时要求ConfirmAttack；未确认原子拒绝，不扣资源、不消耗命令序号。SimulationEngine及GameSession.GetAttackWarning提供结构化警告，确认字段进入命令序列化与重放。
- 旬推进开始检查当前正式设施攻击命令；普通设施执行关系35、基础信望和忠诚扣罚，随后独立叠加背盟处罚。普通成员退出、盟主或两成员联盟解散分别处理；取消命令无处罚，已完成外交转换不重复扣罚。
- 野战目标不触发上述旬初宣战。实际普通交战开场将关系≥40降到39，20–39减1；不额外扣信望/忠诚、不解除联盟。反击不要求外交敌对或预先指定攻击命令。
- 自动选敌要求关系<40且无联盟保护；野战接近保留明确意图/当前交战目标同势力候选例外。有限自动军事规划不主动选择受保护或中立友好目标。兵法附带范围目标和计略已有联盟保护保留，未借此扩大到未研究的附带伤害规则。
- 普通设施仅对外交敌对行军者构成通行阻挡，同势力、联盟、中立/友好及无主普通设施可穿行；工作物始终阻挡。目标接近和新对象放置保留实体占用检查。设施属性IsWork独立于驻人、兵粮和贴图语义。
- 原版导入阵型统一MovementStepCost=10：地形费用用于选路，步进扣费独立。所有通行地形的普通移动速度为ceil(机动力/2)细坐标/日。自制内容可用正值指定固定步进费用，null明确使用地形扣费；不把原版常数藏进A*。

## 实际验证

全量解决方案1341项测试通过；最终稳定排序与设施自动选敌补证后，28项外交定向测试再次通过。额外外交矩阵覆盖39/40/59/60/79/80、工作物豁免、野战反击、忠诚与信望叠加、两种联盟解散、三类命令确认、取消、序列化和恢复后事件/状态一致。实际路径测试检查可穿过普通设施与外交变化后绕行，固定步进测试覆盖普通移动及两类射程接近接口。既有A*最短路、保存和重放检查保持通过。

默认190年包原位重新导入成功：94个据点保留，17种设施定义完整，10–16七项工作物标记为true，其余false；28阵型均为步进费用10。剧本schema52、组合schema56，规则san9-core-g08-v4，存档/日志27；旧包须重转，旧规则存档和重放拒绝。

本轮没有启动游戏、没有新增原作动态实验、没有录像。交互验证是公共命令/查询和保存重放测试，不计作图形确认框画面验收。当前军事出征/改令GUI本就按后续界面阶段交付，本轮不新建整套军事窗口。

## 保留边界

攻击请求的初始状态、创建和履约/毁约生命周期尚未接入，相关保护和处罚与该外交系统一并后续处理，不以空引用伪装支持。特殊减半移动分支对象语义仍待证实。用户允许保留确定性预算和统一细坐标A*，不复制原作粗格/局部算法及其对象软代价内部实现；困难搜索进一步优化后移。
