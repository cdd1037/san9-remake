## 适用范围

适用于已建立单挑配对后的单次攻击以及同一人物连续配对时的 HP 继承。`trunc0` 表示有符号整数除法向零截断，`rnd(N)` 返回 `0..N-1`，概率判定记为 `chance(P)`。

## 原作基线

令攻守双方当前有效武力为 `MA/MD`，性格编码为 `CA/CD`，本刀前 HP 为 `HA/HD`，武力差 `delta=MA-MD`。规范分值为：

```text
T(x) = max(0, 3*max(x-90,0) + 2*min(x,90) - 160)
     + max(0, min(x,80) - 60)
     + max(1, trunc0(min(x,60)/2))
```

逐刀严格按看破、基础伤害、动画必杀、双倍必杀、普通攻击短路：

```text
P0 = min(8, 2*CD + 2 - trunc0(delta/5))
若防守者是吕布或赵云且 MD-MA >= 20，则 P0 = 40

base_cap = 33，若攻击者是吕布且 delta >= 20；否则 22
fixed = min(base_cap, max(5, trunc0((T(MA)-T(MD))/3) + 20))
base = fixed + rnd(trunc0((100-HA)/20) + 2)

P1 = min(8, trunc0(4*delta/5) + 2*(4-CA))
animation_damage = 3*base + max(trunc0((HD-HA)/2), 10)

double_cap = 24，若攻击者是马超且 delta >= 20；否则 12
P2 = min(double_cap, 3*(4-CA) - trunc0((MD-MA)/5))
```

看破成功造成 `0` 伤害；动画必杀成功造成 `animation_damage`，并把防守者伤势增加 `1+rnd(2+(delta>=0))`、上限为 `7`；双倍必杀成功造成 `2*base`；否则普通攻击造成 `base`。概率阈值没有额外的零下限。

调用方实际扣除 `min(raw_damage, defender_hp)`，HP 不得小于零。发起方每轮先攻击，守方存活才还击。胜者进入下一配对时恢复 20 HP、上限 100；新替补以 100 HP 入场。

核心随机调用顺序必须是：看破；若失败则基础随机、动画必杀；动画必杀成功时再抽伤势，否则再抽双倍必杀。原作看破后的台词选择还从同一全局流依次判定 8%、失败后 4%，因而会推进下一刀所见的随机序列。

## 重制行为

重制版关系保留上述概率、伤害、伤势、HP 截断和连战恢复关系。为满足 `DEC-SIM-0001`，玩法随机只消费显式稳定随机流；表现随机与玩法随机分流，因此无需复制原作中看破台词对后续玩法随机序列的偶然影响。这一随机流分离是既有确定性架构决策的直接结果，不改变单刀概率分布。

按2026-09-19用户确认的重制选择，概率判定先判断结果是否确定：`P <= 0`直接失败，`P >= 100`直接成功，均不消费随机；只有`0 < P < 100`时抽取概率骰。保留看破、基础伤害、动画必杀、伤势或双倍必杀的短路顺序及原有公式，基础伤害与伤势仍按各自范围抽取随机数。当前逐刀公式的概率上限均小于100。此选择不复刻原作在必然失败时推进随机流的行为，会改变同一种子下的后续序列，但不改变各项判定的概率分布或重制版的确定性。

## 状态与不变量

特殊人物优待在共享人物内容中表达为可独立组合的`DuelAdvantages`：`DominantParry`、`DominantAttack`、`DominantDoubleStrike`。版本Importer把原版列传身份转换为这些语义特性；Core不检查人物编号或姓名，独立创作人物可配置相同优待。

- 输入与前置条件：有效攻守人物、双方当前有效武力/性格/身份、双方 `1..100` HP 和显式随机状态。
- 状态变化：返回结果类别与实际伤害；动画必杀还可提高防守者伤势；HP 由调用方扣减。
- 始终成立的不变量：看破优先且短路；HP 不小于零；伤势不超过 7；同一刀只产生一种结果。
- 失败或无效输入行为：无效人物或越界 HP 属于调用方领域错误，不消费随机数。

## 示例与边界

- 满 HP 时基础随机项仍为 `rnd(2)`，即增加 0 或 1。
- 一般人物基础上限为 22、双倍概率上限为 12；满足身份与 20 点武力差条件时，吕布基础上限为 33，马超双倍概率上限为 24。
- 原始伤害超过剩余 HP 时，只记录并扣除剩余 HP。
