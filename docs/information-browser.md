# 情报界面

情报按钮及右侧名单快捷菜单打开十项入口。行为依据[BEH-UI-0004](../specs/behavior/BEH-UI-0004-information-browser.md)，设计取舍见[DEC-UI-0007](../specs/decisions/DEC-UI-0007-information-browser.md)，原作调查及IDA同步见[RE-SAN9PK-0161](../research/findings/RE-SAN9PK-0161.md)。

## 当前行为

| 入口 | 内容 |
| --- | --- |
| 全官爵 | 八项官爵的指挥、信望与就任势力 |
| 全势力 | 状态、战力、资金、兵粮、相对玩家的外交关系数值，以及君主头像详情 |
| 全军团 | 归属、都督、驻兵、武将、金库及详情 |
| 全都市 | 驻防、内政、人口与详情，关联地域/武将 |
| 全地域 | 地域所属城市、已建设施与驻防，包括没有建筑的地域 |
| 全部队 | 活动部队兵力与坐标；190年初始无活动部队，入口禁用 |
| 全武将 | 通用目录的13页列组、表头排序、15行视口、头像联动；详情与关联列表 |
| 全宝物 | 可见宝物持有人、增益和图像详情 |
| 进行记录 | 本会话成功商业/开垦的日期、执行者、增量与费用 |
| 年表 | 开局统治、军师及玩家手工笔记 |

点击列头排序；滚轮、滚动条、方向键、PageUp/PageDown、Home/End浏览。点击行或Enter打开详情；详情可切换上一项/下一项并打开关联名单。Escape、右键或关闭按钮逐层返回，保留原名单状态。地图按钮关闭情报并定位，不改变地图命令起点。年表点击输入年表后输入文字，Enter保存，Escape取消。

这批窗口呈现已实现领域状态，未接入原作全部说明文本、人物列传/兵法详情、经济预测、AI请求、人物生命周期及存档。记录和笔记随当前会话保存在内存；部队没有新增出征、移动或战斗规则。外交显示关系数值，不臆定文字等级阈值。

## 分层与数据

Core保存人物身份、人口、官爵归属、军团、宝物归属和关系值；Application的InformationQuery从同一只读快照投影，InformationBrowser保存模态导航。直属军团的Treasury为空，明确使用势力金库；子军团单独持有CorpsTreasury。领域不读取源格式或图像索引。

组合包schema10、地图schema8、初始态schema8、皮肤schema10；旧包重新导入。导入器转换官爵/官职/宝物定义、可见人物及图像，客户端只读取生成包。人物详情图像角色为information-person-{id}，目录使用原生64×80的catalog-person-{id}，宝物为information-treasure-{id}，包校验要求所有可见对象的图像与文本引用闭合。190年导出含210名可见人物（195在职、15在野）和14件宝物；隐藏人物不加入目录。

## 菜单样式专项修正

十项菜单已改用IDA配置4对应的三段四帧原图，按状态应用文字颜色、描边及按下位移；九段外框按源尺寸平铺。十二条底部提示从原版消息目录转换，包含无部队与无宝物的禁用原因，移出清除。此次构建、数据审计与引擎输入检查不代表用户视觉验收；画面由用户自行核对。

### 禁用悬停描边试验

首轮原生双层描边经用户截图比较仍有空心轮廓感，已移除。该轮仅情报菜单禁用悬停使用缓存的Godot TextLine：同一份16像素现代字形向八邻域各偏移1逻辑像素，以f0f0f0、Alpha 0.25绘制，然后在原位绘制黑色正文。该轮其余状态沿用现有Label；现已统一为GameTextPresenter的Label叠加阴影实现，见DEC-UI-0002。此为现代字形上的合成试验，不宣称等价于原版调色板覆盖度或已通过视觉验收。编译通过；按用户要求未启动游戏、未做运行检查，画面由用户验收。

## 通用表格候选版（2026-09-06）

以武将一览接入CatalogView，页面和列由OfficerCatalog声明；其他目录尚未迁移。能力页恢复九列，13个页签按7+6排列；恢复独立表头、行高亮、页签、排序标记、头像框、表格边框与滚动条资源。行身份、排序、滚动与详情导航分别管理。本人习得、宝物/势力提供三态显示与九类熟练度使用转换后的运行时数据。

尚未实现的命令调度、大将/布阵及擢升等字段显示“—”；爵位缺失时指挥与俸禄未模拟原作派生规则，显示“—”。帮助按钮使用重制操作说明。姓名使用现代中文排序；未宣称与原作编码排序一致。

已在原输出目录增量导出，复用未变化地图。自动测试与离线原图/数据审计结果记录于本次交付；没有启动Godot、执行引擎输入自检或截图。用户自行检查实际布局、字体和交互。
