## 适用范围

本规格定义大地图静态视觉快照的已确认行为，用于研究导出、视觉回归和正式渲染实现前的资源/坐标基线。它不把实验脚本的模块结构规定为产品架构，也不声称静态快照等同于完整运行时画面。

当前快照包含地貌、八方向地貌过渡、桥、静态建筑和显式启用的 MESH 诊断层。水面动画、旗帜、士兵、疆界、部队、云层及其他运行时对象不在本规格的输出范围内；正式产品若省略或改写这些图层，须另立行为规格或决策记录。

## 原作基线

### 输入模型

渲染输入由两个部分组成：

- 场景快照：40,000 个方格、17 个固定建筑定义、有效城市和据点快照；
- 已验证视觉资源：地貌、遮罩、桥、MESH、建筑及其调色板。

桥使用 `G_LHashi 10004/10005` 与 `P_LndAdd[0]`；建筑资源 ID 按注册分段选择 `G_LBUILD/P_LBUILD` 或 `G_LBAdd/P_BAdd`。

### 坐标与画布

对逻辑方格 `(x,y)`：

```text
center_x = 32 * (x + 200 - y)
center_y = 16 * (x + y + 1)
anchor   = center + (-32, -16)
```

局部导出只改变目标画布原点。地貌纹理取样始终使用全地图中心坐标，不能随裁剪窗口改变相位。桥从锚点出发再左移 64 像素；建筑从中心出发并应用 `-10 * (squa[+0x08] - 1)` 高度修正，随后叠加组合记录偏移。

### 图层行为

#### 地貌

每个目标方格先生成八方向边缘记录，再生成当前格记录，并按原作链表插入规则的结果排序。同键记录不能改用普通稳定排序。

当前格按 `G_MASK` 每行首尾非零点复制连续源图横段；横向循环只作用于扫描线源起点。边缘格只处理非零遮罩像素，并按以下 256 权重公式与目标混合：

```text
result = (source * (256 - mask_red) + target * mask_red) >> 8
```

#### 桥

方格仅在 `terrain == 11` 且 `square_flags_02 bit9` 置位时绘制桥。`bridge_orientation_code` 的 `0/1` 分别选择资源 `10004/10005`。

#### 建筑

固定建筑代码、耐久阶段和城市外观选择建筑组合。城市组合中带 `resource_offset_flag` 的记录按 `max(current_income, current_harvest)` 选择 `+0/+1/+2` 资源帧。组合记录按表顺序绘制，不按 `z_offset` 重新排序。

带动态标志的建筑记录由运行时选择动画状态，并走 `BitBltKBMPPaletteAlpha` 的逐索引 Alpha 路径。

#### MESH

MESH 仅在调用者显式提供状态 `0..5` 时绘制。裸 `squa` 的高差字段不能自行触发覆盖层；`elevated-only` 只是诊断过滤器。

## 重制行为

重制版保留上述资源选择、坐标关系、地貌排序、遮罩权重和建筑组合关系。资源装载先验证记录数和调色板数。静态研究导出器冻结建筑动画帧但保留逐索引 Alpha，并省略范围外图层；这只是验证边界，不是正式产品对动画或图层的删减决定。

### 颜色精度

输出按 [DEC-RENDER-0001](../decisions/DEC-RENDER-0001-high-color-map-rendering.md) 使用 RGB888，不执行原作 RGB555 写回量化。地貌边缘仍保留 256 权重公式，建筑调色板 Alpha 仍保留 128 分母公式；提高目标颜色精度不授权改变混合语义。

## 状态与不变量

- 输入与前置条件：已通过对应 `BEH-IMPORT-*` 校验的场景快照，以及记录数和调色板数均合法的视觉资源集合。
- 状态变化：渲染产生 RGB888 画布，不修改场景或资源数据。
- 始终成立的不变量：绘制阶段不读取文件；地貌、桥和建筑由领域值选择；局部与全图的纹理相位一致；建筑保持组合表顺序；`D_Sce002.S9` 全图的地貌与建筑 fallback 为 0。
- 失败或无效输入行为：区域越界、资源计数错误、调色板缺失或建筑高度代码无效时拒绝导出。

## 示例与边界

- 全图边界：`x=0,y=0,width=200,height=200`，输出 `13056×6656`。
- 局部边界：目标裁剪改变画布位置，但同一逻辑方格的源纹理相位不变。
- 桥反例：bit9 置位但 `terrain != 11` 时不绘制桥。
- MESH 反例：仅有非零高差字段但未提供状态时不绘制 MESH。
