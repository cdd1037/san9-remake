# BEH-ECONOMY-0001：经营命令与周期经济

- 状态：已确认
- 最后更新：2026-09-12
- 关联决策：[DEC-PROJECT-0002](../decisions/DEC-PROJECT-0002-selective-inheritance.md)
- 范围：G03普通剧本经营、兵员与账户闭环；不包含买卖、战争补给和人事命令。
- 证据：[RE-0095](../../research/findings/RE-SAN9PK-0095.md)、[RE-0096](../../research/findings/RE-SAN9PK-0096.md)、[RE-0098](../../research/findings/RE-SAN9PK-0098.md)。基础内政计算沿用[BEH-DOMESTIC-0001](BEH-DOMESTIC-0001-base-development-effect.md)。

## 状态与不变量

据点所属军团有独立金库时使用该账户，否则使用所属势力账户。军团引用必须存在且归属一致；据点没有资源副本。所有收支经过同一账户服务，事件包含账户、资源、原因、关联对象、请求变化、实际变化、短缺与饱和损失。普通存档只保存当前状态，事件仍由显式录像持有。

四项内政、征兵和训练即时提交。参与者为1至5个不同身份的当前同势力驻留在职人物，均未行动且无持续任务占用；城市限定巡查、商业、开垦、征兵，修筑与训练允许设施。每个项目每旬一次，旬恢复清除全部使用状态；拒绝不改变任何状态、序号、事件或随机。所有计算读取提交时当前能力、资金和容量，外部不提供费用、效果或能力。

## 重制行为

四项内政每人费用50；巡查上限1000，其余使用据点定义上限。多人组合由转换器输出运行时人物身份有序对、资格要求；领域不识别列传码。**重制选择**：参与者按对应当前能力降序、同能力按人物ID升序（2026-09-19统一人物顺序选择），君主独立优先；身份仅用于破平，不参与能力分数，取消原作打包排序键隐含的编号范围及君主200能力分界。按此顺序枚举参与者有序对，匹配后先掷10%，再检查身份资格与至少一人距君主相性不超过5；未成功再按`5*(最大同相性人数+1)`掷骰。单人或基础效果已满不消费组合随机。相性环长150。修筑给类别5、6各基础熟练度1；训练给0至4各1，精通乘3，饱和1000。

征兵以当前统率和S、人数n计算`Q=3*(100*S/(n+4))/2`，按兵役人口、`10*账户资金`和兵力剩余容量共同夹取D。D为0拒绝，费用`(D+9)/10`，兵役减少D、现役增加D。士气按原兵力和新兵基准`floor(sqrt(信望))+40`加权。**重制选择**：消除原作创建与提交间少付款、满编损失兵役的竞争窗口，兵员严格守恒。

训练使用执行统率`max(1,2*(min(A,60)/3))+max(0,min(A,80)-60)+max(0,2*A-160)`。令S为执行统率和，G为新兵基准士气，R为`floor(sqrt(士兵+10000))`，K为`10*(11-n)*(G-当前士气+100)/100`，基础增量`min(100-当前士气,n+(S*K/R)/10)`；随后按训练组合规则加倍并饱和100。无兵或士气满拒绝，不扣钱粮、不增加兵数。

## 周期与边界

新局选择特殊势力时，创建世界必须清除所选势力的`IsBarbarian`，随后按普通势力规则计算收入与收获；未选势力保留内容定义的身份。该归一化只发生在新局创建，不修改内容包，不在读档、委任或经济结算时重新推导。依据为[RE-0021的开局选择链](../../research/findings/RE-SAN9PK-0021.md#2026-09-12新局选择异民族势力的标记清除)。验收须覆盖双方选择对照、普通收入和特殊补给、跨七月及保存重放。

每旬前置更新支付在职非君主俸禄，按俸禄降序、身份升序；官职目录提供金额，无官职为1。按驻留据点解析账户。足额支付，否则保留资金并报告整笔短缺。恢复原作双向忠诚关系：欠薪以`5*(16-义理)`百分比减1；足额支付以`(信望/10-人物与君主相性距离+50)/20`百分比加1，整数逐步截断，相性距离封顶50，缺少君主取50。每名符合俸禄资格者固定消费一次命名运行流`personnel-salary-loyalty`，概率为0、忠诚已到0/255仍抽样；只在实际变化时发布忠诚事件。忠诚饱和0至255，不形成隐含债务。本项替代此前欠薪必减1、支付不增加的未经平衡验证选择；依据见RE-0098本次补证。

每日命令前扣粮，驻兵每据点`ceil((现役+伤兵)/500)`、野战兵每部队`floor(3*(现役+伤兵+333)/1000)`，按实际归属账户汇总扣除。排除的设施由规范化规则字段明确标识。钱粮下限0、自然收入上限100万。**2026-09-13按原作对齐**：启用军事规则的会话，对需求大于0的账户，扣粮后余额为0（含恰好耗尽）即进入断粮分支。合格野战单位或耗粮守军士气减3、现役损失向上取整1%，并按有效阵型／守军比例转伤兵；溃败部队有粮也进入同一分支，两者不重复。地利及异民族不豁免。账户统一承担，不能因单位遍历顺序抢粮；零兵／零士气部队复用无胜者终止与人员安置，驻军不凭缺粮直接换属。此规则替代旧`ceil(10*缺粮/需求)`强度选择；证据和恢复规则见[WAR-0004](BEH-WAR-0004-normal-combat.md#周期士气与地利)。

季度首日且距剧本起始至少30天，先更新人口，再发资金；七月同条件另发收获。整数运算逐步截断并使用宽中间量。总非兵役人口a、城市民心总和b、军事人口c（兵役、驻兵及野战兵）：新增兵役总量`f=(max(0,a-c+99999)/100000)*(a/100)/10`；每城按民心比例分配。民心总和为0时分配0，非兵役增量仅保留最低人口恢复；其他城市非兵役增量`max(30000-人口,民心*(a/20)/b-人口/20)`。人口上限100万，兵役自然增长上限50万。2026-09-13重制选择：兵员回收允许兵役人口超过50万，存档完整保留；自然增长在超限时为0，不削减既有存量。兵役自然新增不从非兵役扣除，与原作两个独立人口池一致。

普通势力每城令R为`floor(sqrt(人口+兵役))`：季度收入为`((R+600)*商业*6/1000)*(2500-商业)/2500`；年收获为`((R+300)*开垦/10)*(4000-开垦)/4000`。超出公式适用范围的内容拒绝加载。异族身份读取当前势力`IsBarbarian`，不判断势力或城市编号；恢复原作特殊经济：有城市的账户季度资金设为30000，七月粮食设为`min(1000000,max(100000,所属整个势力的驻兵与野战兵总数))`。这是赋值，不是每城叠加，也不与普通收入同时发放；同账户只结算一次，超过目标的库存亦下降并以独立原因报告实际变化。仍遵守季度/七月和开局至少30日门，独立军团使用自己的账户。G07已将伤兵并入日粮耗、异族年度补给和兵役人口核算。本项替代此前统一普通经济的未经平衡验证选择；依据见RE-0098本次补证。

巡查后按基础信望、城市贡献、玉玺及拥立贡献重新计算信望并饱和1000；每城贡献`((人口+兵役)*max(0,民心-300)/1000)/5000`。基础信望与相关规则身份必须由内容保留，不能从当前信望倒推。周期人口更新后同样重算。新局前置只执行一次，恢复不重复支付或增长。

## 验收标准

- [x] 重复身份、跨城、敌属、占用、资金不足、满值均拒绝且零副作用；五人、精通、组合概率和恢复后的随机连续性有独立预期。
- [x] 独立军团与势力账户不串账；征兵容量和费用守恒；训练不增兵；资源事件能够解释实际变化、短缺与饱和。
- [x] 开局、普通旬、季度、七月、跨年、29/30天门分别验证；原作竞争窗口和本规格重制选择明确区分。
- [x] 俸禄双向概率及忠诚0/100/255、异族赋值与多城账户、固定驻军十年补给，以及超大ID和高能力下的组合排序有独立边界验证。
- [x] 公开场景与190年内容经正式命令经营一年，确定性简单策略实际经营补员；连续、磁盘恢复、日志及录像重放结果一致。

## 未决问题

俸禄忠诚与异族周期补给恢复上述原作关系；内政排序采用显式语义。完整战略AI与额外地理补给线尚未实现，不将零粮可运行作为经济可持续验收。

特殊对白延后至经营UI接入时设计，不纳入G03退出条件。届时区分特定组合对白、相性加倍回复和独立辅助提示；巡察「我们的英雄」为相性加倍成功后的三选一回复，时机证据见[RE-0095](../../research/findings/RE-SAN9PK-0095.md#2026-09-12巡察我们的英雄回复时机)。当前事件仅保留最终增量，尚未保留加倍类型、触发人物与对白绑定；UI接入时补齐结果数据，不重新执行玩法概率判定。

输送载荷沿既有承运规则保存，只有实际抵达指定己方据点才能卸入目标账户；载荷不算作出发势力已可用粮食，也不自动供给沿途部队。每日命令前先耗粮，日地图阶段再卸货，故补给到达只阻止后续日的缺粮损失，不追溯恢复当天士气。目的地失效沿既有返城/待命规则保留载荷，不向新所有者卸货。当前补给覆盖由势力/军团账户决定；不将未实现的地理封锁、补给线截断或围城断粮作为既有行为。
