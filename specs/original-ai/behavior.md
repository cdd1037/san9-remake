# 原版 AI 决策基线行为规格

状态：已确认；2026-10-16采用。本文规定目标行为，不表示新基线已经实现或通过验收。

## 采用范围与依据

本次建立以繁中PK 1.0.1为依据的完整规则型AI基线，保留策略骨架及人物特色，并按B01～B30修正已确认异常。原作事实及证据等级统一见[权威研究](../../research/ai.md)，人物配置见[人物特判](character-rules.md)，可执行验收见[验收标准](acceptance.md)。

下表确定各主题继承的基线；B条目是明确覆盖项。未列出的已闭合规则按对应研究的候选、排序、公式、阈值、投入及受限随机语义保留；研究中的推断、设计动机和待验证内容不自动成为要求。新差异必须补充采用理由与验收，不能以“更聪明”为由自行改写策略。

## 调度与战略

<a id="b01"></a>
### B01：工作顺序

军团轮转后依次执行战略准备、人员配额及有序工作批次；保留各控制类别、异民族和模式的工作顺序。前项完成后再推进后项，读取已经生效的变化，日期与行程按公共阶段结算。主军团、直接军团和根势力的查询范围分别保留；策略门不转为玩家命令禁令。

<a id="b02"></a>
### B02：模式生成与更新

内部模式、策略分组与外部委任方针分别建模；保留方针对模式的影响、目标失效判断、准备指标和更新概率。正常自动生成原作已确认的六种模式（研究中0／1／2／3／5／6）；区域模式不额外编造生产规则，不为原版旧存档保留兼容入口。目标以势力／建筑等类型化引用表达，失效时原子清理或回退。

<a id="b03"></a>
### B03：战略目标从实际排序表选取

原作对一张合格对手表排序、却从另一张统计表取目标。重制保留候选资格、原排序依据和后续关系分流，从实际排序后的合格对手表首项读取。目的为使既定优先级实际生效，不另加全局强弱搜索。

<a id="b04"></a>
### B04：保留准备指标

经营及军事准备指标保留原聚合对象、整数运算、固定分母与严格阈值，包括累计民心／士气按固定分母计算。它们未被证明是错误，不改为平均指标或重新平衡。正常数值使用宽整数安全运算，不复现溢出。

<a id="b05"></a>
<a id="已采用差异外交排名不随策略分组清零"></a>
### B05：外交排名独立保存

有效势力在既定全局策略准备的日期门通过时，按原排序依据重算排名并完整发布；分组更新只改分组，不清排名。日期门未过时使用最近一次完成的排名，首次消费前必须初始化；失效势力不因残值进入候选。排名快照不能作为普通查询缓存按当前信望随时重建，否则会改变两次准备之间的外交选择；保存恢复须保留该快照。保留赠与要求目标排名值较大、劝降要求较小的严格方向；以可扩展的完整排序表达，不继承低七位或50槽限制。本项修正使排名实际服务外交选择，不要求解释原作正常旧档的非零留存路径。

<a id="b06"></a>
### B06：策略分组与历史偏好

保留分组对尝试数、攻击及计略的影响；历史人物、家族、起兵、继任和国号偏好按[人物特判](character-rules.md)配置。规则消费语义属性与引用，不以姓名、源编号、列传资源码或槽位分支。独立内容和Mod可配置同类规则。

<a id="b07"></a>
### B07：难度差异

保留高级缩短开局等待、调整部分尝试次数以及更早纳入新建部队的候选门；候选资格不保证出兵。开局资源补偿、加兵和伤害倍率属于独立场景／规则配置，本次不自动启用。

<a id="b08"></a>
### B08：稳定周期错峰

开局等待、日历周期窗口和尝试预算分别计算，不采用上次行动后的统一冷却。周期保留原窗口宽度和相位公式中的稳定身份错峰关系；内容中的持久调度标识在创建时确定并进入保存，恢复或列表重排不改变相位，不依赖固定身份范围。

## 人员、轮转与预算

<a id="b09"></a>
### B09：人员配额的对象与数值域

分子总人数采用当前直接军团的在职人员，含君主、都督、军师、普通在职及外出任务人员；俘虏、在野、未登场和死亡人物不计入。实际调动另查驻留与可行动资格，不能把闲置人数作为总人数。保留原兵力／兵役／伤兵权重、驻军统计和建筑最低配额，但使用宽整数及完整数值，不继承低八位截断和32位溢出。配额是各建筑需求，不强制总和等于人数；真实人员迁移守恒。建筑兵力保留及量化仍按采用的原策略参数计算。

<a id="b10"></a>
### B10：配额失效与重算

批前计算配额；新设／解散军团、建筑归属变化后，标记并重算受影响军团，后续工作使用新辖区的配额。其他工作间不无条件全量重算；缓存必须声明输入依赖，缓存温度不改变结果。这明确修正原作组织变化后仍沿用旧配额的时点。

<a id="b11"></a>
### B11：调动只消费实际处理项

保留余缺配对、人物排序、单次人数上限和空城单人补缺；目的地每次只消费当前处理项，来源用尽时按引用移除实际选中来源。禁止误弹下一目的地或原始来源表头；失败候选是否继续仍按B13的工作生命周期处理。

<a id="b12"></a>
### B12：同旬军团列表变化

新军团追加到当前轮转末尾，通过控制资格时同旬获得行动机会，并执行自己的批前准备；解散军团按引用移出待轮转表。不重排全表、不从初始快照复活已解散对象。已有游标的恢复不重复全局准备或已经完成的工作。

<a id="b13"></a>
### B13：有界失败消费

保留各工作的尝试预算、候选消费与终止位置；准备失败、生成空命令、公共拒绝和成功分别表达。失败可以消费尝试或候选，不统一改为跳过当前城市继续，也不自动重建失败来源反复尝试。B11／B19明确修正的错误消费优先。策略尝试数与异常规模保护分开，保护触发报告未完成，不能伪装为无候选。

<a id="b14"></a>
### B14：资源预算按提交反馈结算

预测与规划仅作临时预留；无法形成合法命令、提交拒绝或事务回滚时释放对应资源预留，成功提交并承担资源占用后才保留扣账。覆盖赠与、输送和部署等私有预算，避免失败虚耗可用资源；尝试／候选仍可按B13消费。任务间重新读取当前账户与占用，公共规则已承担的出使费用及后续外交失败成本不因此退款。

## 预测与外交

<a id="b15"></a>
### B15：赠与使用同一正式载荷

先按本方资源及原保留公式确定钱粮载荷，同一候选计划的军师预测、使者排序与提交均使用该载荷；不采用静态小额、目标自身资源或零载荷替代。保留钱粮二选一、数量限制及目标外层优先。若世界变化使载荷失效，重新形成并完整评估新计划，不沿用旧预测。

<a id="b16"></a>
### B16：以实际使者复验攻击请求

目标组合保留原优先级，使者保留原距离偏好与稳定并列顺序；最终选择的使者必须对当前目标组合通过采用的可行性判断。失败时按既定使者顺序尝试剩余人，再按工作规则继续其他目标；有界消费，不使用高政治人物的预测替另一人担保。只有最终可提交配对才消费受请求势力、目标与使者。

<a id="b17"></a>
### B17：配对分数不因超过100被拒绝

赠与、劝降保留最低可行分数33，取消100上限。其他工作保留已确认下限，军师意见映射仍按各工作规则；实际排序阈值不先夹到100，公共结算继续按已采用概率规则处理。本项修正高阈值反而失去可行性的异常，不把预测分数当作最终成功保证。

<a id="b18"></a>
### B18：目标外层与稳定配对

先按工作目标顺序找首个可行目标，再在该目标下选执行者，保持各工作不同的预排序、可行性回调、排序键及逐候选调用次序；单候选仍执行必要预测与评分。普通列表、交集及有意重复的计划项不统一转成去重集合；同分保留已定义输入顺序，来源枚举与保存恢复必须稳定。

## 军事与公共响应

<a id="b19"></a>
<a id="已采用差异攻击请求续行与最终出征兵力"></a>
### B19：请求履约续行与来源消费

同一攻击请求最多处理两个不同来源，各消费一次；首队提交后，请求／目标仍有效、需求未满足且预算有余时继续第二来源。按前项实际执行后的世界复验人物、留兵、容量、路线和公共资格，单项失败跳过、整体失效结束。修正第二来源随任务结束丢弃的问题，不保证必定派两队。普通攻击可从同建筑形成多个部署额度，每队重新核对资源与人物，不把有意重复来源误判为重复命令。

<a id="b20"></a>
### B20：最终出征兵力下限

普通自动攻击与攻击请求履约在选将、主将容量、任务额度及来源留兵限制之后，实际计划兵量必须达到城市10000、其他来源5000；不足不出征，按生命周期继续。不能超容量、动用保留驻兵或凭空补兵。该策略门不改变玩家公共资格，也不覆盖其他部署、输送或单人后备的独立门槛。

<a id="b21"></a>
### B21：预测不改对方命令

部署准备中的敌方目标分析保存在规划器私有上下文，不修改真实对方单位。路线障碍确需转换目标时，由玩家、电脑共用的命令／导航规则在公共阶段执行；新AI规划期间不提前代执行。预测与正式状态分别持有，失效时重建所需投影，不并发共享原作式全局临时命令上下文。

<a id="b22"></a>
### B22：部署使用战斗出发等待一次

军事目标评分采用Q＝路线预计时间＋目标剩余战斗出发等待。需要协调等待的分支生成新队等待`max(0,Q−10)`，其他主路径沿用目标剩余战斗出发等待，单人后备为0；协调分支仍按原作组0候选表是否非空判断。人员出使行程倒计时不作为军事输入，目标等待不因缓存重复相加。此为明确修正，预测的时间口径与字段所有权必须分开。

<a id="b23"></a>
### B23：旬级撤回使用统一兵力口径

保留三组候选、普通军团选择优先级及两套独立预算；异民族仍走独立候选规则。中间组初始累计量改为当前驻兵加已确定返回该建筑、尚未抵达且通过对应资格的部队兵力，后一项及后续计入均用“现役兵＋向下取整的半数伤兵”，替代把部队数量与兵数相加。已经抵达并并入驻军的兵力只计入当前驻兵，不再作为返回部队重复累加。第一组仍使用独立初始量和压力集合半数门；第三组不消耗这两预算。每个本工作已提交回撤的部队只处理一次，允许原有组条件重叠而不重复提交。

<a id="b24"></a>
### B24：路线、机动力与费用有效性

区分合法零长度路线和求路失败，失败不作为ETA0通过；仅在共享路径规则认定无需移动时使用合法零长度结果。没有有效移动能力的计划不进入需行军分支，不发生除零。所有最终阵形／船型必须可用、可负担，特殊和后备分支也通过费用门；本分支无合法选项时按已有后备／候选顺序继续，不凭空扩展阵形池。费用与公共命令保持一致，拒绝时按B14释放预留。

<a id="b25"></a>
### B25：保留不同工作的策略特色

不同军事工作保留各自的选人、相性补员、兵量、兵法、阵形及随机算法；不统一为最高能力或最高熟练度。保留低耐久更容易进入部分攻城选阵分支、褒美并非忠诚最低优先等已确认偏好；人物能力保护依当前能力，不增加名将白名单。

<a id="b26"></a>
<a id="已采用行为每日追击与撤退"></a>
### B26：共同的部队自主响应

玩家、电脑共享敌接近、撤退、追击及目标失效后的规则；敌接近保留旬级活动扫描，撤退／追击按每日阶段先撤退后追击，后者读取已提交状态。保留性格、许可、士气／兵力严格阈值、优先级及近邻口径，不增加随机或冷却，关闭许可仍可按性格产生擅自行动。继续／擅自追击、中止追击及返回分别表达；返回转换必须具备可转换动作及有效返回对象，失败完整保留原状态且不发成功消息，次日条件仍满足则重试。

<a id="b27"></a>
### B27：自动部队方针配置

按“接近攻击／自主撤退／追击／事后攻击”顺序，普通主路径为关／开／关／开，异民族主路径为开／关／开／开，既定单人后备为关／开／关／关。分别配置，不把主路径扩展到所有出征。方针由B26的共同响应消费，不是绝对禁令。

## 权限、范围与交付

<a id="b28"></a>
### B28：获准信息与公共命令

仅使用当前获准情报和公共预测；缺少精确信息时，不进入依赖该信息才能成立的分支，沿该工作的既有后备或下一候选继续，不读隐藏真相、不凭空补估值。AI只提出语义意图，通过公共命令验证、支付与结算。已有公共费用、资源守恒、资格修复及整编禁用继续有效；外层失败不得残留世界、策略记忆、随机或命令水位的部分修改。

<a id="b29"></a>
### B29：完整主线与明确排除

覆盖经营、人事、军事、建设、输送、八计略、四外交、公共响应及支持的电脑待决选择，普通电脑、玩家委任与异民族分别验收。39项源工厂及表外准备逐项有去向；标准调度不使用的独立工作10／60不接入生产，普通攻击内的建设与无主目标出征仍实现。玩家专属事件不编造电脑回答；教学／挑战及小兵培养继续在主线外，不为工厂库存建设无消费者框架。

<a id="b30"></a>
### B30：确定性与唯一生产入口

使用独立规划随机，保持采用分支的抽样范围、短路及顺序；诊断、缓存和机器速度不影响结果。所有身份与集合可扩展，状态所有权按Core领域规则、Application控制／策略和Content契约划分；地址、位域及源编号范围留Importer与研究。保存策略版本、实际参数和必要持久状态，协议切换同步摘要、日志与录像并明确拒绝旧版；最终旧自主增强原型退出本范围，不保留长期双调度或兼容回退。以真实经营、出兵、战斗／占领、回撤、恢复／重放和长期对局验收，不以强过老玩家作为前置。
