# DEC-SCOPE-0001：最小可玩版本的剧本范围

- 状态：已确认
- 日期：2026-08-16
- 决策者：项目所有者
- 关联行为：`BEH-IMPORT-0001`
- 替代或被替代：无

## 背景

原版数据目录中除正式剧本外，还包含教学剧本和挑战剧本。正式剧本是当前重制版核心地图、规则和内容转换的基线；教学与挑战内容有独立的流程、目标和体验要求，不应在最小可玩版本中隐式扩大交付范围。

## 决策

- 2026-09-06用户确认：特殊人物的新局增兵暂不考虑，不加入当前初始化或导入流程。后续考虑统一人物规则、不再区分特殊人物；这是后续设计方向，尚未确定统一后的增兵规则。原作700–799编号门仅保留为研究事实，见[RE-0061](../../research/findings/RE-SAN9PK-0061.md)；当前初始显示遵循[BEH-UI-0001](../behavior/BEH-UI-0001-initial-strategy-screen.md)。

- `D_Sce001.S9`–`D_Sce020.S9` 作为正式剧本数据范围，继续用于最小可玩版本的格式研究和内容转换。
- `D_Ttrl00.S9`–`D_Ttrl05.S9` 为教学剧本。
- `D_Trst01.S9`–`D_Trst28.S9` 为挑战剧本。
- 教学剧本和挑战剧本不属于最小可玩版本的实现范围、验收条件或回归样本。
- 研究区可以继续记录这两类文件的容器和字段证据；实现它们需要单独的范围决策、行为规格和验收标准。

## 备选方案

- 将教学、挑战和正式剧本同时纳入首个可玩版本：范围不可控，且会把独立流程需求混入核心闭环。
- 暂时删除或忽略两类文件：会丢失后续扩展所需的格式研究线索，因此保留研究登记但不进入产品实现。

## 影响

- 玩家可见影响：最小可玩版本不承诺教学流程或挑战剧本。
- 数据/存档影响：核心内容包只需覆盖正式剧本范围；未来接入两类剧本时另行定义内容包版本和迁移边界。
- 测试影响：最小可玩版本的导入、模拟和回归测试不要求通过 `D_Ttrl*` 或 `D_Trst*` 样本。
- 风险与代价：后续接入时需要补充专属流程和规则规格。
- 回退方式：按独立扩展重新建立范围决策，不修改正式剧本的核心接口。
