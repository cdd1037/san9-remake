# 地图编辑器

标题菜单点击“地图编辑”，或在仓库根目录运行。

```powershell
godot --path src/San9.Client.Godot -- --map-editor
```

`--content-root` 指定转换内容目录。打开时按目录的 `sharedMap` 引用读取地图、地理、设施位置和共享规则，不读取剧本入口或初始状态。预览以完整外观展示共享设施，未建地点用标记显示。

## 操作

| 工具 | 可编辑内容 |
| --- | --- |
| 地貌 | 默认换地形并保留坡形；精确涂刷可分别指定地形、高度、地表样式 |
| 地域 | 地域范围、名称显示资格、关联都市 |
| 通行与影响 | 特殊需求下手工设置部队阻断、都市影响传播阻断，支持重新生成全图 |
| 建设地表 | 普通设施、横向设施及纵向设施的地表资格 |
| 桥 | 清除或放置方向 0／1 的桥锚点 |
| 据点布局 | 选择共享地点，拖动或输入格坐标移动 |

编辑器使用整个窗口，支持宽屏和窗口缩放。左侧直接选择工具，数字键 1–6 可切换工具。精确涂刷时，字段旁的勾选决定本笔的内容。地域、关联都市和据点使用共用选择弹窗，支持按名称或ID搜索；地域可选“无地域”清空。

左键拖动涂刷，笔刷半径以格为单位。拾取与网格按基础格的四角高差表面定位，高亮覆盖实际笔刷范围。Ctrl 加左键吸取当前格。右键、中键或按住空格加左键拖动平移，滚轮以鼠标为中心缩放。地图上方提供季节、图层、缩放比例、100% 和全图取景，F 键查看全图。左下角显示当前悬停格的基础数据。

一次拖动是一笔，Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做，最多保留 50 次。精确涂刷的组合受所选资源主题支持范围约束，无效组合整笔撤回并提示原因。地形选项以常驻按钮列表展示，单击选择，按钮提示及悬停信息显示名称及编号，名称读取文本目录的 `terrain.<id>` 词条。桥锚点、地表地貌与领域通行分别编辑。

「换地形」按目标格原高度逐格替换。目标地形相同时保留该格全部属性；切换地形时选用笔刷默认地表样式，高度超出该地形的制作范围时取最近的可用层，同距取较低层。原版水面和桥岸取高度 1。Ctrl+左键在地貌工具里吸取后进入「精确涂刷」，下一笔复制地形、高度和样式，可取消勾选任一字段。

原版素材主题依据[原图使用统计](development/original-terrain-styles.md)优先展示常用地形和选项。精确涂刷中，森、岩、土列出高度 1–7，草类突出高度 1，水面突出样式 0、3。打开「更多选项」可查看全部素材选项；当前吸取的罕见值即使收起更多选项也会显示。其他主题按自己的素材列出选项。**待定**：按原图频率自动分配变体。频数尚不能说明相邻样式的空间分布，当前笔刷使用确定的默认样式。

涂刷改变地形类型时，自动按默认规则填充改变格的影响阻断，并更新这些格及周围八格的部队阻断。水畔按当前剧本中标为港口的设施位置统一判断；任一港口覆盖就开放影响传播，最后一个覆盖港口移开后恢复默认阻断。这些更新与地形笔画或据点移动一起撤销、重做。“通行与影响”用于特殊需求下手工设置两个字段。“按规则重新生成全图”覆盖整张地图的两个阻断值，支持撤销。

默认规则由地图的 `BlockingDefaults` 声明地形资格与港口开放半径。原版地图默认将岩、浅濑、水畔设为影响阻断，港口中心两格范围内的水畔开放影响传播。部队阻断由当前格及周围八格的影响阻断推导，邻域超出地图也阻断。局部更新读取周边现有的影响阻断值，保留影响范围外的手工设置。地形类型变化时重新生成该格默认值，高度、变体和手工阻断编辑沿用作者设置。原版导入保留源阻断值，包括45格地形例外。地图编辑预览和新局均使用当前布局。港口类型可在「游戏资料编辑器 → 基础规则 → 设施类型」勾选；开放半径由地图统一指定。手工指定的影响阻断和部队阻断各自优先，其他地形的已存例外沿用地图输入。

从据点所在格拖动可移动据点，青绿色轮廓显示目标格，松开后应用。也可在左侧输入 X、Y 并点击“应用位置”。移动据点时，其初始状态、军事地点与显示锚点共同更新，目标格归入该据点地域。目标占地须在地图内并避开其他地点。调整地域范围时，应保留据点锚点所属地域，保存会检查该约束。

## 保存

点击「保存共享地图」或按 Ctrl+S。修改用于所有引用同一地图的新局。共享范围由资源引用决定：

| 编辑内容 | 保存位置与生效范围 |
| --- | --- |
| 地形、高度、地表样式、桥、建设资格、格所属地域及名称显示、基础阻断 | 当前地图定义旁的 `*.player.json`。所有引用同一地图的新局共用。 |
| 地域关联都市 | 所引用地理文件旁的 `*.player.json`。所有引用同一地理的新局共用。 |
| 移动据点 | 共享地点目录旁的 `places.player.json`。目标格地域变化随地图保存，既有剧本的已建／未建状态和驻兵保留。 |

共享修改在发布前检查引用它的剧本；校验失败会指出剧本并保留草稿。共享输入在一次事务中发布。旧内容目录通过 `import-content --rebuild worlds` 补建共享地点表；已有玩家剧本的开局状态继续使用，坐标以共享地点为准。基础转换文件保持原样，缓存与输入不匹配时由加载器重建。

新局使用保存后的地图。开局选城页仍使用原版示意图，实际开局后显示编辑后的地图和据点位置。地图预览提供静态水面；当前完整画面的检查按用户验收执行。工具栏的“建设”开关控制建设资格显示。左侧“建设地表”面板按“展示类型”和“涂刷资格”分组，展示类型可切换普通、横向、纵向，采用游戏内目标展示的压暗方式保留对应资格区域的亮度。选择建设工具时自动开启上次所选类型，初始为普通，涂刷、撤销和重做后的展示跟随当前已呈现的草稿版本。

## 内容格式

正式地图定义为版本 3，保存基础格与默认阻断规则；资源包版本 10 将地貌取样展开为资源主题表。高差、过渡、绘制记录、疆界和地图外缘由公共构建生成。领域地理缓存记录基础格、规则、地域关联、地点与算法版本的输入哈希，依赖变化时正常加载自动重建。转换旧地图内容时使用当前转换器准备资源与剧本目录，命令见[内容管线](client-content.md#转换与运行)。行为与验收见[地图编辑规格](../specs/behavior/BEH-EDITOR-0003-map-editor.md)。
