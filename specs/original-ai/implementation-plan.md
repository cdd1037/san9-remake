## 当前目标与复刻口径

先得到一套有原作证据、覆盖完整控制周期、可独立运行及对照的规则型 AI。保留原版的决策先后、状态转换、候选过滤、排序、阈值、投入数量和受限随机，形成稳定可玩的参考基线；之后再决定恢复何种增强。复刻完成不要求击败老玩家，也不以比当前原型多出征或更快统一作为通过条件。

范围涵盖全局策略准备、军团控制轮转、战略模式与目标、工作批次及尝试门、经营与买卖、人事与配置、计略与外交、军事与建设、输送和撤退、每日部队公共响应，以及所有支持的待决选择。普通电脑、玩家委任、异民族和支持场景分别记录覆盖；项目已明确排除的教学／挑战及小兵培养不因原版存在入口而回归主线。

复刻对象是决策语义。现代集合、类型化引用、公共命令、权限和事务继续保留；源槽位、内存布局、虚表、对象编号上限不进入产品。规则中的最多五人或单次调动十人若确属策略选择，可以作为命名策略参数；不能因此限制人物身份或世界总量。

**当前采用边界：**恢复原版策略顺序、候选排序和有证据的策略门；继续遵守已采用的公共规则、B28逐工作定义的输入权限、独立分析随机与资源守恒；玩家显示设置不自动定义AI权限。范围内确有冲突的原作信息读取与隐式写回逐项列入差异表，不能静默混成“完整原版一致”。资源补偿、额外加兵和伤害倍率不属于OAI阶段的考虑、实现或验收范围，不在本阶段裁决是否采用或默认开关状态。严格同程序随机轨迹和全局逐帧一致不属于本次目标；相同语义输入及注入的规划随机下，已采用的原版规则应得到同一分支和动作。

## 研究依赖

原作事实、争议裁决及各AI-R项的状态与证据边界只在[原版AI权威研究](../../research/ai.md)维护。2026-10-16已完成决策基线静态研究收口；逐工作覆盖、共享边界与规格前复核见该页AI-R13～R15。实现阶段必须链接相应结论，不在本计划另抄研究清单；原作动态对照与重制验收仍须分别记实。

## 实现结构与状态所有权

沿用Application唯一自动控制入口，内部改为“准备当前军团→选择有序工作→在真实执行反馈后继续”的状态机。不要把原作工作顺序映射成现有全局效用分数，也不要让现有SharedAllocator在后台重新排序原版动作。

| 职责 | 建议落点 | 约束 |
| --- | --- | --- |
| 控制轮转、待决恢复、命令身份、外层原子发布 | 既有GameSession、AutomaticTurnRunner、AutomaticResponseRunner | Godot与Headless共用；只改必要接线 |
| 原版工作调度及协议 | Application/AI中的OriginalAiTurnRunner等实际所需实现 | 类型化工作和结束原因，研究码不充当领域ID |
| 内部战略模式与目标 | Application会话持有的显式策略状态 | 与外部CorpsDelegation分开；目标类型安全、失效原子清理 |
| 人员配额、候选及路径分析 | 单个军团／工作单元生命周期 | 可派生数据重建，不把源元数据打包位写进Core |
| 策略门、排序、分配和选项选择 | 无引擎依赖的纯策略函数 | 只消费获准输入、配置、显式规划随机；产生语义意图 |
| 资格、成本、效果、部队自主响应 | Core公共规则 | 玩家／电脑共用；禁止AI私改世界 |
| 工作表、模式参数及人物偏好 | 独立内容可表达的策略定义；确需通用契约时由Content定义 | 原版映射留Importer，Mod不维护EXE地址或偏移 |
| 诊断 | 原有有界诊断入口按新策略调整 | 不保存无用候选，不反馈隐藏信息，不影响选择或随机 |

具体类名是施工建议，不预建空接口。先复用明确符合边界的查询与命令；旧战役观察、粗格路线预测、兵棋估值、训练链和长期承诺不因已存在而自动成为原版规划依赖。原作路径查询的参数和判定用途先恢复，再选择当前共享路径能力；替用近似路线必须登记会改变什么判断并对照，不能默认复用暂停原型的预测。

持久状态仅保存会影响后续决策而无法从当前世界重建的内容：策略版本与实际参数、战略模式／目标、最近一次全局准备的外交排名快照、已证实跨旬标志或抽样决定。原版策略准备中跨旬保留的分组标志不能仅按“缓存”删掉。稳定边界若不允许中途保存，批次游标不进存档；事务内仍要保证挂起／续行不重复执行。公共已签发任务以Core为准，不另存一套原版部队真相。

独立分析随机保留原版分支的调用范围、短路和顺序，使用当前项目稳定随机协议；它不要求与原版共享全局随机状态。诊断不得额外投骰。候选自然有穷、元数据尝试数与安全工作上限分开计量：先按已确认的规则完成正常工作，不沿用65536搜索预算任意截断基础工作表；异常规模的保护限额要显式报告未完成，不能当作无候选。限额具体值在代表规模测试后登记。

## 阶段顺序与交付出口

每阶段都是“补研究→无地址行为规格→独立实现→对应验证”的闭环。已有证据能支撑的单元先实现；不先把全部RE重新写一遍，也不先交一个所有模块待机的框架。

| 阶段 | 依赖 | 可运行交付 | 必须通过的出口 |
| --- | --- | --- | --- |
| OAI-00 证据与决策清单 | 本轮盘点 | 各AI-R项有明确状态，B01～B30／C01～C09已确认；完整工作／提示清单有去向 | 39项分支与表外准备均有去向；公共规则与策略分开，影响首个闭环的未知项闭合；对应异常采用与独立工厂排除已明确；未闭合公共事件前置不由AI补造 |
| OAI-01 调度及经营纵向闭环 | 对应调度、战略和经营证据 | 独立内容的小局面运行战略准备、工作门、0–5/61/63，提交公共命令并结束控制 | B01～B08／B13～B14／B28基础规则、顺序与交易、无候选、失败、恢复及委任权限通过；生产接管范围唯一 |
| OAI-02 人事与组织配置 | OAI-01；对应人事证据 | 军师、官职、宝物、奖惩、调动、搜索、24/56登用、军团管理及55处置 | B09～B12的配额→盈缺→调动及同旬轮转闭环；执行后后项看到新状态；两条登用与处置全部分支独立验证，无越权／跨账户透支 |
| OAI-03 军事全链 | OAI-02必要人员与策略能力；对应军事证据 | 57撤退、58部署、51输送／后备、9攻击与建设、59部署；独立10／60排除，9内部建设／无主目标路径完整接入 | B19～B27的来源、时限、撤回量、无路和费用修正，以及组队、兵法、阵形、建设和失败回退；真实小局面完成经营→补兵→出征→占领，无旧战役搜索代选 |
| OAI-04／05 计略外交、全部响应与生产协议 | OAI-01～03及对应研究；2026-10-17按用户决定合并交付 | 25～36完整策略、每日公共响应及支持的电脑提示；普通电脑、玩家委任、受支持特殊势力唯一生产入口；新内容与协议 | B15～B18的正式载荷／实际使者、高分与配对；B26每日顺序与旬级扫描；命令／提示覆盖、删除占位；默认解决方案、独立Headless、连续／恢复／日志／录像一致 |
| OAI-06 完整内容与原作基线验收 | OAI-04／05 | 190年完整内容、代表势力规模、原版决策对照、长期全图报告 | 固定种子十年或合法提前终局，无权限／资源／引用错误；分支符合性、差异表、冷暖性能及最慢军团有记录；G11/G12按实际出口判定 |

顺序允许在一个阶段内穿插已具备证据的策略，但生产切换必须按“控制范围×行为类别”登记唯一执行者。开发中可以用测试宿主调用新策略、在测试侧保留旧原型对照；2026-10-16用户已决定立即退出旧主动策略；未接入行为暂不执行，不再由旧共同分配器补做。OAI-05完成后产品不保留长期双调度、自动回退或复刻开关。

OAI-01只证明骨架和经营可运行，不代表原版AI完成；OAI-03只证明军事闭环；全部策略、响应、内容、协议和长期对局闭合才交付完整参考基线。当前OAI-00～05已完成生产接线与阶段出口；OAI-04／05合并交付，OAI-06原作对照和十年全图验收仍未完成。各阶段按[行为规格](behavior.md)与[人物规则](character-rules.md)实现，不把文档确认作为产品验收通过。

### OAI-01交付出口

2026-10-16，规则v118。`OriginalAiTurnRunner`成为普通电脑、玩家委任及异民族经营的唯一执行者，按各自首批、六模式二级表及63末批顺序运行。`OriginalAiStrategy`／`OriginalAiState`持有全局准备、排名快照、跨旬分组、模式及类型化目标，`OriginalAiProjection`按直属军团提供当前能力、原版季度／七月保留需求和公共拓扑。Content提供独立策略参数与人物偏好，Importer负责版本身份转换；不引入运行时源槽位限制。

`OriginalDomesticWork`实现0～5的稳定排序、专精修正、半数检查预算与逐人抽样及确定征兵；`OriginalAiEconomy`实现61正常／零余额交易和63留人、搜索及训练。日期、身份相位、难度、分组尝试数与权限分别过门。准备失败、概率失败、空计划、公共拒绝和成功分别诊断；只以公共提交承担资源占用，事务失败完整回滚。

`OriginalDomesticWorkTests`与`OriginalAiCycleTests`覆盖顺序、边界、无候选、失败续行、直接玩家／委任／电脑／异民族、事务回滚、参数与排名恢复及事件重放；默认解决方案4631项、独立Headless25项通过。190年完整内容以种子190全自动运行12旬，完成1067条经营及23条交易，连续／恢复／日志／重复前缀／录像一致。代表规模、冷暖成本和最慢军团见[性能记录](../../docs/ai-performance-records.md#oai-01调度及经营基线)。

OAI-01交付时生产接管范围为每个自动直属军团的战略准备与0～5／61／63；外层沿用公共势力控制席位，势力内部根军团先于子军团，这是[B01已采用的重制选择](behavior.md#b01)，不是临时调度或后续必须补齐的原作全军团排序。其余有序工作明确报告`LaterStage`，不执行旧策略；人员配额、组织调整及所属势力内的军团列表变化由OAI-02接入。本阶段不声称原版全部军事／人事／外交或十年基线验收通过；这些仍归后续既定出口。

### OAI-03军事闭环

2026-10-17，规则v120／`original-military-v1`。`OriginalAiMilitary`由同一生产工作调度接入57撤回、58三组部署、51输送与非城市搬空后备、9普通攻击／无主目标／建设、59请求履约。工作内持有候选、模拟分配、两套撤回累计量及路线投影；提交后重新读取世界、人物和账户，不恢复旧战役搜索或共同评分器。9保留重复来源额度，59最多两个不同来源，并允许首项公共拒绝后继续第二项；最终兵量同时受任务额度、留兵、主将和阵形容量限制。
