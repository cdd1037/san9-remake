# 原版 AI 决策基线行为规格

状态：已确认；2026-10-16采用。本文规定目标行为，不表示新基线已经实现或通过验收。

## 采用范围与依据

本规格采用以繁中PK 1.0.1为依据的完整规则型AI基线，保留策略骨架及人物特色，并按B01～B30及B32修正已确认异常。原作事实及证据等级统一见[权威研究](../../research/ai.md)，人物配置见[人物特判](character-rules.md)，可执行验收见[验收标准](acceptance.md)。

下表确定各主题继承的基线；B条目是明确覆盖项。未列出的已闭合规则按对应研究的候选、排序、公式、阈值、投入及受限随机语义保留；研究中的推断、设计动机和待验证内容不自动成为要求。新差异必须补充采用理由与验收，不能以“更聪明”为由自行改写策略。

## 调度与战略

<a id="b01"></a>
### B01：工作顺序

军团轮转后执行战略准备、配额和有序工作批次，前项完成后读取已生效状态再执行后项。各控制类别、异民族、模式及直属／根势力查询范围分别保留，策略门不成为玩家命令禁令。

**重制选择：**外层采用Core势力席位顺序，席位内先根军团、再稳定顺序的子军团，完成本势力才进入下一席位；玩家直接军团由玩家下令，委任在所属席位执行。协同控制军团允许玩家下令，结束控制时继续执行AI批次，复用剩余人物资格并跳过本旬已下令部队；下旬允许重新安排，采用边界见[委任控制](../behavior/BEH-GOVERNANCE-0002-delegation-control-and-automatic-scheduling.md#协同控制与管理入口2026-11-09)。不采用[原作跨势力全军团排序](../../research/topics/ai/control.md#lifecycle)，以保持控制身份、结束控制、事务与保存共用边界。这会影响后手读到的登用／外交／争夺状态，是采用差异，不属于默认待补或验收前置。

<a id="b02"></a>
### B02：模式生成与更新

内部模式、策略分组与外部委任方针分别建模；保留方针对模式的影响、目标失效判断、准备指标和更新概率。正常自动生成原作已确认的六种模式（研究中0／1／2／3／5／6）；区域模式不额外编造生产规则，不为原版旧存档保留兼容入口。目标以势力／建筑等类型化引用表达，失效时原子清理或回退。

<a id="b03"></a>
### B03：战略目标从实际排序表选取

原作对一张合格对手表排序、却从另一张统计表取目标。重制保留候选资格、原排序依据和后续关系分流，从实际排序后的合格对手表首项读取。目的为使既定优先级实际生效，不另加全局强弱搜索。

<a id="b04"></a>
### B04：准备指标按统计对象归一化

**重制修正（2026-10-22确认，替代此前保留固定分母的选择）：**原作累计民心／士气使用单对象上限作分母，多据点会淹没发展／耐久不足，使军团更容易跳过或退出集中整顿模式。结合相邻属性的总上限比例与模式消费，判断为疑似归一化遗漏；这是修正依据，不将作者意图记为已证实事实。

保留直属、非休眠且未销毁的统计范围：经营仅计城市，军事准备计全部直属建筑。令`ratio(value, maximum)`在分母正时为整数`100 * value / maximum`，否则为100：

- 经营指标为`(ratio(收获合计, 最大收获合计) + ratio(收益合计, 最大收益合计) + ratio(民心合计, 1000 * 城市数)) / 3`。
- 军事准备指标为`(ratio(耐久合计, 最大耐久合计) + ratio(士气合计, 100 * 建筑数)) / 2`。

保留整数逐步截断及宽整数安全运算。无城市时经营指标为100，无建筑时军事准备指标为100；不因无统计对象进入集中整顿。增加相同状况的据点不改变指标。发展与耐久仍按总上限加权，不改为各据点百分比的简单平均。

模式回退仍先判断经营指标严格小于50进入内政，否则军事准备指标小于50进入备战，其余进入一般模式；既有内政／备战模式仍在对应指标严格大于50或通过8%更新门时重新选择模式。不调整工作顺序、普通进攻的来源士气门槛、显式委任及联盟／攻击请求的优先级。

<a id="b05"></a>
<a id="已采用差异外交排名不随策略分组清零"></a>
### B05：外交排名独立保存

有效势力在既定全局策略准备的日期门通过时，按原排序依据重算排名并完整发布；分组更新只改分组，不清排名。日期门未过时使用最近一次完成的排名，首次消费前必须初始化；失效势力不因残值进入候选。排名快照不能作为普通查询缓存按当前信望随时重建，否则会改变两次准备之间的外交选择；保存恢复须保留该快照。保留赠与要求目标排名值较大、劝降要求较小的严格方向；以可扩展的完整排序表达，不继承低七位或50槽限制。本项修正使排名实际服务外交选择，不要求解释原作正常旧档的非零留存路径。

<a id="b06"></a>
### B06：策略分组与历史偏好

分组统一命名为未分组（`Unassigned`）、战略优待组（`Favored`，原版元数据bit7）和行动收敛组（`ReducedActivity`，原版元数据bit8）。战略优待组影响部分敌对规划的回避和进攻兵力门槛；行动收敛组影响工作尝试次数、部分规划的概率跳过、劝降资格及军事后备分支，不只减少尝试次数。保留这些既有行为；历史人物、家族、起兵、继任和国号偏好按[人物特判](character-rules.md)配置。规则消费语义属性与引用，不以姓名、源编号、列传资源码或槽位分支。独立内容和Mod可配置同类规则。

<a id="b07"></a>
### B07：难度差异

新游戏默认采用高级难度（`OriginalAi.Advanced = true`），内容可显式配置初级；读档保留存档中的难度。保留高级缩短开局等待、调整部分尝试次数以及更早纳入新建部队的候选门；候选资格不保证出兵。开局资源补偿、额外加兵和伤害倍率不属于OAI阶段的考虑、实现或验收范围；本阶段不裁决是否采用及默认开关状态。

<a id="b08"></a>
### B08：稳定周期错峰

开局等待、日历周期窗口和尝试预算分别计算，不采用上次行动后的统一冷却。周期保留原窗口宽度和相位公式中的稳定身份错峰关系；内容中的持久调度标识在创建时确定并进入保存，恢复或列表重排不改变相位，不依赖固定身份范围。

**可选重制差异（2026-11-02用户确认）：**开启伴侣“取消电脑褒奖时机限制”时，仅电脑主军团的褒奖工作免除开局等待与日历周期窗口，每旬均有安排资格；关闭时沿基础日期门。预算、候选、每人每旬一次及其他工作不变，子军团不新增独立褒奖。完整边界见[066扩展](../behavior/BEH-COMPANION-0001-settings-and-player-domestic.md#computer-reward-timing)。

## 人员、轮转与预算

### 军师选择

**重制选择（2026-10-19，根据优化伴侣修正）：**军师候选先按当前有效智力降序，相同时再按仕年降序，防止资历加分压过智力。仕年为`当前年−StatusStartYear+1`，加入当年算1年，不截到10；未记录起始年时不获得资历优先（按0年），不以年龄代替。两个键均相同时保留输入顺序。本项覆盖[原作](../../research/topics/ai/domestic-personnel.md#1317任命官职与宝物)的`当前有效智力+min(仕年,10)`加分排序。

同根普通在职人物至少五人；替代者忠诚至少80，当前有效智力至少80且严格高于现任，无现任时只检查80下限。现任追加参与排序，仍胜出则不任命。**重制选择（2026-11-01用户确认）：**移除原作候选115上界及随之配套的下限夹取，不排除有效智力超过115的人物。受伤、宝物和官职通过当前有效智力参与资格与排序，不按基础智力保护现任，也不设置伤愈自动复职。

### 自动执行者的能力资格

**重制选择（2026-11-01用户确认）：**探索、登用、计略与外交选人取消当前有效能力≤115的上界，保留各工作政治／智力／武力／统率的最低资格及其他条件。074玩家自动探索和夺取复用同一选人入口，因此采用相同规则。基础成长上限不成为有效能力上界；AI评分中的115平移项、概率饱和点和人物特判不随之改变。

### 自动任官的仕年

特殊官职直接从当前爵位允许的官职表分配，不要求君主未行动、驻留或无任务占用；人物候选仍遵循任官资格，不给普通任官添加君主可行动门。原作皇帝专属阶段与实现纠错见[工作14复核](../../research/topics/ai/domestic-personnel.md#1317任命官职与宝物)。

三段人物排序分别使用`当前统率+当前智力+仕年`、`当前统率+仕年`、`当前智力+当前政治+仕年`，各段另加忠诚至少150时的5分。仕年与军师选择使用同一定义，缺失起始年按0年，不使用出生年或年龄。本项纠正研究与实现的字段混用，保留原作加分排序及其他任官资格，不将军师的智力优先优化扩大到任官；证据见[年份消费端复核](../../research/findings/RE-SAN9PK-0009.md#2026-10-19年龄与仕年消费端复核)。

任官计划只扣除不参与本轮分配者的占职；参与者现职统一分配，不消费虚拟撤职槽，不合格人物不阻断后续合格人物。未获新职者保留仍合法且未被分配的现职，否则撤职。排序仍使用当前能力和当前忠诚，不扣除现职加成。

<a id="b09"></a>
### B09：人员配额的对象与数值域

分子总人数采用当前直接军团的在职人员，含君主、都督、军师、普通在职及外出任务人员；俘虏、在野、未登场和死亡人物不计入。实际调动另查驻留与可行动资格，不能把闲置人数作为总人数。保留原兵力／兵役／伤兵权重、驻军统计和建筑最低配额，但使用宽整数及完整数值，不继承低八位截断和32位溢出。配额是各建筑需求，不强制总和等于人数；真实人员迁移守恒。建筑兵力保留及量化仍按采用的原策略参数计算。

<a id="b10"></a>
### B10：配额失效与重算

批前计算配额；新设／解散军团、建筑归属变化后，标记并重算受影响军团，后续工作使用新辖区的配额。其他工作间不无条件全量重算；缓存必须声明输入依赖，缓存温度不改变结果。这明确修正原作组织变化后仍沿用旧配额的时点。

<a id="b11"></a>
### B11：调动只消费实际处理项与空城补缺

保留余缺配对、人物排序、单次人数上限和空城单人补缺；目的地每次只消费当前处理项，来源用尽时按引用移除实际选中来源。禁止误弹下一目的地或原始来源表头；失败候选是否继续仍按B13的工作生命周期处理。

2026-10-17明确采用缺陷修正：[RE-0124补证](../../research/findings/RE-SAN9PK-0124.md#工作22来源筛选与空城后备补证)确认原作正常生产链不能成功执行单人后备，不存在额外对象关系门；无法确认作者原本意图。重制每个目的地优先从有可行动人物的盈余来源普通调动；无此来源且目的地为空城时，从当前军团全部有效可驻人据点中选有可行动人物且驻留人数大于1的来源，允许突破配额。按驻留人数降序、同数按收集顺序，选一人；人物沿用后备官职优先量与政治、武力评分。补缺不得搬空来源，不向非空城市或非城市启动后备，不跨军团借人。已成功离开的人员不再计入来源驻留数，拒绝不扣人数；无来源正常消费当前目的地后继续。此为重制修正，不声称恢复了原作本意。

<a id="b12"></a>
### B12：同旬军团列表变化

在B01的势力级轮转边界内，新军团追加到所属势力当前军团队列末尾，通过控制资格时同旬获得行动机会，并执行自己的批前准备；解散军团按引用移出待轮转表。不重排全表、不从初始快照复活已解散对象，不为新增军团重新打开已经完成的势力席位。已有游标的恢复不重复全局准备或已经完成的工作。

军团分区启动及数量上限使用势力有效总城市数，避免分区减少根直属城数后反向解散。数量未达上限时，保留仍满足原分区条件、完整管理同一省份己方城市且都督仍合格的已有军团，补建其他分区不先解散它们；跨省等不合格辖区仍按原流程处理。保留原区域评分和都督排序，不增加现任优先或目标辖区差量重组。

<a id="b13"></a>
### B13：有界失败消费

自动经营0～5、交易61和剩余搜索／训练63在来源收集时排除混乱及近距交战据点；在选人、规划抽样及消耗尝试次数前完成，不依赖最终提交拒绝来代替筛选。执行前复读沿同一状态规则；该条件不豁免据点日粮和俸禄需求。证据与回归见[来源状态复核](../../research/topics/ai/domestic-personnel.md#domestic-origin-state)。

人员移动的出发据点、探索／登用执行者、计略／外交执行者，以及普通攻击、请求履约、攻击内建设和输送来源，同样在候选阶段排除混乱及近距交战；人员接收地和势力管理操作不套用来源门。迎敌部署的组0／1来源及组2被援据点仅排除混乱，允许正常但交战；组2供援来源仍沿自身选择及公共最终校验，不把被援据点门复制过去。依据和验证见[同类排查](../../research/topics/ai/domestic-personnel.md#automatic-origin-state-audit)。

保留各工作的尝试预算、候选消费与终止位置；准备失败、生成空命令、公共拒绝和成功分别表达。失败可以消费尝试或候选，不统一改为跳过当前城市继续，也不自动重建失败来源反复尝试。B11／B19～B20及B32明确修正的错误消费优先：普通进攻候选失败继续当前城市的后续目标；常规经营0～5的局部失败继续后续据点；出击跳过同一世界下已被拒绝的相同完整计划。策略尝试数与异常规模保护分开，保护触发报告未完成，不能伪装为无候选。

剩余工作63的单城失效或留守扣空只结束该来源，继续其他城市，保留选人、训练及搜索规则。

<a id="b14"></a>
### B14：资源预算按提交反馈结算

预测与规划仅作临时预留；无法形成合法命令、提交拒绝或事务回滚时释放对应资源预留，成功提交并承担资源占用后才保留扣账。覆盖赠与、输送和部署等私有预算，避免失败虚耗可用资源；尝试／候选仍可按B13消费。任务间重新读取当前账户与占用，公共规则已承担的出使费用及后续外交失败成本不因此退款。

## 预测与外交

<a id="b15"></a>
### B15：赠与使用同一正式载荷

先按本方资源及原保留公式确定钱粮载荷，同一候选计划的军师预测、使者排序与提交均使用该载荷；不采用静态小额、目标自身资源或零载荷替代。保留钱粮二选一、数量限制及目标外层优先。若世界变化使载荷失效，重新形成并完整评估新计划，不沿用旧预测。

赠与候选仅限地域直接邻接的势力，不经第三方领土递归扩展。来源不得为异民族或当前联盟讨伐对象；目标仍须非异民族、非讨伐对象且严格通过排名门。普通关系范围为20～59，只有本方为联盟成员且目标为盟主时才豁免关系门，不能向所有势力或普通盟员扩展豁免。按2026-10-22用户要求，自动赠与复用玩家公共上限：资金10000、兵粮100000；保留扣除需求与固定保留量后取半、十比一比较且同值优先资金的原公式，不另加冷却或小额替代。这是针对原作自动赠粮封顶10000、只能送10000的重制修正，不改变原作研究事实。候选证据见[赠与候选复核](../../research/topics/ai/missions-diplomacy.md#gift-candidate-audit)，金额依据见[RE-0117](../../research/findings/RE-SAN9PK-0117.md#2026-10-22-玩家赠礼输入上下限补证)。

<a id="b16"></a>
### B16：以实际使者复验攻击请求

目标组合保留原优先级，使者保留原距离偏好与稳定并列顺序；最终选择的使者必须对当前目标组合通过采用的可行性判断。失败时按既定使者顺序尝试剩余人，再按工作规则继续其他目标；有界消费，不使用高政治人物的预测替另一人担保。只有最终可提交配对才消费受请求势力、目标与使者。

来源几何时间门以受请求势力君主当前所在地图对象为终点，不以任意所属城市替代；正式选将仍按到攻击目标建筑的距离优先。受请求势力保持外层顺序，同一势力下比较实际使者的免费接受阈值，最高者优先，同分保留建筑类别优先及原顺序。城市及配置了正外交优先量的设施进入攻击建筑候选，原版港口不进入；异民族身份不一概排除受请求方。

攻击对象须通过发起方的战略敌对资格；被攻建筑属于攻击对象并直接邻接受请求方，不要求与发起方接壤。原版对同一建筑先要求属于攻击对象、后要求受请求方所有且在前线，当前归属一致时两者冲突；重制明确采用前述可运行的领土协同语义，不模拟同一建筑双重所有或历史缓存残值。该差异与实际使者复验均保留，证据及边界见[请求再次核查](../../research/topics/ai/missions-diplomacy.md#attack-request-recheck)。有有效军师时区分免费／条件／拒绝三态；对玩家无法判断按50评估，无军师则使用真实免费阈值，不以玩家目标替代军师上下文。

<a id="b17"></a>
### B17：配对分数不因超过100被拒绝

赠与、劝降保留最低可行分数33，取消100上限。其他工作保留已确认下限，军师意见映射仍按各工作规则；实际排序阈值不先夹到100，公共结算继续按已采用概率规则处理。本项修正高阈值反而失去可行性的异常，不把预测分数当作最终成功保证。

### B18：目标外层与稳定配对

先按工作目标顺序找首个可行目标，再在该目标下选执行者，保持各工作不同的预排序、可行性回调、排序键及逐候选调用次序；单候选仍执行必要预测与评分。普通列表、交集及有意重复的计划项不统一转成去重集合；同分保留已定义输入顺序，来源枚举与保存恢复必须稳定。

**自动离间目标最低能力（重制选择）：**保留当前战略对手、可见在职、非休眠、忠诚≥70及有效智力≤90的筛选，再要求目标当前有效统率、武力、智力、政治至少一项≥60。共用现有有效能力查询，包含伤势、宝物和官职；在目标洗牌前过滤，不为被排除人物消费排序随机。该规则固定用于电脑势力和玩家委任军团的自动离间，不新增开关或阈值输入，不改变手动离间资格、公共成功率与结算；它是002的重制采用值，不沿用智力／统率65的伴侣门槛，也不引入目标价值排序。验收覆盖四项分别恰好60、全项59、伤势低于门槛、加成达到门槛及既有智力90上界。

**离间目标顺序（采用的日版修正方向）：**29号离间在原有目标过滤后、收集执行者之前，使用本军团现有独立规划随机对目标列表做一次线性Fisher–Yates洗牌；空表／单候选不为排序取随机数，多个候选每轮取当前前缀长度范围内的下标，共取N−1次。随后仍按洗牌后的顺序选择首个可行目标，沿用执行者排序、预测门、尝试预算和目标消费规则。该选择采用[日版1.3随机化目标顺序的修正方向](../../research/topics/ai/missions-diplomacy.md#akainan-jp130-comparison)，消除人物编号靠前导致的固定优先；线性洗牌是重制实现，不复制日版反复随机交换及其随机次数，也不新增目标价值评分。其他工作保持各自目标顺序；同一状态与规划随机产生相同结果，保存恢复沿现有随机种子／续行状态机制。验收覆盖不同规划随机可优先选择不同合法目标、空表／单候选不取排序随机，以及既有失败消费与恢复确定性。

外交范围分别判断：劝降只收集直接邻接势力；俘虏返还按实际拘押与归属收集，不增加邻接或异民族拘押方排除门。返还无军师时的真实可行性以及军师预测必须同时检查对方报价与本方接受条件，不能将“存在报价”当成“双方可达成”；最终谈判仍按实时状态复验。证据见[其他外交定向核对](../../research/topics/ai/missions-diplomacy.md#diplomacy-candidate-audit)。

### B19：请求履约续行与来源消费

同一攻击请求最多处理两个不同来源，各消费一次；首队提交后，请求／目标仍有效、需求未满足且预算有余时继续第二来源。按前项实际执行后的世界复验人物、留兵、容量、路线和公共资格，单项失败跳过、整体失效结束。修正第二来源随任务结束丢弃的问题，不保证必定派两队。普通攻击可从同建筑形成多个部署额度，每队重新核对资源与人物，不把有意重复来源误判为重复命令。

<a id="b20"></a>
### B20：最终出征兵力下限

普通自动攻击与攻击请求履约在选将、主将容量、任务额度及来源留兵限制之后，实际计划兵量必须达到城市10000、其他来源5000；不足不出征，按生命周期继续。不能超容量、动用保留驻兵或凭空补兵。该策略门不改变玩家公共资格，也不覆盖其他部署、输送或单人后备的独立门槛。

v252起，军事空间候选统一使用会话持有的`SettlementTransitNetwork`，旧`MilitaryCityNetwork`及内容字段、生成器已退出。静态表按参考行动力50、陆上5×5／水上4×4及`ReferenceHorizonDays=60`建立直接有向关系；普通进攻实际行程上限`MaximumAttackTravelDays=60`是独立策略参数，两者当前同值但不互相引用。所有本次迁移的候选只取表内，不因实际阵形更快、同属城、明确目标、请求或输送而补查表外关系；公共路线只复核表内候选及其替代路线。地理`CityConnections`与地域接壤仍按各自职责保留。

目标排序和无主目标需求使用目标自身及直接入边来源，逐据点去重；优待组额外留兵使用敌据点→来源的入向关系，保留最大敌驻兵一半的算法。请求履约和据点救援只取来源→目标直接边，保持现有人物、兵量、任务及公共通路条件，不追加普通进攻60日实际行程门。迎敌组0／1的候选地域为来源自身及直接出边端点实际所在地域，不扩展属城辖区或途中空地域；部队仍按真实位置及既有接近时间／等待规则复核。输送的前线判定使用入向非己方非异民族据点，接壤优先级仍用地理规则；目的地必须有来源直接出边，并按参考行程排序、同值保持原预算顺序，保留实际运输路线的工程障碍／敌地域检查。已在场部队的压力和撤回继续使用既有任务、真实位置及时间规则。

派生输入为完整城市定义、地形通行、地理阻断、城市建筑占地和城防射程上界，以及代码中的校准参数；不读取原版EXE、研究脚本、原表或模型JSON。参考移动几何固定为陆上5×5、水上4×4细格、等速成本尺度，不随玩家默认部署阵型变化。无绝对行程上限，不限制城市编号或每城邻城数量；共用粗格的城市共享战略位置，生成后展开到城市身份。派生表随内容包发布；内容依赖或算法变化须重新转换剧本并重新加载，不在开局或读档时重新生成，也不把表复制进存档。缺失字段的旧包要求重转，不回退到地理邻接或运行时生成。验收要求同输入结果确定、引用有效、空表及方向原样加载、会话内共享、读档读取同一内容；本地图必须与实验112组、224条有向边逐条一致。该规则是暂用的校准模型，解释性及跨地图准确性仍待优化；未来优先拆分静态机会范围与前沿来源／近处目标的实际出兵裁决，并用统一性能与AI行为基准评估，详见实验的待优化方向。

**据点交通与普通进攻（2026-11-05用户授权实施，规则v251）。**Core在开局与恢复时以全部有效物理据点完成有向参考网，固定每日行动力50（阵形机动力10）、陆上5×5／水上4×4参考占地、等速水陆成本及60日范围；同来源共享单源搜索，保留参考行程、水陆代价和路线。几何变化发布新的完整网络；归属、兵量及部队移动不重建参考网，局部依赖维护仍待讨论。Application普通工作9的目标／来源严格取自当前交通网的直接有向可达关系，网外设施不进入候选，不按真实阵形速度补查网外关系，也不通过多跳拼接扩展范围。网内来源不会再被目标属城筛掉。普通进攻按基础编成换算参考路线的60日行程，包括同属城、指定目标及异民族来源；普通已占领敌设施阶段另须地域接壤己方有效据点，指定目标及无主后备保持各自阶段。具体设计及实现边界见[据点交通网](transport-network-design.md)和[白马港方案](local-attack-proposal.md)。这属于重制选择，不将参考范围或新候选顺序写成原作事实。

来源资格有可行动人物即可参与强度估值，实际分配仍须至少留一人，单人来源不能出队；按模拟剩兵择优，不用来源表顺序代替剩兵排序。现有强度算式、薄弱来源负贡献、留兵及顺序编队保持。工作9的来源预估和选阵前上下文直接使用交通边摘要：经过的地形、按首次经过顺序的地域、参考中心线实际穿过的中间设施，以及离开来源占地后至进入目标占地前的水陆费用。费用按当前移动预算换算，速度变化不重选参考路线。敌我、工程类别及施工冲突按当前世界判断；中间敌设施阻断参考路线，或基础编成不能走其水路时，仅对该网内目标查询公共替代路线。实际选阵／船型和兵量确定后仍执行既有连通性、出发位置、粗格行程及途中敌设施检查，不增加逐日预演。公共查询结果缓存的结构、生命周期及失效逻辑本轮不调整。实际通行由正常每日导航处理；拒绝不计入投入、不扣兵将，来源、路线、强度或零分配阶段失败可继续后续目标；已有兵力分配后的结束规则见下段。引用原作流程的[来源与压力研究](../../research/topics/ai/military.md#military-source-pressure-closure)保留原作事实，履约仍使用自己的来源规则。

**普通进攻后续目标。**沿用v207采用的失败后继续评估，v245将候选关系统一到实际据点。指定目标、指定势力城市、其他城市、无主城市及普通设施的阶段优先级保持；城市分组只负责调度。v250修正v249的部分恢复：按本批兵量优先的网内来源读取参考路线，首个满足战略目标资格的途经据点（含城市及中立据点，不含工程障碍类）承接原目标阶段，不另加前沿门；实际目标仍须有同来源直接交通边，随后按统一交通关系收集合法来源，不恢复城市邻接门。普通已占领敌设施独立候选阶段的前沿门保持。每批按实际目标去重，多队仍逐队读取当前兵将与账户。v251恢复改造前的结束规则：来源、路线、强度不合格或分配结果为空时可继续后备目标；一旦分配出至少一队，尝试完本目标的各队后即结束当前城市批次，无论最终命令是否全部为空或被拒绝。失败后继续后备目标可能有助于减少空转，是可能合理的独立改进，但用户确认本轮暂不采用，避免交通网改造夹带执行策略变化。沿路施工冲突只检查目标及本批主路线实际相交的有效非工程建筑，不因经过尚无建筑的建设目的地域而取消进攻，也不逐一剔除途经施工区的额外参战来源；转建设的地域从实际选中来源—目标路线取得，建设来源再从同城士气合格且至少有两名空闲人物的据点中按兵量重选。履约仍只处理请求目标，不改选普通目标；不引入批次预编、持久战役规划或提前为未来提交的动作消耗随机。

### B27：自动部队方针配置

按“接近攻击／自主撤退／追击／事后攻击”顺序，普通主路径为关／开／关／开，异民族主路径为开／关／开／开，既定单人后备为关／开／关／关。分别配置，不把主路径扩展到所有出征。方针由B26的共同响应消费，不是绝对禁令。

## 权限、范围与交付

<a id="b28"></a>
### B28：决策输入、界面披露与公共命令

AI输入权限按具体工作及本规格明确采用的规则定义，不能由玩家界面是否显示、玩家控制身份或公共查询是否返回某字段推导。原作已核查的输入按基线采用；明确限制某类信息的重制选择须列出适用工作、理由和验收。输入缺失的后备／跳过也须有对应工作规则，不得从笼统的信息原则推导整项工作停用；研究证据缺失不等于运行时信息不可用。AI只读确定性领域状态与预测，不修改对方命令、不读取未来正式随机；通过公共命令验证、支付与结算。已有公共费用、资源守恒、资格修复及整编禁用继续有效；外层失败不得残留世界、策略记忆、随机或命令水位的部分修改。

玩家界面披露与AI决策输入分别定义。依据[RE-0193](../../research/findings/RE-SAN9PK-0193.md)，攻击、请求履约、部署、撤回及救援的已核查路径读取实际有效命令，不受“他势力部队的命令”显示开关控制；关闭显示不得漏算来袭压力或跳过这些工作。当前目标／主目标、返回状态继续采用Core有效命令语义。该结论不外推尚未核查的其他情报读取。

**23号探索：**依据[原作23](../../research/topics/ai/domestic-personnel.md#re-0110-交互与自动生产)，先从公共命令允许的地点中保留确有未发现人物的目标，不因仅有埋藏宝物而建立候选；再从本军团城市收集有效政治至少45的可行动人物（2026-11-01取消原作115上界），来源到至少一个候选目标的预计行程须在0～255日内。该距离门用于来源准备，不另加每个最终配对的距离门。按目标外层顺序与政治降序选择人物，真实探索命令的公共结果预测为不利时记0，其余记100；无军师不构成额外准备失败。选中后消费目标与人物，通过同一公共探索命令提交，不提前发现或改变人物状态。允许策略只读未发现人物的所在地点。63剩余探索沿独立训练／本地探索规则，不套23的人物目标门；电脑结算仍限人物、资金或无结果，不进入宝物与玩家专属探索事件。官职排序以内容优先量表达，原格式的无官职项表达为撤职选项，不依赖源官职编号或人物编号区间。

25伪报／26扰乱直接读取有效命令，不受玩家命令显示开关影响；前者取直接军团、后者取根势力，两项判断已有针对部队时均排除单人队，26另排除内嵌守军。部署58扫描敌队成员当前装备兵法，破陷／教谕不受兵法显示开关影响。证据见[RE-0113](../../research/findings/RE-SAN9PK-0113.md#2026-10-172526目标筛选与命令显示开关)和[逐人选法](../../research/topics/ai/evidence.md#source-0079)。无效单位引用由世界不变量禁止，不为不可构造状态添加兼容分支。

人物`IsVisible`表达身份状态，不能当作界面开关；登用／离间沿各自资格，23探索使用公共合法地点与未发现人物位置的交集。资源补偿不属于OAI阶段考虑范围，不借输入复核作额外裁决。

<a id="b29"></a>
### B29：完整主线与明确排除

覆盖经营、人事、军事、建设、输送、八计略、四外交、公共响应及支持的电脑待决选择，普通电脑、玩家委任与异民族分别验收。39项源工厂及表外准备逐项有去向；标准调度不使用的独立工作10／60不接入生产，普通攻击内的建设与无主目标出征仍实现。玩家专属事件不编造电脑回答；教学／挑战及小兵培养继续在主线外，不为工厂库存建设无消费者框架。

攻击内转建设只沿已形成的进攻计划及路线转换，不在无目标时额外寻找空地建设。建设地点独立声明横／纵方向偏好许可，不从可建设施集合或3×3石兵资格反推；横向许可优先，否则检查纵向许可，所选方向候选为空或均无许可时回退普通设施。

建设目标不要求其所属城市属于建设方，普通电脑和委任军团均通过[公共建设规则](../behavior/BEH-WAR-0006-facility-construction.md)提交和逐日执行；城市易主不取消仍有效的建设计划。不能在AI层绕过费用、人物、占用或重复建设校验。

**公共事件差异：**重制统一禁止玩家／电脑君主所在据点和君主野外队主动归附，不保留原作电脑最后资产特例。仅限旬级主动归附，不扩展到外交劝降、战败或灭亡；资格、原作可达性和验收统一见[治理规格](../behavior/BEH-GOVERNANCE-0003-xun-personnel-and-territorial-transition.md)。

#### 普通俘虏处斩限制

采用玩家与电脑两个独立、默认关闭的处斩禁止开关，按处置势力当前是否存在玩家控制席位选用，包含该势力所有军团。常规俘虏工作在候选准备时排除受限的普通俘虏并继续关押，公共处斩入口同步终验，玩家手动命令也受玩家项限制；君主在常规工作与独立待答中均沿原有处置规则，含讨伐联盟目标。关闭时保留原有概率及规划随机顺序；处斩之外的工作和其他死亡规则保持原定义。设置所有权、恢复及验收见[伴侣设定016](../behavior/BEH-COMPANION-0001-settings-and-player-domestic.md#prisoner-execution-permissions)。

<a id="b30"></a>
### B30：确定性与唯一生产入口

使用独立规划随机，保持采用分支的抽样范围、短路及顺序；诊断、缓存和机器速度不影响结果。所有身份与集合可扩展，状态所有权按Core领域规则、Application控制／策略和Content契约划分；地址、位域及源编号范围留Importer与研究。保存策略版本、实际参数和必要持久状态，协议切换同步状态诊断与命令日志并明确拒绝旧版；最终旧自主增强原型退出本范围，不保留长期双调度或兼容回退。以真实经营、出兵、战斗／占领、回撤、恢复／重放和长期对局验收，不以强过老玩家作为前置。

工作内来源／人物／基础阵形／留兵及导航查询可复用；缓存按实际输入依赖失效，不改变抽样顺序。单条AI出征共用Core的[公共准备](../behavior/BEH-WAR-0001-movement-and-command-lifecycle.md#deployment-preparation)、预留及按引擎／载荷／版本绑定的提交结果；不因此引入真实批次优势裁决。

<a id="b32"></a>
### B32：局部经营失败与确定拒绝不阻断后续候选

**重制选择：**依据[经营停滞及出击失败评估](../../research/topics/ai/domestic-personnel.md#patrol-stall-20261029)，替代0～5单城准备失败即结束整项的原版行为，并约束58对确定拒绝的重复提交。能力、概率、资源门及工作优先级保持。

- 常规巡察、商业、开垦、修筑、征兵和训练按既有目标顺序逐一处理；某据点失效、人物已用尽、无人满足能力门或逐人概率全部失败，只消费该据点，继续下一候选。同一据点本次工作不重新抽选。准备失败不消耗命令尝试数，实际提交（包括拒绝）才消耗；候选列表自身有界。所有候选处理完仍无命令可提交时，保留准备失败及概率失败诊断。
- 整个账户的钱粮不满足对应保留门时停止；征兵资金／粮食门与普通经营的薪需加250、训练无资源保留门分别保持。每次提交后依当前人物和账户状态继续，不预占失败计划的资源。
- 出击在本次工作内、同一不可变世界下，不重复执行公共资格准备或提交已被拒绝的相同完整命令计划，继续按原优先顺序检查其他目标／来源。命令标识和序号不作为计划差异；来源、兵量、人物顺序、阵形、兵法、阵位、目标、出发延迟、许可和路径点均参与识别。不同随机编成仍可尝试，没有形成完整命令的随机规划失败继续受原有尝试上限约束。
- 成功提交后世界发生变化，或其他实际状态变化后，清除该工作内的失败记忆并按当前条件重评；保留同一来源向同一目标继续派遣的能力。失败记忆不持久化、不跨工作复用，不因一个被拒绝的编成永久排除整对来源与目标。
