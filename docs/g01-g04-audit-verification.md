## 边界

代码职责复核：`EconomicCycle.Apply`只调度周期步骤，收入循环保留稳定城市顺序与特殊账户去重，普通收入和特殊补给分开执行；特殊资金目标、粮食目标及俸禄忠诚概率归入领域经济规则。七月补给在本次结算内按势力缓存粮食目标，避免同势力多个军团重复汇总兵力。此次为行为不变的重构，规则仍为v19；重新运行Core313项和Application89项全部通过，包括经济边界、十年固定驻军恢复、特殊势力选择及保存重放，`git diff --check`通过。

没有运行原作或Godot；原作结论为主IDA库静态调用、指令与读写链核验，注释变更及回读已登记在RE-0098。十年测试是固定驻军公开场景，不是190年完整战略AI十年对局。缺粮伤亡、伤兵接入和完整战略AI仍按G06/G07/G11推进；不把零粮仍可推进当作经济可持续。
