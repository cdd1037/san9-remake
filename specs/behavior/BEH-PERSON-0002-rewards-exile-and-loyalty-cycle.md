## 适用范围

适用于褒美、授予宝物、任命军师、放逐和俘虏忠诚旬更新。一般官职分配不在本规格内；官职俸禄及其忠诚影响由导入规格定义。

## 原作基线

褒美要求忠诚小于 100、未在本旬受褒美且资金足够。令义理为 `G`、忠诚为 `L`：

```text
gain = min(min(trunc0(50*(20-G)/100),10), max(0,100-L))
```

每人增加 `gain`、扣 100 资金并置本旬已褒美位。授予宝物先转移持有者，再把宝物忠诚增量加入受赠者忠诚。

军师任命要求选定人物为通常在职身份 3，且当前有效智力至少为 70。有有效旧军师且新军师当前有效智力不高于旧军师时，从玩法随机流抽取 `0..2`，把旧军师对任命势力的忠诚减去该值，下限为 0；智力相等也进入此分支，抽到 0 时数值不变。没有旧军师或新军师智力严格更高时，不执行这次抽样和忠诚扣减。

忠诚结算后，把旧军师身份 2 改为 3、新军师身份 3 改为 2，并更新势力军师引用，随后才进入表现分支。不写一般官职或俸禄。此处依据 RE-SAN9PK-0112 的 2026-09-06 调用链复核，替代旧版“不写忠诚”的错误结论。

放逐非俘虏时把其对放逐势力忠诚写为 45；放逐俘虏时改为增加 `trunc0(义理/5)` 后释放/安置。

每旬清除全人物的已褒美位。身份为俘虏的人物另作独立周期判定：令其与被俘前所属势力君主的相性环距为 `d`（封顶 50；无有效君主时取 50），按阈值 `15*floor(sqrt(d))+10` 投骰。命中且原势力有效时，对该原势力的忠诚减 1，下限为 0；不修改对扣押势力的忠诚。该周期不要求发生登用，也不检查义理是否为 15。相性距离为 0 时阈值仍为 10，距离至少 36 时阈值至少为 100。没有有效原势力时仍投骰，但忠诚写入无效。

俘虏旬更新独立于登用；失败反馈及重制版保留的俘虏排除规则统一见 [BEH-PERSON-0001](BEH-PERSON-0001-discovery-recruitment-and-affiliation.md)。历史公式纠正保留在 RE-SAN9PK-0112。

## 重制行为

重制版关系保留以上资金、忠诚、宝物持有者、身份和旬周期顺序。军师替换保留当前有效智力比较、等值分支、`0..2` 扣减和零下限；符合扣减条件时恰消费一次显式玩法随机，即使旧忠诚已经为 0，也不省略抽样。一般命令占用与本旬已褒美必须是两个独立状态。没有机器支持的“放逐必没收宝物”和“忠诚通用默认 50”不得实现为基线规则。

## 状态与不变量

- 输入：势力资金、人物义理/忠诚/身份、宝物与增量、军师引用、新旧军师当前有效智力、显式玩法随机状态、相性关系。
- 输出：资金、忠诚表、宝物持有者、身份、军师引用和旬标志。
- 不变量：忠诚反馈有界；宝物先转移后加忠诚；军师任命不写一般官职；褒美位在下一旬人物更新中清除。

## 验收标准

- [ ] 褒美公式、100 上限和资金扣除由边界测试覆盖。
- [ ] 宝物持有者与忠诚写回顺序由状态测试覆盖。
- [ ] 军师替换、非俘虏/俘虏放逐分支互斥。
- [ ] 军师候选智力 69/70、没有旧军师、新智力低于/等于/高于旧智力，以及基础智力与当前有效智力排序相反的情形均有测试。
- [ ] 军师替换覆盖扣减抽样 0/1/2、旧忠诚 0/1/100、随机消费次数、仅旧军师对应势力忠诚项变化，以及忠诚先于身份和表现提交的顺序。
- [ ] 俘虏周期相性距离 0/1/3/4/35/36/49/50 对应阈值 10/25/25/40/85/100/115/115；命中仅扣原势力忠诚 1，覆盖原忠诚 0/1 及原势力失效边界。
- [ ] 无登用命令也执行俘虏旬周期；义理 15 和相性距离 0 不误用在职登用失败分支的豁免。
- [ ] 测试不依赖原版文件或研究地址。
