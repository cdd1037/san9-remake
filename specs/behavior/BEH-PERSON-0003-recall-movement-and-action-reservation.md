# BEH-PERSON-0003：人物召回、移动与行动占用

- 状态：已确认
- 负责人：项目开发者
- 最后更新：2026-10-20
- 关联证据：[RE-SAN9PK-0009](../../research/findings/RE-SAN9PK-0009.md)、[RE-SAN9PK-0112](../../research/findings/RE-SAN9PK-0112.md)、[RE-SAN9PK-0150](../../research/findings/RE-SAN9PK-0150.md)
- 关联决策：[DEC-SIM-0001](../decisions/DEC-SIM-0001-determinism-and-saves.md)
- 继承方式：关系保留

## 适用范围

适用于多人物召回、移动、目的对象写回、公共命令参与占用，以及探索、登用、救援等任务共用的人物返程。

## 原作基线

召回复制参与人物，按当前关联对象稳定分组，每个来源对象形成一个调动组并移向同一目的对象。移动创建命令事件后进入共享调动；君主跨势力时使用专用势力/部队迁移，其他人物使用普通对象调动。

命令提交/执行准备给参与人物置公共占用位；候选和复验拒绝已经占用的人物，命令完成后由公共链释放。该位不同于褒美命令设置并在旬人物更新清除的“本旬已褒美”位。

## 重制行为

移动、探索和登庸的出发据点必须未混乱且未处于近距交战；准备查询与提交均复验当前状态。召来通过同一移动命令检查各人物的出发据点，不对接收据点施加这两个限制。该门槛不扩展到任免、褒奖等势力管理操作，依据见[RE-0073菜单补证](../../research/findings/RE-SAN9PK-0073.md#菜单禁用条件与提示补证2026-10-07)。

重制版保留多来源分组、单目的地、君主跨势力专用迁移和参与者占用不变量。目的地建模为显式声明 `CanHostPersons` 的可驻留对象，不把所有运行时子类压成城市，也不得把障碍物、未完成设施或已移除对象仅因属于“地域建筑”便视为合法目的地。电脑、委任和玩家命令必须共用该最终验证。

## 状态与不变量

人事倒计时在每次每日命令前先消耗一天，再判定到期，最后推进游戏日期。令提交倒计时为N，结算日相对提交日的偏移为`max(0,N-1)`；0与1均在首次每日命令阶段结算，不能在提交时立即兑现。例：1月1日提交10天任务，1月10日结算；11天任务在1月11日结算。`JourneyDays`保留原始倒计时，任务`Due`保存实际结算日，保存恢复与查询遵循同一映射。跨旬清除Acted不取消持续任务，也不允许在途人物重新下令人事任务。证据见RE-0112的2026-09-12后续复核。

G04多人物调动创建逐人任务，按人物ID升序创建任务（2026-09-19统一人物顺序选择）；同一命令共享序号而各自拥有任务ID。每人至多一项任务。途中服务驻地保持，到达时原子写入新驻地，目的地必须同势力、可驻人且耐久大于0。跨军团移动允许都督，离任军团根据剩余人员及城市接替或合并；君主不得通过普通移动脱离根军团。

途中服务驻地因战斗、归附、城市独立或撤除失效时，任务的历史出发地点与当前服务地分别维护。优先把己方可用目的地作为新服务地，否则按原路线起点距离、身份升序选择己方可驻人据点；不取消仍有效的在途任务，不重置其路线、进度、到期日或序号。没有可用服务地时走共享失势安置；实际任务目的地失效仍走取消／返程。移动完成时修复的是人物当前关联军团，不从可能已经易主的历史出发地读取旧军团。证据见[RE-0138全链复核](../../research/findings/RE-SAN9PK-0138.md#2026-10-20丢城与丢设施全链复核)。

共享复验以人物当前己方服务地作为执行人附属关系；没有在途行程的本地任务仍要求位于原执行据点。在途探索、登用和计略结算的接收军团、资源账户、兵员及登用接收地点使用当前服务地；历史出发地点继续用于原路线、顺序与任务身份，不据其当前主人决定执行人的归属。各任务目的目标与条件仍由其规则独立复验。

搜索、普通登用成功/失败及任务取消都创建归队任务，被登用者单独归队。返回原有效服务地点，失效时选择几何最近、ID稳定破平的己方可驻留地点；无归处普通人物转当前目标地点在野，势力灭亡/君主特殊迁移由G06/G09处理。目标改属、移动或被另一任务处理时，引用它的任务只取消一次，其他执行者立即进入返回。城池失守或设施拆除时，该处理同样覆盖已经在返程中的人物，复用公共返程选择有效己方据点。原作对象变更通知与返程重建证据见[RE-0112](../../research/findings/RE-SAN9PK-0112.md#2026-09-13人物返程途中目的地失效复核)。

返回时间保留原链的剩余倒计时修正：令事件目标到返回地的基础天数D、去程剩余R；普通D≥R时取D−R，否则D；探索令Q=max(10,ceil(D/10)×10)，Q≥R时取Q−max(R,Q−D)，否则D。每日阶段已先消耗一天；正常到期R=0的返回为D，搜索返程不凑十天。`ReturnLeg`保存起点、初始返回天数及创建阶段；稳定下令创建仍用max(0,N−1)，每日命令结算中新创建任务的到期偏移为N，不强加至少一天。每日命令遍历结束、日期推进及地图更新后，单位/建筑阶段继续结算已到期的归队任务，不再次递减倒计时，也不重复执行探索或登用。

例如1月1日探索本城，1月10日完成探索并生成0天归队，推进到1月11日后的单位/建筑阶段并回驻地，在新旬恢复后可用；同坐标不同对象采用相同规则。附属地域若基础距离1天或10天，1月10日新建的返程仍须等待后续每日倒计时，1月11日下令时不可用；不能用归城关系免除实际返程。同地登用的执行者与新入仕人物也遵循统一归队阶段。

出发、到达、归队与官职/治理变化重选现场负责人，排除任务中的人物。旬恢复清Acted不会清持续任务；完成或取消当日置Acted，后续正常旬恢复释放。保存恢复保留完整任务、历史签发者与占用；军团解散或交接控制后历史签发者不作为新命令授权凭据。

- 输入：稳定人物列表、各人物当前所属对象/势力、目的对象、身份和占用状态。
- 输出：人物对象/势力位置、必要的部队归属及占用释放。
- 不变量：失效或不可驻留的目的地不得写回；批量任务按人物ID稳定处理；跨势力君主迁移必须同时维护势力与部队引用；占用位必须最终释放。

## 行程位置与返还不变量

新建行程统一查询据点当前设施坐标，非设施地点使用内容位置；保存出发与目的坐标快照及野战目的标记。存档校验、到期时间和返还使用已保存路径，不以当前重建坐标改写历史行程。返还到新归队地点时只查询新目的的当前位置。

途中取消以实际已排定去程倒计时扣除已过天数；探索和四类外交使用相同旬取整修正：原始返程距离天数D，Q=max(10,ceil(D/10)*10)，去程剩余R，Q≥R时返程为Q-max(R,Q-D)，否则为D。正常抵达后R=0，返程为原始D，不取整到10天；已经进入返程后再次改道，D≥R时为D-R，否则为D，不再应用外交去程修正。外交返还保留使者业务标记，重定向继续保留；获释俘虏和随行人员不继承该标记。

依据见[RE-0118返程证据](../../research/findings/RE-SAN9PK-0118.md#g08-audit-diplomacy-return)。

## 多人探索（2026-10-18）

探索采用批量派遣：客户端从当前据点选择一名或多名可行动武将，共用一个目标地点；人数以合格候选集合为限。公共`SearchCommand`使用`OfficerIds`集合，单人使用单元素集合。提交先复验全部成员及控制权限，空集合、重复成员或任何失效成员均整批拒绝，不产生部分行动占用。按人物ID升序建立独立探索任务，共享命令序号、分别保存任务ID和按人物／日期／目标决定的发现骰；不合算能力，不增加队长或团队成功率。AI仍按既定策略单人选派。

准备窗口显示分页已选名单，候选首页与已选名单的第一数据列为军师意见：空白表示没有可用意见，×表示不利，○表示有利，◎表示三顾专用提示（不是必定成功）。候选名单与已选名单默认按◎、○、×、空白排序，同档按有效政治降序、人物ID升序排列；意见按每人的当前目标查询，换地点后刷新并重排，手动选择后显示顺序不改变已选集合或领域结算顺序；意见列仅显示符号、不另加标题和悬停说明，候选页保留原有选人提示，初访／再访继续使用原有军师对白。查询只读，不消费随机。未手动编辑名单时，选定或切换地点默认选择全部○／◎武将；未选地点、无军师或无推荐者时留空，仍可手动选人（包括唯一候选）。手动确认过名单后，切换地点保留选择，显式清空也不被自动补选。预览名单右侧固定展示排序后的第一名已选武将，翻页不替换头像；军师对白仅针对该代表，代表或目标变化时刷新，无人则无对白。整批出发也由该代表发言一次。

后续按公共任务顺序逐人结算，前人的发现、一次性事件消费及资源变化影响后人，事件等待回答后继续剩余队列。每人独立归队。全部出发后统一维护大将；到达／归队继续在各任务结算边界维护，可能产生同城连续换任事件，保持后续规则读取正确状态。本次不新增换任通知或整日事件合并。

命令载荷变化将日志格式升至121、录像格式升至30，规则v148；存档格式117和逐人任务结构不变，内容包无需转换。

### 其他单人任务的批量改造参考

本次可复用的是“批量提交、独立执行”。先确认目标任务是否仍按人独立结算；需要共同支付、合算能力或团队结果的任务应另定领域规则，不能直接套用探索。

1. **命令与权限**：将执行者改为集合，单人调用也传单元素集合；同步玩家入口、AI、准备查询、序列化及军团控制校验。参考 `SearchCommand`、`CorpsControl.Authorize`。由 Core 先校验整批成员、目标和资源，再建立任务；有费用的命令还须校验整批总额，不能只逐人检查当前余额。
2. **任务与确定性**：参考 `PersonnelMissions.StartSearch`，按人物 ID 固定顺序创建独立任务，保留各自来源、行程和随机输入；共享命令序号，首任务使用命令 ID，其余使用世界任务 ID 分配器。提交只产生一次事务，失败不留下占用或扣费；出发后的公共状态维护沿用提交边界。
3. **结算与交互**：继续复用原单人任务的到达、待答、失效和返程流程，后人读取前人结算后的世界。多人共享目标时，明确目标被招募、宝物被取走、一次性事件被消费后，剩余任务应如何处理；不要在派遣时冻结整批最终结果。
4. **草案与界面**：参考 `PersonnelDraft`，区分已选集合、显示排序和对白代表，代表不参与替代其他成员结算。预览只读并绑定世界版本；默认推荐与手动编辑分开，保留显式清空，换目标刷新预览，执行时重新校验。名单复用多选与分页控件，意见、到达时间按任务语义展示，文案接入 `TextCatalog`／`CommandText`。
5. **协议与验证**：命令载荷变化同步日志、录像和规则版本；是否升级存档或转换内容包由实际持久化结构变化决定，不添加旧单人字段兼容分支。至少覆盖整批拒绝不改状态、输入乱序结果一致、逐人占用与返程、共享目标竞争及待答续办、预览只读和保存／回放一致。现有示例见 `PersonnelMissionTests`、`SearchDecisionTests`、`SearchOutcomeTests`、`BeastSearchTests` 与 `PersonnelCommandTests`；运行入口见[测试说明](../../tests/README.md#运行入口)。

## 验收标准

客户端召来固定当前设施为目的地，从其他可用己方设施选择人物并显示逐人的来源／预计天数；移动从当前设施选择多人，再选择其他可驻留己方设施。子名单编辑和地图选择均属于本地草案，取消不占用人物；执行以一条批量命令复验全部成员并原子提交，召来／移动均从整批成员按统辖优先级选择一名发言者，只显示一次出发对白。查询与提交共用领域资格和计时，不以目录显示时间创建另一套行程。

- [x] 多来源召回按来源分组且全部落到同一目的地。
- [x] 普通移动、都督跨军团移动与根君主保护分别覆盖；君主跨势力/灭亡归G06/G09。
- [x] 已占用人物被拒绝，成功/失败后无占用泄漏。
- [x] 本城探索、同坐标目标、正距离地域返程、同地登用及发现人物的独立归队覆盖日内阶段、下旬可用性、保存恢复与重放。
- [x] 0/1天首次每日阶段、10/11天跨旬边界及20天搜索的结算日期有公开测试；提交与跨旬保存恢复保持事件一致，途中Acted恢复不释放任务占用。
- [x] 电脑、委任和玩家调动均拒绝障碍物、未完成设施、已移除对象及其他 `CanHostPersons=false` 的目的地，且失败零写回。
- [x] 测试不依赖原版文件或研究地址。

## 未决问题

当前已采用行为没有待定规则；实现范围与后续阶段边界如下。

正常归队和异常返回依据见RE-0112收尾复核，采用的几何退回和日内调度选择见[实现依据审计](../../docs/g04-implementation-audit.md)。G04不执行单位地形寻路或战争撤退；这些由G05/G06接入，不以贴图实例代替人事任务。

## 任务中止与到达反馈

玩家直接控制的在途人事、计略、外交或修行任务因目标／目的地变化而中止、且执行者仍能开始返回时，先显示执行者的中止对白，再显示选定返回地的撤回说明，并写入独立进行记录。原作使用公共命令名称，不按取消原因另造对白。执行者死亡、被俘、改属而无法继续本方任务，没有返回地，或已经在返程中再次改道时，不生成该主动中止演出。正常完成转返程不说中止台词。

正常移动到达和每日阶段的归队生成无指定人物发言的到达说明与记录；同批、同日、同目的地合并人数，君主优先。日期推进后的零天归队收尾保持安静。发生时事实保存命令、人物、归属／军团、目的地和通知资格，表现层不从最终任务是否消失倒推结果。计略／外交同一次主动中止不再额外重复通用取消记录。证据及赠与退款重制边界见[RE-0112](../../research/findings/RE-SAN9PK-0112.md#2026-10-23任务中止到达与归队的消息渠道)。

取消赠与时，返程任务另持有钱粮载荷，改道完整交接，抵达只入库一次；普通到达通知的省略不省略实际入库记录。执行者丧失本方资格、没有返回地或势力退出时，按[赠与载荷规则](BEH-DIPLOMACY-0002-command-negotiation-and-resolution.md)结清途中损失，不在返程任务删除时自动退款。
