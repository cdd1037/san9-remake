# 优化伴侣对三国志9威力加强版的改动汇总

整理日期：2026-09-13。范围：本地 San9PKHard 源码、设计公式资料及优化伴侣 2019 年版说明。

本文按玩家是否能独立控制改动分类，供对照原版与理解优化伴侣使用；不代表重制版已采用这些规则。

## 阅读口径与来源

- **隐式改动**：随伴侣安装的基础改动，没有独立设置入口。其结果仍可能受参数和其他选项影响。
- **可控制改动**：有勾选项、数值参数或配置表。存在选项不等于默认启用；实际状态受加载的配置文件影响。
- **事实·代码**：本次查看的源码直接支持选项、绑定或分支存在；不等于已完成游戏运行验收。
- **待验证·说明**：帮助或更新说明描述的行为，本次未逐项独立复验。表中“改动”列按作者说明概括，不提升为已确认原版事实。
- **资料已校核**：公式资料已包含项目对机器实现的校核；本次引用该结果，没有重新进行逆向或对照实验。

## 一、隐式改动

本表为基础改动的功能摘要，主要依据 S1；行为效果状态为“待验证·说明”。存在明确开关的部分移入下一节，避免将旧帮助的“优化”章节误当作全部强制启用。

| 类别 | 改动 | 相对原版的主要作用 | 来源及边界 |
| --- | --- | --- | --- |
| 进攻决策 | 出征前检查钱粮；优先攻击空城；将武将数量纳入双方实力评估 | 改善目标选择，减少补给不足时盲目出征 | S1·电脑进攻 |
| 进攻协同 | 高统武将分开带队，低统君主减少主动参战；分配多队兵力；野战护卫配合攻城队；协调出征日期 | 强化多队协同 | S1；不把“群狼”一词解释成固定编队公式 |
| 反诱敌 | 据点预警和攻击决策增加对中继点、诱敌战术的防范 | 减少利用电脑目标判断的便利 | S1；未逐场景验证防范效果 |
| 防守反击 | 按来犯攻城能力决定留守兵力；改善武将、兵法、阵型及兵数配置 | 提高主动防御质量 | S1；接力救援另有开关 |
| 追击撤退 | 改善反击队追击、撤退；进攻兵力劣势时撤退，并选择路线附近据点 | 减少无效消耗 | S1 |
| 兵力调度 | 内部兵力向边界调度；随兵力分布调配武将；运输路线避开敌方据点 | 加强前线补充 | S1；对玩家边境额外重点布兵另有开关 |
| 蛮族应对 | 电脑势力可以反击蛮族势力 | 扩大电脑反击范围 | S1；使用蛮族阵型为独立选项 |
| 内政决策 | 改善征兵、褒奖、收益、收获、民心之间的安排；平衡兵粮与兵力 | 改善电脑经营 | S1；“电脑自动征兵”还存在独立开关，不能混同 |
| 武将布置 | 减少在兵力很少的设施配置武将；都市邻近设施保留一定兵力 | 减少人员浪费与空虚据点 | S1：分别描述为低于 4000 兵不放武将、邻近设施至少 6000 兵；实际边界待复验 |
| 离间与探索 | 改善离间目标选择，允许重复离间，限制执行天数；扩大电脑探索范围 | 加强人才竞争和探索 | S1；禁用电脑离间、允许探索宝物为可控项 |
| 俘虏外交 | 电脑可拒绝交还俘虏；提高俘虏交换金额和宝物估价 | 提高人才与宝物价值 | S1 |
| 官爵分配 | 按能力分封，并调整原先的官爵属性限制 | 改善电脑任用及自制剧本适配 | S1 |
| 联盟 | 综合都市数、士兵数选择联盟目标；增强联盟对信望的影响 | 更重视势力综合实力 | S1；联盟时间、反玩家联盟系数仍可配置 |
| 军事成本 | 出征费随兵数变化，提高救援出征费 | 提高军事行动成本 | S1 |
| 商业与储备 | 玩家与商人的钱粮交易量减半；军团兵粮上限调整为 300 万 | 限制交易便利与储备 | S1；收入递减门槛可配置，另表列出 |
| 处斩代价 | 处斩俘虏减少势力信望 | 增加处斩的战略代价 | S1 |
| 熟练度分配 | 区分主发、联动、其他队员收益；攻城阵型增加更多攻城熟练度；部分计略成功及建设增长相关熟练度 | 将成长与实际行动关联 | S1、S3·28；动态增量和仅发动时增长为独立开关 |
| 智力兵法 | 增大智力差影响；习得但未装备教论、破陷也提供部分识破；调整减损效果和智力兵法带动物理兵法 | 重分配智力、已学兵法与抵抗价值 | S1、S3·23；减损后剩余效果约由 30% 改为 50%，不是剩余效果降低 |
| 混乱效果 | 将混乱威力纳入效果计算 | 允许威力参数影响持续效果 | S1、S3·24；S1 后部配置说明有相反表述，不能同时照抄 |
| 设施兵法 | 港口使用齐射，城塞使用连射；改善发动武将选择；缩短设施智力兵法间隔 | 加强设施作战 | S1；设施属性还可能被配置表覆盖 |
| 攻城能力 | 攻城熟练度参与攻城阵型对守兵、对城壁数值计算 | 提高攻城专长价值 | S3·15、16，资料已校核：对应比例分母为 2048 |
| 象兵抗性 | 取消步兵兵法弱点，改为部分抵挡步兵、骑兵兵法 | 改变象兵克制关系 | S1、S3·19 |
| 阵型行为 | 投石攻击时停止移动；运输、长蛇尽量绕过障碍 | 改善攻城和行军行为 | S1 |
| 救援计略 | 降低成功率 | 限制救援效率 | S3·10 描述为原成功率减 25 |
| 夺取计略 | 夺取金额与目标军团资金关联 | 调整计略收益尺度 | S3·12；S2 明确指出玩家夺取时原加强金额代码无效，不能宣称玩家必然增收 |
| 俘虏概率 | 对围攻对象数量做递减修正 | 削弱堆叠围攻数量对俘虏率的放大 | S3·25；最后据点武将处理另有开关 |
| 阻击公式 | 改写熟练度与阵型的概率计算 | 调整狙击效率 | S3·26，资料已校核；系数与阵型特殊效果可控制 |
| 伤兵容量 | 设施伤兵上限调整为士兵上限的一半 | 限制设施容纳伤兵 | S1；伤兵生成比例另有开关 |
| 电脑军团 | 禁止电脑新划分军团改为默认加入 | 改变电脑组织结构 | S2·2019 年 7 月；S5 对应旧开关写入被调整，现选项控制合并副军团 |

## 二、玩家可控制的改动

以下设置入口存在属于“事实·代码”（S4、S6；部分分支亦查看 S5）；具体效果以 S1、S2、S3 概括，除标为资料已校核者外仍为“待验证·说明”。没有逐项判定随附配置的默认开关组合。

| 类别 | 开关或参数 | 控制的改动 | 版本与边界 |
| --- | --- | --- | --- |
| 物理兵法伤害 | 士兵数和统率增加兵法伤害；士兵数减少兵法伤害；伤害系数 | 使伤害随部队规模、发动者统率或全局倍率变化 | 源码中兵数减伤和增伤相关入口分开，不能视为单一开关；公式见 S3·20 |
| 远程攻城 | 减少远程兵法对设施伤害 | 耐久抵挡部分弓骑、弩兵兵法伤害 | S1 排除井栏；S3·20 已校核比例分母为 2048，具体前置须保留 |
| 第二兵法 | 开启第二兵法系统 | 已学但未装备的兵法可作为第二兵法发动，物理与智力类型互补 | 限陆战；不包括水军、设施、势力和宝物兵法；不触发联动，详见 S1 |
| 发动机会 | 士气影响兵法发动概率 | 调整反应入口的随机门控 | S3·17 已校核：阈值为 `50 + 士气 - 80`；不是全部兵法最终成功率 |
| 发动概率 | 统率和智力影响发动概率 | 物理、智力兵法分别受执行统率、执行智力影响 | S1 描述倍率为 `min(150, 执行能力 + 60) / 100` |
| 编组参数 | 一至五人部队发动系数 | 按队内武将人数设置发动相关系数 | S4 的五个 `PersonKillerProp` 参数；未独立核验精确计算链 |
| 兵法联动 | 同系物理兵法联动 | 同一兵种体系内不同级别兵法可联动 | S1 |
| 联动阵型 | 箕形利于联动，雁行附加阻击概率 | 调整阵型特殊效果 | S2；取代旧版“雁行利于联动” |
| 水军 | 调整水军兵法发动率 | 未习得部队所用船只时，水军兵法发动率降低 | S1 描述为减半 |
| 水军兵法 | 艨艟可发箭雨；斗舰不能发箭岚 | 改变船只可用兵法 | S2；禁用斗舰箭岚后，电脑水战进攻优先选楼船 |
| 普攻统率 | 队内最高统率决定普通攻防 | 改变部队普通攻防所用统率来源 | S1 |
| 耐久防御 | 增加耐久普防系数 | 耐久防御系数由 0.4 提至 0.6 | S3·15，资料已校核；不是加倍 |
| 破城 | 设施耐久为零即破城 | 将零耐久设为攻陷条件 | S1；最低耐久处理与破城行为不能当成原版公式 |
| 低耐久状态 | 都市耐久很低时容易混乱 | 据点低于最大耐久五分之一时可能混乱 | S1；S5 存在 `m_bLowDurabilityChaos` 分支 |
| 战后恢复 | 减少伤兵率 | 减少战斗损失转化为伤兵的比例 | S3·22：设施分母 10→12，部队分母 10→13 |
| 领袖作用 | 君主、都督交战随机鼓舞 | 无需装备鼓舞也可能发动 | S1 |
| 战争破坏 | 交战破坏内政系数 | 调整交战对内政的破坏程度 | S1 |
| 寿命 | 武将长生不老 | 阻止寿命耗尽死亡 | 不代表免疫阵亡或处斩 |
| 阵亡 | 高能武将可阵亡；部队大将可阵亡；单挑阵亡系数 | 调整人物豁免和阵亡概率 | 原版高能力门槛在 S3·27 为基础四维最大值至少 80，旧帮助措辞不精确 |
| 俘虏 | 不保证俘获被灭势力武将；最大俘虏系数 | 调整灭势力时人物处理和据点俘虏人数上限 | S1、S4；最大俘虏数按人数与系数计算并向上取整 |
| 处斩 | 禁止电脑处斩俘虏 | 限制电脑处斩行为 | S1 明列君主及电脑之间处斩的例外；S2 又调整实现，不能写成全局禁止处斩 |
| 熟练度成长 | 动态增加熟练度；仅发动兵法时增长 | 调整熟练度增长速度与触发条件 | S3·28 校核了动态增量的整数运算；不是旧文的浮点比例 |
| 能力成长 | 动态增长能力；增加能力上限 | 低能力更容易成长，可提高上限 | S1 上限描述为 125；S3·29 区分基础能力与执行能力 |
| 小兵培养 | 培养开关、基础能力系数、男生比例 | 调整小兵生成和培养收益 | S1、S4 |
| 相性 | 相性影响离间和登用；相性同化系数 | 调整相性差作用及向君主相性靠近的速度 | 同化有同处据点或部队等条件，见 S1 |
| 计略限制 | 禁止电脑离间；禁止电脑烧夷 | 禁用对应电脑行为 | S4、S6；与加强计略效果不同 |
| 烧夷 | 增加烧兵粮效果 | 调整烧粮概率、数量和耐久损伤 | S3·13；不是只添加一项无代价收益 |
| 人事调动 | 禁止武将飞调 | 禁用移动、召来菜单 | S1 |

| 电脑资源 | 增加电脑钱粮收入；电脑自动征兵 | 直接增强电脑资源或补兵 | S4、S6；区别于基础内政决策优化 |
| 电脑扩展 | 可探索宝物；启用蛮族阵型 | 扩大电脑探索、出征选择 | S1、S4 |

### 可编辑配置表

| 配置表 | 可控制内容 | 说明 |
| --- | --- | --- |
| 武将 | 可习得最高兵法、精进熟练度上限、亲密度 | 影响学习与联动；基本信息栏按 S1 为只读，不是通用人物编辑器 |

| 阵型 | 对部队、对守兵、对城壁、守备、机动力及其他阵型参数 | 改动数据本身；与固定算法补丁分开理解 |
| 兵法 | 威力、间隔、学习所需熟练度 | 混乱相关旧帮助有冲突，按 S3 的实际计算进一步判断 |
| 配置同步 | 保存、加载及自动同步配置 | 新游戏或读档时可能将配置写入游戏，或从游戏读取；配置文件影响实际启用状态 |
| 玩家势力 | 动态选择玩家势力 | 改变受玩家规则识别的势力，见 S1 |

## 四、2019 版差异与公式易错点

| 项目 | 旧说明或易误读口径 | 应保留的结论 |
| --- | --- | --- |
| 人口分配 | 兵役分隔点只影响兵役 | S2 指出旧代码还影响非兵役人口流动；新版另设都市人口系数并重写兵役分隔点 |
| 都市人口系数 | 所有城市人口价值相同 | 五档为 2、3/2、7/6、1、2/3；相同民心下，长安与武威的兵役增量可为 3∶1，非兵役人口比例也向该比例趋近 |
| 玩家兵役惩罚 | 城市系数替代原玩家惩罚 | 两者可叠加。S2 的“单城可少至电脑的 1/12”是特定城市权重和分隔档位组合，不是所有玩家城市恒定倍率 |
| 电脑军团 | 禁止划分军团全部由开关控制 | 2019 年 7 月禁止新划分默认加入，选项控制合并电脑副军团 |
| 自动配置兵法 | 始终可以独立关闭 | 2019 年 7 月已移除该选项，功能默认加入 |
| 联动阵型 | 雁行代替锥行提高联动 | 2019 年改为箕形利于联动、雁行增加阻击概率 |
| 耐久普防 | 加倍 | 实际由 0.4 提至 0.6，即提高 50%（S3·15） |
| 士气发动率 | 士气直接决定最终发动率 | 修改特定反应入口门控，不能替代整套兵法发动公式（S3·17） |
| 兵数统率增伤 | 超过一万兵、统率超过 70 才增伤 | S3·20 的已校核高兵数分支使用 `max(统率 - 60, 0)`，并保留逐步整数截断；此外源码存在独立兵数减伤开关 |
| 定点比例 | 攻城熟练度和远程减伤按 2000 为分母 | 对应补丁实现为 2048，不能直接照抄旧文近似式（S3·15、16、20） |
| 熟练度成长 | 按旧文浮点比例增长 | 已校核算法先应用精通系数，再按当前熟练度分档、整数除法计算（S3·28） |
| 兵法减损 | 减损由 70% 降至 50%意味着伤害更低 | 指被抵消的比例变小，即剩余效果由约 30% 增至约 50% |
| 阻击参数 | 模板立即数就是最终系数 | 安装时被配置覆盖，系数为 `40 - 2×配置值`；默认配置值 5 对应 30（S3·26） |
| 原版 Bug 分析 | 公式资料提出正确公式，因此伴侣已修复 | 必须另查实际安装补丁；不能把作者建议自动写成已实现改动 |
