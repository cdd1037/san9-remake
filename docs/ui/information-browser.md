# 情报界面

情报按钮及右侧名单快捷菜单打开十项入口。行为依据[BEH-UI-0004](../../specs/behavior/BEH-UI-0004-information-browser.md)，设计取舍见[DEC-UI-0007](../../specs/decisions/DEC-UI-0007-information-browser.md)，原作调查及IDA同步见[RE-SAN9PK-0161](../../research/findings/RE-SAN9PK-0161.md)。

## 当前行为

总括选择／解除使用原生金色四帧按钮，中段平铺。普通浅灰黑描边，悬停／按下白字棕描边，禁用灰字黑描边，禁用悬停黑字白描边；仅使用禁用素材帧，不额外压暗整颗按钮。按下文字偏移(2,2)，点击后的键盘焦点不维持悬停亮帧。依据见[RE-0177](../../research/findings/RE-SAN9PK-0177.md#总括按钮高亮复核2026-09-27)，画面待验收。

公共目录正文高亮按按住、当前行、已选项的优先级使用源资源第2、1、3号帧；普通当前行为暗金色，按住时为更亮的黄白色。左右端与中段同步切帧，保留一像素拼接重叠，正文文字不因按下偏移。依据见[RE-0151](../../research/findings/RE-SAN9PK-0151.md#目录行选择与禁选复核2026-09-27)。

公共目录的普通浏览行在可用行内松开左键时激活，按下状态仅负责瞬时反馈。多选目录采用重制交互：在可用行按下左键立即切换选择，按住划过其他行时统一应用起始操作（从未选行开始则选入，从已选行开始则解除）；快速移动补齐沿途行，往返经过不反复切换，禁用项跳过。松开、切页、排序、滚动和窗口失焦结束拖动并清除按下反馈，已完成的选择保留；表格外松开也结束，且不额外触发一次点击。拖至上下边界处理到当前可见行，不自动滚动。多选满额时未选项变灰并禁选，已选项仍可取消，取消后恢复其他候选；人数上限只限制选入，不阻断未选行的悬停、当前行高亮和头像／说明预览；选择框仍响应自身悬停。鼠标和回车遵守同一选入限制。选择框的悬停只由自身16×16区域决定，离开后已选用第2帧、未选用第0帧，不把正文当前行当作选择框悬停。本约定不改变表头和页签按钮。

共用目录、详情等 UI 皮肤在启动时统一加载并常驻，加载完成后才进入战略界面；人物与宝物头像仍按需加载，不增加窗口切换等待状态。资源生命周期见[纹理资源](../texture-resources.md#所有权与预算)。

点击列头排序；滚轮、滚动条、方向键、PageUp/PageDown、Home/End浏览。点击行或Enter打开详情；其他情报详情可切换上一项/下一项并打开关联名单。武将详情使用右侧18人名单：移入只改变焦点，单击或回车换人；状态/兵法切页、宝物查看均保持当前人物上下文。Escape、右键或关闭按钮逐层返回，保留原名单状态。势力与都市一览的地图按钮切换全国情报图，悬停显示摘要，点击标记打开详情；关闭详情返回原模式，一览按钮恢复表格。其他情报的定位操作不改变地图命令起点。年表采用下述独立文本页，“输入年表”按钮暂时禁用。

这些窗口呈现当前查询已投影的领域状态，尚未逐项对齐原作全部字段、说明文本与交互。Core/Application 已具备人物生命周期、出征、移动、战斗及存档能力；客户端相关操作和显示覆盖须另行核对，不能把 UI 未接入写为领域未实现。记录和年表属于可持久化的会话状态，但客户端储存／载入入口仍未接通。外交显示关系数值，不臆定文字等级阈值。

## 分层与数据

`InformationBrowser`的历史栈保存`InformationPageContext`，每个上下文独立持有过滤路由、目录排序／滚动／选中项及详情状态。`CatalogView`直接绑定上下文中的`CatalogTableState`。`InformationPanel`负责切页与候选有效性协调，`InformationPageFactory`装配具体页面；菜单和记录／年表使用独立视图。会话变化只刷新当前页面的数据，保留当前文本视口及导航状态；路由变化才替换整页并释放旧纹理作用域。详情正文或目录几何变化仍可重建局部控件。

武将忠诚列与详情对君主显示横线，但保留高于普通忠诚值的排序键：降序在普通武将之前，升序在数值之后，不按不可用值固定置尾。都督、军师、一般武将仍读取当前忠诚。不清零或修改领域中的忠诚状态。

武将“所属”页的“大将”读取当前任命：驻点人物使用据点大将状态，部队成员使用所属部队的主将引用，不按能力重新选人。大将显示“○”，非大将（含出行中人物）留空，在野或无当前位置的人物显示“—”；排序保留是／否的数值。原作依据见[RE-0152](../../research/findings/RE-SAN9PK-0152.md#大将列取值与显示复核)。

武将“命令”页和详情中的“到达预定”显示人物任务剩余天数，不显示月／日：调动、登用及计略按路程，搜索、外交按十天取整，归队按独立返程倒计时，兵法修行按修行时长。查询考虑任务进度、返程创建阶段和每日命令决策暂停，不修改调度日期。己方无人物任务（含野战部队武将）显示“—”；其他势力及无所属人物显示“**”，不提供可用于排序的隐藏数值。该栏保持原版的人物任务语义，不查询野战部队行军预计时间；生成表格及详情不触发部队寻路。依据见[RE-0152](../../research/findings/RE-SAN9PK-0152.md#到达预定列与人物任务时间复核)。

命令页其余五项由`OfficerCommands`统一查询，名单和详情保持一致，显示词采用原版简体转写（如“探索”“登庸”“撤回”“修行”）：

| 字段 | 取值与边界 |
| --- | --- |
| 命令 | 驻点未行动留空、已行动显示“完”；人物任务显示对应人事、计略或外交命令；野战成员显示所属部队当前有效命令，包括交战目标覆盖与强制撤退，不读取过期的原计划。建设显示内容定义提供的设施名称。 |
| 对象 | 探索为地域，登庸／离间为人物，外交／流言为第一目标势力；其余人事任务及野战成员显示横线，不把部队攻击目标错放此栏。 |
| 目标 | 移动／撤回为地点，部队计略为目标主将姓名加“队”；赠与为资金、兵粮或宝物，请求为被请求攻击的据点，交还为俘虏，流言为第二势力。部队目标使用当前有效命令及目标的实时姓名；设施目标包含当前设施后缀，建设位置显示地域周围。 |
| 布阵 | 武将在部队中的前锋／中锋／后卫，不是鱼鳞等阵形名；无有效战斗排位时显示横线。敌方排位同样可见。 |
| 兵法 | 当前装备兵法；未装备留空，装备但无有效排位时显示横线。采用原版默认“显示他势力部队兵法”，不随命令隐藏；“隐藏敌军兵法”开关按当前约定仅记录，暂不实现。 |

非己方人物的命令／对象／目标分别显示2／4／5个全角星号，不保留隐藏数值排序键。共有无适用值继续使用统一横线，不复制原版重复横线填满各列的字节宽度。自由坐标移动按目标所在地域显示“周围”；独立内容未提供地域划分时显示实际坐标。设施内容未提供名称时使用“建设”，不猜测设施编号。原作事实与重制表示选择见[RE-0152](../../research/findings/RE-SAN9PK-0152.md#命令页其余字段复核与对齐)。

Core保存人物身份、人口、官爵归属、军团、宝物归属和关系值；Application的InformationQuery从同一只读快照投影，InformationBrowser保存模态导航。直属军团与子军团均独立持有必填CorpsTreasury；IsRoot标识直属军团，势力金粮为全部所属军团账户的只读汇总。领域不读取源格式或图像索引。

各文件格式版本见[内容管线](../client-content.md)，旧包重新导入。人物有效能力由当前快照的基础能力、伤势、官职和宝物持有关系计算，查询结果不回写世界状态。转换保留全部100件内置宝物的定义、名称、说明和图像，以及120个宝物槽的发现状态、持有人与发现地域。20个未启用扩展槽保留为Disabled状态，不伪造内容；已配置扩展槽因独立文本来源未接入而明确拒绝。700名内置人物及资源完整进入内容与世界状态，人物和宝物可见性由当前世界快照查询决定。190年初始包含61件未出土、39件已出土宝物，普通情报查询仍为210名可见人物和14件可见宝物，这些数量不参与导入筛选。人物图像角色为information-person-{id}/catalog-person-{id}，宝物为information-treasure-{id}；全部定义的资源与文本引用须闭合。

武将详情由OfficerDetailState保存进入时的候选顺序、查看人物、焦点、视口和页签；OfficerDetails投影数据，OfficerDetailView只显示和转发输入。240×240头像、表字、四维图、四列状态与列传、九类兵法和持有宝物已接入。表字/列传键属于内容定义；列传来自M_RtdnPK，保留原始文本并投影简体。未知命令字段仍显示不可用标记。

右侧名单的装饰与数据独立于地图侧栏；只复用滚动组件和目录皮肤。关闭返回原一览排序和视口。原作证据及主库注释见[RE-0162](../../research/findings/RE-SAN9PK-0162.md)。宝物按钮复用全宝物通用目录，并按当前持有人筛选；关闭恢复原人物详情页签、名单焦点和视口。帮助保留重制浮层。

## 显示与通用表格

详情右下的行政关联按钮复用绿色四帧主体，蓝色主体仅用于武将状态／兵法页签。共用详情动作按钮使用20像素文字，并响应禁用、悬停与按下状态；关闭保留红色主体。此轮按用户对照图调整，画面待验收。

十项菜单采用三段四帧原图，按状态应用文字颜色、描边和按下位移；九段外框按源尺寸平铺。十二条底部提示由原版消息目录转换，包含无部队、无宝物的禁用原因，移出后清除。文字统一通过GameTextPresenter绘制，效果方案与后续评估见[DEC-UI-0002](../../specs/decisions/DEC-UI-0002-modern-text-effects.md)。

武将、宝物及官爵／势力／军团／都市／地域一览接入CatalogView，各目录查询声明页面和列；部队一览共用目录视图，进行记录使用独立文本页。能力页九列，13个页签按7+6排列；行身份、排序、滚动与详情导航分别管理。本人习得、宝物/势力提供及九类熟练度来自转换后的运行时数据。

“学得”使用Core的TacticAvailability查询，将本人永久习得、当前势力提供及当前持有的已发现宝物提供的兵法合并去重。兵法格与详情亮起状态也使用该查询：本人习得优先显示○，仅外部提供显示△。底层成员兵法拥有判断复用同一来源枚举；临时提供不写入LearnedTactics，来源及计数不进入存档，也不在查询之间缓存。

同一目录的各页共享最后排好的名单顺序。切页只更换列值并清除当前表头排序标记，保留当前对象和滚动位置；在新页再次点击表头才重新排序，相等值沿用此前顺序。从详情或关联名单返回也保留该顺序，重新打开目录重新初始化。CatalogView在会话刷新时保留存续对象的相对顺序，移除失效对象并将新增对象追加到末尾；其他情报表格仍在存在当前页排序条件时按最新值排序，切页清除条件后沿用保存的顺序。依据见[RE-0151](../../research/findings/RE-SAN9PK-0151.md#目录切页保留名单顺序2026-09-24)。

情报一览的节点数量由15行视口与当前列数决定，不随记录总量增长。CatalogView与其他情报表格均复用可见行节点；滚动只重新绑定可见数据，同一视口内的选择变化只更新选择显示。行事件按当前滚动偏移取得数据，不能捕获创建节点时的记录。列排序复用已查询的行数据与节点；打开、切页和会话变化时重新查询。完整数据保留在普通C#行数组中，不能为不可见记录创建隐藏控件。主界面与详情侧栏名单同样按固定视口复用节点。

视图回调从当前表格状态取得总行数，不为同步滚动或选择再次执行查询。武将目录在每次查询内建立人物、势力、军团、官职和宝物关联索引，避免逐行扫描完整集合；索引随查询结束释放，不跨快照缓存。

目录框架保留源调色板Alpha，头像从共享大图按归一化锚点裁取96×120区域并显示为64×80。正文在24像素行内垂直居中；正文、表头和页签分别使用已确认的文字效果。共用状态和输入约定见[战略界面](strategy-ui.md)。

人物和宝物一览的预览图随当前可见行移动：外框右边贴齐表格左边，顶边对齐行高亮顶边，底边不超过逻辑坐标704；图片在框内四边内缩12像素，宝物显示为120×120。悬停、键盘选行、滚动和排序统一按当前索引与视口偏移计算位置；当前行不在视口内或列表为空时隐藏图片与外框。定位依据见[RE-0151](../../research/findings/RE-SAN9PK-0151.md#目录预览图随行定位2026-09-24)。

仍显示“—”的字段需逐项核对当前查询是否支持、值是否缺失，不能统一称为领域未建模；指挥、俸禄、命令和任职等以当前规则与投影为依据，不在控件里另算原作公式。帮助按钮展示重制操作说明。姓名使用现代中文排序，不等同于原版编码排序。标题及关闭按钮文字效果仍待原版核对。

四维图使用固定面板坐标的程序渐变与连续能力轮廓，放大时由着色器抗锯齿；只保留此实现。原版位图方式的取舍见[DEC-RENDER-0003](../../specs/decisions/DEC-RENDER-0003-procedural-officer-radar.md)。

宝物详情使用DetailSelectionState保存排序候选、当前宝物、焦点和25行视口，TreasureDetails投影持有人、说明及增益。说明使用TreasureText.DescriptionKey语义键，导入保留换行，组合包校验引用完整性。点击一览行或按回车进入，右侧点击/回车切换宝物；关闭返回一览并同步最后查看者，保留排序与视口，再关闭回到原入口。

## 官爵、势力、军团、都市、地域

AdministrativeCatalog声明完整18页：官爵就任；势力状态／战力／资金／兵粮／外交；军团状态／战力／资金／兵粮；都市所属／战力／内政／邻接／地域；地域所属／战力／邻接。列矩阵依据见[五类统一审计](../../research/findings/RE-SAN9PK-0161.md#五类目录与详情统一审计2026-09-24)。官爵只提供一览，以内容的IsUnranked排除无官爵，说明和州名来自转换文本，不在运行时比较原作编号。

势力资源合计根账户与子军团账户，士兵／伤兵包括驻防、部队及运输中的兵员。资金与兵粮预测由Core只读EconomicOutlook提供：按当前人员和驻防冻结支出、收入，分别估算至下次季度收入与七月收获；复用运行时俸禄、逐实体军粮、收益与收获公式，每账户独立处理短缺和上限再汇总。不预测未来命令、迁移、战斗或人口变化，不推进模拟或随机流；这不是原作聚合取整的逐位复刻。缺少作者元数据显示“—”；敌方委任及受保护字段显示“＊＊＊”，不携带可排序的隐藏数值。友好仍显示重制关系数值，不冒充原作五档称谓。

AdministrativeDetails明确声明所属、战力、经济等分区，不再从一览列去重拼接。四类详情按势力／军团／都市／地域分别接入14／16／18／21行候选侧栏，悬停只移动焦点，点击／回车切换当前对象；目录及详情状态由浏览历史保存，返回恢复排序、页签、选择和视口。军团关联名单限定当前军团，都市／地域当地人员及部队按实际地域过滤，与地图定位回退分离；君主／都督在上方显示姓名、头像和当前四维图。

`FormationBoardView` 只消费 `FormationBoardData`，把武将点击交还调用方；`FormationVisionView` 只消费内容中的视野几何，独立于部队身份和会话。原始全屏外框及 `G_Jinkei` 51／52牌框、67详情底框已接入，65出征底框用于出征准备。阵形默认可用格由内容定义；当前领域只保存前／中／后排，列位置由同排默认槽按主将优先、人物ID稳定派生，不声称保存原版拖拽位置。自制阵形可定义其他网格和资源；超出一格容量的成员叠排，避免丢失人物。视野使用 `formation_vision.gdshader` 参数化绘制：每级半径固定12逻辑像素，鱼鳞半径3对应36像素，角度来自内容，朝向向上；120×120控件中心为圆心，调整控件尺寸只移动圆心，不把不同半径都拉满。内绿、外青蓝，环间细蓝紫线，逐环透明度与外缘渐透参考原图，边缘按屏幕导数抗锯齿；这是经授权的现代重绘，不追求原贴图逐像素一致。取消原有12环截断，超出控件的部分按显示区域裁切；零半径或零角度不绘制，360度不保留切边。陆水位置采用原版(177,512)／(435,512)。仅作展示，不改变战斗资格。出征准备复用该组件，通过可选的具体格位置及拖拽／双击回调编辑独立草案；部队详情仍只读。目标选择和实际出征提交暂缓，见[设施出征准备](../../specs/behavior/BEH-UI-0001-initial-strategy-screen.md#设施出征准备2026-09-27)。

两张参考图客户区均约(2,39)，缩放1.5。详情在1024×768下：左底框(76,100,520,540)，布阵(136,116,432,264)，格子144×88，牌框120×80，兵法与姓名分别在牌内(24,8,72,28)及(8,42,104,28)居中显示，使用 Label 呈现描边文字，由无主题最小尺寸的 BaseButton 处理点击；右信息框(604,100,256,612)，部队名单使用160像素宽的专用底框（G_Common 55／56，经皮肤转换器处理透明色），从(864,72)绘制，上段裁至452像素，下段从(864,524)衔接；名单行从(898,124)起，宽88；局部对照图以装饰纹理匹配消除两侧裁剪差后，文字横向差约13截图像素，按1.5倍缩放修正8逻辑像素，保留右边界986。陆上／水上能力标题使用现有 `detail-admin-label` 三段金边纹理（G_Common 75～77），位置为(728,508)／(792,508)，尺寸48×24；不使用数值输入底框。使用原生尺寸与共同锚点，核对了贴图边框及透明区。截图量测与[阵位／视野证据](../../research/findings/RE-SAN9PK-0017.md)分别记录，不把量测认作IDA常量。此次仅编译及自动测试，画面由用户验收。

## 年表文本页（2026-10-18）

年表使用独立全屏文本视口，标题为“某某军年表”，22行、24像素行距，按原有记录顺序呈现。日期按年／月／旬逐级省略重复部分，同旬不同日期不重复日期标签；省略基于完整记录序列，滚动不会重新计算日期分组。正文保留姓名、地名强调与势力色块，不使用表头、排序、页签或条目计数。统治和军师条目在新局时记录一次，读档直接恢复；自动事件按事实写入独立的势力历史，继任沿用同一历史，标题显示当前国号或君主姓名。用户既有笔记按纯文本转义显示。持久化、事件范围和内容契约见[统一消息规格](../../specs/behavior/BEH-UI-0006-unified-messages.md#年表历史与进行记录的边界)。

两页共用`JournalPage`的关闭、帮助、悬停提示和滚动输入，各自持有筛选／日期数据与行绘制。进行记录只读取客户端发布历史，`InformationQuery`不再提供旧商业／开垦记录表格；测试分别覆盖发布历史、年表事实与目录查询。

输入年表使用原作金色按钮及坐标，但按当前范围禁用，不绑定点击事件，也不提供输入框；领域已有的笔记命令和存档保持原有行为。关闭与帮助图标保留，超过22行显示滚动条，可用滚轮或上下键等浏览。底栏悬停提示及帮助正文使用原作消息；帮助弹层采用重制排版，进行记录帮助还可打开原作子主题。布局、资源与日期证据见[RE-0084](../../research/findings/RE-SAN9PK-0084.md#年表页面布局与日期分组复核2026-10-18)。实际画面待用户验收。
