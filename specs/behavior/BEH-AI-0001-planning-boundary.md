## 适用范围

适用于 AI 势力在稳定规划边界读取观察、执行分析、生成候选命令并提交选择的公共生命周期。具体威胁评估、兵力投送、意图判断、随机模拟、战区规划算法及难度策略不在本规格内。

## 原作基线

不适用。本规格定义重制版为确定性测试、长期模拟和现代 AI 扩展建立的系统边界，不声称描述原作内部结构或决策算法。

## 重制行为

Application 在稳定规划边界从已提交的世界快照构造势力视角观察。观察只包含该势力获准读取的信息、权威日期和用于确定派生数据身份的状态哈希，不暴露可变世界对象或正式随机状态。规划器读取观察、命名规划用途、确定性预算和诊断级别，返回保持偏好顺序的候选命令、整数评分、理由和可选诊断。

每个候选先经过公共命令验证；只有被选择且验证成功的候选进入公共提交队列。验证失败不写世界状态、不占用命令 ID，也不阻止调用者检查下一候选。分析使用由观察身份、势力和用途派生的独立稳定随机流；重新创建同一上下文会从同一分析种子开始，不改变正式结算随机序列。

诊断只解释已经产生的分析与候选。关闭、摘要或详细诊断级别不能改变分析预算、随机消费、候选集合、评分、顺序或提交结果。

## 状态与不变量

- 输入与前置条件：稳定世界快照、有效观察势力、非空命名用途、至少一项为正的节点或 rollout 预算、有效诊断级别。
- 状态变化：观察、上下文、计划和诊断均不修改世界；只有公共 `Submit` 接受的命令进入待结算队列。
- 始终成立的不变量：规划无可变世界引用；分析随机与结算随机隔离；工作预算确定；诊断不影响行为；玩家与 AI 共享最终验证和结算。
- 失败或无效输入行为：空用途、零或负预算、无效诊断级别及无效候选被明确拒绝，不使用默认无限预算、墙钟超时或宽松 AI 专用提交路径继续。

## 示例与边界

- 同一状态哈希、势力、日期、用途和预算重复规划，候选及顺序相同。
- 同一上下文分别关闭和开启详细诊断，候选完全相同，只有诊断集合不同。
- 分析运行任意允许数量的 rollout 后推进一旬，结果与未运行分析时相同。
- 候选命令使用负序号时，验证和提交返回同一拒绝原因，旬事件中不存在该命令的结算事件。
- 未来战争迷雾只改变观察生成策略；规划器不存在读取完整世界的后门。

## 验收标准

- [x] 不可变观察不暴露 `WorldState` 或正式随机状态。
- [x] 同一观察、用途和预算产生同一分析种子及计划。
- [x] 分析随机消费不改变正式旬结算结果。
- [x] 诊断级别不改变候选命令。
- [x] 零预算、负预算、空用途和无效枚举被拒绝。
- [x] AI 候选通过公共验证和提交入口，拒绝时无部分写回。
- [x] 测试夹具不依赖原版文件、私有样本或研究工具。
