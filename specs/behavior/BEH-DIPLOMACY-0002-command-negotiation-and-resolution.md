## 适用范围

适用于赠与、攻击请求、俘虏返还和劝降的玩家/AI 命令创建、复验、军师反馈、谈判、随机结算及世界状态写回。不规定 AI 如何选择候选。

## 原作基线

玩家与自动路径最终创建相同的类型化命令并共享执行器。赠与按提交资源和接受判定转移资金/兵粮，可伴随宝物、关系和政治成长；攻击请求经过报价/接受阶段，成功后写攻击目标，并按已接受条件释放交换俘虏或转移资金/宝物（不存在本链已确认的兵粮报价）；俘虏返还经过报价但不消费命令保存的随机数，成功后转移俘虏及相应资源/宝物；劝降消费保存的 `0..99` 随机数，成功时进入势力解体与归并链。军师意见是分类反馈，不等同于最终结果。

## 重制行为

保留四类命令的类型化状态、玩家/AI 共用执行器、提交/执行复验、资源守恒、命令特有谈判阶段及关系/人物/势力写回关系。报价、接受与最终效果必须分为可诊断阶段，不能用 UI 分支复制规则。

按[随机约定](../../docs/randomness.md)，赠与、劝降的自动接受及攻击请求的公共咨询参考使用提交时保存的固定条件百分骰：本局种子、用途、下令日期、使者及相关目标身份；攻击请求包括被请求势力与攻击目标。同条件不受无关操作顺序、命令序号、玩家读档或重启影响。资格、关系、资源和阈值在相应阶段重算，玩家选择仍由玩家决定。原作证据见[RE-0171](../../research/findings/RE-SAN9PK-0171.md)。

劝降后的逐人物归属、成长及其他随机后续效果采用独立用途的运行随机，不随接受骰一起锁定。俘虏返还按条件与谈判选择结算，不创建原作未消费的随机字段。军师采用[计略意见约定](BEH-STRATEGY-0001-command-advice-and-resolution.md)：固定条件、查询稳定、不消耗运行流、不读取已保存任务骰。

所有资源预留、命令参数、任务骰、随机状态和事件进入存档与状态哈希。玩家读档保留任务骰，仅改变未来运行抽样；录像精确恢复完整起点，不调用玩家读档换种入口。

赠与载荷在资金、兵粮与宝物中互斥选择，不接入源格式的保留数值。宝物阈值使用共享定义的`LoyaltyBonus`，不另外维护价格或从能力加成推算；字段依据见[RE-0117补证](../../research/findings/RE-SAN9PK-0117.md#2026-09-17-赠与宝物公式输入补证)。

自动谈判选择宝物时，宝物定义以`AutomaticDiplomacyOfferAllowed`表达自动报价资格，以`FavoredOwnerIds`引用具有专属偏好的人物。两个字段属于独立内容规则，不能从当前持有人或人物姓名推导，也不把原版宝物编号、列传码带入Core。无专属偏好使用空集合，默认独立创作宝物允许自动报价；JSON必须显式携带两个字段，缺失不隐式补值。该资格只限定自动报价候选，不扩展为玩家赠与禁令。Importer读取版本表并映射到完整保留的人物身份；无对应人物的配对不生成悬空引用，有多个对应身份时全部保留。俘虏返还自动报价通过该共享规则选取候选。

赠与宝物候选及提交均限本方当前君主持有、已发现且持有人未被任务占用的宝物；其他武将持有物须先没收回君主，不能借外交赠与绕过没收代价。候选与提交复用同一资格；原作候选证据及重制完整复验边界见[RE-0117补证](../../research/findings/RE-SAN9PK-0117.md#2026-10-10-赠与宝物候选与授予边界补证)。

赠与采用主势力账户，提交时复验完整余额并一次预扣；拒绝以饱和扣除代替余额校验。去程任务唯一保存预付载荷，宝物先交使者持有。接受时转入目标主势力账户或当前君主；拒收资金／兵粮在拒收结算时退回来源主势力账户，使者继续正常返程，拒收宝物仍由使者持有。按2026-09-18用户决定，不继承原作拒收资金／兵粮直接消失的行为，避免拒收本身造成没有接收者的资源损耗。资源归属沿现有势力账户模型在谈判结算时确定，不增加返程携款状态。

赠与结算事件分别记录接收量、实际退款量和容量溢出损耗，满足预扣量＝接收量＋退款量＋损耗量；来源或接收方账户上限仍遵守公共资源规则，溢出由资源事件明确记录。拒收仍降低关系5，不触发成功成长；宝物及接受流程不变。因目标、执行者或据点失效而取消时，同样退回来源账户，但不写拒收关系或成长。取消和拒收共用退款计算，各自只在当前活动任务结算一次；返程不再携带已结算载荷，重复回答、取消返程、归队、存读档和录像不得再次退款。

### 旬边界外交与选择续行

自动宝物报价按君主当前已出土持有物筛选，先排除不允许自动报价者，再按稳定宝物身份顺序处理。`RetentionGroup`明确区分武力、智力、政治、统率及其他类，能力为零也保留类别；比较值由对应能力增量或其他类的忠诚增量派生，不另存报价价格。普通物品保留同类较强者，同值保留先遇者；后来的更强者使此前普通保留品进入报价集合。来源君主专属偏好优先保留，替换同类保留基准时不释放旧基准；已有来源偏好基准时其他普通同类物品可报价。目标君主偏好物品可直接报价，但不能覆盖来源君主偏好。最后按忠诚增量升序稳定排序，取首项报价；同值保留候选入列顺序。该顺序以稳定身份替代原作枚举槽位，支持独立内容；分类和特殊偏好依据RE-0118及RE-0141。此规则只决定自动候选，不执行支付或宝物转移。

四类外交去程根据出发地与目标君主当前所在据点或野战位置计算基础行程，向上取整至10天倍数，最少10天。到期任务在日期进入下一旬后、旬更新和新一轮下令前结算，不在旬中触发外交谈判；这是全局旬边界，不等待接收方控制席位。证据见RE-0118的四类外交时序补证。

通用日内暂停与续行仍保留。待决状态在内存记录日内命令或旬边界结算阶段；回答后从对应位置继续，不重复推进日期、日级更新或旬更新。对话、消息、动画的表现等待由客户端组织，不要求无选择的播放等待进入Core待决状态。

使者在旬边界到期时，实际响应方接受、提出条件或接受反要约形成仅在内存续行的决策边界，不允许中途保存或开启录像。世界保留当前日期、待谈判任务、实际响应方及尚未完成的结算阶段与任务队列；不能把外交选择当作季度联盟选择恢复。等待期间只允许实际响应方回答当前谈判，普通下令、结束控制和再次推进均拒绝。

回答后继续当前任务，再处理同日尚未执行的其他任务及剩余阶段；已经执行的每日状态、粮食消费、任务效果和随机抽样不得重复。多项外交同日到达时按现有任务稳定顺序逐项处理，可连续停在不同选择边界。去程任务在谈判完成前仍负责使者占用，最终结算或失效后才转换返程。最终接受时复验对象与报价，付款和转移至多一次；从此前稳定存档继续及录像重放必须得到相同结果。旬完成事件只能在剩余日程真正完成后发出一次。

任务的结算阶段号独立于行程进度：自动处理和玩家回答均可进入下一阶段，但不能重建任务身份、改变抵达日期或提前发出任务完成事件。阶段号与报价只在本次交互内保留，不进入存档，回答必须匹配任务身份、当前阶段和实际响应方；同一任务的旧阶段回答即使携带新的命令序号也拒绝。规则只接受自身支持的阶段，未抵达或不处于当前等待位置的任务不能持有已推进的谈判阶段。该阶段标识为重制续行协议，不是原版字段映射。

## 状态与不变量

### 攻击请求的履约状态

阶段军事策略的重制选择：在当前可控制的空闲部队或出征据点内，将仍有效的本方约定目标排在普通距离排序之前，再沿公共命令资格、外交保护及可达性检查。不可达或当前禁止攻击时回退普通候选，不为履约自动强攻盟友，也不因设置命令提前奖励。读取当前快照，不缓存过期目标；来源、编队及兵力预算仍沿既有有限策略。此项是阶段级请求消费者，不代表原作完整军事AI已复刻。

谈判成功后，由受请求方持有请求方、指定据点和剩余19旬的有向约定。每个受请求方同时至多一条，双方互相请求是两条独立约定；持久化集合不继承原作势力槽位。请求配对保护普通自动选敌，不能只记录一个军事目标而丢失外交关系。

每次旬更新将正期限减1，归零处理未履约。对指定据点开始实际普通攻击时即履约，受请求方基础信望加10并清除；占领入口可以处理尚未结算的履约，已清除者不得再次奖励。设置攻击命令或靠近不等于履约。依据见[RE-0118补证](../../research/findings/RE-SAN9PK-0118.md#2026-09-16-请求方向期限履约与联盟清理补证)。

有向约定的到期处罚由持有人承担；主动毁约由主动方承担。每条实际解除的约定使双边关系减20、责任方基础信望减20、责任方在职非君主人物忠诚减义理，经过公共有界写回。双向约定不得静默去重为一次代价。新请求被接受且请求方与旧约定不同，先结算旧约定毁约，再执行新请求成功效果；执行时已有同请求方、同目标的约定则收尾，不重复付款、提高关系或重置期限。

联盟形成先处理成员与联盟目标的请求配对，责任方为加入成员，再应用联盟关系公式；不能对已经规范化后的关系追加同一毁约损失。成员之间的约定若请求攻击对象属于联盟目标则保留；请求攻击对象有有效君主且属于其他势力时无处罚结束。对方灭亡、目标失效等对象清理与主动毁约分开表示，不能统一收取罚款。玩家同意前的影响查询须包括实际有向约定、责任方及处罚顺序。

运行态记录签约时目标归属，作为判断易主失效的约定条件；目标归属变化则无处罚取消，不将请求自动转向新主人。当前已接旬期限、履约/毁约、联盟清理、自动敌我判断、独立内容初始请求和稳定边界保存；请求驱动军事规划及公共外交创建命令均已接入。TC101剧本没有请求元组，原版存档格式有而本项目不导入；不能把剧本宿敌引用当作请求。重制新局如有初始请求，旬调度不自动套用联盟开局豁免。作者只维护双方、目标据点与正的剩余期限；签约目标归属由初始据点推导，建局规范排序，内容指纹包含完整约定。初始集合不覆盖恢复后的当前集合，缺字段、重复持有人或无效引用必须拒绝。

G08采用已核对的繁中PK 1.0.1.0算术；`S(A)`沿用当前分段执行能力，整数除法向零截断。公式不替代外交资格和显式玩家选择：赠与阈值基础为`S(使者政治)/10 + max(0, 关系-60)`，资金、兵粮、宝物分别加`资金/200`、`兵粮/2000`、`宝物忠诚增量*2`；免费攻击请求阈值为`使者政治+关系-80`；俘虏补偿为`max(500, ((最高能力+次高能力)/2)^2/4 - 8*(使者政治+关系))`。对应 [RE-0117](../../research/findings/RE-SAN9PK-0117.md)、[RE-0118](../../research/findings/RE-SAN9PK-0118.md)。

赠与接受时关系增加`max(60-当前关系,20)`；攻击请求成功增加`max(40-当前关系,10)`；劝降拒绝减少`max(10,当前关系-39)`，均经统一关系服务夹到0至100。仅数值实际变化时产生关系变化事件。

- 输入与前置条件：命令类型、来源/目标势力、使者、目标对象、报价或赠与资源、当前资格和显式随机上下文。
- 状态变化：命令占用；资金、兵粮、俘虏和宝物转移；关系、政治成长、攻击目标或势力存续变化；结果事件。
- 始终成立的不变量：玩家和 AI 共享命令与结算；无效对象不写回；资源不凭空产生；使者占用最终释放；军师意见不预写结果；命令类型与事件匹配。
- 失败或无效输入行为：提交复验失败不创建命令；执行时失效则不应用目标效果，并释放预留/占用或给出明确失效事件。

## 示例与边界

俘虏返还报价使用互斥的免费、交换俘虏、资金、宝物、拒绝五类载荷。交换对象为请求方当前扣押、归属释放方的俘虏，包括野战拘押；按当前四项能力总和降序、稳定身份同分排序。有交换对象优先交换；无交换对象且关系至少80才免费，否则尝试资金、宝物，最后拒绝。报价不消耗运行随机、不转移资源；最终支付前独立复验资金或对象持有状态。宝物报价限请求方当前君主持有物；自动候选的保留规则不作为玩家显式报价的额外禁令。免费成功返还给释放方基础信望加2，经过统一有界写回；付费或交换成功不享有该增量，成功均沿原有独立政治成长路径，拒绝关系减5。

公共军师咨询的参考报价／接受规则保留原作算术，不决定生产 AI 的实际选择；生产策略见下文 AI-05。参考资金报价要求当前资金严格大于补偿公式值。请求方接受正赎金`Q`须满足`Q <= 补偿值`、`Q < 当前资金/2`及`Q < 当前资金-俸禄预留`，除法向下取整；负的可支配余额保持负值，不能发生无符号回绕。免费返还用独立报价类别，不以零赎金绕过这些门。宝物接受要求忠诚增量严格小于`min(29, 补偿值/100)`。预留跨度按日历十日块计算：1月1日为9旬、1月10日为8旬、3月21日为1旬、3月30日为0旬，下一季度首日重新为9旬；该跨度不等于距季度边界的精确自然日数。依据为RE-0118报价补证，实际预留人员集合由直属归属及人物集合资格决定，不能用公式测试代替集合验证。

- 赠与余额竞争导致提交资源不足时，不得部分扣除后继续。
- 攻击请求的对方拒绝、报价失败和最终失败是不同结果阶段。
- 俘虏返还不创建无用途的随机字段，按实际条件与谈判选择结算。
- 劝降成功必须原子维护人物、据点、部队、联盟和势力引用。

## 验收标准

- [x] 四类外交覆盖最短10天、距离跨越10/20天边界、野战目标、跨月跨年到期及旬更新前谈判；回答后不额外推进一天。
- [x] 日内及旬边界等待的内存续行与稳定起点录像覆盖接受、拒绝、两阶段报价、同日多任务及跨日继续，已完成阶段不重复消费资源或随机。
- [x] 非响应方、旧谈判回答及等待期间普通命令被拒绝且无副作用。
- [x] 四类命令的玩家与 AI 路径产生相同类型化命令。
- [x] 请求19旬到期、单向/双向毁约责任、开战履约一次性、重复请求不重复支付、对象失效及联盟形成处罚顺序有测试。
- [x] 每类命令的提交失效、执行失效、成功和失败路径有自动测试。
- [x] 资金、兵粮、俘虏和宝物转移满足守恒与所有权不变量。
- [x] 俘虏返还无多余随机字段，改变种子不改变相同条件和选择下的谈判结果。
- [x] 固定命令日志和随机种子得到固定事件与状态哈希。
- [x] 测试夹具不依赖原版文件、机器地址或研究工具。

- [x] 相同条件下，改变无关操作顺序、命令序号、玩家读档或重启不改变提交骰；实时阈值变化仍可改变成败。
- [x] 军师重复查询稳定且不推进规则随机流；军师或有效条件变化会重算。
- [x] 玩家读档保留任务骰，混合流程仍有独立运行抽样；录像精确恢复完整事件与状态。

### 俘虏返还执行接口补充

正式命令到达时由释放方提出互斥报价，再由请求方接受付费／交换；免费及拒绝直接收尾。报价不预扣资源，最终复验后一次结算。军师按公共参考报价入口判断免费、交换或付款可用性；实际谈判由合法响应方显式选择，玩家目标不自动代答。俸禄预留为直属主账户在职非君主人物的官职俸禄总和乘剩余旬块，无官职为1，独立军团、俘虏及在野不计入。

释放人物从当前拘押位置返程，野战使用真实坐标；普通人物没有友方接纳据点时沿公共释放规则安置为在野，君主不得失去接纳地。人员身份变化取消引用该人员的其他返还／交换谈判，取消不产生支付或拒绝关系效果。稳定保存位于谈判完成之后；活动报价及阶段仅在内存续行中保留，旧阶段回答不可重复支付。

2026-09-18采用重制选择：军师意见包含免费分支，替代原作只检查补偿的预测规则。军师意见复用公共参考报价：无交换候选且关系至少80时可免费，否则优先交换，再检查资金／宝物补偿；不再单独维护一套只看补偿的资格。报价不为拒绝时向公共军师判断提供成功条件，军师准确率规则仍有效；智力100军师在相同条件下不会因没有资金或宝物漏报免费返还。目标玩家的选择仍不预测，查询无军师、无效目标及只读随机边界沿用公共约定。

### 请求攻打执行接口补充

`RequestAttackCommand`指定使者、被请求势力和目标据点，提交骰同时包含两类目标身份。抵达时已有同方同目标约定即直接收尾，无报价、支付、关系增长、政治成长或重置期限。正常谈判由被请求方报价，资金／宝物／俘虏再交请求方接受；免费或拒绝直接结算。最终复验目标所有权资格及支付条件，失效取消不视为拒绝。

自动履约检查排除已有承诺、联盟内部请求及攻击对象与受请求方的反向约定；必须有领地属于目标同都市或邻接都市，并拥有都市。选距实际目标坐标最近的本方都市（稳定身份同分），其兵力至少10000，所在都市范围没有关系低于40的其他普通野战部队，含军团的总兵粮至少1000。动态设施从当前地图推导所属都市，不要求作者维护第二份地理引用。

公共军师咨询的参考免费报价要求具备履约条件、没有交换俘虏、被请求方与目标归属关系低于40、请求双方关系至少80，使用政治加关系减80的严格骰门。交换候选存在时，目标君主义理低于6的门为100；否则须能履约，门为政治加关系。仍未选中时尝试付款：义理至少6须能履约且双方关系至少60；资金报价为`10*(300-政治-关系)`，须为正且来源余额严格大于报价，否则尝试宝物，再拒绝。独立内容超出原作能力范围时不产生非正资金报价，按同一互斥支付契约尝试宝物。

公共咨询参考的请求方接受交换；正资金报价须不超过`4000-目标君主义理*(使者政治+关系)+2*目标基础信望`，并严格小于来源资金一半和扣除直属俸禄预留后的余额。宝物须在当前免费门未通过时，忠诚增量严格小于`(关系-40)/2`（向零截断）。玩家显式选择不被这些自动意愿条件替代。军师继续采用重制分类，预测可取得免费或反要约的机会，不读取执行骰，也不承诺对方实际履约。

接受先结算旧请求的责任，再执行支付、关系及成长，建立19旬约定；后续正常旬更新仍递减，不以新签约额外跳过旬调度。支付／俘虏回收与返还命令共用事务内效果服务。报价失败、免费、反要约及最终接受／拒绝通过报价与结果事件区分。

### 劝降执行与势力归并

`DemandSurrenderCommand`与其他外交共用单使者占用、主账户资格、去程和日内响应。目标须为有效普通势力，不得为双方联盟成员或有双向任一攻击请求配对。玩家目标显式接受／拒绝；自动资格不覆盖玩家选择。自动阈值要求势力领地邻接、目标君主允许自动接受，且健康兵及伤兵总量的整数比`来源/max(20000,目标)`至少5；在途增援仍计入所属势力，预备役人口不计入。通过后为`S(政治)*((来源当前信望-目标当前信望)/40+兵力比-10*目标都市数-max(0,5*目标君主野心-40)+10)/60`，两方信望先限于0..1000，所有整数除法向零截断，骰严格小于阈值。邻接读取当前领地归属及公共地图地域连通；据点易主后不能使用旧邻接缓存。

人物显式保存`Ambition`（0..15）及`AutomaticSurrenderAllowed`；后者只限制作为君主时的自动接受，默认允许，不通过人物编号、名字或列传资源在Core推导。Importer将版本特定列传排除映射为语义布尔；JSON两字段必须显式存在，字段进入内容指纹和世界摘要。

成功按同一世界事务归并：先取消目标势力在途任务及指向该势力的谈判，退回可退预留，再汇总根账户及军团账户的资金／兵粮，将总额的一半加入请求方主账户，原账户清空。奇数余量、未转移的一半与接收上限差额不凭空保留，事件记录完整移出量和实际接收量。取消预留先于分割是重制的事务规则，防止已消失任务继续持有资产。

原在职人员逐人以`rnd(100)<对原势力忠诚`判定随降，君主也读取实际忠诚；每人使用独立运行流抽样，按稳定身份排序。判定式与原作相同，但随机流和枚举顺序不保证抽出与原作相同的名单。随降者改属并重置官职、原领导身份和兵法间隔，按请求方君主相性设定忠诚`75+(50-相性距离)/2`。离开者在当前地理位置转为在野；其对请求方忠诚高于45时，按原作的`min(原值-45,5)`增加并遵守255上限。此正增量按2026-09-18决定保留，仅记录[研究疑点](../../research/research-open-questions.md#g08保留疑点与证据边界)。目标势力人员已被第三方拘押时保留拘押地点并清除灭亡归属；未登场等非在职身份不被改成在野。

完整据点与有随降人员的野战部队归请求方主军团；部队保留幸存成员的相对顺序，首人成为指挥者，旧命令、路线和临时接敌状态清除，后续重新下令。这是以显式部队所有权和人员顺序落实原作归并的重制选择，避免继续执行原势力作战意图。无随降成员的部队解除，现地所属都市接收其兵与伤兵为预备役；没有有效都市时显式记录无法安置的数量。人员地理位置及俘虏沿公共释放／安置规则处理，不能保留指向已删除部队的引用。转移资产中请求方自己的俘虏恢复服役；其他势力俘虏继续拘押，空部队解除时按公共释放流程归队或安置。

目标全部军团解除；战败退出与归并共用势力身份退出服务，清除控制席、联盟及攻击请求引用，不收主动毁约代价。变成攻击己方资产的部队命令和临时接敌解除。势力记录以已灭亡状态保留稳定身份，人员、据点、部队、军团及活动控制不能再归属它；旧忠诚记录仍可保留历史身份键。失效谈判不执行归并，明确拒绝只按劝降关系公式扣除关系。接受、拒绝、玩家灭亡终止和仍有第三方时继续同旬均须能保存及重放。


## 外交行程与使者占用

外交正常抵达并结束谈判后，返程按普通距离天数计算，不向上取整至整旬。例如基础距离11日，去程20日，正常返程11日。去程尚未结束时取消／改道，使用已取整去程的实际剩余倒计时修正；已经成为返程后再次改道使用普通返程修正，不因保留外交业务身份而继续套用去程公式。来源、目的地采用当前设施坐标并保存路径快照；具体公式和不变量见[人事行程](BEH-PERSON-0003-recall-movement-and-action-reservation.md#行程位置与返还不变量)，依据见[RE-0118](../../research/findings/RE-SAN9PK-0118.md#g08-audit-diplomacy-return)。

返程只保留使者业务标记，不再携带已结算的付款／赠与／谈判载荷。预算持续到使者实际归队，途中重定向和存读档不释放预算；获释俘虏、普通人事返程和随行人员不占用该外交预算。四类命令均验证正常返程、去程中断和返程重定向，设施坐标变更后可恢复历史路径。

## G08阶段自动外交（2026-09-17重制选择）

以下保留独立历史规划器的有限脚本说明。当前生产 AI 已由 AI-05 共享分配替代，不使用此逐项优先级。

阶段策略以有限、可解释的工作量接入公共命令：每个势力最多保留一个活动外交任务，结束自动势力控制前规划一次；去程、谈判与返程期间不再派第二名外交使者。按当前有效政治能力降序、身份稳定排序考察最多8名空闲人物；每人依次考虑本方俘虏返还、军师有利的劝降、军师有利的请求攻打和改善关系的资金赠与。目标势力最多32个，俘虏及攻击目标各最多16个；这是每次规划的工作预算，不是内容容量或身份范围限制。

请求攻打只考虑关系至少60的受托方与本方关系低于40的第三方据点，已有受托任务时跳过。赠与要求主账户至少20000资金，只向关系40至79的对象赠与2000，优先当前关系较高者。没有军师或意见不可用时不主动规划劝降／请求攻打。所有候选经实时公共验证，执行使用同一命令；规划不消费随机、不预扣资源，命令身份由当前状态确定。该阶段政策为重制选择，不声称复现G11完整自主AI。

玩家仍通过正式响应命令回答日内谈判；自动规划不能代答玩家。无界面验证显式采用拒绝谈判、同意联盟的脚本政策，在选择前的稳定边界保存恢复，完成全部回答后再保存检查点，并比较回答后的事件、状态和最终录像。报告按实际外交／计略事件计数，不以运行成功替代未触发分支的验证。

## P1 主动外交操作（2026-10-10）

赠与、请求、交还、劝降从设施正式外交菜单准备并确认提交公共命令；赠与资源互斥，请求选择势力及设施，交还选择本方俘虏并按拘押方绑定谈判对象。准备不预留资源或占用使者，数值和权限由公共校验决定；预测不泄露实际执行骰。抵达后的补偿或请求待答复用既有谈判窗口；结论和返还进入消息记录，并对已由待答窗口显示的结论去重。原作四类意见采用各自消息而非统一套用一组通用句。证据见 [RE-0182](../../research/findings/RE-SAN9PK-0182.md)，入口、数据与验收见[操作说明](../../docs/ui/mission-corps-commands.md)。

## AI-05 公开谈判选择（2026-10-12）

攻击请求和俘虏返还在报价阶段向所有合法控制者产生同一待决，正补偿再向请求方产生接受待决；免费与拒绝直接按规则收尾。Application 从公开合法报价、关系、当前履约资格与扣除预留后的自身余额选择：俘虏返还优先交换，关系至少80选择免费，否则选择最小可付资金；攻击请求还要求当前可履约且目标为敌。请求方接受交换、免费、至多可支配资金四分之一的付款或忠诚增量至多10的宝物。实际选择通过正式响应命令执行与记录，Core 不替电脑隐式作答，不借用参考意见或任务骰替代策略。赠与和劝降仍保留既有公共自动效果规则。

上述参考报价公式继续用于原作语义的公共军师咨询，不承诺 Application 将采用相同报价，也不承诺请求方后续实际履约。候选收益与响应的范围、玩家权限及排除原因见 [AI-05](../ai-system-design.md#ai-05-已实现行为与证据)。
