# AI 工程边界

2026-10-16退出自主增强策略后，OAI-01～05已接入原版调度、经营、人事组织、军事、计略外交及公共响应。普通电脑、玩家委任和异民族分别按工作权限运行；0～5／61／63、12～17／22～24／55／56、57／58／51／9／59及25～36均有生产执行者，生产没有旧策略回退或切换开关。

- `AutomaticTurnRunner`校验身份／稳定边界后调用`OriginalAiTurnRunner`，后者按直属军团准备策略、有序选择工作、处理公共提交反馈，再结束控制。
- `GameSession`继续负责事务、记录、命令水位、玩家暂停及连续／分步推进。旧缺粮目标、战役承诺、机会冷却、共同分配预算与诊断已删除，不为空缺的原版策略预建状态。
- `AutomaticResponseRunner`继续处理Core产生的电脑待决，并经公共命令提交；玩家仍等待输入。选择沿研究采用规则：求官相性概率、合格联盟参加、公共国号偏好、被俘君主处置及继任；外交报价与接受调用Core，玩家专属探索／修习不生成电脑答案。
- `AiPlanning`保留独立确定性分析随机和脚本预算。`DomesticObservation`、`DomesticPlanner`、`DomesticCommandSelection`仍有玩家脚本／Headless消费者，不由自动结束控制调用；训练选人辅助已收归该脚本。
- `OriginalDomesticWork`与`OriginalAiEconomy`分别实现0～5和61／63；`OriginalAiProjection`提供直属账户、到下一季度／七月的原版保留需求、当前能力与获准拓扑。`OriginalAiStrategy`计算模式、目标、分组及独立排名快照，不读取外国账户、任务载荷或单位命令。
- 内政观察由当前军团持有，同一不可变快照复用完整结果；己方能力投影依赖公共能力缓存和人员归属集合，外方能力不进入观察。官职分配仅计算薪俸，63内层仅刷新单个据点状态。人事据点／人物／任务索引分别失效；登用直接使用公共行程预测返回的同次阈值。
- `OriginalAiStaffing`持有批前配额及组织命令规划；成功变更辖区后重算受影响范围，队尾追加新军团并移除注销引用。`OriginalAiPersonnel`处理人事候选、稳定排序、规划随机和公共提交；23先按未发现人物所在地点筛合法目标，再按来源行程及政治筛人物，用公共探索结果预测配对；无军师不额外停用。
- 55处置触发玩家继任时，`OriginalAiContinuation`在不可保存边界保留不可变游标及剩余候选；回答后继续原工作和后项。全局／军团准备、已消费随机及已提交命令不重复执行，事务失败不发布游标。
- `OriginalAiState`由会话事务持有并保存；实际参数来自Content，Importer只转换源人物偏好及初始错峰标识。工作尝试与自然候选有限，没有旧搜索预算截断；`LastOriginalAiWork`区分资格、日历、无候选、准备／概率失败、空计划、公共拒绝和实际提交，成本诊断不进权威状态。
- Core持有公共资格、成本、效果、任务和每日部队响应；AI不得直接写世界。整编仍由公共入口拒绝。

- `OriginalAiMilitary`持有单个军事工作的候选和快照投影，57／58／51／9／59各自保留生命周期；军事配置由Content的语义阵形角色、人物、设施和地形引用表达，Importer映射原版身份。预测不会改写外国部队命令。来源、配额、人物、留兵、费用和路线在实际提交前重核；公共导航区分0日到达、不可达和未完成，诊断累计实际路径查询。
- 攻击按固定驻兵及指向来源的压力留兵，51输送另用前线建筑保留量，不混用两种预算。59预留至多两个不同来源，按实际提交兵量判断需求，拒绝不提前消耗需求。提交结果直接驱动记账；部队目标与建筑救援目标分别持有消费集合。
- 军事工作按不可变世界快照惰性建立人物、据点、目标兵量、能力和地理投影；Core的`MilitaryRouteQueryContext`复用同一快照的导航索引及出发占位，Application复用来源出发位置和路线结果，命中后不再复制预测单位。军事ETA使用`Estimate`进行一次粗格求路并换算地形时间，`Plan`保留给需要逐日轨迹的公共查询；部署先做当前位置的关联地域筛选。据点变化使地理／建筑索引失效，人物／任务变化使可用人员索引失效，部队变化使目标兵量失效；路线及出发占位依赖军团归属、据点、部队与外交（势力、关系、联盟及请求），不因单独的金钱或行动标记变化全部重建。各次提交仍读取当前军团账户；不缓存随机选择或修改并列顺序。建设同分地点沿内容数组顺序，哈希字典只作资格查询，避免跨进程哈希种子改变选点。

- `OriginalAiActions`实现25～36，按目标外层、工作专属预排序、军师映射与真实阈值配对。赠与共用一份正式载荷；请求按距离顺序复验实际使者；无军师使用公共公式，不把预测分数钳制到100。工作元数据包括几何时间上限，设施外交优先量由Content引用、Importer映射。
- 救援保留量按已出发、指向来源的活动攻击队及公共路线计算。军事、救援及25／26读取实际有效命令，部署58读取目标成员装备兵法；这些决策不受玩家命令／兵法显示开关影响，具体范围按B28和对应研究定义。军事`ProjectedOrder`另投影途中障碍目标，不修改Core主命令；主命令直接读取`UnitState.Order`。

当前规则为`san9-core-g10-v139`／`original-complete-v1`；保存116、日志120、录像28、剧本135及组合185明确拒绝旧格式。旧内容包须原位重转，复用未变纹理；已转换的135／185产物继续有效。v138将普通反击与每日主动攻击机会分离；v139统一等待期的主动交战资格，并补齐设施防守兵法的50%入口。内容及协议结构不变。

`HasEnteredDailyCycle`由Core持有，与旬内下令、等待和实际位移分别表达；AI消费者按各工作读取历史资格。`OriginalAiMilitary.Navigation`集中维护私有目标投影与路线分析，区分建筑占地和地域；候选、人数、兵量、军团范围及阻断门保留在各工作中。具体规则与采用差异统一见[行为规格](../../../specs/original-ai/behavior.md#b19)。

Headless的`--strategy autonomous`运行同一生产入口，报告策略版本及每旬／各工作成本、外层路线查询、底层搜索和展开节点数。全部工作均有元数据与执行者，无`LaterStage`占位或被俘君主低预算替代响应；玩家脚本预算仍有独立消费者。历史阶段验证见[实施计划](../../../specs/original-ai/implementation-plan.md)，当前回归不能替代原作动态或长期验收。
