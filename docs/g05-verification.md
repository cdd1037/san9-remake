# G05 领域地图与出征行军推进记录

日期：2026-09-12。状态：G05完成；战争闭环仍需G06/G07。

## 当前实现

`BattlefieldMap`保存不可变地形和独立硬阻挡，提供细坐标中心矩形、四向加权最短路、稳定择路和日预算消费。静态内容与当前单位占用分离，每日重新寻路；单次搜索按格索引占用，索引不跨日保存。地形、陆水方式、预算及入口由`MilitaryDefinition`提供，与地图图片无依赖。

公共`DeployUnitCommand`原子转移据点兵力、成员、阵型费用和显式载荷；`OrderUnitCommand`变更当前坐标/返城/输送目标。`MilitaryMovement`在日地图阶段串行执行，精确抵达己方目标据点才合并兵力、加权士气、成员与载荷并删除部队。目标失效时尝试有效原据点，原据点也失效则清除命令并保留部队等待新令。无路等待跨旬可保存，后续阻挡消失即可继续。

武将的`UnitId`与据点位置互斥；成员出征后不参与据点内政、驻地查询和太守选择。俸禄随当前单位军团账户，普通单位日粮继续使用既有账户规则。部队身份递增分配不复用，位置、载荷、阵型及当前命令是权威存档状态；路径与占用索引为派生数据。当前规则选择及原作证据边界见[BEH-WAR-0001](../specs/behavior/BEH-WAR-0001-movement-and-command-lifecycle.md)。

军团成员按武将当前据点或所属部队统一判定；都督出征不会被误判离团。跨军团返城同时修复原军团负责人，最后成员离团则解散并归并账户。归并超过账户表示范围时保留部队、成员及载荷等待，避免部分吸收；君主出征后的行政归属据点仍受军团划分约束。
