# BEH-SAVE-0001：玩家存档、调试录像与无界面运行

- 状态：已确认
- 最后更新：2026-09-12（项目所有者确认默认轻量存档与独立录像模式）
- 关联决策：[DEC-SIM-0001](../decisions/DEC-SIM-0001-determinism-and-saves.md)
- 前置行为：[BEH-SIMULATION-0001](BEH-SIMULATION-0001-time-progression-and-state-visibility.md)
- 继承方式：重制存档和调试协议，不导入原作存档，不声称复刻原作文件格式

## 重制行为

Application提供新局、稳定边界保存恢复、操作水位与显式录像。默认模式服务长期玩家对局，录像模式服务确定性重放与调试，二者共用规则、状态及恢复入口。独立`San9.Headless`只依赖Application/Content/Core，可读取公开夹具或转换剧本，下令、推进、保存、录制和重放，输出机器报告与失败码；不加载Godot、原版EXE或S9。

本次选择替代早期G02“存档内保存整局操作与事件，按历史ID逐条去重”的方案；旧协议版本明确拒绝，不通过兼容分支继续保存历史。

## 状态与不变量

- Core拥有日历、起始日期、领域集合、控制席位、下一命令序号、活动持续任务及命名随机。已完成命令ID集合不再保存；水位拒绝旧命令，活动任务保留自身ID和序号并验证身份/占用唯一性。
- Application拥有规则内容身份、下一会话操作序号、最近128条自动内政记录和玩家主动填写的年表。记录超过上限按时间顺序淘汰最旧记录；手写年表保留，不自动累计逐旬事件。
- 默认存档保存以上完整当前状态及版本/完整性摘要，不保存命令历史、事件历史、录像、UI缓存、对象指针或半执行事务；初始种子只存在于世界调度状态。存档大小随当前世界、任务及玩家记录变化，不随已执行操作数线性增长。
- 规范化UTF-8 JSON按Ordinal排序对象键，整数无浮点，枚举使用已定义整数，Guid使用标准小写字符串，null显式保留。身份/关系/无序兵法集合稳定排序；控制、熟练度下标、玩家记录和录像操作保留顺序。
- 世界/会话摘要是按需计算的诊断值，不持久化，不作为普通快照恢复的前置；前者覆盖权威世界与摘要版本，后者再覆盖序号水位、最近记录和年表。内容身份和规则版本由文件封套单独表达。每个外部存档/录像文件保留一个完整性校验（不含自身），检测意外损坏，不作为防作弊或安全认证。
- 内容指纹覆盖规范化剧本初始规则状态、起始日期/玩家配置、身份/地域引用和当前规则目录，排除显示名称、文字、纹理及美术标志。尚未接入Core的地图拓扑在G05扩充指纹。

## 操作水位与原子性

每条请求包含从0开始的会话序号、关联ID、控制者及类型化载荷。本地请求直接绑定当前GameSession；外部JSONL在文件头核对规则版本、内容指纹和初始种子，不为每条操作另建流指纹。Core命令序号独立计数，会话序号另覆盖结束控制、推进和年表。

- 序号小于下一序号返回`AlreadyProcessed`，不执行、不返回旧结果或事件，也不声称核对过旧载荷。序号大于下一序号返回`OutOfOrder`。
- 下一序号按当前权限与业务规则终验；成功后水位加一。拒绝不占用序号、不改变世界/随机/会话或录像。自动生成的ID直接编码初始种子和序号，不经过SHA-256，只用于命令、任务和事件关联；旧请求改成新序号视为新请求，重新终验。
- 操作包括领域命令、结束控制、推进旬和年表；推进显式结束剩余控制席位再前进，不能称为AI决策。操作在候选世界上执行，全部成功后发布世界、玩家记录与水位。
- JSONL输入按行提交，首个拒绝停止，接受前缀保持可保存的稳定进度。旧序号前缀可跳过；不是整个外部文件的跨行事务。CLI尝试诊断不进入权威状态。

## 保存与恢复

只从稳定边界或已提交终局捕获，允许未完成任务；执行中保存拒绝。读档严格检查结构、版本、内容、文件完整性、世界不变量、当前身份引用、记录和序号水位，再构造查询；缺字段、额外字段、重复键、未知类型/枚举、null集合元素、截断、未知任务规则均明确拒绝。

恢复创建新会话，不重跑新局准备，不自动开启录像。未知旧版本拒绝，没有隐式迁移。文件使用同目录唯一临时文件，写完flush再原子替换；失败保留旧文件并清理本次临时文件，不承诺超出操作系统的断电保证。

内容指纹在剧本准备时生成并复用，只覆盖内容数据，不混入已单独记录的规则版本。录像恢复直接复用同一会话恢复入口，不通过临时存档编码/解码。哈希用途与边界见[约定](../../docs/hash-and-fingerprint.md)。

## 显式调试／录像

`BeginRecording`在任意稳定边界捕获完整起点快照，随后仅记录已接受操作及每步世界摘要/事件；`CaptureRecording`导出独立录像，`EndRecording`返回录像并停止、释放会话内部历史。再次开启从当前快照重新记录。普通保存不复制录像，读档后若要继续录制，开始新的片段即可。

录像文件包含独立格式版本、规则/哈希版本、起点内容身份与快照、后续操作、最终会话摘要和完整性摘要。重放严格校验并恢复起点，按连续序号重执行，比较每步世界与事件，最后比较完整会话摘要；报告首个世界/事件差异序号或最终会话差异。可从普通存档恢复后开启新片段，以形成检查点。

录像为模拟重放，不是视频；不承诺跨规则版本播放。当前录像带完整事件诊断，显式录制期间在内存累计、导出时原子写文件；长期录像的流式分段与自动落盘另行扩充，不影响默认玩家模式。

## 验收标准

- [x] 公开夹具CLI下令推进，报告含指纹、种子、日志路径、旬数、结束原因、哈希、首个失败、耗时及失败码。
- [x] 36旬连续与首次命令后、任务跨旬、跨年前磁盘恢复结果一致；待执行任务、已消耗随机流、控制、最近记录、年表、水位完整往返。
- [x] 默认模式40年运行不保存历史命令ID、操作和事件；自动记录限128条，玩家年表保留。
- [x] 旧序号跳过且无事件，外部日志版本/内容/种子不匹配、未来序号和未知操作拒绝；水位和拒绝语义跨存档保持。
- [x] 中途开启、停止、重新开启录像，经磁盘重放结果与事件一致；录制开关不改变默认存档字节。
- [x] 存档和录像截断、未知版本、内容不符、损坏及异常引用拒绝；录像每步差异可定位；注入存档写入失败保留旧文件。
- [x] 集合/键顺序和文化设置不改变规范化摘要；保留有序语义；全解决方案和本地190年集成通过。

实际证据与命令见[G02验收](../../docs/g02-verification.md)。
