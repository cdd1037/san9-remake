## 适用范围

普通部队与据点守军共用的战力、普通兵力伤害、耐久伤害及伤兵分配。失守和终止分别消费WAR-0002/0003，兵法另在G07接入；单独通过本规格算术测试不表示G06战役闭环完成。

## G07 伤兵后勤

每个据点的军事定义显式声明可空的`WoundedRecovery`；null表示该自制内容未支持恢复，0仍是有效系数，禁止套用默认建筑值。TC101城市读取固定建筑0，地域建筑读取实际类型的`RecoveryPerTurn`，按[RE-0014](../../research/findings/RE-SAN9PK-0014.md#5-每旬建筑伤兵恢复消费链)映射。

旬更新在出逃之前按据点ID处理未毁坏、有耐久且有伤兵的支持对象，每对象消费`military-wounded-recovery`百分骰一次。恢复基数为`100*R+rnd(100)+min(1000,W/10)`，未交战时翻倍，最终按伤兵和剩余驻兵容量封顶。当前有合法敌方攻击命令且在攻击距离内定义为被围攻，是重制对原作被动交战标记的确定性解释。满员未恢复的伤兵保留；野战伤兵通过归城吸收进入该周期，不套用设施恢复系数。

伤兵等量转为现役，两侧分别记录资源事件。恢复者士气采用当前势力征兵士气，与原驻兵加权取整；无势力恢复者士气0。这是重制的士气来源选择，不宣称已复刻原作混合士气全部输入。粮耗、异民族年度粮食目标和兵役人口核算均计入伤兵，避免把伤兵视为已经死亡或可再次征集的人口。

验收覆盖战时/平时倍率、系数0、满员保留伤兵、伤兵封顶、恢复资源守恒、死亡/毁坏对象跳过、保存恢复不重复准备以及伤兵粮耗。

## 普通战斗原作基线

RE-0068记录统率限制有效兵力、士气与状态影响战力、阵型对部队/守兵及守备系数、耐久防御加成、普通伤害和耐久伤害关系。普通损失的一半转伤兵，方圆为八成；源伤兵容量50,000。电脑对玩家的额外倍率是独立难度机制，不作为默认普通伤害。

## 重制行为

### G06 日级交战约定

以下为明确采用的重制调度，不声称复刻原作内部时间片：公共持续命令分别指定敌方部队或据点。不同且仍存续的势力允许交战；关系好感数值不代表联盟，联盟期限与禁战在G08接入。无主据点允许占领，己方目标明确拒绝。阵型必须同时提供战斗系数和普通攻击能力；普通射程、削墙资格独立于视野。G07已由下述阵型范围和目标约束替代G06近战基线。

每日先完成全部部队移动，再按单位身份稳定排序处理攻击。每个单位每日最多一次攻击机会（主动攻击或反击共用），据点每天最多一次反击；反击要求存活、范围有效且机会未消费。双方伤害分别读取交战前快照，先同时扣除，再处理终止和占领；目标此前换属、被移除或脱离关系时清除旧攻击令，不把剩余攻击转给新所有者。损失造成的士气下降为实际损失占交战前兵力的百分比向上取整，最低一、最高当前士气；零损失不减士气。零兵或零士气的部队进入统一战败处理。

战力读取参战成员最高有效统率（空守军指挥为零）。2026-09-13按原作补齐动态攻击程度：分别枚举当前以本方为目标、归属敌对且处于攻击范围的有效交战对象，再把本次对手加入集合去重，集合大小作为本方参数。双方参数独立，普通攻防与武力兵法的内嵌普攻共用查询。对象击破、移动离开、命令改变或换属立即影响查询，不保存需要清理的第二份交战列表。设施当前目标复用实际日级选敌规则；附近未指向本方的部队不计数。本次保留既有日级顺序结算与设施选敌方式，不复制原作任务槽。

正常状态效果为10，混乱为8、溃败为6，混乱设施为8。无阵、混乱、溃败部队通过`MilitaryDefinition.UnformedFormationId`引用有效战斗配置，普通攻防、削墙系数和受损伤兵比例共用该查询；当前移动阵型、占地与成员顺序保持权威状态，不因暂时异常改写。该引用可空，表示自制规则不提供异常阵型替换；非空必须指向提供Combat的阵型。TC101引用完整保留的无阵型定义27，Core不判断源身份。混乱和溃败部队不能主动普攻或反击，混乱设施不能攻击；状态效果用于受击防御。落石独立攻击项继续绕过攻击程度，但其对方普通防御项仍按动态参数计算。非交战的方针强弱估计继续采用单对手基础战力，不把周围敌军隐情带入公开策略查询。每场交战记录健康兵损失、伤兵、死亡、耐久和士气变化，便于重放和兵员守恒核对。

### 周期士气与地利

**2026-09-13原作对齐**：采用混乱8／溃败6及有效无阵配置，替代此前效果5；采用原始系数攻击`2*K/25`、防御`2*D/15`，替代此前均按系数/10的重制约定。用户已授权本轮实施。证据见[RE-0068后续复核](../../research/findings/RE-SAN9PK-0068.md#后续复核原始系数异常状态与有效阵型)。

2026-09-13接入每日命令前的普通周期扣减：非嵌入、非人物队伍的有效野战部队，非异民族、未处于断粮异常分支且非溃败时，在本势力都市地利外于月内奇数日扣1；正在主动或被动交战时，另于月内日期可被4整除之日扣1。地利实时读取城市当前归属与范围，范围内跳过这组扣减，不返还已损失士气。持续交战的1–10日、11–20日、21–30日分别扣7、8、7点；非交战每旬扣5点。士气饱和扣减，归零进入一次统一战败处理。

每日粮耗按归属账户汇总；只有总需求大于0的账户进入该组结算。粮食扣除后为0（包括恰好耗尽）或部队处于溃败时，合格部队／耗粮守军每日士气减3、现役减少`ceil(soldiers/100)`，两种原因同时成立也只处理一次；地利与异民族不豁免。野战伤兵按有效配置分配，正常方圆80%、异常无阵50%；守军50%，均受50,000容量约束。剩余损失计死亡，不额外套战损比例士气、不套电脑伤害倍率。归零部队进入统一无胜者终止；守军不因缺粮自动换属。

补给正常的非异民族耗粮守军，在月内3的倍数日且当前士气小于`isqrt(根势力信望)+40`时加1（上限100），高于阈值不回落；不排除交战或混乱，也不要求地利。异常分支优先，不能同日既断粮又回气或再扣普通周期士气。各分支先使用本次账户归属计算，随后终止部队与修复军团，避免途中归属变化造成重复扣减。事件分别记录异常兵损／士气和守军回气；状态与具名随机流支持保存恢复。依据[RE-0099](../../research/findings/RE-SAN9PK-0099.md#2026-09-06复核都市周边地利出征覆盖与士气)。

**重制选择（2026-09-13用户确认）：普通攻防采用队内参战成员最高有效统率，明确保留与原版取主将（大将）统率的差异。** 有效统率包含伤势、宝物与官职修正，不求和或平均；主将80、副将95时，重制普通攻防按95计算，原版按主将80计算。原作基线见[RE-0068](../../research/findings/RE-SAN9PK-0068.md#事实公式-15-普通攻击)；优化伴侣也提供[队内最高统率决定普通攻防的可选改动](../../research/guides/san9pkhard-changes.md#二玩家可控制的改动)，该参照不代表继承其全部规则。

此选择只明确普通攻防的统率来源，不改变主将选定规则，也不推广为所有部队行为统一取最高能力。[设施建设](BEH-WAR-0006-facility-construction.md)进度仍使用主将当前有效统率；主将80、副将95时，建设按80计算。

出征成员按命令中的明确顺序占用阵型位置，`UnitState.MemberRanks`保存成员与阵位的对应关系，不从武将编号推断阵位。TC101陆行阵型按已解码的3×3槽位行映射前/中/后排；20–26水行定义的五个槽位全部为无阵位标记9，G06明确采用中排捕获系数，不伪造源阵位。守军使用中排。名马类别由Importer转换为`EscapeMount`，世界按实际持有人查询；普通交战不启用捕获加倍修饰。完整兵法/特殊效果归G07。

有限军事策略只读取己方状态、公开据点归属与静态拓扑。空闲部队选择附近据点；士气不足30或少于500兵优先返城。来源至少6,000兵、65士气及两名可用武将，保留3,000守军与一名行政人员，逐次公共校验出征；已在攻击的目的地不重复派兵。最多8支空闲部队、4个来源、各4个目的地和32种阵型候选；通路按位置、形状、方式和射程在本次规划内复用，无路等待。没有可执行攻击时复用G05增援策略。该有限策略不使用敌方兵力或隐藏单位位置，不等于G11完整军事AI。

### 接敌距离与移动

攻击距离使用双方占地矩形中最近细坐标点的四向距离：两轴各取非负间隔后相加，边相邻为1，角相邻为2，重叠为0。接敌移动必须保持目标占位不可穿越，寻找代价最低且满足给定正数射程的可站立位置，不要求进入目标中心。射程由调用方显式给出；该算法不推断阵型或兵法射程。

接敌与普通行军共用同一四向加权搜索和预算消费；目标当前矩形始终作为障碍加入本次快照。范围内不移动，无路原地等待，目标移动后下一次调用重算。目标所在的地形不可站立不等于周围没有合法攻击位置，例如陆地部队可以走到水中目标的岸侧。这里只确定位置关系，能否攻击仍取决于关系、武器和日级机会等战斗规则。

`OrdinaryAttack`提供基础范围、每级高差加成、加成上限和是否只允许水域／港口目标。范围在每个候选站位计算：只计来源高于目标的级数，按上限截断，目标高于来源不减基础射程。接敌寻路、实际普攻、反击、兵法机会、围攻恢复判定及有限军事策略复用相同规则；规划内缓存包含完整攻击配置，不把同基础射程但不同限制的阵型混用。

TC101源阵型10基础15细单位；21／26基础5且仅可攻击位于水域的单位或港口据点；其他可战阵型基础10。陆行阵型每级高差增加5、最多10，水行阵型无高差加成；27无普通攻击。设施每级高差同样增加5、最多10，射台基础加成另算。`TerrainPassage.IsWater`与`FacilityRule.IsHarbor`是明确语义，源水域地形10／15／16和港口类型1在Importer映射，Core不检查源编号。水域目标按当前位置地形判断，不以目标当前阵型替代；普通据点即使位于水域也不能绕过港口限制。当前碰撞模型不允许野战部队占用港口建筑内部，不引入原作内嵌代理对象来绕过这一不变量。依据[RE-0068范围补证](../../research/findings/RE-SAN9PK-0068.md#2026-09-13补证设施落石射台与普通射程)。落石覆盖中的目标使用独立特殊范围，见WAR-0005。

### 战力与普通伤害

输入显式提供兵力、士气、有效统率、攻击程度和状态效果，以及阵型攻击/防御系数；不从身份编号推导，不在缺定义时使用默认阵型。士气范围0–100，统率非负，攻击程度和状态效果为正数；阵型系数非负。公式中每个除法均先取整数商，再进入后续步骤。

`FormationRule.Combat`保存对部队、对守兵、对城壁、守备及伤兵比例。空值表示该定义只支持移动，不提供普通战斗能力，后续攻击验证必须明确拒绝，不能自动补默认值。TC101全部28项阵型保留RE-0017已解码的四个战斗系数；方圆源身份7的伤兵比例为80，其余50，身份依据RE-0075、比例依据RE-0068。版本Importer完成身份解释，共享战斗算术只读取显式属性。此映射不表示兵法、射程或削墙资格已完成。

```text
cap = min(soldiers, floor(leadership * 5 / 2)^2)
term = isqrt(floor(cap / intensity)) / 6 + 2 * leadership + 30
base = floor((morale + 100) * floor(5 * floor(effect * term / 10) / (intensity + 4)) / 200)
attack = max(1, floor(attacker.base * 2 * attackCoefficient / 25))
defense = max(1, floor(defender.base * 2 * defenseCoefficient / 15) + floor(durability * 2 / 5))
margin = max(0, attack - defense + 900)
a = max(1, floor(margin^2 / 2000))
b = floor((attacker.soldiers + defender.soldiers) / 70) + 400
loss = min(defender.soldiers, floor(a * b / 1200))
```

G07设施落石仅替换上述`attack`，不额外增加一次攻击；射台修正当前普通范围。具体规范及落石覆盖范围见[兵法与设施能力](BEH-WAR-0005-tactics.md#设施来源与胜者身份)。

阵型系数按上述原作比例和每步整数截断计算；`margin`非负钳制仍为明确重制约定，防止极高防御因负数平方反而放大损伤。不采用隐式电脑加成，不强行保证最少损失一兵。零兵攻击者或零兵目标不产生兵力伤害。中间量使用精确整数，不允许溢出改变战果。

### 电脑强度修正

**重制选择（2026-09-13确认）：电脑强度对每个伤害方向只修正一次，明确不继承原作武力兵法内嵌普攻和电脑反击的重复修正。** 普攻分量与兵法成员分量先完成本次伤害的计算与合成，再统一应用一次`floor(damage*(100+bonusPercent)/100)`；仅来源非玩家、目标玩家时生效，其他控制方向不修正。反击以自身的来源和目标独立判断，不因玩家发起交战而漏算或多算。修正后按目标现有兵力限制实际损失，再分配伤兵与死亡；已修正的普攻结果不得再次作为待修正分量复用。原作重复修正事实和设计意图限制见[RE-0068](../../research/findings/RE-SAN9PK-0068.md)、[RE-0071](../../research/findings/RE-SAN9PK-0071.md)。

`SimulationState.ComputerDamageBonusPercent`保存新局明确选择的非负整数加成，默认0；`GameSession.Start`与`WorldState.Create`接受该设置，客户端启动参数`--computer-damage-bonus 100`选择+100%。它属于会话状态，不从TC101初始剧本字段推测，也不写入共享内容定义。保存、恢复、状态哈希和录像初始状态保留设置；旧规则存档直接拒绝。

结算在统一的单位／据点伤害写回入口完成，按当前ControlSeat判断玩家归属。普通攻击、武力兵法合成及幻术／妖术／陷阱的直接兵损各修正一次；叛逃兵员转移、耐久与独立士气效果不作为直接兵损倍率输入。反击以本身方向判断，无主来源属于非玩家。实际兵损封顶后才分配伤兵、死亡和相应士气损失。普通战力中的攻击程度`intensity`仍是独立算术输入，不代表难度加成。

### 耐久与伤兵

有削减耐久资格的攻击者使用以下公式；资格由外层战斗规则和内容能力决定，不在公式中检查原版阵型编号。无兵力不造成耐久伤害。

```text
a = floor(isqrt(soldiers) * isqrt(100 * leadership) / 3000)
b = a + 3 * trunc((wallCoefficient - 2) / 9) + 1
damage = min(durability, max(1, trunc(b / 3)))
```

兵力损失先按当前兵力截断。实际损失按显式伤兵百分比向下取整，再按接收方剩余伤兵容量截断；其余记为死亡。返回剩余兵力、实际新增伤兵、死亡及因伤兵容量不足而死亡的子集，满足`实际损失 = 新增伤兵 + 死亡`。这里容量是独立玩法参数，不限制对象身份和数量。

部队和据点分别保存`Wounded`，当前玩法容量均为50,000；健康兵与伤兵不互相替代，伤兵不能用于出征。返城只在精确到达后将部队伤兵加入目的据点，容量外伤兵按[WAR-0001](BEH-WAR-0001-movement-and-command-lifecycle.md)转入所属城市兵役人口，完成兵员安置后才删除部队，不重复回收。战斗当场伤兵容量不足所计入的死亡不属于和平归并溢出。TC101单位使用已解码的载入伤兵数并保留有效士气，非法士气拒绝转换；城市/地域初始记录没有该持久字段，重制新局据点伤兵明确初始化为零。该初始选择不用于清空存档中的当前伤兵。伤兵恢复与日粮规则在G07闭合。

## 状态与不变量

## 石兵受击反作用

设施可显式提供`FacilityReprisal`，缺省为空表示没有受击反作用；TC101仅源类型16映射此能力，不能按归并编号误赋给栅栏。它不需要守兵、大将或已选兵法，不产生主动攻击，也不占用武将兵法间隔。

普通日级攻击实际削减耐久后，设施和攻击者均仍有效时触发一次。兵损为`max(1,(1000-P)/10)`，P取攻击部队当前在职成员的最高智略类别熟练度。按现役封顶，复用阵型伤兵比例和伤兵容量；不额外扣士气、不套电脑普通伤害倍率。若击破则沿无俘虏接收者的统一终止链安置人员和载荷，不把不可驻人设施作为拘押点。设施当次已毁坏、攻击不削墙或攻击者已败时不触发。

部队存活后，以`clamp(10-I/10,0,100)`百分概率赋予混乱5日；I取当前成员最高有效智力，是明确重制取值（源属性29直接读人物智力槽）。使用独立`military-facility-reprisal`随机流，概率端点不投骰；不套混乱兵法装备反制或高昂免疫。复用异常写入、较长混乱时间保留及逐日到期，保留攻击命令以便恢复后继续。能力参数和抵抗类别由内容作者定义，不在Core判断源编号。

验收要求：成员最高值、兵损下限／截断／伤兵封顶、非致命攻击与致命削墙、无削墙能力、无反作用类型、反作用击破、混乱到期以及保存恢复事件／随机一致。依据[RE-0138](../../research/findings/RE-SAN9PK-0138.md#石兵受击反作用复核2026-09-13)。
