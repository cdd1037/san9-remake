# 本地私有样本区

此目录是项目当前使用的本地样本入口。除本文件外，目录内容均被 Git 忽略，不得提交原版程序、游戏资源、编辑器截图或存档。

目录用途（私有输入按需放置，不保证每个检出都有全部样本）：

- `private/游戏文件/`：统一的繁中 PK 1.0.1.0 游戏源目录，`San9PK.exe`、`.s9` 数据／剧本和原版 DLL 同层存放。转换器通过 `--game-dir` 选择此目录；DLL 仅作研究样本，不作为重制运行时依赖。
- `private/剧本编辑器截图/`：用于黑盒字段对照的编辑器截图。
- `private/ida/legacy/`：旧 IDA 数据库原件的登记路径，只作为研究输入，不承载项目新标注；当前工作区未提供该目录，来源记录保留历史路径。
- `private/research/docs/`：来源与许可状态尚未逐项确认的电子书、分析文章与配图。
- `private/research/upstream/`：本地第三方源码和资料快照；可用于寻找线索，不自动成为项目事实。
- `private/大地图云截图/`及其他原版截图：视觉对照输入，不能按生成缓存清理。
- `private/template/`：本地 Godot 导出模板；字体、手册等其他本地输入也保留在本目录，按实际工具配置使用。

研究文档引用本地样本时统一使用上述仓库相对路径，不记录个人安装路径或其他机器隐私信息。每次实验只操作工作副本，不修改唯一原件；可提交的研究记录仅包含必要的逻辑样本 ID、版本、合法可记录的哈希和复现说明，不包含样本本身。
