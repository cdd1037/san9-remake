# BEH-UI-0003：战略全图面板

- 状态：已确认
- 依据：用户纠正大小按钮语义；[RE-SAN9PK-0160](../../research/findings/RE-SAN9PK-0160.md)。

## 目标行为

HUD「小」打开独立战略全图面板，「大」关闭面板回到详细地图。打开和关闭不改变详细地图的中心、缩放、命令选择、世界时间或行动状态。大小按钮本身不缩放；全图地形内滚轮调整详细地图视野，倍率沿用0.25～2及每步1.2倍，保持中心（边界约束除外），同步白框，返回后保留。面板打开时禁用疆界按钮，隐藏详细地图标注，阻断输入穿透到详细地图的拾取、拖动和滚轮处理器。

面板使用转换后的原图：全屏底景、位于(40,71)的800×400地形、势力区域和边线、(56,529)的排行榜背景。三个独立开关为势力(564,385)、设施(504,415)、部队(445,445)，各108×60；三者互不排斥，开关状态在本次会话内保留，初始均开启。右侧名单页签独立。全图点击仅定位详细地图中心并更新白色视野框，保持面板打开；菱形外及排行榜不定位。小雷达和名单定位继续有效。右下地域按全图鼠标位置逆投影到方格更新，不取隐藏详细地图的鼠标位置；图外和按钮区域隐藏。底部提示分为默认与悬停：详细地图默认显示命令起点提示，全图默认留空；工具栏及全图图层按钮悬停显示说明，移出恢复当前模式默认值，禁用按钮仍提供说明。按钮说明取转换包ui.hint.*原作消息，禁止自行编写替代文案；可用为白色F0F0F0，不可用为橙红色F06850，黑色描边与阴影保持。此为用户确认的重制行为，见[DEC-UI-0006](../decisions/DEC-UI-0006-overview-navigation.md)。

势力区域颜色根据城市当前归属派生；无主城市使用无主颜色。设施标记区分城市与其他可显示建筑，不能从图像推断领域所有权。部队标记读取运行时部队位置与归属；本阶段没有出征、行军或战斗命令，初始无部队时图层自然为空，不能绘制虚构部队。

排行榜只列普通势力及玩家势力，排除非玩家异族势力。四列分别按运行态信望、城市数量、所属武将数量、据点和部队现役兵力总和降序。相同值共享名次（1、1、3），同值按势力ID升序稳定排列。每列显示前三项；玩家不在前三项时在底行显示玩家名次和数值，否则底行为空。数值不得从参考截图硬编码。世界版本改变后统一刷新。

## 状态与实现边界

Application持有独立面板开关及排行榜投影，Core持有势力类别、据点类别和部队状态；Content与Importer定义并转换对应初始态。图像中的城市区域掩码仅是显示资产，不进入Core。显示层不保存第二份世界状态。保留现代字体与既有文字效果约定。

此规格取代BEH-UI-0001中「大小按钮选择1倍/0.5倍」及完整大小地图流程未实现的约定。完整战斗、信息目录及详情卡不属于本面板的导航修正。

## 验收

自动测试覆盖并列、玩家附加行、异族过滤、兵力聚合、不可变快照与开关独立性。引擎输入自检覆盖打开关闭不缩放、图层组合、面板输入隔离、全图/雷达/名单定位与状态保留。实际Godot GPU截图核对全图、排行榜和关闭后的详细地图。资产契约及审计器变更运行原图审计`--all`。

### 排行榜数值留白

按用户视觉反馈，保留现代字体与数字右对齐，四列数值距各自右分隔线统一14逻辑像素；前三与玩家附加行共用同一右边界。背景图局部右分隔线为194、357、528、736，加面板原点56后为250、413、584、792。此为重制排版选择，不按原作空格数量模拟占位。仅做编译与自动测试，未启动画面验收。

表头按各列实际左右分隔线水平居中，五条边界为73、250、413、584、792逻辑像素；不复用行内排名和姓名区域作为表头布局框。数值右侧留白仍沿用上述14像素。
