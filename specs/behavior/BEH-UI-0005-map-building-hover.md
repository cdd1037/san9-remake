# 大地图建筑悬停

状态：采用。原作证据见[RE-SAN9PK-0163](../../research/findings/RE-SAN9PK-0163.md)。

详细地图鼠标命中城市或普通建筑时，建筑变亮，名称和兵力变黄，并显示信息卡。悬停、命令选择、侧栏焦点分别持有状态；移出建筑、进入界面、打开全图或情报、离开窗口时清除悬停。相机及世界更新后重新查询鼠标下对象。卡片不拦截地图输入，同一对象内移动不移动卡片，换对象时重新定位。

信息卡宽160；城市高316，普通建筑高248，按1024×736逻辑范围限制位置，鼠标横坐标大于643时向左展开。标题下64像素开始，行高24，标签宽32、值宽80。城市依次显示状态、军团或势力、大将、民心、收益、收获、耐久、士气、士兵、在任；普通建筑不显示三项内政。自势力显示军团首领，其余显示势力名称。在任为可用在职人数/在职总人数，两侧各至少占三位数字宽，右对齐、空格补位，无兵士气显示空缺。图标仅使用该城市自己的状态，不传播到关港。

三套背景按当前归属和外交关系选择：自势力、无主或其他势力关系小于40、其他势力关系至少40。采用转换的原版九宫格与分隔线，保留逐色Alpha。当前没有军团切换入口，以玩家势力为当前上下文。

大将由导入的驻留负责人状态查询，不以最高能力或君主身份猜选。当前会话只有稳定一般状态，战斗异常状态的产生不在本次范围。颜色混合采用现代RGBA；不复制RGB555取整误差。拾取复用当前建筑可见像素查询，不宣称与原版4×4视觉对象搜索完全等价。

验收：覆盖三种关系、城市/普通建筑、无主及无兵、人员已行动后的刷新、移入移出和界面阻挡；编译与跨层测试通过。用户已确认整体画面无明显问题；随后按用户要求将“在任”调整为三位占宽，编译与相关测试通过。
