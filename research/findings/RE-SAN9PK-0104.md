## 边界、记号与不变量

本批完整覆盖 `resolve_duel_strike(0x500650..0x500872)` 及 `resolve_duel_combat(0x503AC0)` 中两处调用、伤害截断、连战 HP 和看破表现随机。令攻守双方当前有效武力为 `MA/MD`，性格为 `CA/CD`，列传资源编号为 `RA/RD`，本刀前 HP 为 `HA/HD`，`Δ=MA-MD`。所有有符号整数除法均向零截断，记为 `trunc0`。

不变量：逐刀总是按“看破 → 基础伤害 → 动画必杀 → 双倍必杀 → 普通攻击”短路；输入武力是人物 `+0x50` 当前有效武力，不是基础武力；概率阈值只有上限、没有统一的零下限；核心逐刀与随后看破台词共用全局随机流。

## 事实：规范武力与基础伤害

`compute_nonlinear_ability_score(0x41D2A0)` 把当前有效武力 `x` 映射为：

```text
T(x) = max(0, 3*max(x-90,0) + 2*min(x,90) - 160)
     + max(0, min(x,80) - 60)
     + max(1, trunc0(min(x,60)/2))
```

看破失败后，固定部分与基础伤害为：

```text
capB = 33, 当 RA=3 且 Δ>=20；否则 22
fixed = min(capB, max(5, trunc0((T(MA)-T(MD))/3) + 20))
base  = fixed + rnd(trunc0((100-HA)/20) + 2)
```

`rnd(N)` 的上界不含，因此满 HP 时仍加 `0..1`；`HA=80..99` 时加 `0..2`。随机项只取决于攻方本刀前 HP。机器分母是 `20`，不是资料所写的 `25`。

## 事实：四类结果按顺序短路

### 看破：`outcome=0`

```text
P0 = min(8, 2*CD + 2 - trunc0(Δ/5))
若 RD 属于 {3,9} 且 MD-MA>=20，则 P0=40
```

第一条随机调用是 `kakuritsu(P0)`。成功即写 `outcome=0`、返回伤害 `0`，不计算 `T`、基础伤害或后续必杀。一般式只对 `Δ/5` 做除法，不是把整个分子除以 5；负阈值仍原样传入 `kakuritsu`，按严格的 `rnd(100)<chance` 判定自然失败。

### 动画必杀：`outcome=3`

看破失败并生成基础伤害后，调用：

```text
P1 = min(8, trunc0(4*Δ/5) + 2*(4-CA))
damage = 3*base + max(trunc0((HD-HA)/2), 10)
```

`kakuritsu(P1)` 成功后返回上述伤害，并立即把守方伤势增加：

```text
injury_add = 1 + rnd(2 + (Δ>=0))
new_injury = min(7, old_injury + injury_add)
```

所以攻方武力较低时增加 `1..2`，否则增加 `1..3`。`set_person_injury_state(0x44F040)` 写人物 `+0x80` 并在值变化时刷新人物状态。伤势写入发生在调用方截断 HP 伤害之前。

### 双倍必杀与普通攻击：`outcome=2/1`

动画必杀失败后才计算：

```text
cap2 = 24, 当 RA=4 且 Δ>=20；否则 12
P2 = min(cap2, 3*(4-CA) - trunc0((MD-MA)/5))
```

`kakuritsu(P2)` 成功时返回 `2*base` 并写 `outcome=2`；失败时返回 `base`，保留预置的 `outcome=1`。两条路径都不再修改人物伤势。P1 使用原始 `MA-MD`，不是资料中的规范武力差；P1/P2 同样没有零下限钳制。

## 事实：HP、交替攻击与连战

双方整场初始 HP 都是 `100`。发起方先调用逐刀；原始伤害由调用方执行 `applied=min(raw_damage, defender_hp)` 后再扣除，记录的也是实际伤害，因此 HP 不会小于零。守方 HP 归零便不再还击；若仍大于零，则交换人物与两侧当前 HP 调用同一逐刀函数。双方存活时直接回到下一轮首击，HP 不重置。

一名人物归零后进入下一配对。仍保留当前胜者的槽位执行：

```text
next_hp = min(current_hp + 20, 100)
```

败者人物指针在上一配对末尾被清空；该侧随后从剩余名单取得替补，并把 HP 明确初始化为 `100`。因此只有胜者以残余 HP 加 20（封顶 100）连战，替补总是满 HP 入场。外层最多记录五组退场，但完整胜负、阵亡和战后写回留给 `DUEL-03`。

## 事实：完整随机调用顺序

核心逐刀的全局随机调用严格如下：

1. 总是先抽 `kakuritsu(P0)`；看破成功即返回。
2. 看破失败后抽基础伤害 `rnd((100-HA)/20+2)`。
3. 再抽 `kakuritsu(P1)`。
4. 动画必杀成功则抽伤势 `rnd(2+(Δ>=0))` 并返回；失败则抽 `kakuritsu(P2)` 并返回。

所以核心看破只消耗 1 次，另外三类结果都消耗 4 次。不过调用方收到 `outcome=0` 后还会用同一全局流先抽 `kakuritsu(8)` 选择表现消息；若失败，再抽 `kakuritsu(4)`。这两次只影响消息，却会推进后续逐刀所见的随机序列。首击和还击两侧完全对称。

## 特殊人物常数与资料标签

机器事实读取人物 `+0x3C biography_resource_code`：守方列传码 `3/9` 的强差看破为 40，攻方列传码 `3` 的基础上限为 33，攻方列传码 `4` 的双倍上限为 24。基础列传资源把 `3/9/4` 分别标为吕布、赵云、马超；其中列传码 `9` 的赵云标签还与 `compute_tactic_link_relationship_bonus(0x4FF770)` 的独立分支一致。该字段来自 `prsn +0x10`，不是人物表下标、运行时 PersonId 或序列化人物 ID；身份域复核见 `RE-SAN9PK-0106`。

## 资料冲突校核

SanIX 章节与电子书重复章节的流程骨架、T 函数、P2、动画伤害和特殊列传码常数大体对应机器，但有三项可执行差异：

- 看破一般式：资料排版成整个分子除以 5；机器只计算 `trunc0((MA-MD)/5)`。
- 动画必杀：资料使用规范武力差且方向相反；机器使用当前有效武力原差 `MA-MD`。
- 基础伤害随机项：资料分母为 25；机器分母为 20，并使用不含上界的 `rnd`。

此外，资料没有记录看破台词的 `8% → 4%` 两次表现随机，却因共享全局流而影响后续结算。上述差异均以当前样本机器事实为准，不建立兼容分支。
