# 巡察命令：消息与音效流程

本页以“设施 → 巡察”为消息调用索引，串联已有分类目录中的内容，不复制正文、不去重，也不表示客户端已经接入此流程。依据 TC101 原作静态调用链和当前转换包，证据见 [RE-0095](../../research/findings/RE-SAN9PK-0095.md#2026-09-27巡察消息序列与音效)。没有进行原作动态播放或音频试听。

## 从确认命令到结果

确认参与武将后，原作验证命令并即时执行，不等到旬末。先计算基础增量；只有基础增量还不能把民心补到 1000，才检查加倍。下面三条回应路径互斥，且只在原作玩家可见势力条件成立时生成显示：

| 路径 | 触发条件 | 消息顺序 | 新触发的音效 |
| --- | --- | --- | --- |
| 普通巡察 | 没有成功加倍，包括基础效果已足以达到上限 | 武将回应 5592 | 无 |
| 特定组合加倍 | 匹配有序人物组合、概率与资格检查均成功 | 武将甲 5861 → 武将乙 5862 | 两句均无 |
| 相性加倍 | 特定组合没有成功，后备相性概率成功 | 武将回应 5826 → 百姓回复 5832 | 百姓回复触发 SE 8 |

随后，增量大于 0 时显示结果 5598，触发 SE 18；再进入内政共用提示选择，最多追加一条 5873–5877，也可能没有提示。三条回应路径都汇合于这个结果与提示阶段，不会在特殊对白后再补播普通回应。

这里记录的是调用／入队顺序。原作主地图可把消息加入队列，执行器随后写回民心、行动状态、费用、信望和本期使用标志；不能据此断言必须点击关闭所有消息才发生状态写回。

| 5827–5831 | `dialogue.cooperative-patrol.variant-002` 至 `variant-006` | 5826 的人物身份分支；不是额外五轮发言 |

5598 报告的是民心及由民心推导的增兵役值变化，不能解释成下令时立即补充了同等数量的士兵。表中的列传码只用于原作溯源，不是产品 `OfficerId`。

5832 保留三选一结构，“我们的英雄”是其中一个候选。因此它要求**相性加倍分支成功，再选中对应候选**；普通成功、特定组合加倍都不会调用这一回复入口。后面的 10% 提示概率与它无关。

## 音效与 BGM

| 调用值 | 原作含义 | 巡察用途 | 源文件 |
| --- | --- | --- | --- |
| SE 8 | 播放音效目录第 8 项 | 百姓回复 5832 出现时 | `SE/SE_G008.WAV` |
| SE 18 | 播放音效目录第 18 项 | 结果 5598 出现时 | `SE/SE_C006.WAV` |
| SE 170 | 超出有效音效索引 0–169，不发起新音效 | 普通／相性武将回应、组合对白、共用提示 | 无 |
| BGM 27 | 超出有效曲目索引 0–26，不切换背景音乐 | 结果显式传入；人物对话沿用构造默认值 | 无 |

音效目录索引与文件名后缀不是同一个编号域，尤其不能把 SE 18 找成 `SE_G018.WAV`。这里确认的是调用用途与资源映射，没有把试听尚未确认的声音命名为某种人声或乐器。“不触发新音效”也不表示停止已经在播放的声音。

主地图队列保存音效参数，取出消息时再进入对话框播放路径。BGM 哨兵表示这些消息不请求切曲，不保证整个命令期间其他系统不会切换音乐。通用按钮按下／确认声属于控件输入链，本次未追踪，不混入巡察事件音效。

## 后续接入所需信息

现有消息转换和求值已保留上述分支，但客户端巡察入口尚未提交完整领域命令，也没有这套消息／音效编排。当前领域结果只返回增量和费用，加倍判断返回布尔值；要正确接入，命令执行结果须保留“普通／组合加倍／相性加倍”、相关参与者及结果前后数值，表现层消费该次结果，不能重新掷骰决定加倍或反推参与者。具体领域规则仍以 [经济规格](../../specs/behavior/BEH-ECONOMY-0001-domestic-and-economic-cycle.md) 为准。

消息文本、显示人物和音效是三个独立信息，音效不写进文本节点。这个流程索引用于保留三者的关系；共享提示继续由多种内政命令引用。未来细化消息入口名称时可依据此调用证据区分回应、结果、组合对话和提示，源序号映射同步更新。
