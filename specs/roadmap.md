# 三国志 9 重制整体路线图

状态：已确认

## 产品基线

- 完整的 Windows、macOS、Linux 单机重制版，键鼠操作，简体中文首发并预留 i18n。
- 保留旬制同步推进、大地图一体化和部署后自主战斗；优先现代化 AI、规则透明度、信息反馈和工程可维护性。
- 首个完整内容为 190 年反董卓全地图剧本。
- 原版研究基线为繁中 PK 1.0.1.0、x86 PE、大小 2,636,800 字节、SHA-256 `D20794AEFF67301EC2BF8C3BECB1E9944C68C6C0588FBFD4BF04E8597F0E5028`。
- 原版转换数据与资源仅供本地开发，不入库；v1 不含多人、原版存档导入、公开模组 API、作者 GUI 编辑器或公众导入流程。

## 里程碑

| 里程碑 | 交付结果 | 退出条件 |
| --- | --- | --- |
| M0 工程基线 | Godot/.NET 分层、确定性旬推进样例、测试、版本锁定和架构决策 | Core 可独立测试；Godot 只经 Application 调用；构建和测试通过 |
| M1 数据转换 | 指定构建识别、190 年所需数据和资源转换、JSON 内容包与校验 | 未知哈希被拒绝；重复转换一致；引用、范围和地图拓扑有效 |
| M2 垂直切片 | 自制小地图上的内政、旬推进、编队、出征、自主战斗、占领与存档闭环 | 全流程可连续完成；同种子和命令得到相同结果 |
| M3 全地图 Alpha | 190 年完整地图、多势力、内政、人才、外交、计略、战争、事件和 AI | 十年无人值守模拟无崩溃或世界状态违规 |
| M4 内容体验 Beta | 本地原版内容接入、现代 UI、规则说明、i18n、设置与武将编辑 | 主要流程完整；经研究确认的玩家编辑范围可用；回归通过 |
| M5 本地完整版本 | 三桌面平台、教程、难度、结局、性能和完整回归 | 三平台构建验证通过；190 年剧本达到发布候选质量 |
| M6 后续扩展 | 其他剧本、作者编辑器及单独评估的公开分发/模组/旧存档项目 | 每项扩展独立决策，不污染 v1 核心接口 |

## 系统推进顺序

1. 内容身份、地图拓扑、游戏时钟、命令队列和存档骨架。
2. 城市与武将分配、基础内政、征兵训练和旬结算。
3. 编队、路线、行军、普通战斗、伤亡、撤退和占领。
4. 阵型、兵法、设施、攻城、后勤、俘虏与伤兵。
5. 人才、忠诚、外交、计略、事件、胜负与结局。
6. 分层 AI：战略规划、资源预算、人才、外交和军事执行。
7. 规则解释、批量操作、信息图层、战报、教程和体验优化。

## 阶段门槛

- 每个阶段必须同时具备功能闭环、相关规格、自动测试和已知限制记录。
- AI 与玩家通过同一命令验证入口；难度加成必须透明且可关闭。
- 存档格式升级只允许显式迁移；不做静默兼容。
- Godot 负责表现和输入，Core 负责规则；原版地址和内部结构不得进入产品接口。
- M2 完成前不给后续里程碑承诺日历工期，之后依据实测速度更新规划。
