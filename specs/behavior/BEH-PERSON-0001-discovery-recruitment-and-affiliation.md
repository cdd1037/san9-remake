## 适用范围

适用于探索/发现人物、对合格的俘虏、在野或他势力在职人物登用，以及成功或失败后的身份、归属、位置和按势力忠诚写回。

## 原作基线

探索命令提交后占用执行者，事件可把隐藏人物转为通常在职身份 3 或在野身份 5，并写目标地点。登用命令提交时保存 `0..99` 随机载荷，到阶段判定时才按公式 2 重算实时阈值并严格比较；成功初始化身份 3、执行势力、目的对象和新势力忠诚：

```text
Lnew = 75 + trunc0((50-affinity(target,newLeader))/2)
```

有旧势力时把旧势力忠诚写为 45。负责人成功归顺时可带动同对象人物逐人竞争。

普通行程登用失败不改变身份、所属势力或位置，按顺序执行以下反馈：

1. 非俘虏且旧势力有效时，两势力友好度减少 `1 + rnd(3)`，遵循关系值下限。
2. 按阈值 `75 - affinity(target, recruitingLeader)` 判定，命中则目标对招募势力忠诚加 1，上限为 255。相性比较对象是招募方君主，环距封顶 50，不是执行武将。
3. 旧势力有效、目标为在职身份 1/2/3、与旧君主相性距离大于 0、义理小于 15 时，另按本次阶段判定保存的登用阈值投骰；命中则目标对招募势力忠诚减 1，下限为 0。此门不依赖第 2 步命中。

两次忠诚反馈作用于同一个招募势力项，不扣旧势力的个人忠诚。先加后减不能合并成净增量；原忠诚 255 且两门都命中时最终为 254。普通未饱和值可净增 1、不变或净减 1，不能把反复失败描述为必然提高好感。普通行程成功分支尝试执行者政治成长，失败分支不执行该成长调用；探索发现时的即时登用使用独立路径，不套用本段失败规则。

普通登用公式仍有资格门：对招募势力忠诚低于 50，或非俘虏对现属势力忠诚大于 99 时返回 0（特定剧情旁路除外）。反复失败带来的招募势力忠诚增加不能绕过后者，不能承诺必定登用成功。

## 重制行为

重制版保留候选、提交随机载荷、阶段实时复验、成功归属和失败不变量。随机载荷及失败反馈抽样必须来自显式玩法随机流；两次忠诚反馈保持独立条件、固定顺序和逐次饱和，不以界面显示的 100 上限截断逐势力忠诚字节。表现层不改变最终阈值、顺序或写回。

按 DEC-PERSON-0001，失败第 3 步改为扣目标对结算时所属势力的忠诚 1 点，下限为 0；第 2 步仍加招募势力忠诚。减法保留所属势力有效、在职身份 1/2/3、与所属君主相性距离大于 0、义理小于 15 的前置条件，以及本次成败判定保存的阈值 P；不因第 2 步加分而重算 P。

失败减法仍排除俘虏与在野，二者不消费该减法随机。俘虏的独立旬扣减由 BEH-PERSON-0002 定义，与登用结算分开。

## 状态与不变量

### G04普通人事任务的执行约定

探索允许以执行者服务驻地为目标，也允许无隐藏人物或低政治人物探索。目标为己方建筑时可选；目标为未建设地域或无主建筑时，还须其所属城市为己方或无主。这里“未建设”表示地域上没有设施，不表示其所属城市无主；“无主建筑”表示已有建筑但没有占有势力。敌方建筑不可选。提交与结算共用当前归属校验，不能把自动探索的政治45门槛、隐藏人物优先策略或对话框选择变化检查套为玩家资格。本城探索仍耗时至少10天，零天返回在日内后续归队阶段收尾，下一旬开始时可再次下令。

普通登用阈值采用已确认公式2：招募势力忠诚低于50直接为0；非俘虏的原势力忠诚超过99直接为0。其余为当前政治、特殊招募政治补偿、俘虏加30、信望差除5、原/新君主相性距离差除5，减义理和原忠诚，再加招募忠诚减37。无原势力时公式使用比较基准忠诚70、信望0、旧相性距离50，这不是把人物忠诚表初始化成70。所有有符号除法向零截断，负阈值保留，最终以0–99随机值严格小于阈值判定。特殊政治补偿由内容属性表示；剧情旁路留给事件阶段。

任务保存执行者驻地、出行目的地、目标人物和提交随机值。驻地表示服务/薪俸所属据点，任务是出行和占用真值；不可据服务驻地把在途人物当作城内候选。基础行程使用精细中心的整数欧氏距离除30向上取整，搜索去程再向上凑10天、至少10天，格中心为5*x+2。到期/取消/改属和归队见[BEH-PERSON-0003](BEH-PERSON-0003-recall-movement-and-action-reservation.md)。普通登用成功把目标的服务地点设为执行者驻地并创建独立归队任务；执行者无论成功失败都归队。失败保持目标身份、归属和位置。

`SearchCommand`按普通探索终端顺序选第一个满足项：人物、宝物、资金、无结果。人物门为`2×非线性政治分值×floor(sqrt(100×人数))/30`，宝物门为`政治分值×floor(sqrt(100×宝物数))/90`，都使用提交骰；自动控制不进入宝物门。候选按ID排序后用各自随机流选择一个，已发现人物或已持有宝物不会重复获得。宝物交给君主并刷新各项最大加成、特殊信望，人物和宝物结果尝试3%政治成长。资金重新抽骰，门为max(1,政治分值/2)，获得`政治分值×(rnd(3)+1)+rnd(10)`，记入服务驻地所属军团账户，遵循普通收入上限并报告差额，不抽成长骰。

人物发现先增加招募忠诚`10+(50−相性)/5`。命令保存`AcceptRecruitment`策略：接受时重新抽即时登用骰、成功入仕，失败转当地在野并设忠诚49；拒绝时直接在野，不抽登用骰、不写49，两种情况仍尝试政治成长。提交时预先声明选择是G04无界面工程协议；G10再接实时选项会话和历史/特殊探索，不把上述四种终端称为原作全事件表。原作证据见RE-0112的G04收尾复核。

普通登用支持在野、他势力通常在职/军师/都督/负责人，以及扣押于己方据点的俘虏；排除君主和在途目标。俘虏仍保留原归属，扣押方从地点解析。负责人归顺会把当前服务对象及其内嵌单位转入新势力根军团，并逐个处理同地点人员：所属忠诚≥100不追随，其余按`(16−义理)×(trunc0((新信望−旧信望)/50)−所属忠诚+100)/2`判定。目标负责人和追随者留下；拒绝者与原服务地点的在途人员保留原归属，重新安置并归队。旧子军团重选都督或解散，设施负责人重新选举。普通成功关系扣`3+rnd(3)`，带对象成功扣`5+rnd(3)`。君主服务对象的归顺涉及势力退出，G04明确拒绝，终止链归G06；主动叛离/新势力诞生另归后续生命周期与事件阶段。

发现、登用和下野把当前身份起始年`StatusStartYear`写为当年，清一般官职并刷新官职加成、设置已行动，保留持有宝物。在职情报以当前年减身份起始年加1显示年数；这不是首次仕官年份。转换、互相引用任务清理、负责人和军团修复在一个候选事务提交。

- 输入：执行者、目标、来源/目的对象、实时身份归属、公式 2 输入和稳定随机载荷。
- 输出：行动占用、身份、势力、对象位置、每势力忠诚和势力关系。
- 不变量：提交不冻结成功阈值；失败不改身份/势力/位置；成功后身份、势力、目的对象与忠诚必须原子一致。

## 验收标准

- [x] 隐藏人物、在野人物和俘虏候选边界由状态机测试覆盖。
- [x] 相同提交载荷在不同实时状态下按实时阈值判定。
- [x] 成功、失败和负责人带动分支的最终状态哈希稳定。
- [x] 失败增加门使用招募方君主相性；执行者与君主相性不同的夹具能区分二者。
- [x] 失败加减门四种命中组合、在野/俘虏/在职身份、义理 14/15、旧君主相性距离 0/1、忠诚 0/254/255 及随机消费顺序有测试。
- [x] 两势力不同的在职夹具中，两门均命中时招募忠诚 50→51、所属忠诚 94→93；只命中减法时招募忠诚保持 50、所属忠诚 94→93。两项分别在 255/0 饱和，其他势力项不变。
- [x] 俘虏与在野不执行失败减法、不消费其随机；俘虏无登用时仍可独立执行旬周期。减法使用已保存 P，不因加法写入而重算。
- [x] 个人忠诚与两势力友好度保持不同对象域。普通成功/失败政治成长调用边界分别测试。
- [x] 普通公式招募势力忠诚 49/50、非俘虏现属势力忠诚 99/100 的边界证明不能以反复失败承诺成功。
