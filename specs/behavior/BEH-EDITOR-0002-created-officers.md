# BEH-EDITOR-0002：共享武将与开局部署

- 状态：已实现。
- 日期：2026-11-18。
- 原作研究见 [RE-0202](../../research/findings/RE-SAN9PK-0202.md)。本页记录重制选择。

## 范围与所有权

主菜单“登录新武将”、选择势力页“编辑武将资料”和参数 `--officer-editor` 打开当前资料集的同一张武将表单。游戏资料编辑器也提供这张表单。保存后即使退出开局，资料仍保留。

`OfficerDefaults.Id` 标识人物。创建和复制各自分配新 ID，改名保留原 ID，删除后的 ID 不再分配。亲代、血缘、剧本安置、君主和双人联携都引用这套身份。修改人物的基础数值只影响之后建局。

TC101 转换包为[原版玩家新武将](../../research/findings/RE-SAN9PK-0202.md)预留 ID 700–799，基础人物目录的 `nextOfficerId` 至少为 800。编辑器新建和复制沿用基础目录、玩家副本及已有引用中的最高分配进度。旧包可通过 `import-content --rebuild worlds` 更新基础目录；已有角色及引用保留原 ID。本次仅预留编号，原版玩家新武将导入待后续接入。

共享目录中尚未被所选剧本安置的人物自动成为开局候选，按[开局部署规则](BEH-UI-0011-new-game.md#新武将部署与新势力)检查年龄与安置。剧本作者也可直接从共享目录添加武将，指定初始身份、归属、位置和宝物持有。

## 直接创作

不采用点数预算、随机寿命、信念生成、特殊姓名或确认时重新生成。四维、熟练度、精通和已学兵法分别保存。默认四维50、出生170、登场184、寿命档7，仅为输入初值。

辅助按钮只修改当前人物的草稿，仍须保存人物库：“能力全满”将四维设为默认能力上限100，之后可继续手动调整。兵法页只保留三个批量按钮：九类熟练度均不低于1000时显示“清空熟练度”并清零，否则显示“熟练度全满”并设为1000；九类均精通时显示“取消全精通”，否则显示“全精通”；共享目录的全部可学习兵法都已学会时显示“清空兵法”并清空已学集合，否则显示“全兵法”并加入全部可学习兵法。兵法批量操作与手动勾选共用同一筛选，单项调整后按钮文字立即跟随当前状态更新。熟练度、精通和已学兵法的辅助操作不互相改写；缺少可学习兵法时禁用“全兵法”。

两个入口采用相同字段范围：四维、熟练度、寿命档及两类优先级为非负整数，不受原版能力或寿命档上限硬截断；相性0–149、义理／野心0–15、性格四档、连携加成0–100。固定出生年为正整数，登场年不得早于固定出生年；相对年龄模式只保存非负的开局年份差，固定出生年为0，部署／建局时以开局年减年份差确定出生年。登场年独立填写，不自动按出生加14设置；寿命档不解释为固定死亡年龄。

兵法勾选项按规则语义提供可选兵法、阵形／舰船技术、营造和石兵；不把舰船自动攻击或地形决定的具体陷阱效果当作独立学习项。水军保留艨艟、楼船、斗舰；谋略保留“陷阱”，不显示其穴陷／火陷／水陷／岩陷变体。不按兵法名称或原版编号区间筛选。

人物从当前资料集选择亲代和血缘。正式建局仅加入已安置人物和部署所需的亲代、血缘根，未部署的依赖保持休眠。

## 头像

“选择头像”显示游戏现有转换头像，可分页查看、按编号搜索并选取。支持上一页／下一页、直接输入页码后按回车跳转及箭头调整；搜索时回到第一页，页码范围按筛选结果更新。预览使用游戏公共`AsyncPortrait`、裁切定义和`TextureService`缓存；从标题菜单进入时复用已有服务，独立入口加载共享纹理目录。选择头像不需要先载入剧本。

人物只保存可空的`PortraitKey`资源引用，不提供图片导入、编码、缩放或内嵌文件。不限制为某个原版编号区间。未选择时显示占位；资源缺失时显示不可用并保留引用，不静默替换。

## 旗字

人物资料保存确定的旗字或无字。可手动选择、按当前姓氏重设，或启用随姓氏编辑自动关联的界面偏好。预览和读档从当前人物资料取得显示旗字。

## 分享与存档

玩家目录下的 `player-officers.json` 保存新建和复制的人物，与头像包、宝物插画使用同一玩家目录。原有武将的编辑继续写入共享人物玩家副本。

存档携带资料集标识、入局人物的身份和当前世界。读档从对应资料解析显示属性及规则。缺少资料集或部署人物时提示所需标识。跨机继续游戏需携带存档、所用游戏资料以及引用的玩家人物库与图片。详见[存档规格](BEH-SAVE-0001-session-persistence-replay-and-headless.md)。
