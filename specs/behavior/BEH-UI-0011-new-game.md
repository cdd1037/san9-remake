# BEH-UI-0011：新游戏创建与开局设定

状态：已确认

## 目标与入口

无参启动按“主菜单 → 剧本 → 玩家势力 → 开局设定 → 决定”创建新会话。设定页默认高级、史实，六项电脑战力增量为零；返回保留草稿，更换剧本重新准备势力与设定。创建期间锁定重复确认及返回，地图资源就绪后才完成确认；内容或地图读取失败时整体释放本次运行场景，保留草稿并允许重试。地图、纹理与界面共属该场景，界面先于它使用的音乐和纹理服务退出。

新游戏确认后立即以500ms连续淡出，同时在后台读取内容、校验并创建新会话；Godot节点、纹理上传和界面组装由主线程完成。地图与界面保持隐藏，全黑后若仍未就绪则继续等待；目标画面就绪且已全黑时替换场景，再以500ms淡入。准备与淡出并行，不串行增加一段淡出等待；准备较快时也必须等到全黑才替换。淡入完成前暂停新场景的演出与交互；完成后先播放既有“战略”字图和音效，字图结束才进入军师开局发言。字图与对白均不在黑屏期间消耗播放时间。转场不推进日期或额外执行领域操作；准备失败时释放新场景、淡入恢复原页面及草稿，再提示并允许重试。原作换景节拍及重制采用连续透明度的边界见[RE-0200](../../research/findings/RE-SAN9PK-0200.md#2026-10-23主菜单换景时序复核)。

最多八个玩家势力是选择界面的限制；会话按明确选择集合建立控制席位，领域身份不按编号或原版槽位推断。先激活所选预留势力、清除所选异民族身份，再执行一次性初始化与既有首旬准备。所有选中玩家及其委任军团都免于电脑补偿；仅把控制器用于自动执行不能改变选择身份。

## 难度与电脑战力

| 设置 | 一次性对象与效果 |
| --- | --- |
| 初级 | 活动普通电脑势力的每个军团账户资金、兵粮乘12/10，整数截断 |
| 高级 | 上述倍率改为14/10；每座活动普通电脑城市另加10000兵 |
| 资金、兵粮增量 | 上述账户在乘倍率后分别相加，各自封顶1000000；不是周期收入倍率 |
| 内政增量 | 已占据的非玩家活动城市，包括电脑异民族；增加当前治安、商业、农业、耐久，各受自身上限约束 |
| 士兵增量 | 同上城市；与高级加兵、电脑异民族原有的开局加兵独立叠加，受城市兵力容量限制；兵役人口不变 |
| 士气增量 | 非玩家活动城市、有效地域设施及野外部队，封顶100；无主城市不加，非玩家地域设施包含无主设施 |
| 强度 | 接入既有电脑对玩家的伤害修正字段，独立于初级／高级 |

休眠、失效对象不领补偿。持续AI等待、尝试预算和军事候选读取世界保存的难度；内容中的AI难度默认只决定未显式指定设定时的新会话默认值，读档不再用它覆盖保存的难度。

## 史实与虚拟

史实保留剧本人物属性和关系。虚拟以会话种子和稳定身份顺序重建存活人物的义理0–15、野心0–15、性格0–3、寿命档0–7、相性0–149；清除亲代、血缘根改为本人；对各势力忠诚先置50，当前所属改为80–100。统率、武力、智力、政治、兵法与在职归属保留。活动在野、未发现、未登场人物从内容显式声明的候选地点中重新选址；休眠组保持预留地点。活动势力之间关系改为50，联盟与攻打约定分别保留。

虚拟跳过特定人物配对及亲属连携加成，保留相性与人物独立加成；阻止三顾茅庐推荐、连环计前置、二乔、孙尚香婚姻、汉中王、五虎将、出师表、乌巢和赤壁的相关史实入口。已开始的事件链仍按其既有状态继续；称帝维持已采用的“虚拟可称帝”，不把虚拟当成全部事件的总开关。消息中的史实／虚拟条件读取当前世界设定，独立于剧本一般／if分类。

候选地点为剧本契约`fictionalOfficerPlaceIds`；版本Importer负责解释原作排除表，共享Core不含源编号范围。自定义内容可以独立声明候选地点与可扩展人物、势力集合。

## 开局发言与保存

首次进入各玩家势力时，依次显示开场、联盟成员／讨伐目标或敌方关系、友方关系、内政说明、必要的资源不足提示、势力目标，最后进入既有“请下令”提示。优先由现任军师发言；无军师时选智力最高的其他在职人物，仅君主一人时由君主发言。台词、说话人绑定及条件交给内容消息图，客户端不写原版消息编号。演出只读世界，不消费玩法随机、不重复结算或写进行记录。

模式、难度、五项资源增量、电脑强度及初始玩家集合随会话保存；存档摘要显示实际模式与难度。载入恢复保存状态，不重发补偿、不重掷人物、不重新播开局介绍。命令脚本记录完整建局配置，在第一条操作前拒绝设定或初始玩家集合不符。

## 验收与范围

- 设定页确认创建对应剧本与玩家集合，正常进入地图、显示开局介绍并生成首旬自动存档；失败可重试，重复点击不会创建多局。
- 分别覆盖两种难度、普通／异民族／玩家／玩家委任／独立军团、休眠、设施与容量上限。
- 固定种子下虚拟结果一致；不同种子改变随机属性，基础能力与在职归属保留；保存恢复不重复初始化。
- `verify-content`核对正式目录、世界、查询和双模式下各可选势力的开局介绍；逻辑求值不代替实际画面验收。
