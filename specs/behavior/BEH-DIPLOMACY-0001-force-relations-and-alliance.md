# BEH-DIPLOMACY-0001：势力关系与联盟状态

- 状态：已确认
- 负责人：项目开发者
- 最后更新：2026-09-21
- 关联证据：[RE-SAN9PK-0119](../../research/findings/RE-SAN9PK-0119.md)、[RE-SAN9PK-0120](../../research/findings/RE-SAN9PK-0120.md)
- 关联决策：[DEC-SIM-0001](../decisions/DEC-SIM-0001-determinism-and-saves.md)、[DEC-PROJECT-0002](../decisions/DEC-PROJECT-0002-selective-inheritance.md)
- 继承方式：关系保留

## 适用范围

适用于主势力之间的数值关系、关系档位、临时联盟的目标/成员/盟主身份、形成、期限、到期和提前解除。不规定联盟事件的具体文案或演出。

## 原作基线

双边关系是对称的 `0..100` 数值，按每 20 点划为五档。联盟身份与关系数值分离：一次只存在一个全局联盟目标和期限，参与势力中一名为盟主。联盟形成按季度在资格、开局时间和 1/4 随机门后选择目标与成员；成功时期限为 36 旬，成员间关系至少提高到友好区间、成员与目标关系压低，盟主获得基础信望。期限每旬减一，归零或状态清理时统一解除身份。

## 重制行为

保留对称有界关系、五档关系、联盟身份独立建模、单目标/单盟主、按旬期限和成功才写持久状态的关系。联盟目标与参与者资格使用类型化谓词，不把未确认的原作内部汇总量固化为产品字段。

初始联盟从内容完整保留目标、盟主、成员和剩余旬数，由 `SimulationState.Alliance` 唯一持有，成员集合不继承固定槽位。新局首轮更新不消耗期限，之后每次有效旬边界减一；恢复稳定存档不重复递减。联盟身份阻止成员间普通自动选敌；明确攻击沿公共强攻确认规则执行，反击独立检查状态与射程，不能因联盟身份一律禁止。联盟目标不受成员保护；到期只解除身份和保护，不重置已形成的数值关系。成员不足两方、盟主消灭或目标消灭时解除；普通成员消灭且仍至少两方时只移除该成员。依据 RE-0119 的通知/清理调用链，不因表现层通知缺失保留失效引用。

按 `DEC-SIM-0001`，季度形成门与候选二选一使用命名的显式稳定随机流；AI 通过成员资格后直接参与，不增加随机同意门。状态、随机状态和形成/解除事件进入存档与状态哈希。事件文案可现代化，但不得反向承担关系或联盟真值。

### 季度关系自然变化

依据 RE-0119 的季度入口补证，开局满30日后，每个有效季度更新在自然死亡及他势力忠诚恢复之后、季度经济之前，对仍存续的不同根势力无序对各处理一次：双方均非异民族时，关系低于39加1，高于50减1，39..50不变；任一方为异民族时，低于36加4，高于50减4，36..50不变。不是统一收敛到50；异民族关系51会降到47，35会升到39。联盟身份和玩家/电脑控制不豁免，不消费随机数。终局短路后不执行。

重制以根势力对象集合为准，军团不是额外势力对，不继承固定槽位。缺省关系0也参与，首次变化创建对称关系记录；沿统一关系写入发布变化事件。只在季度流水线执行，新局不足30日及非季度不执行，稳定存档恢复不重复执行；季度选择续行沿原流水线边界处理。规则版本为`san9-core-g10-v48`，旧规则存档与录像明确拒绝，内容包无需重做。

### 季度目标与参与

目标门槛使用同根势力现役兵与所属城市预备兵役人口之和，不含伤兵，不只统计野战部队。重制的救援在途兵属于现役兵，去返程期间仍计入，避免兵力仅因交接就改变总量。主路径在合计严格超过300000且至少拥有一座城市的有效主势力中取所属城市最多者；另一条路径在合计严格超过200000且基础信望低于30者中取基础信望最低者。两条路径均要求玩家控制或非异民族。先各选出目标，再检查该目标有至少三名合格成员；不因首选成员不足而自动尝试次名目标。两条路径均有效时二选一。

成员资格要求有效非目标主势力、玩家控制或非异民族、对目标关系低于60、双方君主不是亲子，并满足双方所属地域直接相邻或双方在同一州拥有据点。邻接来自可通行地理边界，不用递归可达或城市数量代替。最终参与时，非目标玩家势力单独选择是否加入，不受AI成员资格筛选限制；AI直接使用该资格。玩家接受前须能够查看将受到的请求违约及冲突清理影响。

地域边界保留方向：从目标地域到成员地域存在有效边即满足邻接，不要求反向边。水域格参与邻接须其地域当前具有港口；完全阻断格不参与，四方向出口独立定义。重制按据点当前位置查询所在地域，城市州归属直接引用城市ID，设施州归属通过所在地域的城市引用取得，不要求据点、城市和地域编号相等。只缓存不可变地图产生的候选边，当前港口、据点归属及存续每次查询；修改地图或地形定义后重新构建规则对象。没有地域拓扑或州归属的自制内容不凭空生成该项资格。

参与者至少两方才成立，盟主取当前信望最高者。为保持确定顺序，重制按稳定势力ID升序遍历；目标评分相同取前者，盟主信望相同取后者，与原版遍历的比较方向一致，但不继承槽位容量。形成后清理成员间当前接战目标和路线，将针对成员的普通攻击意图转为返城，并撤销指向成员的军团定向委任；不撤销对联盟外势力的所有命令。攻击请求另按其违约与失效语义处理，不能全部当作无代价删除。

## 状态与不变量

### 季度选择的提交边界

开局满360日、进入季度且没有联盟时，使用`alliance-formation`运行流通过1/4门；两条目标路径均有效时使用`alliance-target`二选一，即使两条路径指向同一目标也消费该次抽样。刷新当前信望后固定目标与候选成员，先按势力ID征询所有非目标玩家，再按势力ID征询合法电脑成员；电脑由 Application 经公共命令回答。

`AllianceEventSession.Proposal` 保存目标、合法候选及逐方已答／未答状态，不将电脑候选预先计入实际成员。季度事件阶段完成后进入`AwaitingDecision`，这是仅在内存继续执行的已提交边界，不允许保存或开启录像；仅接受当前受询势力合法控制者的参与命令，普通命令及推进拒绝。缺失回答字段不能视为拒绝。最后一方回答后，仅执行季度更新及适用的年度后续阶段，不重复此前阶段、日期推进或抽样。提案和已有回答不进入存档；录像从此前稳定起点重放选择。

实际成员不足两方时不写联盟、关系或基础信望；成立时期限36旬，盟主基础信望加25并限制到1000，再刷新当前信望。只读参与提示列出AI、已接受及尚未回答者之间的可能部队冲突，最终效果按实际成员重算。参与提示已包含可能受影响的有向攻击请求；成立时按实际参与者处理请求处罚与失效，并由公共军团方针维护清除外交保护下的无效定向目标。

重制选择：成员间攻击意图没有有效己方归属据点可返时清空，不虚构返城目的地；有合法归属据点则改为返回。人员任务不因联盟成立统一撤销，针对外部势力的主命令在仅清理成员接战目标时保留。

关系采用稀疏定义：两个不同有效势力缺少显式关系记录时数值为0；首次非零写入创建规范化对称记录。存档保留初始关系身份并允许运行时新增有效关系，不要求自制内容预填全部势力对。未知势力与自身关系仍拒绝。

- 输入与前置条件：有效主势力、双边关系、联盟资格、季度时间点、候选目标/成员、显式随机上下文。
- 状态变化：对称关系写回；联盟目标、成员、盟主和剩余旬数写回；形成/解除事件；盟主基础信望变化。
- 始终成立的不变量：关系处于 `0..100` 且双边一致；联盟身份不等同于关系档；目标不是成员；盟主必为成员；成功前不写持久联盟状态；期限归零后不残留身份位。
- 失败或无效输入行为：无目标、参与者不足或资格失效时不创建联盟；无效势力不得写关系。

### 君主死亡解除（2026-09-22）

依据[RE-0119君主死亡补证](../../research/findings/RE-SAN9PK-0119.md#2026-09-22君主死亡后的联盟解除漏接)，盟主或讨伐目标君主死亡即解除联盟，不因其势力仍可继任而延续；普通成员君主死亡不单独解盟。自然死亡、处决、单挑、狙击及历史事件共用此规则，在死亡提交后、继任／势力清理前执行一次。不得通过表现通知或特殊事件调用代替共享死亡入口。验收覆盖三种联盟角色、有无继任、重复清理、日结处决及保存重放。

### 讨伐成功结算（2026-09-23）

依据[RE-0119讨伐成功补证](../../research/findings/RE-SAN9PK-0119.md#2026-09-23讨伐成功与普通解散的区分)，成功须有明确完成方：战斗击破导致目标势力不再满足存续条件，且击破方是当前联盟成员（含盟主）；或日结被俘君主处置中，联盟成员决定处决目标君主。后者在死亡提交前结算，目标势力能否继任不影响成功。普通战略处决命令、自然／单挑／狙击／剧情死亡不借用日结成功入口；第三方击破、劝降及其他无战斗击破归属的退出仍沿普通解散处理。

成功方基础信望增加15，上限1000，不奖励其他成员或固定奖励盟主。记录目标、完成方、成功原因及实际增加量，并以讨伐成功原因解除联盟；同一联盟只结算一次，后续死亡、继任或势力清理不重复奖励或发送普通解散结果。战斗归属在击破源被吸收入城或删除前取得，不能从剩余单位、历史事件列表或当前城市所有者反推。范围攻击先完成同一效果的设施占领，再处理相关势力灭亡与入城。失败／普通解散没有额外信望扣罚，背盟处罚保持独立。

验收：盟主／普通成员／第三方击破，尚有城市或合格人物的非灭亡对照，日结处决／释放／普通处决，有无继任，奖励上限和重复清理；等待继任答复前不提前奖励，答复后原子完成；稳定保存及录像恢复保留奖励与完整事件。

## 示例与边界

- 关系 19/20、39/40、59/60、79/80 分别跨越档位边界。
- 成员对目标的旧关系减 20 后限制在 `0..35`；成员之间旧关系加 20 后限制在 `60..100`。
- 形成时参与者少于两名，只产生失败事件，不写期限和身份。
- 剩余 1 旬的联盟在下一次有效旬更新后解除全部身份。

## 验收标准

- [x] 季度自然变化覆盖普通/异民族阈值、开局29/30日、缺省关系、存续筛选、联盟不豁免及无随机消费；联盟选择续行顺序和保存恢复/录像不重复结算有测试。
- [x] 关系边界、对称写入与五档映射有自动测试。
- [x] 联盟形成成功/失败、成员不足、目标失效和盟主选择有测试。
- [x] 36 旬递减、到期和势力消灭提前解除均不残留联盟状态；存档恢复不额外扣旬。
- [x] 固定世界状态和随机种子得到固定联盟事件与状态哈希。
- [x] 目标门槛包含预备兵役人口，严格边界、同分目标顺序及首选成员不足不回退有测试。
- [x] 地域单向邻接、实时港口、同州异主据点及独立编号有测试；候选查询不消费随机数、不改变世界，恢复后结果一致。
- [x] 玩家绕过AI成员资格、拒绝参加、选择过程内存续行、稳定起点录像及成员间攻击清理有测试。
- [x] 自然死亡／处决覆盖盟主、目标和普通成员差异；继任不保留应解除的联盟，重复死亡清理不重复通知，日结处决保存／录像结果一致。
- [x] 测试夹具不依赖原版文件、机器地址或研究工具。
