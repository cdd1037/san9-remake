# 剧本编辑器

首版在已有内容目录中编辑单个剧本，入口为标题菜单的“剧本编辑”按钮。也可从仓库根目录独立启动，`--scenario`使用内容目录中的剧本ID，省略时选择首项。

```powershell
godot --path src/San9.Client.Godot -- --scenario-editor --scenario 0
```

`--content-root <目录>`选择转换内容根目录。独立启动与其他编辑器、直接内容包启动及世界验证互斥。

“武将安置 → 批量安置武将”可按姓名或 ID 搜索、多选共享武将，再统一选择都市和在野／仕官身份。撤回安置后，武将可重新参加开局部署。仍担任君主、军师、军团长、参加部队或持有剧本指定宝物的人物须先解除引用；一批中有人无法撤回时保留整批安置。

首页「开局地图」按当前草稿显示各城市归属，无主城使用中性色。点击城市或从列表选城，可查看所属势力、军团、兵力及城内武将，直接移交据点或在该城批量安置武将。应用后仍停留在所选城市，名单与配色同步刷新。点击「查看辖区」会在「据点」页选中并展开该都市，点选下属港口或关隘即可编辑。

在「势力」页选择势力，可按军团查看各据点的兵力和驻将数。展开据点可见本势力驻将，点击武将打开其安置表单；点击已启用的都市定位到开局地图，其他据点打开据点表单。未驻扎在本势力据点的所属武将单独列出。撤回安置时可按姓名、ID、势力、地点或身份搜索武将。批量安置和撤回窗口右侧显示完整已选名单，切换搜索词后仍可选中条目并移除。

## 编辑范围

| 页面 | 可编辑内容 |
| --- | --- |
| 剧本设置 | 标题、简介、年份、月份、开局旬、默认玩家势力，以及登场、自然死亡、迁移、官职请求、叛变、都市独立、势力兴起与合并开关 |
| 势力 | 建立与删除势力、联动任命君主与军师、信望、基础信望、爵位、国号、休眠状态，以及各军团的资金和兵粮 |
| 据点 | 移交归属、同势力军团、兵力、伤兵、士气、耐久、民心、商业、农业、人口、预备兵役和休眠状态 |
| 武将安置 | 势力、据点或地域、身份、官职、伤病、休眠、本旬行动、军团长标记和对所属势力的忠诚 |
| 宝物 | 当前安置、投放到武将、埋藏到地域、清除剧本安置 |
| 外交 | 在「关系矩阵」选择两个势力的交叉格，编辑 0 至 100 的关系值，两侧对称格同步更新。「联盟与委托」配置联盟目标、盟主、成员、期限和各势力接受的攻打委托 |
| 完整初始状态 | 完整`ScenarioDocument`的JSON，可配置部队、宝物持有、外交、事件进度、额外人物、人物安置与显式资料差异等现有契约 |

势力、据点、武将和宝物页可按名称或ID搜索。表单中的人物、势力、军团、据点、地域、官职、爵位和国号引用共用可搜索选择弹窗，可按名称或ID筛选并选择“无”清空。建立势力时选择未安置或在野武将和空白都市；势力以君主命名，自动建立直属军团，新军团资金和兵粮从零开始，可在势力页填写。移交据点时，新归属使用接收势力的直属军团。在职驻将可撤往原势力其他据点，也可就地改属，无主时转在野。君主、军师或军团长须撤回或先调整职务。人物基础资料由共享默认值和剧本显式差异组合，未覆盖的字段继续继承共享资料。完整数据页可添加共享目录中人物的安置，或声明剧本额外人物。

在「势力资料」中确认删除后，该势力的据点转为无主，在职武将就地转为在野，军团及其物资一并移除。剧本同步清理相关外交关系和攻打委托。删除盟主或讨伐目标时解散联盟，删除普通成员后至少还需两名成员才能维持联盟。删除默认玩家势力会清空该设置。势力仍有初始部队或受登场事件引用时，须先调整对应配置。

宝物页列出当前有效定义中的全部宝物，包含未投放项。名称和效果取自共享宝物资料。通过“投放到武将”选择存活人物，或通过“埋藏到地域”选择地图地域，两者共用可按名称或ID搜索的选择组件。选择新位置直接替换原位置，埋藏宝物可在该地域通过探索获得。“清除剧本安置”移除当前安置，开局采用共享默认。宝物页与完整数据页共用同一初始状态，随“保存剧本”发布。

完整数据应用前进行结构、引用和建世校验，拒绝未知字段、无效身份及地图布局修改；失败保留输入。切出完整数据页、保存时均先应用输入。首版使用原有剧本身份、分类、地图布局、据点集合、据点类型及外观；地图布局可在[地图编辑器](map-editor.md)中调整。事件进度可在完整数据页编辑。

## 保存与恢复

点击“另存为新剧本”，填写标题、简介并选择已有分类。副本使用当前草稿（含未保存的修改），获得独立 ID。创建后自动切换到副本，原剧本和副本都可从标题菜单选择。副本有独立的初始状态和入口，地图、表现资源与共享资料继续使用来源引用。自制剧本索引保存在内容根目录的 `player-scenarios.json`。

点击“保存剧本”或按`Ctrl+S`保存。发布文件位于原始文件旁，通常为`scenario.player.json`与`content.player.json`，分别保存完整初始状态和带预览的入口。两个副本共用现有文件锁、快照冲突检查和失败回滚事务。保存失败保留内存草稿。

玩家副本优先于对应基础文件。它保留共享资料引用与显式覆盖，初始状态为完整副本；基础剧本重建后，玩家副本仍保持自己的初始状态。玩家副本格式失效时明确报错。编辑器不改写已有对局，保存后新局使用修改后的数据；当前标题菜单的剧本名称、日期和城市归属预览同步更新。

点击“检查剧本”可在保存前执行建局校验。常见的武将驻地、君主／军师归属、据点军团或宝物持有人冲突会定位到相应页面和对象。开局日期须为1、11或21日。保存复用内容组合、文本格式和新局建世校验，保留有效对象与休眠状态。共享资料编辑器的引用检查同时读取玩家剧本，受初始状态引用的自建资料不能删除。

“恢复打开时的值”将整个当前剧本草稿恢复至本次打开时的状态，恢复后可再次保存。切换剧本、关闭编辑器或退出窗口时，有修改则提供保存、放弃和继续编辑选项。
