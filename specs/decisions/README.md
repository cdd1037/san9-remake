# 改良决策目录

本目录保存 `DEC-*`。只有涉及重要且长期有效的取舍、且理由无法由行为规格直接表达时，才新增决策记录。DEC 记录选择理由、备选方案与代价，并引用描述最终行为的 BEH，不重复规格。局部实现选择、一般视觉差异和未来设想不要求另立 DEC；不因不同于原版就自动新增记录。

新增决策使用[改良决策模板](../templates/improvement-decision.md)。决策被替代时保留原文件并标为“已废弃”，同时链接替代决策。
