## 对象、状态、输入、输出与不变量

对象是交互 code 25/26、对应自动行动、来源部队、执行人物、目标部队、军师、类型 25/26 命令事件和势力关系。输入包括目标资格、人物当前有效智力、目标部队成员的当前有效能力、阵形、异常状态、兵法、稳定随机种子和提交时保存的 `0..99` 结果；输出包括部队异常状态、剩余日数、士气、势力关系、人物能力成长、策略熟练度、表现消息和任务占用。

不变量：玩家与 AI 必须汇合到同一命令构造器；军师意见与最终执行必须使用同一公式族但不能共享一次随机结果；提交阶段只保存稳定 `0..99` 载荷，执行阶段重新计算实时阈值；成功判定严格为 `stored_roll < live_threshold`；命令不扣资金或兵粮，行动成本是参与者占用与来源任务占用；持续日数写回保留已有值与新值的较大者。

## 已确认事实

### 玩家与 AI 生产者

交互 code 25 的 `COrderGihouDlg` 与 code 26 的 `COrderKakuranDlg` 均以虚表 `+0x20` 复验/填充、`+0x24` 消息映射、`+0x28` 创建命令。伪报要求目标满足单位有效、运行时标志 `0x8`、敌对/关系过滤和命令对象关联等条件；扰乱复用这些条件，并额外排除阵形类型 27。两者的执行者均要求人物有效且未置公共参与占用位 `0x1000`。

自动 code 25/26 先通过公共自动行动门，再建立目标、来源对象和执行者列表，任一列表为空即拒绝。两个执行者收集器都把人物当前有效智力限制在闭区间 `45..115`。目标扫描覆盖 850 个部队记录，排除同势力、兵力小于 5000、状态 4/5/7/8 和不匹配当前命令对象的部队；扰乱目标另有自身专用排除条件。自动评分回调临时构造真实命令，取得军师结果：结果 1 映射为 100、结果 3 映射为 0，其余使用真实公式阈值，最后由公共选择器创建与交互路径相同的命令。

### 复用公式 6/7 与军师意见

伪报公式 6 在非覆盖模式下要求目标状态为 1 或 5，且目标没有兵法 22。令执行者当前有效智力为 `A`、目标成员最高当前有效智力为 `T`：

```text
threshold = min(trunc0(3 * max(0, A-T+10) / 4), 35)
```

目标阵形为方圆（7）时再除以 2。扰乱公式 7 在非覆盖模式下要求目标状态为 1、阵形不是 27、目标没有兵法 22；把 `T` 换成目标成员最高当前有效统率，上限改为 30，其余相同。

军师阈值槽分别以覆盖参数 1 调用公式 6/7。公共军师判断取得真实阈值 `P`、军师判断准确度 `J` 和同一个稳定种子，分别求 `rnd(P, kind 0, seed)` 与 `rnd(J, kind 0, seed)`，只比较两者是否为零：零/非零真值相同时返回结果 1，不同时返回结果 3。这里不是两个百分比布尔检定；`rnd(n)` 的结果域是 `0..n-1`。

### 提交、行动成本与阶段竞争

两类命令提交都先经过公共参与者准备路径，把参与人物置为 `0x1000` 占用。随后以目标和执行者生成稳定种子，调用 `rnd(100, kind 0, seed)`，把结果写入类型 25 或 26 命令事件并挂到来源部队，再把来源任务标为活动。玩家可见时同时发出提交表现消息。

提交链没有资金或兵粮扣减。其成本边界仅包括人物参与占用、来源部队命令事件和任务活动状态。命令执行前仍会重新验证目标；因此从提交到执行之间的状态变化可使命令失效，不能把提交时的候选资格当作永久保证。

### 执行随机、部队状态与持续日数

执行器从事件中读回提交时保存的 `0..99` 结果，以覆盖参数 0 实时重算公式阈值。两类命令都仅在 `stored_roll < live_threshold` 时成功。

伪报成功调用公共状态写入器，给目标部队写状态 4、持续 `5+rnd(3)` 日，即 5 至 7 日；并尝试让执行者基础智力成长。失败不写目标状态，只把执行势力与目标势力关系降低 `1+rnd(3)`。扰乱成功写状态 5；令目标成员最高当前有效智力为 `I`，先经公共执行能力换算，再由 SanCalc 的整数平方根 `sqr` 计算：

```text
duration = 20 - isqrt(compute_executed_ability(I))
```

成功还使目标士气降低 `1+rnd(3)`，并尝试让执行者基础智力成长。失败同样只把势力关系降低 `1+rnd(3)`。正常能力范围内扰乱持续日数约为 10 至 20 日。

公共状态写入器处理状态 4 至 8：执行状态专用的目标/命令清理，写异常状态标志，以 `max(current_duration, new_duration)` 保存剩余日数，刷新部队，并尝试让目标成员习得兵法 22。故覆盖已有异常时不会缩短剩余时间。

### 表现、熟练度和收尾

成功/失败消息仅在相关势力对玩家可见时进入表现路径。无论结果，两类命令都会让来源参与人物在策略类别 7 和 8 各获得基础值 2 的兵法熟练度增量；公共精通倍率会使实际增量为 2 或 6，并受既有上限约束。随后统一处理被击破对象人物与命令任务收尾。
