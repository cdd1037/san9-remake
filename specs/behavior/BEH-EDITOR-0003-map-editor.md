# BEH-EDITOR-0003 地图编辑器与地图创作输入

状态为已确认。

## 目标与范围

地图编辑器从内容目录的共享入口打开，不选择或解析剧本。可编辑地貌、地域、通行、建设、桥和共享地点位置。独立启动使用 `--map-editor` 与可选 `--content-root`。

编辑草稿、操作历史与发布由 Application 持有，Content 定义基础数据与确定性构建，Rendering 提供地貌合成和基础格的高差表面几何，Godot 组织输入和显示。正常运行只读取转换内容。

## 基础输入与派生数据

- `MapDefinition` 保存地图宽高、基础格及建筑显示类型目录。每格维护地形引用、高度、纹理变体、可空地域、地域名称显示资格、可空桥方向、部队阻断、影响传播阻断及建设地表资格，并声明默认阻断规则的地形引用和港口开放半径。
- 部队阻断和影响阻断是可独立定制的作者规则。原版导入完整保留两个源值，包括45格地形例外。地域连接由四邻格的地域、影响阻断及港口资格生成。建设地表以普通、横向、纵向资格表达，设施目录的占地决定具体设施能否在对应地表建设。
- `MapResources.TerrainStyles` 声明地貌排序、变体和逐高度／高差形态的资源选择，以及水面、岸边的显示资格。Importer 将源版本的取样公式展开为资源表，通用构建读取声明。源样本中超出自然地貌坡面范围的高度仍有明确取样结果，转换保留该结果。
- 高差掩码、八邻格过渡、地貌绘制记录、画布尺寸、桥图片位置、水面位置和地图外缘在加载时重建。作者维护基础字段。基础格与资源主题决定同一结果，预览和游戏共用构建流程。
- 重制选择采用相邻地域及其关联都市生成疆界，每条共享边绘制一次。都市归属的关联由地图草稿维护。源格式的疆界方向位留在 Importer 的源记录与研究中。
- 领域地形、高度、地域、阻断、建设位置、人事连接和军事都市网络由地图和剧本布局生成，转换时可将离线构建结果保存在地理文件。依赖为地图基础格、地域与都市关联、设施规则、地点占地与位置及都市集合。剧本地图入口记录这些输入与构建算法版本的哈希。缓存缺失或依赖变化时，正常加载在内存重建；保存时验证有效地图和派生地理。正常客户端核对显示地图和领域格数据一致性。
- 地点目录按 ID 保存唯一格锚点与占地，覆盖已建和未建地点。剧本只持有地点启用与设施状态；选择页、新局、军事地点与显示按相同 ID 解析。移动共享地点时将目标格归入其地域。对象占地须在地图内并与其他地点互斥。

## 编辑与预览

左键连续涂刷，移动轨迹插值补格，一次按下到松开形成一笔。默认换地形逐格沿用高度，必要时取目标地形最近的可用制作高度，同类地形保留原样。精确涂刷支持独立修改地形、高度和样式，无效组合撤回整笔并显示原因。地貌取样后复制三个字段；常用选项折叠不影响吸取、展示和保存罕见值。Ctrl 加左键吸取当前格，右键、中键或空格加左键平移，滚轮围绕鼠标缩放。数字键 1–6 切换工具，F 查看全图，输入字段持有焦点时保留字段的键盘操作。编辑器填满实际视口，窗口尺寸变化时保持地图视图中心。

据点移动从已有据点的格开始拖动，显示目标格预览，松开后统一应用位置。也可通过坐标字段应用位置。

涂刷改变地形类型时自动生成改变格的默认影响阻断，并重算这些格及周围八格的部队阻断。移动港口时自动更新旧、新开放范围内的岸地形及其周围部队阻断，与原操作共用撤销历史。通行工具用于特殊需求下手工设置两个阻断值。默认生成按地图声明的地形资格计算影响阻断，按港口布局开放指定半径内的岸地形，再由当前格与八邻格的影响阻断及地图外缘计算部队阻断。局部生成只重填受影响格的影响阻断，并重算这些格及八邻格的部队阻断，其他区域的已存规则保留。原版默认规则将岩、浅濑、水畔设为阻断，港口两格范围内开放水畔。整图重新生成由作者显式触发。高度、变体、普通据点位置及手工阻断编辑沿用作者设置。未标记手工例外的水畔始终按当前所有港口的覆盖范围计算。

Ctrl+Z 撤销，Ctrl+Shift+Z 或 Ctrl+Y 重做。历史最多保留 50 次操作，覆盖笔刷、阻断生成、地域关联及据点移动。历史与未保存判断使用独立快照，后台预览读取草稿快照。

预览提供四季、网格、地域、据点和建设资格图层。顶栏开关控制建设资格显示，左侧建设地表面板独立设置展示类型与涂刷资格。普通、横向或纵向展示保留对应格的亮度并压暗其他格，选择建设工具时自动开启上次所选类型，初始为普通。图层读取当前已呈现草稿的逐格资格。预览采用正式地貌分块合成及资源缓存。拾取、网格、高亮与笔刷覆盖共用基础格四角高差表面，投影重叠时选择前方格。一份草稿的地貌、对象与表面几何一起提交；资源准备期间呈现上一完整版本。失败显示原因并提供重试。预览中的水面使用静态地貌。

## 保存与加载

地图基础修改写到所引用地图定义的玩家副本；地域都市关联写到所引用地理的玩家副本。所有引用同一路径的剧本读取相同修改。移动地点只发布共享地点表及实际变化的地图格，不写剧本入口、初始状态和显示位置。据点当前锚点决定其所在格地域；设施类型的港口标记和当前布局决定水畔开放范围。按地形规则生成的格按本剧本港口解析，手工阻断覆盖规则。旧版剧本状态可读；接入共享地点后以共享坐标构建世界。

共享输入变更发布前逐个验证引用该地图或地理的剧本。发布前统一校验素材、地域引用、据点锚点、领域地理和实际建世。所有文件使用公共保存锁、输入快照冲突检查及失败回滚事务。失败保留草稿，外部修改要求重新打开后再编辑。关闭编辑器及退出窗口时，未保存草稿提供保存、放弃和继续编辑。

开局选城页目前使用原版示意图，实际开局地图使用发布后的地理与位置。

## 验收

- 原版基础格、桥和规则资格完整转换，高差与地形过渡可重建。
- 地形类型和港口位置改变后，默认阻断即时更新，旧、新港口范围及邻格更新正确，与原操作共同撤销。手工指定的阻断优先于港口覆盖规则，高度和变体编辑保留这些设置，经正常保存和加载还原。
- 连续涂刷形成完整笔画，撤销、重做及取消非法笔画恢复正确，保存基线与后台快照独立。
- 改变地貌、地域及位置后，显示与领域查询一致。据点移动的各位置消费者共同更新。
- 保存后通过正常内容入口重开，能创建新局；原始共享地图保持其内容。过期草稿发布失败并保留最新文件。
- 像素预览与拾取使用同一提交版本，资源错误可重试。实际画面验收按用户分工执行。
