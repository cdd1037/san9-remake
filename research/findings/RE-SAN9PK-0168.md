## 目标与方法

本次只处理最近两次文本提交明确留下的逆向未决项。选择器以`0x567460 evaluate_text_expression`的跳转表、实参读取和被调函数为准；对象属性以人物`0x450C20`、势力`0x444880`、建筑`0x437BC0`、宝物`0x448200`、部队`0x469730`五个目录虚函数求值器为准。事实层确认“原版读取什么和如何变换”；重制是否已有对应领域状态或查询由Core/Application另行决定，不反向降低Importer的语义确认度。

## 条件选择器C9..DF

原始字节减`0xC9`后进入22项分派。原解析器把D1误作“一人物加数值”，并把D2..D7整体提前一格；这会消费错误数量的字节，不只是命名缺失。实际映射如下：

| 字节 | 参数 | 原版语义 |
| --- | --- | --- |
| C9/CA | 数值 | 概率／排他上界随机 |
| CB | 无 | 保留槽，固定返回0 |
| CC/CD/CE | 两人物 | 亲子／同父母／同血统根 |
| CF/D0 | 两人物 | 年长亲属／年幼亲属 |
| D1 | 两人物 | 亲密度距离 |
| D2/D3 | 人物、数值 | 持有指定宝物ID／持有指定宝物类别 |
| D4 | 无 | 剧本ID |
| D5/D6/D7/D8 | 无 | 年／季／月／日 |
| D9 | 两人物 | 当前势力同根 |
| DA | 两势力 | 势力关系值 |
| DB | 无 | 保留槽，固定返回0 |
| DC | 无 | 剧本史实模式：0史实、1虚拟 |
| DD | 数值 | 世界标志 |
| DE | 人物 | 其关联部队的命令／事件类型是否在38..52 |
| DF | 人物 | 其关联部队标志位0是否为内部／城内部队 |

CF调用的`0x44D100`此前因函数头前一字节误定义而无法反编译。恢复精确边界后可见：第一人物列传资源码为1时直接为真；否则第一人物是第二人物的父母，或二者同父母且第一人物较年长时为真。D0的`0x44D150`方向相反：第一人物是子女，或同父母且较年幼。这里的“年长／年幼亲属”名称保留列传码特殊入口，不将其缩写成纯父兄／子弟规则。

## 五条EXE文本候选

`0x61851C`实际是DWORD序列`7,6,5,4,3,2,1,0,0`；`0x61AF90`开始是`13,7,13,7,15,0,15,0`，此前`0x61AF94/0x61AF9C`恰因低字节为07被误定义成C字符串。三者已在主库改回DWORD数据，不属于文本候选。

`0x61C258`只有`ESC "[%d"`，唯一调用者用它构造文字样式控制；`0x620008`的`%*c%s`唯一用于目录行字段宽度和补白。两者是完整、有效的内部格式字符串，但不是独立显示消息。研究导出现在明确标为`style-control-fragment`和`catalog-row-template`，Importer验证原字节后不送入消息语法解析。重新导出得到2,446条登记字符串，其中2,444条消息候选全部语法支持、118条含格式参数，另两条按上述边界排除。

## 覆盖结果与剩余边界

四档案26,641条记录仍全部逐字节核对；26,636条完整消费，26,634条本条语义确认，26,633条依赖图确认，21,848条无需玩法绑定即可求值。剩余拒绝项只有五条异常尾部、四处宿主展示控制`1B 48`，以及一条引用异常记录导致的依赖拒绝；部分记录同时命中两类原因。

RE-0167的102条动态观察和47处未匹配调用属于窗口归属、接收对象别名与函数边界清单，不构成通用文字颜色通道的未知语义。帮助／教学正文额外规范化已确认但尚未接入；Godot原生富文本缺少局部阴影表达能力也是产品实现边界，二者均不需要继续逆向才能作决定。
