# BEH-UI-0009：PK设定

- 状态：已接入，画面待验收
- 依据：[RE-SAN9PK-0193](../../research/findings/RE-SAN9PK-0193.md)

## 目标行为

战略面“功能→PK设定”显示五行：兵法演出、单挑演出、他势力部队的命令、他势力部队的兵法、武将的阵亡。单挑演出一行仅作禁用预览，其余各行独立二选一。窗口沿用原版 `431` 像素宽度、55 像素行距和转换皮肤，按行数扩展高度并居中。点击执行提交变更，点击中止、关闭、Esc 或右键不提交；打开窗口时分别读取本地偏好和当前战局规则。

兵法演出作为本地 `UserSettings` 保存，默认开启；切换战局及存读档后保留当前偏好，关闭仅跳过武力兵法特写，地图消息、命中／抵挡及狙击结果记录和战斗结算照常进行；特写对白改为地图喊话，特写专用画面及狙击插画不创建。其余三项随确定性世界状态存档和录像回放，新局恢复默认：他势力命令显示、他势力兵法显示、战斗阵亡关。世界处于非稳定阶段时拒绝修改战局规则。命令开关控制他势力部队当前命令及目标在部队目录、详情和地图命令摘要中的披露；人员移动等内部任务及其余部队策略仍不公开。兵法开关独立控制他势力部队成员的装备兵法信息。武将阵亡控制已有战斗阵亡门，不影响自然死亡、处决及其他人物生命周期。

执行时先保存有变更的本地偏好，再以一次会话操作提交有变更的战局规则；本地保存失败时保持窗口草稿并不提交战局规则。原作对命令与兵法分别存位，却未发现命令位的显示消费者。重制版依选项名称建立独立的查询门控，不复制疑似原作错误。验收覆盖两个显示开关交叉组合、执行／取消、存读档和录像、特写开关下战斗事实相同；画面以客户端实际显示另行验收。
