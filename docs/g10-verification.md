# G10实现与验证

状态：进行中，2026-09-19。完整范围与退出条件见[路线图](../specs/roadmap.md#g10事件范围与交付边界)。本记录不宣告阶段完成。

## 已实现与实际验证

- `EndingResolution`实现两类方针、八类结果、四阶段短路、两条继任稳定分支及非法输入拒绝；不足五人的势力不伪造责任者。
- `EndingSnapshotFactory`从只读世界与语义内容引用派生人物、有效能力、兵员、军团账户、都市条件及宝物持有情况；输入不变、旧快照不变，不增加世界权威状态或保存字段。
- 输入生产链已定向核对默认繁中IDA主库，新增证据见[RE-0143](../research/findings/RE-SAN9PK-0143.md#g10输入汇总复核2026-09-19)：在职人物筛选、建筑与野外兵员、同根军团账户及文化宝物持有人。此次为只读静态调查。
- `TerminalDefinition`与`EndingDefinition`已贯通Content、版本Importer、校验、内容指纹及Application；旬前置接入唯一普通势力／核心都市胜利、玩家／AI分流和期限短路。修正一个玩家退出而另一个玩家仍存续时的全局败北误判。
- 玩家胜利后通过`GetEndingPrompt`及`EndingOperation`选择，`Ending`查询结果；会话保存选择、结果从冻结世界派生。稳定保存、重复／非法选择及录像已验证，玩法命令仍被终局拒绝。
- 普通探索发现人物后，玩家直辖任务通过`GetSearchRecruitmentPrompt`与现有逐日任务响应实时决定是否登用；AI／委任自动接受。候选选出后暂停，回答时一次提交发现、登用和成长效果，失效目标取消且不重新抽人；拒绝不抽登用随机。待答期间禁止保存和导出录像，稳定边界恢复能力不变。
- 运行`dotnet test San9Remake.slnx --no-restore`全部通过：Core 1433、Application 246、Content 62、Importer 261、Godot客户端97、Headless 13，合计2112项。覆盖终局／结局、实时探索的接受与拒绝、非法响应、同日多个发现、AI一致性、目标失效以及稳定边界保存和录像；独立CLI实际提交结局选择与探索拒绝、写存档并重放，不以编译代替交互验证。
- 190年运行包已原位重转为剧本schema66／组合70；当前规则`san9-core-g10-v2`，保存及日志57，实时探索变更不改变内容schema。逐身份比较25势力、94据点、700人物、100宝物、1部队均未删减；核心城市45个，文化宝物引用20个与当前导入类别逐项一致。`verify-client`验证13487逻辑图像、5128物理文件通过。审计结果保存在忽略目录`local/generated/verification/g10/content-audit.json`。
