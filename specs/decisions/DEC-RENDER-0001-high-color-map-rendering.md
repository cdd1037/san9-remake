# DEC-RENDER-0001：地图渲染采用现代高精度颜色

- 状态：已确认
- 日期：2026-08-22
- 决策者：项目所有者
- 关联行为：`BEH-IMPORT-0014`
- 替代或被替代：无

## 背景

原作地图资源由索引图和每通道 8 位的 RGB 调色板组成，但地图像素合成后写入 RGB555 目标画面，每个颜色通道最终只有 5 位精度。RGB555 是原作实现与逐像素研究对照的基线，不是重制版必须继承的画质限制。

重制版需要保留原作地形资源选择、遮罩形状和过渡语义，同时避免在正式画面中人为重新引入色阶损失。未来也可能把底图和边缘混合迁移到 GPU shader。

## 决策

正式重制渲染使用每个 RGB 通道至少 8 位的颜色目标（RGB888 或精度更高的 GPU 中间目标），不模拟原作最终的 RGB555 写回量化。

RGB555 只用于原作研究、截图基准和可选兼容对照，不作为正式画面的默认输出。颜色精度选择不自动改变地形资源、遮罩或混合权重规则；若以后把原作的 256 权重混合改为归一化 alpha、线性光照或其他规则，必须另立渲染决策并进行截图验收。

## 备选方案

- 正式画面继续使用 RGB555：逐像素更接近原作，但会主动保留已过时的色阶限制。
- 先渲染 RGB555 再放大到 RGB888：输出容器位深提高，但已丢失的颜色精度无法恢复。
- 默认使用 RGB888，并提供 RGB555 研究模式：采用此方案，兼顾现代画质与逆向验证。

## 影响

- 玩家可见影响：地形渐变和边缘颜色更平滑，少量像素不会与原作截图完全一致。
- 数据/存档影响：无；资源索引和调色板数据保持不变。
- 测试影响：正式渲染测试以高精度输出为准；原作逐像素测试必须显式启用 RGB555 对照路径。
- 风险与代价：截图对比工具需要区分“资源/遮罩差异”和“RGB555 量化差异”。
- 回退方式：保留或实现独立的 RGB555 量化步骤，仅供兼容和研究输出调用。
