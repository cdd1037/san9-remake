# BEH-WAR-0005：兵法配置、机会与效果

## 适用范围

G07兵法内容、武将选择、冷却、武力连携、智力效果，以及与日级战斗、伤兵和终止清理的连接。采用的目标行为不等于全部已实现，退出证据以验收清单为准。

## 内容和配置

`TacticRule`保存稳定身份、可选熟练类别、明确效果类型、威力、最小间隔、学习门槛、可选择标志、设施作用资格与兼容阵型引用。不存在未知编号的通用伤害；无效引用、负值、重复引用和产生零分母的威力明确拒绝。源身份映射只存在于TC101 Importer。41项完整保留，技术、被动能力及设施攻击描述显式分类，不伪装为可主动选择的武力兵法。

源0–11及31–34为武力；12–18为阵型技术，19造营、20石兵、21破陷、22教谕；23混乱、24陷阱选择、25攻心、26幻术、27辱骂、28鼓舞、29治疗、30妖术；35穴陷、36火陷、37水陷、38岩陷为具体陷阱，39落石、40射台为设施攻击描述。不能把熟练类别内的目录顺序当作效果种类。

名称沿用原版消息资源：[RE-0151](../../research/findings/RE-SAN9PK-0151.md#兵法实例名称与说明的资源绑定)确认兵法名称与说明来自消息文件。38「岩陷」是陷阱选择出的具体效果，39「落石」是建筑能力，两者是独立条目；说明和规格不得把岩陷简称为「落石」或另起「滚石」名称。

武将持有唯一`EquippedTacticId`及非负`TacticCooldown`，进入快照、哈希和存档。新局保留源已选兵法，源无持久冷却输入时明确初始化为零；存档恢复不能套用新局初始化。`SelectTacticCommand`允许己方当前控制范围内的在仕武将设置或取消可选兵法，外出任务中拒绝。资格来自该武将习得、所属势力或该武将持有的已发现宝物，不能借用同部队其他成员。选兵法不消耗内政行动，也不重置冷却；这是重制版对两种状态所有权的明确分离。每日命令前全人物冷却饱和减一，与当天能否发动分开。

## 算术与状态写回

`TacticMath`为纯算术，随机选择、抵抗和目标筛选由结算层负责。采用RE-0068公式17–24的截断顺序，中间量使用精确整数，最终按当前目标和接收容量截断，不继承机器溢出。

- 武力逐成员计算`power*(proficiency/2+1000)*max(70,war+45)/1000`，联动成员随后除二，求和后才加倍；加入内嵌普通伤害，再乘效果和异常目标系数。正常/抵挡/步兵特效为10/1/15；异常目标系数13，通常10。
- 混乱效果为0时不写状态；否则`effect*min(10,Q+intelligence/20)/10+1`日，`Q=(proficiency+100)/250+1`。
- 辱骂、攻心、幻术、妖术、陷阱、鼓舞、治疗使用各自独立公式，不共享默认伤害。效果只接受0/3/10。攻心对设施最多转出3000兵，接收容量不反向减少目标实际损失。
- 治疗按现存伤兵和剩余兵力容量取最小值；公式中至少恢复1000的项不允许创造伤兵。状态恢复和武将伤势清除由结算层另行提交。

## 状态与不变量

### 智力效果与支援

陷阱选择按目标中心所在地图格查询`TrapTacticIds`，格值为具体陷阱引用或明确的空值；提供陷阱选择能力时必须覆盖完整地图。选择资格仍检查武将装备的选择兵法，具体陷阱提供威力、九日间隔及目标/阵型资格，不能要求武将另行习得具体陷阱。成长与习得归属选择兵法，装备保持不变。空格不投效果骰、不重置冷却；破陷反制具体效果。TC101地形及高处岩石的映射仅存在于Importer；高处搜索按整数平方根距离不超过三格，即平方距离小于16；RE-SANCALC-0001已确认正数平方根向下截断。地形证据见RE-0068。

附近存在符合上述距离及高差条件的岩石格时，陷阱选择优先得到38「岩陷」，不是39「落石」。Importer预先为每个目标格计算具体陷阱引用，运行时按目标当前所在格读取；这张表不是已布置陷阱的状态，也不跳过发动和反制判定。

重复混乱取既有混乱剩余日数与新效果日数的最大值，不缩短已有混乱。部队其他状态转为混乱时采用本次混乱日数；通知报告最终权威持续时间。

混乱、攻心、幻术、辱骂、妖术沿普攻机会使用当前已选兵法，智力型不享受武力类别的阵型加倍，也不构造武力连携。成功门为`clamp(100+trunc(6*(T(sourceInt)-T(targetInt)-5)/5),0,100)`，目标取现场最高有效智力；成功后按双方同类熟练度差除10决定效果3或10。失败者不重置冷却，可继续消费本次机会中的后续候选。概率端点不消费随机，其他概率使用独立具名流。

教谕/破陷是可装备的反制兵法，不是阵型技术。反制须由目标现场成员当前装备且仍具有使用资格；不能因为同队有人学过就自动生效。高昂直接抵挡混乱；目标阵型的`ConfusionResistanceChance`、`BypassesPassiveCounters`显式定义额外抵抗与例外。来源和21/22顺序见RE-0068的G07回读补充。

**重制选择（2026-09-13确认）：混乱、攻心、幻术、辱骂、妖术对设施的发动与效果判定均不要求目标存在大将或驻守武将。** 有守军且满足通常目标资格的设施，即使无将驻守，也正常参与判定；幻术、妖术的主目标和范围内设施均遵循此规则。现场无有效防守武将时，防守智力和同类熟练度均取0，不产生武将装备反制。无将不代表必定发动，来源资格、距离、冷却、机会概率及效果规则仍然适用。此选择避免撤空武将反而获得兵法免疫；不继承原作的设施大将有效性门槛，原作证据及其主目标/范围效果边界见[RE-0068](../../research/findings/RE-SAN9PK-0068.md#2026-09-13无大将设施的智力兵法发动门槛)。

部队`ConditionDaysRemaining`保存当前状态剩余日数并保留源单位的`StatusDurationDays`；据点`ConfusionDaysRemaining`保存战斗中产生的混乱，新局为零。每日命令前递减，到零恢复通常状态并通知。混乱暂停移动、攻击及反击，保留原命令，降低普通战斗强度；到期后继续命令。占领/销毁清除据点混乱。计时只由日级阶段推进，保存恢复不能重新初始化。

**重制选择（2026-09-13确认）：攻心容量内倒戈兵加入发动部队现役，超额兵员转入目标所在地域关联都市的兵役人口，不转伤兵、不丢弃。** 对设施目标仍最多转出3000兵；通常从目标扣完整倒戈量。部队目标从`MilitaryDefinition.RegionIds`按当前中心格取得地域；设施目标使用其地域身份。再通过地域关联取得都市，不在地图格保存都市引用。城市是否属于发动方不改变回收地，敌方城市同样可接收。当地没有所属城市时，部队目标回退到其原驻地地域关联都市；两处都无城市时，仅从目标转走发动部队实际能容纳的兵，其余留在目标。每个来源扣减与现役/兵役接收分别记录实际量，兵役回收超过自然增长上限仍完整保留。此规则替代此前“差额仅报告且不转伤兵”的处理，也不继承原作超额转伤兵的做法，证据见[RE-0068](../../research/findings/RE-SAN9PK-0068.md)。

辱骂士气归零、攻心或伤害兵力归零均进入既有战败清理。幻术和妖术对主目标及范围内敌对单位/允许作用的据点逐一判定，第三方势力纳入统一清理，友军排除。

鼓舞和治疗在每日地图交战后有独立支援机会，无攻击命令也可触发；同队按阵位/身份选择合格且冷却为零的发动者，一队每日最多完成一次支援。鼓舞作用于范围内士气低于80的友军；治疗按各目标剩余容量恢复伤兵，并恢复通常状态、清零计时和在队武将伤势，即使没有伤兵也可解除异常。无可改善目标不投骰、不重置冷却。

范围是明确重制规则：`EffectRadius`按细坐标矩形间距定义；TC101幻术、妖术以主目标为中心，鼓舞、治疗以源部队为中心，半径均为3；其他兵法为0。内容必须显式给出，运行时不使用默认范围。恢复兵力保留所在部队士气；没有第二份治疗或倒戈兵员状态。智力兵法成长复用同类熟练度/习得规则，普通能力成长作用于智力。

### 已接入的武力机会链

真实普通交战后双方仍存活才进入武力兵法机会。`FormationTactics`显式提供基础概率、对方入口概率、有利类别、连携倍率和水战自动兵法；未支持机会的阵型为空，不读取原版编号。TC101陆战基础15%、水战10%，高昂加5个百分点；对方入口仅映射阵型1/8的50%门。都市周边10%加成尚待接入周边地理定义，不用行政地域代替。

陆战候选是健康、冷却为零、掌握当前选择且兵法与阵型/目标兼容的在队武将，按前中后排、同排身份升序处理。使用5/4/3阵位系数、20/14/10/9/8人数系数（五人以上取8）、有利类别倍率和末尾5/8截断；该概率曲线不限制武将或部队集合大小。水战直接在健康且间隔合格成员中均匀选择，自动兵法从内容的兼容集合中按威力降序、身份升序取有效项，故舰船无需装备陆战兵法；此选择顺序是明确的重制选择。

当前连携基项按相性环距封顶50，使用`(25+max(0,5*(5-distance)))*linkMultiplier`；同类候选逐人使用独立连携随机。亲密/亲属/列传加成尚待规范化关系输入，不用人物身份号代替资源代码。主发间隔取记录值，联动取各自记录值除三。当前武力抵挡按目标同类最高熟练度与主发之差除20判断，效果为1或10；步兵特殊效果15仍待目标分类映射。

**重制选择（2026-09-13确认）：武力兵法加倍概率取主发动者的对应类别熟练度，明确不继承原作读取参与列表末项的行为。** 概率为`1 + D*floor(E/100)`%，`E`取本次成长前的主发动者熟练度，部队来源`D=1`、设施来源`D=2`。联动者的加入、熟练度或遍历顺序不改变本次加倍概率；联动者仍按既有规则贡献伤害。设施来源不构造联动，只有主发动者，故此选择不改变原作设施加倍取值；设施源机会仍待接入。原作事实与设计意图限制见[RE-0101](../../research/findings/RE-SAN9PK-0101.md#事实间隔联动表现与成长)。

武力内嵌普攻读取当前交战状态，和兵法成员伤害一起提交一次损失；普通交战阶段已有的反击不再次重复，是本阶段的重制结算选择。所有损失、伤兵、士气、占领与终止共用`MilitaryCombat`和`BattleAftermath`。发动后全队同类熟练度增加3（精通增加9，上限1000），符合门槛者尝试习得，实际参与者随机一人取得3%的武力成长机会。顺序和随机流具名且稳定，结果由结构化事件说明。

电脑强度修正尚未接入；后续兵法结算遵循[WAR-0004的单次强度修正规则](BEH-WAR-0004-normal-combat.md#电脑强度修正已采用尚未接入)，武力兵法内嵌普攻与成员分量合成后只修正一次，不继承原作重复修正。

上述都市加成、关系加成、特殊效果与设施源机会仍是G07兵法剩余项，不以已通过的武力场景替代完整验收。

战斗写回复用兵员损失、士气、占领和部队终止链，不另维护兵员或俘虏状态。配置失败不改变世界或随机；冷却不能通过重新配置绕过；原版被动选择输入保留但不取得主动发动资格。纯函数测试不能替代日级效果与清理验收。

## 验收标准

- [x] 武力成员截断、联动折半、加倍与目标系数有手算例。
- [x] 部队真实命令与日级交战中，固定主发动者和随机种子，独发与追加不同熟练度联动者的首次加倍结果一致；覆盖主发动者熟练度0和1000。
- [x] 八类智力公式、零目标、抵抗、容量和大数值有测试。
- [x] 未知、阵型技术和未掌握选择原子拒绝；反制兵法可装备；选择/取消保持冷却，日级递减饱和到零，配置与人物状态可序列化。
- [x] 41项源定义、已选状态与完整运行时引用逐项审计。
- [x] 智力门、装备反制、混乱暂停/到期、攻心容量、范围敌我过滤、无战斗支援及存档计时一致有日级场景。
- [x] 攻心实际损失等于现役接收与兵役回收之和；覆盖所在地城市优先、敌方城市接收、原驻地回退、无城市仅转可接收量及设施目标。
- [ ] 有守军但无驻守武将的设施可分别受到混乱、攻心、幻术、辱骂、妖术；无大将不构成免疫，防守智力和同类熟练度按0判定，并经日级场景验证；幻术、妖术分别覆盖设施作为主目标和范围目标的情况。
- [ ] 普攻机会、陆水/设施候选、连携、间隔重置及抵抗使用独立命名随机流并有边界场景。
- [ ] 每类效果经真实命令和日级调度写回，击破、治疗、倒戈及异常到期不留失效引用。
- [ ] 连续执行、存档恢复、录像与独立CLI重放一致，最后集中验收。

## 未决问题

日级完整接入尚在实现；不得将纯算术和配置入口标记为G07兵法完成。

兵力超限的地理查询统一先取得对象所在地域，再通过地域与都市的关联取得兵役人口接收都市；地图格只保存地域引用，不展开保存都市引用。不优先接收进当地可驻军建筑，也不按建筑当前势力改选都市。地域关联都市的动态变化仅列入[远期规划](../roadmap.md#远期设想地域所属都市动态变化)，不属于当前行为。
