# 用户设置基础

“功能→PK设定”另见 [PK设定研究](../research/findings/RE-SAN9PK-0193.md)：兵法演出属于客户端本地偏好，默认开启。关闭后保留发动、连携及连锁参与者的头像发言和战报，跳过武力特写、命中／抵挡回应及狙击场内对白和特效；实际伤势、死亡及必要后续反馈照常处理。此开关不关闭智略／支援的头像或地图效果，地图喊话渠道不变。他势力部队命令、兵法和武将阵亡属于当前世界，经一次会话操作确认，随战局存档及录像回放。两项他势力信息默认显示，分别控制部队命令／目标和装备兵法，不继承原作疑似联动；武将战斗阵亡默认关闭，只控制战斗阵亡规则。关闭或中止丢弃草稿。“单挑演出”目前仅作为禁用的布局预览，不保存或控制演出。

跨局通关、教学等完成事实不属于设置，独立保存在[玩家档案](player-profile.md)中。

本地设置与内容包、剧本存档、Core 世界状态和规则随机无关。`San9.Client.Godot.Settings` 提供不可变 `UserSettings`、显式存储和客户端生命周期的 `UserSettingsSession`；新局及读档沿用本地偏好，地图创建前的开场影片独立读取已保存设置。“功能→设定环境”依次包含全屏、锁定鼠标、进行速度、讯息速度、进行记录、BGM、音效、电影八项可执行设置；“兵法演出”和“外交演出”在“功能→PK设定”中编辑。

| 设置 | 取值 | 首版默认 |
| --- | --- | --- |
| PlaybackSpeed | Normal／Double／Quadruple，对应 ×1／×2／×4 | Normal |
| MouseConfined | ON／OFF，鼠标限制在游戏窗口内且保持可见 | OFF |
| FullscreenEnabled | ON／OFF，无边框全屏 | OFF |
| MusicEnabled | 开／关 | 开 |
| SoundEnabled | 开／关 | 开 |
| MoviesEnabled | ON／OFF，启动、剧本开场及事件电影 | 开 |
| TacticScenesEnabled | 显示／不显示，武力兵法特写及场内回应，保留参与者发言和战报 | 显示 |
| DiplomacyScenesEnabled | 显示／不显示，外交前后对白与会谈演出 | 显示 |
| MessageSpeed | Normal／Fast／Pause，对应普通／快／暂停 | Normal |
| ProgressReport | Detailed／Summary／Off，对应详细／要约／OFF | Detailed |

默认值是本次基础实现的明确选择，不声称已核对原作编译默认值。原作选项及标签证据见[RE-0065](../research/findings/RE-SAN9PK-0065.md)。枚举以英文名称序列化，不继承原作配置整数编码。影片偏好保留在模型中，本次窗口不新增影片选项，也不控制地图或战斗动画。讯息速度和记录过滤按同一记录中的运行时消费者证据接入。

客户端装配层通过 `ClientDataPaths.Settings` 提供用户数据根目录下的 `user-settings.json` 绝对路径，再创建存储对象；存储本身只用 .NET 文件 API，可以脱离引擎测试。调用方持有当前设置，负责何时应用、保存及显示失败，不在每次读取时访问磁盘，不在存储层创建全局单例或自动覆盖用户配置。

读写时机：启动读取一次，此后消费者读取内存设置，切换剧本或读取存档不重新加载；设置窗口编辑独立草稿，确认／应用时先保存，成功后发布当前设置，取消丢弃草稿。读取失败时静默使用内存默认值，保留原文件；保存失败时保留草稿供重试，不发布新设置或显示成功。不依赖退出时保存，也不在播放声音或显示消息时读取磁盘。

文件采用 UTF-8、格式版本 1；原有字段必填，新增的 `TacticScenesEnabled` 和 `DiplomacyScenesEnabled` 缺省时为开启，`PlaybackSpeed` 缺省时为 Normal，`FullscreenEnabled` 和 `MouseConfined` 缺省时为关闭，保存时写入这些字段。文件不存在时返回默认值且不创建文件；损坏、其余字段缺失、非法枚举、未知字段和不支持版本明确报错，保留原文件。读取与写入权限错误交由调用方处理。保存先校验，在同目录写临时文件并刷新后替换目标，失败清理本次临时文件。当前仅支持一个客户端写入者，不承诺多实例合并。未来格式变化显式处理，不以缺字段默认为成功掩盖损坏。

测试覆盖独立读取、全部枚举往返、替换保存、缺文件、损坏和非法值、失败不覆盖已有值及临时文件清理。窗口布局使用原版客户区锚点及转换皮肤；自动化验证不替代画面和试听验收。

## 界面记忆

`Main`在启动时读取独立的`ui-preferences.json`，并将同一个`UiPreferencesSession`传给开局、局内及重建后的界面。翻页、切换模式只更新内存，返回主菜单、新局和读档不重新读取、不写盘；按用户要求，仅在正常关闭整个客户端时统一原子写入，有变化才写。强制结束进程前尚未保存的变化不会保留。普通环境／PK本地设置仍在确认时保存，二者文件和草稿独立，确认较早打开的设置窗口不会覆盖期间发生的界面操作。

| 记忆 | 共享范围及默认值 |
| --- | --- |
| 存读档页号 | 主菜单载入、局内储存与载入共用最后浏览页；初始第一页，中止保留，手动／自动页都可记忆；打开时按当前页数夹取 |
| 右侧名单页签 | 设施／武将／部队，默认设施；滚动位置与对象焦点仍仅保留在当前上下文 |
| F8边缘卷动 | 默认悬停，切换后新局及读档沿用；不把按键或鼠标手势状态持久化 |
| 图层 | 疆界及全图的势力／设施／部队显示，默认全部显示；全图是否打开不保存，新局／读档从详细地图进入 |
| 地图／一览 | 以下六组独立记忆，初始均为地图，同组不同入口共用 |
| 新武将按姓氏自动关联旗字 | 默认开启，独立编辑入口与主菜单编辑器共用；姓氏完成编辑后才关联，不属于武将资料，选旗不改开关，重设只作用于当前人物 |

地图／一览分组采用已核实的[原作状态所有权](../research/findings/RE-SAN9PK-0161.md#地图一览模式保存范围扩查同日)，使用英文语义枚举，不复制原版配置位：

- 势力：情报、流言两对象、赠与／请求／劝降对象势力、委任势力目标，以及军团编辑的势力目录。
- 都市：情报、委任辖区多选及都市编辑。
- 探索地域：探索目的地。
- 设施目标：移动、烧夷、夺取、请求攻击设施、委任攻略设施。
- 计略部队目标：伪报、扰乱、激励、救援。
- 出征／军令目标：出征、已有部队攻击／进军及输送。

切换即更新对应组的内存偏好，选定或中止不回滚；地图按钮与中止保持各自语义，后者退出目标选择并释放地图输入。详情往返仍使用原导航上下文，不保存候选、已选对象、草稿、相机、排序或滚动到此文件。开局势力选择、新势力起始都市和自创武将配置都市保持原有地图起始行为，不读取或覆盖普通偏好；建设精确用地不复用出征／军令偏好。暂不接入窗口几何或弹窗位置记忆。

文件为UTF-8、格式版本2，字段完整且严格校验，枚举序列化为英文名称；缺文件只使用内存默认值，不创建文件。读取失败保留原文件并报告，运行使用默认值；发生后续用户操作且正常关闭时才尝试保存当前偏好。写入复用同目录临时文件、刷新和替换；失败报告并保留已有目标文件。此文件与普通设置一样只支持一个客户端写入者。

## 窗口显示

环境设定中的全屏选项在执行并成功保存后立即生效，客户端启动时即应用，覆盖主菜单与编辑器入口。使用Godot普通Fullscreen模式覆盖当前显示器，不带边框且不切换显示器视频模式。关闭全屏后恢复此前普通窗口的位置、客户区尺寸及最大化状态；窗口控制器由`Main`统一持有，新局、读档和返回主菜单沿用同一份状态。

普通窗口的位置、客户区尺寸和最大化状态在正常关闭客户端时随`ui-preferences.json`保存。全屏、最小化和最大化期间保留普通窗口几何，重新启动先恢复几何与最大化状态，再应用`user-settings.json`中的全屏开关。首次运行按[系统缩放](ui/strategy-ui.md#启动窗口与系统缩放)决定默认尺寸；显示器移除或工作区缩小时，将保存的窗口夹取至当前可用桌面。显式尺寸、位置或模式启动参数优先，该次运行跳过窗口记忆的恢复和保存；headless及嵌入窗口也跳过。验收包括调整后退出再启动、最大化／全屏后重启并还原普通窗口，以及显示器布局变化后窗口可见。

“锁定鼠标”位于全屏选项之后，默认OFF。执行并保存成功后立即通过引擎Confined模式限制可见光标在游戏窗口内，关闭后恢复自由移动；窗口和无边框全屏均可使用。启动沿用偏好，中止和保存失败不生效，headless及嵌入窗口不应用鼠标限制。F9直接切换当前鼠标模式，仅临时生效，不修改保存的默认偏好；切出游戏应用时解锁，游戏内部下拉菜单等子窗口的焦点切换保持锁定，重新聚焦不自动锁定，可按F9重新锁定。再次执行环境设定时重新应用保存的偏好。

## 消息和进行记录

- PK设定中的外交演出默认“显示”，控制赠与、请求、交还和劝降在任务抵达后的外交接触演出。选择“不显示”后跳过抵达、会谈及答复对白，不创建会谈场景或切换会谈音乐；下令后执行武将的应答，以及自己军师在下令准备与交涉条件编辑时的建议均保留，会谈中的接待发言随演出跳过。玩家仍须选择和确认交涉条件。已有攻打约定时直接显示的使者报告、结果摘要、资源／俘虏交换通知、灭亡插图与进行记录保留，规则结算和随机不变。执行保存后生效，新局及读档沿用本地偏好。
- 进行速度是重制提供的客户端播放偏好，只缩放进行／战略标题、每日行军、普通攻击及兵法演出的时间。每日结算、随机与事件顺序不变，后台计算与资源就绪仍须等待；暂停不发布在途结果，玩家选择不自动回答。镜头操作、菜单动画、地图喊话的出现延迟与阅读寿命、讯息翻页与音乐／音效播放速度不随倍速变化。执行后保存生效，切换剧本或读档保留；不写入战局存档或录像规则。
- 普通消息每页显示4秒、快为2秒，资源就绪后计时，每次手动或自动翻页重新计时；暂停等待点击或按键继续。专用BGM由消息窗口临时接管时保留手动继续，沿用原版自动翻页门控。人物、结果、待答事件与结局的叙述共用此入口，选项确认窗口不会自动回答。地图喊话仍使用独立5秒生命周期，世界推进速度不受设置影响。
- 记录生产者提供 `MapReportImportance.Summary/Detailed`，当前只发布玩家任务结果及已接入的重大日结结果，均使用Summary，包括玩家相关的失败结果；普通叙述日志使用Detailed。普通叙述日志的归类属于重制选择。原版详细档还会显示更多第三方结果，当前生产者未补齐这些消息，本次不扩展事件和披露范围；原版已闭合的结果等级见RE-0065。
- 详细接收全部新即时记录，要约只接收Summary，OFF隐藏左下记录区域并停止即时发布及位置脉冲，右下任务列表继续显示。完整会话历史在过滤前保留，“情报→进行记录”仍可查看全部已收集记录。切换等级不重新发布历史记录、不重新求值、不补发脉冲；此前已显示的即时队列保持，OFF切回后恢复它。
- 执行先保存草稿，成功后立即发布音乐、音效、消息速度及记录设置并关闭；中止、关闭、Esc和右键丢弃草稿。保存失败显示原因，关闭错误提示后可继续编辑或重试；启动读取失败静默使用默认值，原文件保留。
- PK设定中演出变更先保存本地偏好，再提交发生变化的战局规则；只变更演出偏好时不产生战局操作。本地保存失败时不提交战局规则。

## 用户数据目录

客户端启动时由 `ClientDirectories` 统一选择内容与用户数据根目录，`ClientDataPaths` 提供存档、设置与玩家档案在用户数据目录下的路径：

- Windows／Linux 导出版（包括 Debug 导出）：可执行文件所在目录下的 `userdata/`，与启动工作目录无关。
- macOS 导出版（包括 Debug 导出）：系统“文稿”目录下的 `San9Remake/userdata/`，通常为 `~/Documents/San9Remake/userdata/`；同级 `content/` 由玩家自行放入转换内容，不随程序发布。
- 编辑器运行（包括使用编辑器二进制启动项目）、移动端及其他平台：Godot 的 `user://`，经 `ProjectSettings.GlobalizePath` 转为绝对路径。

相对根目录的文件布局为 `user-settings.json`、`ui-preferences.json`、`profile.json`、`saves/quick.save.json` 和 `saves/slots/`；手动与自动栏位共用最后一个目录。玩家档案当前仅提供路径和存储基础，尚未接入启动流程。

macOS 使用固定目录，不增加首次引导或路径配置；需要其他位置时沿用 `--content-root` 与 `--user-data-root`，仅覆盖本次启动。

启动选址不创建目录或文件；各存储在实际写入时按需创建目录。Windows／Linux 导出版需要放在当前用户可写的位置，写入失败沿用对应功能的失败处理，不自动切换目录。不自动迁移或查找旧 `user://` 文件；需要保留旧数据时，手动把原目录中的对应文件和 `saves/` 复制到新的 `userdata/`。
