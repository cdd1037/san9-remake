# 计略、主动外交与委任

P1 已按约定范围完成代码接入、命令文本整理及自动化验证；实际画面、点击手感与试听由用户验收，开发过程中未启动游戏。原作窗口和消息证据见 [RE-0182](../../research/findings/RE-SAN9PK-0182.md)。

## 正式入口与操作

自有设施命令菜单的计略包含离间、烧夷、夺取、流言、伪报、扰乱、激励、救援；外交包含赠与、请求、交还、劝降；任免中的委任打开军团管理。

准备页选择本设施空闲武将及公共规则允许的目标。流言另选对立势力，请求另选攻打设施，交还先选本方被俘武将并由其拘押方确定谈判势力。赠与的钱粮与宝物互斥，数字键盘限制当前可用量。完整输入后以公共只读行程查询的日期差显示“到达预定”天数；资格与行程计算由查询和正式执行共享，名单不逐人试执行、不计算军师意见。武将、目标或赠与改变时刷新所选命令的公共军师意见，相同选择不重播。

赠与准备页初始不选赠礼；钱粮显示“赠送量／可用总量”，未选金额留空，未选宝物及未选目标时的到达栏留空。可先选择目标查看行程，显式选定赠礼后才显示军师意见并允许执行。窗口与字段依IDA控件表核对，见[RE-0182第25节](../../research/findings/RE-SAN9PK-0182.md#25-赠与准备页字段与初始状态复核2026-10-22)。组合包213新增两项数值格式，需重启客户端读取更新后的包；实际画面与点击待验收。

请求准备页显示“请求期间180日”，选定接收势力即可预览行程，设施未选时不能执行或显示意见；更换接收势力只清除不再有效的目标设施。交还未选俘虏时到达栏留空，其顶部分隔宽416；请求及劝降未选对象时保留到达占位。三页布局与字段核对见[RE-0182第26节](../../research/findings/RE-SAN9PK-0182.md#26-请求交还与劝降准备页复核2026-10-22)。本次复用既有内容包，重启客户端采用修正，画面与点击待验收。

外交金额选择器增加重制便利功能：每次打开赠与资金／兵粮输入框时，默认用军师认为有利的最小金额；回复请求／交还的资金条件时，默认用军师认为有利的最大索取金额。此前手动选择的数值不作为再次打开时的初始值；没有可用的有利建议时沿用原默认值。推荐受当前金额范围约束，保留军师判断误差，只预填输入框，取消不改变已确认的条件，确认后照常给意见，最终仍由玩家提交。具体边界见[外交规格](../../specs/behavior/BEH-DIPLOMACY-0002-command-negotiation-and-resolution.md#金额输入默认推荐重制便利性)。本次不改内容包，重启客户端生效。

赠与资金最少1000、兵粮最少10000，由Core统一校验；数字输入、军师推荐、玩家／AI及直接命令提交共用该下限。余额不足对应下限时，该资源按钮禁用。规则升级v174，无需重转内容包；低于下限的旧在途赠礼会被载入校验拒绝，合法存档按现行规则加载。

命令选人窗口在公共武将页之前增加命令专用页。烧夷／夺取按武力、救援按统率、外交按政治、其余计略按智力降序；激励同智力时优先具备鼓舞兵法，专用页同时显示鼓舞。离间对象页按智力升序，包含忠诚、势力、所在及到达预定；交还俘虏页显示能力、忠诚、籍贯与所在。切换页签保留名单顺序，点击表头可自行排序。

计略／外交的设施、部队目标及军团攻略设施使用主地图与一览两种模式。地图的一览打开同一候选集，名单的地图或中止返回地图；地图右键、Escape 或中止返回准备页。设施与部队按对象类型区分身份，无效对象不可选择。

烧夷、夺取、请求攻打设施及委任攻略设施的一览采用各自命令专用首页，随后仅追加设施“所属”“战力”，不套用地域目录。各页名称保留港、关等设施后缀；烧夷首页显示守将统率、耐久、状态和到达预定，夺取另显示士兵与俘虏，请求／委任显示友好、士兵、耐久与在任。默认按守将统率升序，夺取同统率再按士兵升序；请求／委任按友好及所属势力排序。换页保留顺序。到达估计使用公共只读准备查询，并在本次名单中只计算一次；原作距离估算与实际行程预测的区别保持现有约定。

流言的两级势力、赠与、请求对象势力、交还谈判势力、劝降及军团“打倒敌势”使用势力一览共用的缩略图，在都市标记或势力领土选择候选势力；委任辖区都市使用都市缩略图多选，按“决定”写回草稿。缩略图和一览共享候选集，辖区两种模式共享临时勾选状态；往返保留名单页签、排序与当前位置。中止取消本次选择，局势变化后旧选择失效。

都市多选标题为“选择都市”，提供“总括解除”；选中标记使用独立黄色外框，位于城市图标下层。都市与势力缩略图共用原版完整摘要底图和地图原点，多选的一览、决定及底部装饰按原版双按钮布局定位。逐城专用显示坐标表仍按既有决定暂不导入，保留当前投影；见[地图标记边界](../../research/findings/RE-SAN9PK-0161.md#全国情报地图城市标记坐标算法)。

军团界面提供新增、变更、解除，方针随新增／变更提交。新增／变更选择辖区和分配钱粮，都督显示公共命令实际选任结果；解除归还钱粮和所属对象。方针显示为委任、重视内政、打倒敌势、攻略设施，分别对应全权、内政、势力攻略、都市攻略公共规则。管理入口在军团委任后仍可进入；没有可新增辖区时仍可管理已有军团。窗口旁“军团管理”提供军团编组、控制切换和方针调整。控制切换可选本方根／子军团；独立方针只选子军团，复用四种方针和原目标选择器，执行前均不写回。

准备过程中只修改草稿；名单、键盘和选项取消均不提交命令。点击准备页“执行”直接提交，不增加二次确认弹窗，计略、主动外交和委任一致。右键／Escape 关闭顶层准备页，选项窗的“中止”返回准备页。局势变化使旧草稿失效并提示重开；提交校验权限、人物、目标和资源，失败保留原因。成功只提交一次类型化公共命令。

## 布局与反馈

电脑向玩家赠礼或劝降时，进入外交待答窗口。赠礼显示来访势力、友好及实际钱粮数量或宝物名称，可接受或拒绝；劝降明确显示投降对象，可投降或拒绝。回答通过同一日任务响应提交，结论对白只播放一次。目前仅完成功能接线，原版UI待对齐，见下文“赠礼与劝降待答UI待同步”。缺少此接线消息绑定的旧包须重新转换，无需重建纹理；当前190年运行包已包含绑定并通过 `verify-client`。

委任执行成功后关闭准备页，使用公共结果叙述框提示本次操作：新增显示“编组了××军团。”，变更显示“对××军团的委任内容作更动了。”，解除显示被解除的军团。名称由本次发布事件和提交前上下文确定；关闭结果提示后留在地图，不重新打开委任页，也不使用失败提示框显示成功。原作证据见[RE-0182第13节](../../research/findings/RE-SAN9PK-0182.md#13-委任执行结果与返回流程2026-10-10)。

采用原作公共命令窗、名单、人物卡、属性栏、数字键盘和纵向选项素材。十二种准备页及委任页保留 IDA 确认的内容矩形、目标／武将卡锚点与资源行；部队目标显示地图预览。委任内容使用新增／变更／解除，方针随新设或变更一次提交；控制切换和独立方针作为重制便捷页，不放进此处原版三项内容选项；原作入口边界见[RE-0182第16节](../../research/findings/RE-SAN9PK-0182.md#16-独立控制与方针入口的原作边界2026-10-18)。

任务结果使用本次发布事件和发布前冻结上下文，不从之后的世界猜测任务是否完成。只显示玩家直接下令任务；计略成败、外交结论、资源损失／返还及任务失效进入叙述和执行记录。已在外交待答窗口显示的结论不重复播放；并发结果排队，叙述期间暂停既有播放／续行。夺取宝物采用事件事实摘要，避免猜测原作消息要求的旧持有人；损失与送达数字为重制补充。现行音效、对白、音乐及仍简化的演出见下文“命令表现复核”。

### 对白显示位置与后续归属

原版已核对的伪报特殊失败台词是目标部队位置的人物喊话，独立于成败结果的地图记录。重制目前将已接入的行动／回应显示为带立绘、姓名和正文的公共人物对话框，并写入执行记录；尚未显示在部队地图坐标处。因此“对白已接入”只说明消息与人物绑定已接通，不表示地图喊话形式已对齐。
