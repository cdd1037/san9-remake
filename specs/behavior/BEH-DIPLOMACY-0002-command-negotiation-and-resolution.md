# BEH-DIPLOMACY-0002：外交命令谈判与结算

- 状态：已确认
- 负责人：项目开发者
- 最后更新：2026-09-16
- 关联证据：[RE-SAN9PK-0117](../../research/findings/RE-SAN9PK-0117.md)、[RE-SAN9PK-0118](../../research/findings/RE-SAN9PK-0118.md)、[RE-SAN9PK-0120](../../research/findings/RE-SAN9PK-0120.md)
- 关联决策：[DEC-SIM-0001](../decisions/DEC-SIM-0001-determinism-and-saves.md)、[DEC-PROJECT-0002](../decisions/DEC-PROJECT-0002-selective-inheritance.md)
- 继承方式：关系保留

## 适用范围

适用于赠与、攻击请求、俘虏返还和劝降的玩家/AI 命令创建、复验、军师反馈、谈判、随机结算及世界状态写回。不规定 AI 如何选择候选。

## 原作基线

玩家与自动路径最终创建相同的类型化命令并共享执行器。赠与按提交资源和接受判定转移资金/兵粮，可伴随宝物、关系和政治成长；攻击请求经过报价/接受阶段，成功后写攻击目标，并按已接受条件释放交换俘虏或转移资金/宝物（不存在本链已确认的兵粮报价）；俘虏返还经过报价但不消费命令保存的随机数，成功后转移俘虏及相应资源/宝物；劝降消费保存的 `0..99` 随机数，成功时进入势力解体与归并链。军师意见是分类反馈，不等同于最终结果。

## 重制行为

保留四类命令的类型化状态、玩家/AI 共用执行器、提交/执行复验、资源守恒、命令特有谈判阶段及关系/人物/势力写回关系。报价、接受与最终效果必须分为可诊断阶段，不能用 UI 分支复制规则。

按[随机约定](../../docs/randomness.md)，赠与、攻击请求和劝降的AI接受／反要约类别使用提交时保存的固定条件百分骰：本局种子、用途、下令日期、使者及相关目标身份；攻击请求包括被请求势力与攻击目标。同条件不受无关操作顺序、命令序号、玩家读档或重启影响。资格、关系、资源和阈值在相应阶段重算，玩家选择仍由玩家决定。原作证据见[RE-0171](../../research/findings/RE-SAN9PK-0171.md)。

劝降后的逐人物归属、成长及其他随机后续效果采用独立用途的运行随机，不随接受骰一起锁定。俘虏返还按条件与谈判选择结算，不创建原作未消费的随机字段。军师采用[计略意见约定](BEH-STRATEGY-0001-command-advice-and-resolution.md)：固定条件、查询稳定、不消耗运行流、不暴露执行骰。

所有资源预留、命令参数、任务骰、随机状态和事件进入存档与状态哈希。玩家读档保留任务骰，仅改变未来运行抽样；录像精确恢复完整起点，不调用玩家读档换种入口。

赠与载荷在资金、兵粮与宝物中互斥选择，不接入源格式的保留数值。宝物阈值使用共享定义的`LoyaltyBonus`，不另外维护价格或从能力加成推算；字段依据见[RE-0117补证](../../research/findings/RE-SAN9PK-0117.md#2026-09-17-赠与宝物公式输入补证)。

### 日内玩家选择与续行

使者到达时，玩家接受、提出条件或接受反要约形成独立的可保存决策边界。世界保留当前日期、待谈判任务、实际响应方及尚未完成的日级推进位置；不能把外交选择当作季度联盟选择恢复。等待期间只允许实际响应方回答当前谈判，普通下令、结束控制和再次推进均拒绝。

回答后继续当前任务，再处理同日尚未执行的其他任务及剩余阶段；已经执行的每日状态、粮食消费、任务效果和随机抽样不得重复。多项外交同日到达时按现有任务稳定顺序逐项处理，可连续停在不同选择边界。去程任务在谈判完成前仍负责使者占用，最终结算或失效后才转换返程。最终接受时复验对象与报价，付款和转移至多一次；存档恢复及录像重放必须保持相同续行位置。旬完成事件只能在剩余日程真正完成后发出一次。

## 状态与不变量

### 攻击请求的履约状态

谈判成功后，由受请求方持有请求方、指定据点和剩余19旬的有向约定。每个受请求方同时至多一条，双方互相请求是两条独立约定；持久化集合不继承原作势力槽位。请求配对保护普通自动选敌，不能只记录一个军事目标而丢失外交关系。

每次旬更新将正期限减1，归零处理未履约。对指定据点开始实际普通攻击时即履约，受请求方基础信望加10并清除；占领入口可以处理尚未结算的履约，已清除者不得再次奖励。设置攻击命令或靠近不等于履约。依据见[RE-0118补证](../../research/findings/RE-SAN9PK-0118.md#2026-09-16-请求方向期限履约与联盟清理补证)。

有向约定的到期处罚由持有人承担；主动毁约由主动方承担。每条实际解除的约定使双边关系减20、责任方基础信望减20、责任方在职非君主人物忠诚减义理，经过公共有界写回。双向约定不得静默去重为一次代价。新请求被接受且请求方与旧约定不同，先结算旧约定毁约，再执行新请求成功效果；执行时已有同请求方、同目标的约定则收尾，不重复付款、提高关系或重置期限。

联盟形成先处理成员与联盟目标的请求配对，责任方为加入成员，再应用联盟关系公式；不能对已经规范化后的关系追加同一毁约损失。成员之间的约定若请求攻击对象属于联盟目标则保留；请求攻击对象有有效君主且属于其他势力时无处罚结束。对方灭亡、目标失效等对象清理与主动毁约分开表示，不能统一收取罚款。玩家同意前的影响查询须包括实际有向约定、责任方及处罚顺序。

运行态记录签约时目标归属，作为判断易主失效的约定条件；目标归属变化则无处罚取消，不将请求自动转向新主人。当前已接旬期限、履约/毁约、联盟清理、自动敌我判断、独立内容初始请求和稳定边界保存；公共外交创建命令与请求驱动军事规划仍待接入。TC101剧本没有请求元组，原版存档格式有而本项目不导入；不能把剧本宿敌引用当作请求。重制新局如有初始请求，旬调度不自动套用联盟开局豁免。作者只维护双方、目标据点与正的剩余期限；签约目标归属由初始据点推导，建局规范排序，内容指纹包含完整约定。初始集合不覆盖恢复后的当前集合，缺字段、重复持有人或无效引用必须拒绝。

G08采用已核对的繁中PK 1.0.1.0算术；`S(A)`沿用当前分段执行能力，整数除法向零截断。公式不替代外交资格和显式玩家选择：赠与阈值基础为`S(使者政治)/10 + max(0, 关系-60)`，资金、兵粮、宝物分别加`资金/200`、`兵粮/2000`、`宝物忠诚增量*2`；免费攻击请求阈值为`使者政治+关系-80`；俘虏补偿为`max(500, ((最高能力+次高能力)/2)^2/4 - 8*(使者政治+关系))`。对应 [RE-0117](../../research/findings/RE-SAN9PK-0117.md)、[RE-0118](../../research/findings/RE-SAN9PK-0118.md)。

赠与接受时关系增加`max(60-当前关系,20)`；攻击请求成功增加`max(40-当前关系,10)`；劝降拒绝减少`max(10,当前关系-39)`，均经统一关系服务夹到0至100。仅数值实际变化时产生关系变化事件。

- 输入与前置条件：命令类型、来源/目标势力、使者、目标对象、报价或赠与资源、当前资格和显式随机上下文。
- 状态变化：命令占用；资金、兵粮、俘虏和宝物转移；关系、政治成长、攻击目标或势力存续变化；结果事件。
- 始终成立的不变量：玩家和 AI 共享命令与结算；无效对象不写回；资源不凭空产生；使者占用最终释放；军师意见不预写结果；命令类型与事件匹配。
- 失败或无效输入行为：提交复验失败不创建命令；执行时失效则不应用目标效果，并释放预留/占用或给出明确失效事件。

## 示例与边界

- 赠与余额竞争导致提交资源不足时，不得部分扣除后继续。
- 攻击请求的对方拒绝、报价失败和最终失败是不同结果阶段。
- 俘虏返还不创建无用途的随机字段，按实际条件与谈判选择结算。
- 劝降成功必须原子维护人物、据点、部队、联盟和势力引用。

## 验收标准

- [ ] 日内等待的保存恢复与录像覆盖接受、拒绝、两阶段报价、同日多任务及跨日继续，已完成阶段不重复消费资源或随机。
- [ ] 非响应方、旧谈判回答及等待期间普通命令被拒绝且无副作用。
- [ ] 四类命令的玩家与 AI 路径产生相同类型化命令。
- [ ] 请求19旬到期、单向/双向毁约责任、开战履约一次性、重复请求不重复支付、对象失效及联盟形成处罚顺序有测试。
- [ ] 每类命令的提交失效、执行失效、成功和失败路径有自动测试。
- [ ] 资金、兵粮、俘虏和宝物转移满足守恒与所有权不变量。
- [ ] 俘虏返还无多余随机字段，改变种子不改变相同条件和选择下的谈判结果。
- [ ] 固定命令日志和随机种子得到固定事件与状态哈希。
- [ ] 测试夹具不依赖原版文件、机器地址或研究工具。

- [ ] 相同条件下，改变无关操作顺序、命令序号、玩家读档或重启不改变提交骰；实时阈值变化仍可改变成败。
- [ ] 军师重复查询稳定且不推进规则随机流；军师或有效条件变化会重算。
- [ ] 玩家读档保留任务骰，混合流程仍有独立运行抽样；录像精确恢复完整事件与状态。
