# 原版 AI 决策基线行为规格

状态：已确认；2026-10-16采用。本文规定目标行为，不表示新基线已经实现或通过验收。

## 采用范围与依据

本次建立以繁中PK 1.0.1为依据的完整规则型AI基线，保留策略骨架及人物特色，并按B01～B30修正已确认异常。原作事实及证据等级统一见[权威研究](../../research/ai.md)，人物配置见[人物特判](character-rules.md)，可执行验收见[验收标准](acceptance.md)。

下表确定各主题继承的基线；B条目是明确覆盖项。未列出的已闭合规则按对应研究的候选、排序、公式、阈值、投入及受限随机语义保留；研究中的推断、设计动机和待验证内容不自动成为要求。新差异必须补充采用理由与验收，不能以“更聪明”为由自行改写策略。

## 调度与战略

<a id="b01"></a>
### B01：工作顺序

军团轮转后依次执行战略准备、人员配额及有序工作批次；保留各控制类别、异民族和模式的工作顺序。前项完成后再推进后项，读取已经生效的变化，日期与行程按公共阶段结算。主军团、直接军团和根势力的查询范围分别保留；策略门不转为玩家命令禁令。

**重制选择（2026-10-16确认）：**外层采用Core的势力控制席位顺序；每个席位内先处理根军团，再按稳定集合顺序处理该势力的子军团，完成本势力自动控制后才推进下一席位。玩家直接控制的军团仍由玩家操作，委任军团在所属势力席位内自动运行。此选择让控制身份、玩家结束控制、事务发布与保存恢复保持同一边界；不采用[原作全军团统一排序](../../research/ai.md#lifecycle)，也不按原作信望键跨势力交错军团。

该差异可能改变登用、外交及争夺目标时后行动者读到的即时状态；这是已接受的执行顺序差异，不是待补的复刻缺陷。军团内部的工作顺序、公共权限及实际提交反馈仍按本规格对齐。后续只有具体玩法验证表明需要交错轮转时才重新评估，不将其列为OAI后续阶段的默认改造或验收前置。

<a id="b02"></a>
### B02：模式生成与更新

内部模式、策略分组与外部委任方针分别建模；保留方针对模式的影响、目标失效判断、准备指标和更新概率。正常自动生成原作已确认的六种模式（研究中0／1／2／3／5／6）；区域模式不额外编造生产规则，不为原版旧存档保留兼容入口。目标以势力／建筑等类型化引用表达，失效时原子清理或回退。

<a id="b03"></a>
### B03：战略目标从实际排序表选取

原作对一张合格对手表排序、却从另一张统计表取目标。重制保留候选资格、原排序依据和后续关系分流，从实际排序后的合格对手表首项读取。目的为使既定优先级实际生效，不另加全局强弱搜索。

<a id="b04"></a>
### B04：准备指标按统计对象归一化

**重制修正（2026-10-22确认，替代此前保留固定分母的选择）：**原作累计民心／士气使用单对象上限作分母，多据点会淹没发展／耐久不足，使军团更容易跳过或退出集中整顿模式。结合相邻属性的总上限比例与模式消费，判断为疑似归一化遗漏；这是修正依据，不将作者意图记为已证实事实。

保留直属、非休眠且未销毁的统计范围：经营仅计城市，军事准备计全部直属建筑。令`ratio(value, maximum)`在分母正时为整数`100 * value / maximum`，否则为100：

- 经营指标为`(ratio(收获合计, 最大收获合计) + ratio(收益合计, 最大收益合计) + ratio(民心合计, 1000 * 城市数)) / 3`。
- 军事准备指标为`(ratio(耐久合计, 最大耐久合计) + ratio(士气合计, 100 * 建筑数)) / 2`。

保留整数逐步截断及宽整数安全运算。无城市时经营指标为100，无建筑时军事准备指标为100；不因无统计对象进入集中整顿。增加相同状况的据点不改变指标。发展与耐久仍按总上限加权，不改为各据点百分比的简单平均。

模式回退仍先判断经营指标严格小于50进入内政，否则军事准备指标小于50进入备战，其余进入一般模式；既有内政／备战模式仍在对应指标严格大于50或通过8%更新门时重新选择模式。不调整工作顺序、普通进攻的来源士气门槛、显式委任及联盟／攻击请求的优先级。

<a id="b05"></a>
<a id="已采用差异外交排名不随策略分组清零"></a>
### B05：外交排名独立保存

有效势力在既定全局策略准备的日期门通过时，按原排序依据重算排名并完整发布；分组更新只改分组，不清排名。日期门未过时使用最近一次完成的排名，首次消费前必须初始化；失效势力不因残值进入候选。排名快照不能作为普通查询缓存按当前信望随时重建，否则会改变两次准备之间的外交选择；保存恢复须保留该快照。保留赠与要求目标排名值较大、劝降要求较小的严格方向；以可扩展的完整排序表达，不继承低七位或50槽限制。本项修正使排名实际服务外交选择，不要求解释原作正常旧档的非零留存路径。

<a id="b06"></a>
### B06：策略分组与历史偏好

分组统一命名为未分组（`Unassigned`）、战略优待组（`Favored`，原版元数据bit7）和行动收敛组（`ReducedActivity`，原版元数据bit8）。战略优待组影响部分敌对规划的回避和进攻兵力门槛；行动收敛组影响工作尝试次数、部分规划的概率跳过、劝降资格及军事后备分支，不只减少尝试次数。保留这些既有行为；历史人物、家族、起兵、继任和国号偏好按[人物特判](character-rules.md)配置。规则消费语义属性与引用，不以姓名、源编号、列传资源码或槽位分支。独立内容和Mod可配置同类规则。

<a id="b07"></a>
### B07：难度差异

新游戏默认采用高级难度（`OriginalAi.Advanced = true`），内容可显式配置初级；读档保留存档中的难度。保留高级缩短开局等待、调整部分尝试次数以及更早纳入新建部队的候选门；候选资格不保证出兵。开局资源补偿、额外加兵和伤害倍率不属于OAI阶段的考虑、实现或验收范围；本阶段不裁决是否采用及默认开关状态。

<a id="b08"></a>
### B08：稳定周期错峰

开局等待、日历周期窗口和尝试预算分别计算，不采用上次行动后的统一冷却。周期保留原窗口宽度和相位公式中的稳定身份错峰关系；内容中的持久调度标识在创建时确定并进入保存，恢复或列表重排不改变相位，不依赖固定身份范围。

## 人员、轮转与预算

### 军师选择

**重制选择（2026-10-19，根据优化伴侣修正）：**军师候选先按当前有效智力降序，相同时再按仕年降序，防止资历加分压过智力。仕年为`当前年−StatusStartYear+1`，加入当年算1年，不截到10；未记录起始年时不获得资历优先（按0年），不以年龄代替。两个键均相同时保留输入顺序。本项覆盖[原作](../../research/ai.md#13～17任命官职与宝物)的`当前有效智力+min(仕年,10)`加分排序。

保留原候选资格：同根普通在职人物至少五人；替代者忠诚至少80，当前有效智力落在`max(80,min(现任当前有效智力+1,115))～115`，无现任时下限80。现任追加参与排序，仍胜出则不任命。受伤、宝物和官职通过当前有效智力参与资格与排序，不按基础智力保护现任，也不设置伤愈自动复职。

### 自动任官的仕年

特殊官职直接从当前爵位允许的官职表分配，不要求君主未行动、驻留或无任务占用；人物候选仍遵循任官资格，不给普通任官添加君主可行动门。原作皇帝专属阶段与实现纠错见[工作14复核](../../research/ai.md#13～17任命官职与宝物)。

三段人物排序分别使用`当前统率+当前智力+仕年`、`当前统率+仕年`、`当前智力+当前政治+仕年`，各段另加忠诚至少150时的5分。仕年与军师选择使用同一定义，缺失起始年按0年，不使用出生年或年龄。本项纠正研究与实现的字段混用，保留原作加分排序及其他任官资格，不将军师的智力优先优化扩大到任官；证据见[年份消费端复核](../../research/findings/RE-SAN9PK-0009.md#2026-10-19年龄与仕年消费端复核)。

<a id="b09"></a>
### B09：人员配额的对象与数值域

分子总人数采用当前直接军团的在职人员，含君主、都督、军师、普通在职及外出任务人员；俘虏、在野、未登场和死亡人物不计入。实际调动另查驻留与可行动资格，不能把闲置人数作为总人数。保留原兵力／兵役／伤兵权重、驻军统计和建筑最低配额，但使用宽整数及完整数值，不继承低八位截断和32位溢出。配额是各建筑需求，不强制总和等于人数；真实人员迁移守恒。建筑兵力保留及量化仍按采用的原策略参数计算。

<a id="b10"></a>
### B10：配额失效与重算

批前计算配额；新设／解散军团、建筑归属变化后，标记并重算受影响军团，后续工作使用新辖区的配额。其他工作间不无条件全量重算；缓存必须声明输入依赖，缓存温度不改变结果。这明确修正原作组织变化后仍沿用旧配额的时点。

<a id="b11"></a>
### B11：调动只消费实际处理项与空城补缺

保留余缺配对、人物排序、单次人数上限和空城单人补缺；目的地每次只消费当前处理项，来源用尽时按引用移除实际选中来源。禁止误弹下一目的地或原始来源表头；失败候选是否继续仍按B13的工作生命周期处理。

2026-10-17明确采用缺陷修正：[RE-0124补证](../../research/findings/RE-SAN9PK-0124.md#工作22来源筛选与空城后备补证)确认原作正常生产链不能成功执行单人后备，不存在额外对象关系门；无法确认作者原本意图。重制每个目的地优先从有可行动人物的盈余来源普通调动；无此来源且目的地为空城时，从当前军团全部有效可驻人据点中选有可行动人物且驻留人数大于1的来源，允许突破配额。按驻留人数降序、同数按收集顺序，选一人；人物沿用后备官职优先量与政治、武力评分。补缺不得搬空来源，不向非空城市或非城市启动后备，不跨军团借人。已成功离开的人员不再计入来源驻留数，拒绝不扣人数；无来源正常消费当前目的地后继续。此为重制修正，不声称恢复了原作本意。

<a id="b12"></a>
### B12：同旬军团列表变化

在B01的势力级轮转边界内，新军团追加到所属势力当前军团队列末尾，通过控制资格时同旬获得行动机会，并执行自己的批前准备；解散军团按引用移出待轮转表。不重排全表、不从初始快照复活已解散对象，不为新增军团重新打开已经完成的势力席位。已有游标的恢复不重复全局准备或已经完成的工作。

<a id="b13"></a>
### B13：有界失败消费

自动经营0～5、交易61和剩余搜索／训练63在来源收集时排除混乱及近距交战据点；在选人、规划抽样及消耗尝试次数前完成，不依赖最终提交拒绝来代替筛选。执行前复读沿同一状态规则；该条件不豁免据点日粮和俸禄需求。证据与回归见[来源状态复核](../../research/ai.md#domestic-origin-state)。

人员移动的出发据点、探索／登用执行者、计略／外交执行者，以及普通攻击、请求履约、攻击内建设和输送来源，同样在候选阶段排除混乱及近距交战；人员接收地和势力管理操作不套用来源门。迎敌部署的组0／1来源及组2被援据点仅排除混乱，允许正常但交战；组2供援来源仍沿自身选择及公共最终校验，不把被援据点门复制过去。依据和验证见[同类排查](../../research/ai.md#automatic-origin-state-audit)。

保留各工作的尝试预算、候选消费与终止位置；准备失败、生成空命令、公共拒绝和成功分别表达。失败可以消费尝试或候选，不统一改为跳过当前城市继续，也不自动重建失败来源反复尝试。B11／B19明确修正的错误消费优先。策略尝试数与异常规模保护分开，保护触发报告未完成，不能伪装为无候选。

<a id="b14"></a>
### B14：资源预算按提交反馈结算

预测与规划仅作临时预留；无法形成合法命令、提交拒绝或事务回滚时释放对应资源预留，成功提交并承担资源占用后才保留扣账。覆盖赠与、输送和部署等私有预算，避免失败虚耗可用资源；尝试／候选仍可按B13消费。任务间重新读取当前账户与占用，公共规则已承担的出使费用及后续外交失败成本不因此退款。

## 预测与外交

<a id="b15"></a>
### B15：赠与使用同一正式载荷

先按本方资源及原保留公式确定钱粮载荷，同一候选计划的军师预测、使者排序与提交均使用该载荷；不采用静态小额、目标自身资源或零载荷替代。保留钱粮二选一、数量限制及目标外层优先。若世界变化使载荷失效，重新形成并完整评估新计划，不沿用旧预测。

赠与候选仅限地域直接邻接的势力，不经第三方领土递归扩展。来源不得为异民族或当前联盟讨伐对象；目标仍须非异民族、非讨伐对象且严格通过排名门。普通关系范围为20～59，只有本方为联盟成员且目标为盟主时才豁免关系门，不能向所有势力或普通盟员扩展豁免。按2026-10-22用户要求，自动赠与复用玩家公共上限：资金10000、兵粮100000；保留扣除需求与固定保留量后取半、十比一比较且同值优先资金的原公式，不另加冷却或小额替代。这是针对原作自动赠粮封顶10000、只能送10000的重制修正，不改变原作研究事实。候选证据见[赠与候选复核](../../research/ai.md#gift-candidate-audit)，金额依据见[RE-0117](../../research/findings/RE-SAN9PK-0117.md#2026-10-22-玩家赠礼输入上下限补证)。

<a id="b16"></a>
### B16：以实际使者复验攻击请求

目标组合保留原优先级，使者保留原距离偏好与稳定并列顺序；最终选择的使者必须对当前目标组合通过采用的可行性判断。失败时按既定使者顺序尝试剩余人，再按工作规则继续其他目标；有界消费，不使用高政治人物的预测替另一人担保。只有最终可提交配对才消费受请求势力、目标与使者。

来源几何时间门以受请求势力君主当前所在地图对象为终点，不以任意所属城市替代；正式选将仍按到攻击目标建筑的距离优先。受请求势力保持外层顺序，同一势力下比较实际使者的免费接受阈值，最高者优先，同分保留建筑类别优先及原顺序。城市及配置了正外交优先量的设施进入攻击建筑候选，原版港口不进入；异民族身份不一概排除受请求方。

攻击对象须通过发起方的战略敌对资格；被攻建筑属于攻击对象并直接邻接受请求方，不要求与发起方接壤。原版对同一建筑先要求属于攻击对象、后要求受请求方所有且在前线，当前归属一致时两者冲突；重制明确采用前述可运行的领土协同语义，不模拟同一建筑双重所有或历史缓存残值。该差异与实际使者复验均保留，证据及边界见[请求再次核查](../../research/ai.md#attack-request-recheck)。有有效军师时区分免费／条件／拒绝三态；对玩家无法判断按50评估，无军师则使用真实免费阈值，不以玩家目标替代军师上下文。

### B17：配对分数不因超过100被拒绝

赠与、劝降保留最低可行分数33，取消100上限。其他工作保留已确认下限，军师意见映射仍按各工作规则；实际排序阈值不先夹到100，公共结算继续按已采用概率规则处理。本项修正高阈值反而失去可行性的异常，不把预测分数当作最终成功保证。

### B18：目标外层与稳定配对

先按工作目标顺序找首个可行目标，再在该目标下选执行者，保持各工作不同的预排序、可行性回调、排序键及逐候选调用次序；单候选仍执行必要预测与评分。普通列表、交集及有意重复的计划项不统一转成去重集合；同分保留已定义输入顺序，来源枚举与保存恢复必须稳定。

**离间目标顺序修正（v184）：**29号离间在原有目标过滤后、收集执行者之前，使用本军团现有独立规划随机对目标列表做一次线性Fisher–Yates洗牌；空表／单候选不为排序取随机数，多个候选每轮取当前前缀长度范围内的下标，共取N−1次。随后仍按洗牌后的顺序选择首个可行目标，沿用执行者排序、预测门、尝试预算和目标消费规则。该选择采用[日版1.3随机化目标顺序的修正方向](../../research/ai.md#akainan-jp130-comparison)，消除人物编号靠前导致的固定优先；线性洗牌是重制实现，不复制日版反复随机交换及其随机次数，也不新增目标价值评分。其他工作保持各自目标顺序；同一状态与规划随机产生相同结果，保存恢复沿现有随机种子／续行状态机制。验收覆盖不同规划随机可优先选择不同合法目标、空表／单候选不取排序随机，以及既有失败消费与恢复确定性。

外交范围分别判断：劝降只收集直接邻接势力；俘虏返还按实际拘押与归属收集，不增加邻接或异民族拘押方排除门。返还无军师时的真实可行性以及军师预测必须同时检查对方报价与本方接受条件，不能将“存在报价”当成“双方可达成”；最终谈判仍按实时状态复验。证据见[其他外交定向核对](../../research/ai.md#diplomacy-candidate-audit)。

### B19：请求履约续行与来源消费

同一攻击请求最多处理两个不同来源，各消费一次；首队提交后，请求／目标仍有效、需求未满足且预算有余时继续第二来源。按前项实际执行后的世界复验人物、留兵、容量、路线和公共资格，单项失败跳过、整体失效结束。修正第二来源随任务结束丢弃的问题，不保证必定派两队。普通攻击可从同建筑形成多个部署额度，每队重新核对资源与人物，不把有意重复来源误判为重复命令。

### B20：最终出征兵力下限

普通自动攻击与攻击请求履约在选将、主将容量、任务额度及来源留兵限制之后，实际计划兵量必须达到城市10000、其他来源5000；不足不出征，按生命周期继续。不能超容量、动用保留驻兵或凭空补兵。该策略门不改变玩家公共资格，也不覆盖其他部署、输送或单人后备的独立门槛。

普通进攻先从当前批城市选沿路目标的起始建筑，最终目标确定后，再按目标同城建筑、目标邻接城市本体、目标关联且所属城市位于该邻城表中的建筑收集直属来源；保留表序、按实际来源去重，并逐来源检查就绪、士气、人员及非目标敌对实际建筑阻断。来源资格有可行动人物即可参与强度估值，实际分配仍须至少留一人，单人来源不能出队；分配器再按模拟剩兵择优，不用来源表顺序代替剩兵排序。履约仍保留自己的来源规则。依据见[来源与压力收口](../../research/ai.md#military-source-pressure-closure)。

迎敌部署58的组0／1要求来源至少两名可用武将，出征人数取`min(5, 可用人数 / 2)`，允许两／三名候选形成单将战斗队；最终兵力仍须至少8000。来源人数门不等于队伍人数门，单将迎敌仍使用主路径的选法、选阵和方针，不转为组2入城后备。依据见[人数边界复核](../../research/ai.md#deployment-member-count-correction)。

组0只迎击有效攻击目标指向来源据点的敌队；组1只拦截有效任务为建设的敌队，不因敌方进军、攻击其他据点、返回或输送而出兵。分组先决定目标资格，再做地域、行程与已分配兵量判断，不能把两组统一成周边任意敌军扫描。依据见[部署目标任务门复核](../../research/ai.md#deployment-target-command-scope)。

迎敌留兵中的8日接近数量只计有效攻击命令指向来源据点的部队，不计返回与输送。组2救援压力基线分别计入据点驻兵、以其为服务据点且仍有有效军事任务的部队现兵，以及有效返回目标为该据点的己方部队现兵；返回兵不受初级已出发近似门限制，也不将任意指向据点的命令视为返回。两类关联按各自口径求和，不与旬级撤回累计量共用公式。复核见[军事候选检查](../../research/ai.md#military-candidate-audit)。

普通进攻强度检查中，战略优待组对城市及配置为要塞类的来源，另在来源所属城市及其邻接城市辖区内收集有效敌对建筑，排除本次进攻目标、未占领或失效建筑、建设中建筑及路线障碍设施，取最大驻兵的一半向下取整，与原留兵需求取大，不累加各建筑驻兵。敌对资格沿用战略对手规则，包含联盟及请求出兵配对约束；不限制为本次目标势力。该值只影响强度检查的可用兵力估算，不修改实际派兵分配及其他军事工作的留兵规则。未分组、行动收敛组及非要塞来源保留原估算。

强度估值以全部合格来源现兵总和减逐来源保留总量，保留低兵来源的负贡献。2026-10-24用户确认按合理性修正R1：城市／关在强度估值、实际分配及最终组队中统一先留10000，并与来袭压力留兵取大；不继承原作估值阶段仅城市扣除该基础项的行为，避免关26000兵按26000评估、实际只出16000。估值复用实际分配的基础留兵查询；优待组额外敌驻军留兵仍仅影响估值，不改变上述已采用选择。普通125%强度门仍严格大于，不能计入留守兵后虚假通过。指定建筑目标合格时优先于其他城市；每批城市只选择一个目标，后续计划失败消费该城市，不重新尝试它的其他目标。

普通攻击防御估值为目标驻兵加服务于该处、尚未进入每日执行的野战部队现兵。它与已进入每日执行的压力、增援及撤回候选方向相反，均不读取本旬下令标记；上级仅在58组0／1目标与分组标记上允许未进入每日执行的新队，不扩散到压力、留兵或9防御估值。改令后的老部队仍保留每日执行历史。

### B21：预测不改对方命令

普通进攻的沿路任务冲突读取己方直属建设队的建设目的地域；建设命令没有建筑目标字段，不能以该字段判断冲突，也不把输送任务套入建设冲突门。合法路线与公共可攻击资格仍须独立通过。

v136的私有障碍投影覆盖建筑、单位及位置目标；有中继点时按两段完整合法路线的先后扫描，任一段失败不采用局部投影。保留已存在的临时交战目标，返回／输送／建设不会因穿越建筑被转换成攻击压力。进军和攻击的投影可解析途中实际建筑，查询不改变敌队主命令、中继或临时目标。实际建筑占地与所属地域分开：投影及58组0／2的建筑阻断检查占地，51另检查敌对地域；只在城郊经过不算穿过城市。依据见[投影与占地核对](../../research/ai.md#military-projection-and-geometry)。

### B23：旬级撤回使用统一兵力口径

保留三组候选、普通军团选择优先级及两套独立预算；异民族仍走独立候选规则。中间组初始累计量改为当前驻兵加已确定返回该建筑、尚未抵达且通过对应资格的部队兵力，后一项及后续计入均用“现役兵＋向下取整的半数伤兵”，替代把部队数量与兵数相加。已经抵达并并入驻军的兵力只计入当前驻兵，不再作为返回部队重复累加。第一组仍使用独立初始量和压力集合半数门；第三组不消耗这两预算。每个本工作已提交回撤的部队只处理一次，允许原有组条件重叠而不重复提交。

第三组的未交战门使用Core当前攻击范围与双方命令派生的交战关系，涵盖正在被攻击的部队，不以临时目标字段是否为空代替。远离后残留的临时目标本身也不阻止第三组回撤。

中间组阈值的接近部队计数先要求部队到回撤建筑ETA<5，再从该建筑到部队检查实际建筑；障碍设施阻断，其他建筑则按接近部队所属势力判断敌对，回撤建筑本身免除此敌对判断。不套输送的整地域过滤，也不改用守城方关系。路线失败沿B24不计，兵力预算与其他组仍各自独立。

### B24：路线、机动力与费用有效性

区分合法零长度路线和求路失败，失败不作为ETA0通过；仅在共享路径规则认定无需移动时使用合法零长度结果。没有有效移动能力的计划不进入需行军分支，不发生除零。所有最终阵形／船型必须可用、可负担，特殊和后备分支也通过费用门；本分支无合法选项时按已有后备／候选顺序继续，不凭空扩展阵形池。费用与公共命令保持一致，拒绝时按B14释放预留。

OAI-03自规则v121起由Core提供单次粗格战略路线预测：当前阵形／船型、地形与获准占位决定选路，行军成本独立于对象避让惩罚，ETA为地形行军成本除以当前移动预算后向上取整；只返回所经粗格，不逐日推演或保存全程细步。部署0／1组在求路前按候选当前位置所属地域筛选来源同城／邻城的关联范围，缺少地域信息不进入该分支。合法零距离、不可达和分析未完成分别表达；粗格预测不保证大占地部队能通过每处细步间隙，不代替公共命令资格或每日实际导航。该调整依据原作“一次求路再换算”的计算层次，未直接采用源两类格数分别取整的公式；5／8／10／20日门、来源排序、慢路／障碍标志及协调等待可能随预测变化。独立夹具核对零距离／不可达／预算耗尽、地域筛选、等待输入和真实行军／占领；尚未执行原游戏相同局面的路线动态差分，不声称逐格或ETA完全相同。

v135复核保留各路径方向：组0接近ETA为敌队当前位置到来源建筑，来源到敌队的路线另行检查普通障碍及非终点的敌对实际建筑（v136进一步区分占地与地域）；组1仍从来源到候选求ETA，不套组0障碍门。组2按实际建筑、51另按敌对地域检查阻断，51普通输送与搬空非城市的单人后备均须通过。组2可救援同势力其他军团的合格建筑，出兵来源仍为当前直属军团，不能借用受援军团的人或兵。原作证据与当前回归见[第二轮路线核对](../../research/ai.md#military-route-second-audit)。

### B25：保留不同工作的策略特色

2026-10-20按[跨军团专项](../../research/ai.md#military-corps-affiliation-audit)对齐：51输送预算与接收地覆盖同势力有效普通设施，出兵来源仍限当前直属军团并通过正常来源资格；不能把接收地也缩为直属，或借跨军团输送放宽来源控制。58组2救援按公共主将优先规则排序可用人物后取首名，用同一人物作候选阵形／路线准备及实际出兵，不能按内容或人物ID集合顺序选人。君主可入选；跨军团到达共用[君主入驻换属及军团修复](../behavior/BEH-WAR-0003-unit-return-defeat-and-force-cleanup.md#同势力跨军团入驻2026-10-20)，不由AI维护另一套归属规则。

不同军事工作保留各自的选人、相性补员、兵量、兵法、阵形及随机算法；不统一为最高能力或最高熟练度。保留低耐久更容易进入部分攻城选阵分支、褒美并非忠诚最低优先等已确认偏好；人物能力保护依当前能力，不增加名将白名单。

2026-10-24用户授权按合理性对齐出征选阵，规则v182明确9／59的决策顺序：途中有路线障碍时优先可用攻城阵；无障碍的慢路攻港优先长蛇，以行军能力适应路线，不因已有攻城队和目标低耐久改成冲车，也不消费该耐久概率骰。其他上下文继续原有攻城概率及象兵→冲车→发石优先链。长蛇不可用或不可负担时，继续兵法分支及通用排序，所有结果仍通过B24的资格与费用门。

按实际配置的兵法选择分支：有弩兵（含弓骑混编）优先井阑→发石→箕形；仅有弓骑时优先井阑→发石→锥形。专用候选耗尽后统一按可用、可负担陆阵的对守兵效果排序，不因混编分支失败再给予锥形额外优先；锥形仍可凭通用评分正常胜出。这样使自定义内容也保留该队既定兵法分支，而非把候选不足变成另一种编成。当前20正式剧本箕形免费且无兵法要求，后一修正主要约束自定义内容边界。依据及验收见[阵形专项](../../research/notes/2026-10-24-sortie-formation-alignment-audit.md#用户确认后的实现v182)。

普通进攻／请求履约的既有攻城队扫描，按已进入每日周期的军事队伍、当前有效攻击目标和名义陆阵识别冲车／象兵；无阵仍可计入，混乱和高昂也不额外排除，伪报／溃败按有效返回命令自然排除。该资格由选阵消费者持有，不统一放宽其他工作使用的活动部队资格。异民族主计划按当前武力降序，从族阵首个阵位开始安排人物；普通主计划仍按最高武力及人数决定起始阵位，单人后备仍用其独立固定阵位。依据、对齐及验证见[全部选阵复核](../../research/notes/2026-10-25-ai-formation-implementation-audit.md#implementation)。

输送账本按有效任务分类：运输队兵伤计入目的地，其他军事队伍兵伤的一半计入服务据点，但正在建设内容所声明基础据点类型的队伍不计入此余量。其他建设任务保留半数贡献；建设队取消任务或转为返回后，按当前有效任务重新归类，不因固定建设阵形而永久排除。

### B26：共同的部队自主响应

玩家、电脑共享敌接近、撤退、追击及目标失效后的规则；敌接近保留旬级活动扫描，撤退／追击按每日阶段先撤退后追击，后者读取已提交状态。保留性格、许可、士气／兵力严格阈值、优先级及近邻口径，不增加随机或冷却，关闭许可仍可按性格产生擅自行动。继续／擅自追击、中止追击及返回分别表达；返回转换必须具备可转换动作及有效返回对象，失败完整保留原状态且不发成功消息，次日条件仍满足则重试。

普通返城命令与系统自主返回保留独立语义身份。普通返城可以响应敌接近；自主返回不临时迎击，只有目标已经自主返回时才进入追击收尾。自主转换成功后持久保存该身份，玩家或自动工作的新命令清除它，失败转换不设置。敌接近在本队实际主动／被动交战时不再裁决临时迎击，不能仅用临时目标字段判断是否交战。

### B27：自动部队方针配置

按“接近攻击／自主撤退／追击／事后攻击”顺序，普通主路径为关／开／关／开，异民族主路径为开／关／开／开，既定单人后备为关／开／关／关。分别配置，不把主路径扩展到所有出征。方针由B26的共同响应消费，不是绝对禁令。

### B28：决策输入、界面披露与公共命令

AI输入权限按具体工作及本规格明确采用的规则定义，不能由玩家界面是否显示、玩家控制身份或公共查询是否返回某字段推导。原作已核查的输入按基线采用；明确限制某类信息的重制选择须列出适用工作、理由和验收。输入缺失的后备／跳过也须有对应工作规则，不得从笼统的信息原则推导整项工作停用；研究证据缺失不等于运行时信息不可用。AI只读确定性领域状态与预测，不修改对方命令、不读取未来正式随机；通过公共命令验证、支付与结算。已有公共费用、资源守恒、资格修复及整编禁用继续有效；外层失败不得残留世界、策略记忆、随机或命令水位的部分修改。

玩家界面披露与AI决策输入分别定义。依据[RE-0193](../../research/findings/RE-SAN9PK-0193.md)，攻击、请求履约、部署、撤回及救援的已核查路径读取实际有效命令，不受“他势力部队的命令”显示开关控制；关闭显示不得漏算来袭压力或跳过这些工作。当前目标／主目标、返回状态继续采用Core有效命令语义。该结论不外推尚未核查的其他情报读取。

**23号探索按原作候选恢复（v126）：**依据[原作23](../../research/ai.md#re-0110-交互与自动生产)，先从公共命令允许的地点中保留确有未发现人物的目标，不因仅有埋藏宝物而建立候选；再从本军团城市收集政治45～115的可行动人物，来源到至少一个候选目标的预计行程须在0～255日内。该距离门用于来源准备，不另加每个最终配对的距离门。按目标外层顺序与政治降序选择人物，真实探索命令的公共结果预测为不利时记0，其余记100；无军师不构成额外准备失败。选中后消费目标与人物，通过同一公共探索命令提交，不提前发现或改变人物状态。此项替代OAI-02仅用公共军师预测代替隐藏人物目标表的选择，允许策略只读未发现人物的所在地点。63剩余探索沿独立训练／本地探索规则，不套23的人物目标门；电脑结算仍限人物、资金或无结果，不进入宝物与玩家专属探索事件。官职排序以内容优先量表达，原格式的无官职项表达为撤职选项，不依赖源官职编号或人物编号区间。

### B29：完整主线与明确排除

覆盖经营、人事、军事、建设、输送、八计略、四外交、公共响应及支持的电脑待决选择，普通电脑、玩家委任与异民族分别验收。39项源工厂及表外准备逐项有去向；标准调度不使用的独立工作10／60不接入生产，普通攻击内的建设与无主目标出征仍实现。玩家专属事件不编造电脑回答；教学／挑战及小兵培养继续在主线外，不为工厂库存建设无消费者框架。

攻击内转建设只沿已形成的进攻计划及路线转换，不在无目标时额外寻找空地建设。建设地点独立声明横／纵方向偏好许可，不从可建设施集合或3×3石兵资格反推；横向许可优先，否则检查纵向许可，所选方向候选为空或均无许可时回退普通设施。

建设目标不要求其所属城市属于建设方，普通电脑和委任军团均通过[公共建设规则](../behavior/BEH-WAR-0006-facility-construction.md)提交和逐日执行；城市易主不取消仍有效的建设计划。不能在AI层绕过费用、人物、占用或重复建设校验。

### B30：确定性与唯一生产入口

使用独立规划随机，保持采用分支的抽样范围、短路及顺序；诊断、缓存和机器速度不影响结果。所有身份与集合可扩展，状态所有权按Core领域规则、Application控制／策略和Content契约划分；地址、位域及源编号范围留Importer与研究。保存策略版本、实际参数和必要持久状态，协议切换同步状态诊断与命令日志并明确拒绝旧版；最终旧自主增强原型退出本范围，不保留长期双调度或兼容回退。以真实经营、出兵、战斗／占领、回撤、恢复／重放和长期对局验收，不以强过老玩家作为前置。

### OAI-04／05的公共预测与救援输入

规则v122将25～36接入同一生产工作调度，元数据的距离参数以几何时间上限表达；25～28、30／31先按来源到任一候选的距离收集人物，再按当前目标的同城／邻城关系配对。29不套这两道门，32按两方君主当前关联地图对象的中心筛来源，不套近邻门。

公共`GetMissionDecision`只读返回同一正式命令的资格、军师意见与公式阈值；赠与必须传本次钱粮载荷。军师意见按各工作分别映射，不把不可提供意见与没有军师合并：34攻击请求的不可提供意见／不确定均记50，正面100、负面0，其余才取免费接受阈值；不因玩家目标无法预测而提前排除请求。救援保留量按实际有效攻击命令计数，不受玩家显示开关影响，见B28和RE-0193。依据[RE-0113补证](../../research/findings/RE-SAN9PK-0113.md#2026-10-172526目标筛选与命令显示开关)，25伪报／26扰乱也应直接读取有效命令、不受玩家显示开关影响，分别保留直接军团／根势力范围。v127已移除目标筛选的显示门；开关只影响玩家披露，不影响这两项工作的目标、规划随机或提交结果。

25～28的AI目标均须进入过每日军事执行，改令与旬内下令不影响该历史，上级也不能绕过此门。28来源保留压力同样按每日执行历史和对应活动状态收集有效攻击队，不以等待日数等于零判断；已开始执行但尚在等待的队伍仍可形成压力。该边界与58的上级新队例外分别维护，见[生命周期核对](../../research/ai.md#military-lifecycle-closure)。

救援按[研究的工作28候选消费](../../research/ai.md#工作批次资格与失败消费)区分来源准备与最终留兵检查：当前计略规划从城市收集执行人物，来源先过6000驻兵门，重点区域另须13000，不将重点区域替换为立即前线；原作城市／关类型门不表示当前已经支持从关派出计略。选中配对后消费目标和人物，再检查完整保留量。不足时移除该来源全部执行者，在同一次尝试内继续剩余目标；不回填已消费目标，也不预先用留兵量筛人物。最终留兵检查每个选中来源执行一次，成功提交后的下一配对重新读取当前兵力。

B26的敌接近每天在军事移动和活动标记更新后执行；全体撤退先于全体追击，追击只消费新自主返回的一次响应资格。感知、候选战力排序、集合顺序、事后8日可达门及五种结果反馈沿[G07](../behavior/BEH-WAR-0001-movement-and-command-lifecycle.md#g07-出征方针)。2026-10-25用户批准的重制选择也按G07执行：盟军不因射程被算作撤退压力，正在自主返回对象共用追击资格，莽撞分支不把当前撤退目标计为其他近邻敌军，返回反馈保留实际转换结果。事后只新选部队，原主目标变己方的入城分支保留；缺少返回地不阻止一次事后决策，决定返回但无目的地时保存待归队意图，后续只修复目的地。选定一个对象后再裁决是否战斗的规则保持，已列待考虑。

### 同类决策输入复核（v128）

部署58直接扫描敌队成员当前装备兵法，破陷／教谕选择不受“他势力部队的兵法”显示开关影响；依据[原作逐人选法](../../research/ai.md#source-0079)。25／26判断己方是否已有部队针对候选时均排除单人部队，26另排除内嵌守军；25仍取直接军团，26取根势力，不合并这两种范围。原作25还处理失效单位引用；Core世界不变量禁止这种引用，产品不为不可构造状态添加兼容分支。

**既有公共规则差异：君主不主动归附。**原作玩家君主始终拒绝；电脑君主所在对象在没有其他同属非人事对象时仍可继续判定，因此最后一城可由电脑君主带城归附。当前重制统一禁止玩家／电脑君主所在据点及君主带领的野外部队主动归附，不保留电脑最后资产特例。这是2026-09-21已明确采用的公共事件规则，OAI沿用，不是原作一致行为。范围仅限旬级主动归附，不扩展到外交劝降、战败俘虏或势力灭亡；具体资格、原作野外君主分支正常不可达的证据及验收见[治理规格](../behavior/BEH-GOVERNANCE-0003-xun-personnel-and-territorial-transition.md)。
