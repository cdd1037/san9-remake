# 战略界面的状态与显示约定

P3已接地图战斗、计略及兵法演出，背景、编队与分类时间线已按静态证据修正，局部效果与部分动作仍待对齐，当前不能视为P3完成。武力兵法的发动、连携、连锁及特写内结果回应使用头像对白窗口，完成对白后才继续时间线；9类智略与2类支援先播放独立发动头像对白，完成后显示地图行动、结果喊话与效果；范围兵法的发动对白只播放一次，各目标结果分别呈现。特写右下角可暂停／继续、跳过；跳过也保留待播放对白与后续战报。资源等待或失败重试保留同一计划，不推进未展示的一日。对齐缺口与用户验收清单见[兵法表现](../../specs/behavior/BEH-UI-0008-battle-presentation.md)。

本文保存主界面长期有效的实现约定；转换与启动入口见[客户端内容](../client-content.md)，情报页面见[情报界面](information-browser.md)，领域状态见[运行时架构](../runtime-state.md)。原作证据以[RE-0158](../../research/findings/RE-SAN9PK-0158.md)及对应行为规格为准。

## 状态所有权

`Main`装配会话、内容和显示节点。`StrategySelection`管理地图命令选择；`MapWorld`发布拾取事件并接受高亮、镜头定位，建筑显示来自当前会话视图。`MapAnnotations`负责地图标注，`StrategyHud`负责固定界面。控件焦点、地图选择和鼠标悬停是不同状态，不能相互替代。

普通游戏运行中，F1将稳定战略状态写入`user://saves/quick.save.json`，F2读取该存档；修饰键组合不触发快捷键。存档复用会话协议校验，读取成功后重建会话所属HUD、选择和弹窗，保留地图资源并清除旧动画历史。读取失败保留当前会话；快捷键不在画面验收模式启用。界面提示结果与失败原因，存读档实际交互仍需画面验收。

游戏内读档保留旧画面至新地图就绪，不额外插入黑屏。当前新游戏入口则先变暗，再切换已准备的会话并亮屏；兵法特写入口有独立转场，亮屏与动作并行。结局图片在资源就绪后平滑淡入。上述接线已通过逻辑测试，实际画面和听感仍需验收。

`DeploymentFlow`拥有出征草案、来源、目标与子窗口，退出目标选择或流程时清除地图回调；HUD只绑定显示和用户意图。`StrategyInteraction`根据回合、出征阶段、全图和模态覆盖推导输入能力。主情报与菜单挂在`Main`装配的`StrategyOverlayHost`下，出征子窗口由流程持有；全图挂在独立背景宿主下。

设施和武将侧栏复用`StrategyRoster`与`StrategyRosterList`，按直属军团过滤；君主所在项固定首行，从普通13行中去重。两页独立保留滚动位置，焦点由Godot控件管理，不写回世界。点击或Enter只定位镜头，褐色行仍可激活；不因地图选择而强制滚动名单。Tab控件导航和Space激活是现代交互约定，见[DEC-UI-0004](../../specs/decisions/DEC-UI-0004-facility-list-interaction.md)。

模态界面先消费输入，再执行关闭或导航回调。回调可能立即移除当前节点，因此回调之后不能依赖该节点仍在场景树中。

`TurnPresentation`在播放前创建一次日演出及动作计划，资源未就绪时不推进播放时间。演出准备失败保留已计算的会话操作，重试同一日，不提前发布尚未展示的世界。`Main`以取消令牌约束内容加载和逐帧等待，退出后不再安装场景节点；验证场景构造由Diagnostics负责。

## 启动窗口与系统缩放

宽屏第1、2阶段已接入动态地图视口和公共页面宿主，完整设计见 [DEC-UI-0008](../../specs/decisions/DEC-UI-0008-desktop-widescreen-layout.md)。功能入口的设置和提示保持透明外围，存读档外围填黑，忙碌状态使用全屏半透明遮罩；内部使用居中1024×768内容区。HUD贴边、其他页面及演出留待后续阶段。

1024×768是设计内容和启动窗口的基准，实际逻辑视口由Godot的`canvas_items + expand`统一计算；常规宽屏保持逻辑高度768并增加宽度，消费引擎实际尺寸（允许引擎像素取整），不再另算窗口输入缩放。普通窗口启动时，`WindowStartup`按启动显示器的系统缩放计算客户区尺寸；Windows通过`GetDpiForWindow`读取有效DPI，其他平台使用Godot的`ScreenGetScale`（平台未实现时为1）。桌面空间不足时，扣除窗口装饰后等比缩小，并在可用区域居中。

显式`--resolution`、全屏、最大化、嵌入窗口和无头运行不应用自动尺寸；`--position`保留指定位置。这里只决定启动尺寸，不持续覆盖玩家调整后的窗口大小。画面验收覆盖100%、125%、150%、200%系统缩放及可用桌面不足的情况；空间足够时，150%的客户区应为1536×1152。

## 小地图与地域悬停

小地图地形纹理由客户端加载内容时生成一次，与战略全图、情报地图共用实际地图宽高与投影；全图辖区和边界按方格地域及所属城市一次生成；战略全图与情报地图的地形底图暂用转换后的原版`overview-terrain`，见[生成约定](../../specs/behavior/BEH-UI-0003-strategy-overview.md#开局生成地图)。地形、城市标记、视野框分别显示。相机位置或缩放变化只刷新视野框；世界版本变化刷新城市标记；逻辑尺寸变化刷新全部相关层。静止时不重复提交绘制。

小地图只在有效菱形内响应定位，装饰不参与拾取；只显示城市标记，颜色来自根势力与源调色板。主地图视野框使用实际视口；同一缩放下加宽窗口会扩大横向视野，并刷新小地图和战略全图中的视野框。

打开对象命令菜单时，在该对象的位置叠加蓝白光圈；城市、其他设施和部队共用同一行为，不受城市色块的显示范围限制。命令菜单关闭即清除；转入出征准备、选目标或方针页时保留来源位置，取消整项命令或提交成功后清除。光圈独立刷新，不重绘地形底图，五帧素材按100毫秒步进、1.7秒周期扩缩；相机移动和选择攻击目标不改变其来源。

右下地域栏读取鼠标方格，分别显示地域及所属城市；城市地域也保留所属城市名称。地图选择或镜头中心不覆盖悬停内容。鼠标位于UI、小地图、黑边或窗口外时隐藏地域栏。原版按地形高度进一步修正拾取的路径尚未完全接入，不能将当前逆投影视为完全等价。

## 资源与文字

`SkinnedScrollBar`负责原生范围、箭头和绘制，`ScrollBarSkin`提供分段纹理与布局，业务列表持有条目与视口。资源帧数量与文字状态表分别定义，不能从背景四帧推断完整文字状态。

公共平铺和三段拼接使用`SkinPainter`，详情面板使用`DetailSkinPainter`，保留各控件的拼接重叠与文字偏移。静态界面按视觉状态变化重绘；动画、边缘滚动和持续手势仍按帧更新。

`StrategyHudLayout.tscn`持有左上、右上、右下、底栏及居中组的锚点；`StrategyHud.Sidebar`持有侧栏收放状态，六个按钮与名单在侧栏组内，动画仅改变`SidebarMotion`局部位移。背景绘制和命中检测共用该节点变换。战略／执行上下文切换以100ms以上的间隔步进、198像素／200ms的速度收放，名单与滚动条只在展开完成后显示。命令菜单及目标选择立即收放，首次布局直接到位。`ExecutionPanelsLayout.tscn`分别锚定左下消息框与右下命令表，`ExecutionPanels`只控制共同动画位移，按原版坐标和尺寸绘制原版逐色Alpha资源及12号字表头；暂不填充数据行。执行阶段准备／播放时，两框共用214像素纵向位移，以至少100ms间隔按214像素／500ms速度步进；展开到位前不推进每日视觉播放，返回战略面时向下收起。暂停不改变展开状态，失败保留当前展开目标。面板遮挡区域随位移更新。此轮未启动游戏或运行测试，待用户画面验收。

主题为`GameFont.tres`（霞鹜文楷等宽GB Lite，不增补回退字体，四个已知缺字明确接受），纯文字与图文控件共用字体。`GameRichTextLabel`使用Godot原生BBCode和转换包图标；提示、列传、说明及侧栏名称共用消息求值和显示链路。名称排序使用严格纯文本读取，不剥离图标。详见[统一消息规格](../../specs/behavior/BEH-UI-0006-unified-messages.md)。

描边、阴影强一致是未决项，既有纯文字效果可保留；不作为本轮图文验收条件。文字按容器布局，表格正文在24像素行内垂直居中，不针对不同字体追加固定偏移。

地图名称、兵力、状态条及图标当前随地图缩放；固定HUD使用逻辑画布。全图图层按钮的独立文字效果暂缓，目录标题和关闭按钮文字效果仍待核对。

## 初始数值与玩法边界

默认190年1月上旬、春、董卓势力，以洛阳为初始视野。信望100、资金9520、兵粮73200来自初始剧本；原版对照中的9076与9520相差444，已确认属于普通旬俸禄，不在开局硬编码扣除。Core 已接入周期经济，客户端通过 GameSession 创建运行态；界面数值以当前会话查询为准，对照时须明确是否已执行旬前置结算。HUD 与右键菜单的“进行”均已接通：确认后播放进行面与逐日快照，顶部“静止”按钮以按下／弹起切换暂停与播放，文字保持不变，旬末返回战略面。进行面播放中和暂停时均允许中键拖动、滚轮缩放、小地图点击定位及地图悬停；地图左／右键命令和情报按钮仍禁用。阶段字图、确认框、红绿按钮、静止按钮及进度条均读取原版转换资源；阶段标题包含三帧闪现与完整字图，布局保留贴图留白。文本消息、底部记录／任务列表及玩家事件答复界面暂未接入；遇到必须答复的事件会停在等待状态，不代答。详见[战略面与进行面往返](../../specs/behavior/BEH-UI-0001-initial-strategy-screen.md#战略面与进行面往返2026-09-26)。

「小」打开战略全图，「大」返回详细地图并保留镜头比例，已取代早期将两按钮作为1倍/0.5倍缩放的约定。全图图层、定位与排行榜见[BEH-UI-0003](../../specs/behavior/BEH-UI-0003-strategy-overview.md)。

## 验证入口

自动测试按受影响范围运行，实际画面由用户验收，不自动启动游戏。历史脚本的分类、命令和使用限制统一见[Godot 历史画面验收](client-verification.md)。引擎输入自检、GPU 截图和实际交互分别报告，不能互相替代。

## 建筑悬停卡

详细地图由HUD统一判定输入阻挡，MapWorld查询当前呈现的建筑、部队身体／旗帜及部队名牌，悬停身份同时包含对象类别和ID；MapAnnotations据此将名称和兵力变黄，MapHoverCard显示Application查询得到的当前字段。卡片不接管输入，同一建筑内移动保持卡片位置，窗口离开、全图、情报和弹出菜单清除悬停。九宫格在转换时先按索引覆盖组合，再转换RGBA，避免透明角和边框重复混合。完整行为见[BEH-UI-0005](../../specs/behavior/BEH-UI-0005-map-building-hover.md)。

大将与人员信息通过当前会话查询显示；Core/Application 已具备人事任免与调动，具体 UI 操作入口和字段投影须分别核对。悬停状态行的显示覆盖不代表完整战斗查询；人员可用数、内政和兵力等已有字段读取当前世界，后续对齐应逐项检查查询与显示，不沿用早期静态界面的领域能力判断。

## 公共消息／确认弹窗

[GameDialog](../../src/San9.Client.Godot/UI/Common/GameDialog.cs) 是不依赖回合状态的公共组件。调用方提供纹理作用域，使用 `SetMessage(message, confirm, dismiss)` 更新内容，订阅 `Confirmed`／`Dismissed` 决定后续行为；`confirm=null` 显示单返回按钮，`dismiss=null` 显示单确认按钮。组件不会自行推进会话或销毁调用方状态。

背景使用 `PanelContainer + StyleBoxTexture` 的 Tile 九宫格，内容使用纵向容器和居中的按钮行；文字自动换行，过长正文滚动，按钮留在正文外。`PreferredWidth` 默认384，可由调用方调整；宽度受可用空间和边框／按钮最小宽度约束，高度由内容确定，默认最小184。弹窗相对父控件居中，尺寸变化重新布局，不再固定文字与按钮坐标。切边尺寸用于保护装饰，内容内边距左右56、上下40，两者独立。阶段确认和失败提示共用该组件。

这次重构完成编译、资源包校验与相关测试，画面由用户验收；不启动游戏做画面验证。

普通两行确认文案的完整控件尺寸为384×184（含贴图透明留白），正文从(56,40)开始，采用24像素基线间距，保留字体完整升部／降部度量；末行超出24像素行格的部分计入正文可视高度，并从按钮前间隔扣除；两按钮从(92,104)、(200,104)开始，各92×40。原作尺寸取整证据见[RE-0158](../../research/findings/RE-SAN9PK-0158.md#确认框完整尺寸复核)。运行时仍按内容自适应，不复制原版编码字节计宽规则。

进行面进度条位于(285,19)，保持304×16原生尺寸，先绘底图、再从左侧裁剪填充贴图，裁剪宽度向下取整到整数像素。每日展示期分10个小步，整旬100步；暂停冻结日内进度，原作证据见[RE-0158](../../research/findings/RE-SAN9PK-0158.md#进行面进度条绘制与粒度复核)。

进行面播放中和静止时，疆界按钮均可点击，切换地图疆界显示；该显示开关不受下令权限限制。确认框及阶段转场期间仍禁用。

## 地图音乐与进行面声音

战略面按当前季节及玩家势力爵位选择八首季节音乐。确认推进进入进行字图时切换为进行面选曲：玩家部队有主动／被动交战或据点驻军被近距离攻击时优先战斗曲，否则有野外军事活动时用进军曲，无上述活动时用内政曲；战斗／进军各按玩家爵位区分普通与高爵位曲目。选曲依据当前呈现的世界状态，不受镜头和暂停影响；返回战略字图时恢复季节选曲。同曲不重启，异曲从头播放。外交等已接入的场景音乐暂时持有播放权，结束后恢复地图音乐的位置。外交与皇帝会谈循环播放，灭亡插图音乐单次播放；音乐关闭期间仍维护当前场景所有权，重新开启后播放当前应有曲目。音乐与音效分别读取用户设置中的开关，重新进入会话生效。

确认推进后，进行字图第一帧播放锣鼓；取消确认或重复绘制不播放。进行面按已准备日的实际地图动作播放视野内行军、建设、普通近战／远射、设施箭雨及落石声音，交战时只播放一条战场环境循环并压下建设声。镜头移出停止对象声音，移回恢复循环；同日已消费的单次攻击节拍不会因移回或重绘重播。暂停冻结动作节拍，保留当前循环。

本轮完成代码测试和190年转换包校验，未启动游戏试听。用户验收可分别关闭音乐／音效，核对战略进入、取消／确认推进、四季和爵位选曲、外交结束恢复，以及行军／施工／战斗区域之间平移镜头的停止、恢复和左右声像。原作证据与混音取舍见[RE-0186](../../research/findings/RE-SAN9PK-0186.md)。P3兵法、计略特效与特写声音已接入，原作证据见[RE-0192](../../research/findings/RE-SAN9PK-0192.md)，实际试听仍由用户验收。

第三阶段布局入口：`GameDialogLayout.tscn`保存公共确认框容器骨架，`GameDialog`通过场景唯一名称绑定并注入转换包资源；不重建内容来响应窗口变化。情报与功能菜单由`HudDropdown`跟随注入的HUD按钮，地图菜单、悬停卡及喊话通过`OverlayLayout`避让当前HUD占用范围。透明留白按Alpha有效包围矩形排除，点击仍使用逐像素命中；完整页面通过`FixedPage`保持原页面实例及局部布局，内部的`PageSurface.tscn`承担全视口背景和输入阻挡，不参与页面动态子项清理。嵌套半透明页面继承已有背景，详情、全图和结局使用黑底。兵法特写的绘制、效果、数字及命中共享固定内容居中偏移；地图效果仍走动态地图投影。转场单独覆盖实际视口，尺寸变化保留播放状态。
