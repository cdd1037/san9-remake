# BEH-STRATEGY-0003：人物、建筑与势力计略效果

- 状态：已确认
- 负责人：项目开发者
- 最后更新：2026-09-16
- 关联证据：[RE-SAN9PK-0115](../../research/findings/RE-SAN9PK-0115.md)、[RE-SAN9PK-0116](../../research/findings/RE-SAN9PK-0116.md)
- 关联决策：[DEC-SIM-0001](../decisions/DEC-SIM-0001-determinism-and-saves.md)、[DEC-PROJECT-0002](../decisions/DEC-PROJECT-0002-selective-inheritance.md)
- 继承方式：关系保留

## 适用范围

适用于离间、烧夷、夺取与流言对人物、地域建筑、宝物、资金、兵粮、忠诚与势力关系的即时效果。公共提交与随机规则由 `BEH-STRATEGY-0001` 规定。

## 原作基线

四类命令都以保存结果严格小于执行时阈值作为主成功门，且没有持续状态日数。

- 离间成功调整目标人物忠诚并改变相关势力关系；失败只改变执行方与目标侧关系。
- 烧夷成功损伤建筑耐久，并有独立小概率兵粮损失；失败可能提高执行者伤病并恶化关系。
- 夺取按宝物、人物、资金的固定优先级，用同一保存结果逐项比较阈值，第一个命中分支终止后续分支；均未命中时进入失败分支。
- 流言成功降低两个目标势力之间关系，并可能通过独立概率门改变目标侧人物忠诚；失败只恶化执行方与第一目标势力关系。

成功分支仅让所选执行者成长：离间、流言为智力，烧夷、夺取为武力。成功和失败都增加来源部队全员策略熟练度。

## 重制行为

保留对象域、效果方向、夺取分支优先级、主判定与附加随机相互独立、成功能力成长及失败关系代价。资源变化必须通过领域服务维护所有权、上下限和事件日志；人物转移不得绕过归属不变量。

按 `DEC-SIM-0001`，烧夷资源门、夺取宝物门、流言忠诚门及结果幅度随机都使用显式命名随机流。具体常量与公式只在对应已确认公式规格被产品选用时生效。

## 状态与不变量

- 输入与前置条件：单名执行者、人物/地域建筑/双势力目标、保存结果、实时阈值、资源与所有权状态。
- 状态变化：忠诚、伤病、人物归属/位置、建筑耐久、兵粮、资金、宝物持有者、势力关系、能力与熟练度。
- 始终成立的不变量：资源不为负；耐久保留下限；宝物只有一个持有者；人物归属与位置一致；夺取至多命中一个成功分支；即时命令不创建持续日数。
- 失败或无效输入行为：执行复验失败不写目标；普通失败只应用该命令明确规定的伤病/关系代价，不产生成功资源。

## 示例与边界

- 夺取保存结果同时低于宝物和资金阈值时，只执行宝物分支。
- 目标资金小于计算金额时，转移量夹到目标现有资金。
- 烧夷主判定成功但附加资源门失败时，只写耐久等主成功效果，不扣兵粮。
- 流言主判定成功但忠诚门失败时，仍保留两目标势力关系变化。

## G08 采用公式

输入均为当前有效能力，`S(A)` 为既有分段执行能力。整数除法向零截断，主骰严格小于阈值才成功；负阈值保留为必败。公式及义理字段依据 [RE-0067](../../research/findings/RE-SAN9PK-0067.md) 与 [RE-0115](../../research/findings/RE-SAN9PK-0115.md#2026-09-13-g08-义理与夺取人物补证)。

| 行为 | 规则 |
| --- | --- |
| 离间阈值 | `min(40, 执行智力 + 5*(7-目标义理) - 目标智力)` |
| 离间忠诚损失 | `4 - 目标义理/5 + rnd(3)` |
| 流言阈值 | `min(40, 执行智力 - (目标君主智力 + 目标军师智力)/2)`；无军师时比较值为60，有军师时不设60下限 |
| 烧夷阈值 | 耐久不超过100时为0；否则 `min(50, 执行武力 - 2*守将统率/3 - 20)` |
| 烧夷耐久损失 | `S(执行武力)/7 + 当前耐久/50 + rnd(5) - 3`，限制在0至`max(0, 当前耐久-10)` |
| 烧夷兵粮损失 | 独立3%门命中后，`(目标士兵+伤兵)*S(执行武力)/2000 + rnd(100)`，不超过目标所属账户实际余额 |
| 夺取宝物阈值 | 独立50%门命中且存在候选时，`执行武力 - 2*宝物忠诚加成 - 持有人当前武力/智力/政治/统率最大值`；否则为0 |
| 夺取人物阈值 | 有己方被拘押俘虏时，`候选人数 + 执行武力/20`；无候选时为0 |
| 夺取资金阈值 | `min(25, 执行武力 - 目标士兵/1000 - (2*守将统率+30)/3)`；无守将取统率0，目标必须有资金 |
| 夺取资金量 | `min(目标资金, (目标士兵+伤兵)/80 + rnd(50) + 10)` |

重制选择：耐久损失下限为0，避免低能力极端输入把破坏效果变成修复；保留10点耐久生存下限。资源转移按实际余额及接收能力计算，不继承饱和扣款与原请求量入账产生的复制窗口。

### 烧夷命令与行程

烧夷由单名可行动驻地武将执行，目标须为有效、已完成且非工作物的他方据点，目标所属势力不能为异民族，双方不能同属联盟。目标地域所属城市须为来源所属城市或其有向直接邻接城市；不递归扩展。地域和城市引用复用人事地理定义，缺少定义时拒绝命令。攻击请求保护随外交请求系统接入，不以空状态声称支持。

提交不预扣资源，只保存固定条件骰并占用执行者；以人物每日行程到达后复验资格、按当前守将和执行能力结算。目标换为其他合格势力时按当前归属结算；目标变为己方、盟友、异民族、未完成或销毁时取消并返程。意见查询使用同一资格及阈值，不改变状态或玩法随机。

失败伤势为`max(原伤势, min(7, 原伤势+(主骰-当前阈值)/10))`，双方关系减`1+rnd(3)`。成功独立尝试执行者武力成长；成功、失败均仅给执行者策略类别7/8各增加基础熟练度2，随后返程。去返程复用现有人事生命周期；保存恢复与命令重放不得重复结算。依据与本轮补证见[RE-0115](../../research/findings/RE-SAN9PK-0115.md)。

### 夺取命令与行程

夺取复用烧夷的地域建筑资格和有向直接邻城范围，并额外要求目标当前所属根势力资金大于0。提交只占用单名驻地执行者并保存固定条件主骰，不预扣资源；人物每日到达后按目标当前归属、资金、守将、兵力、伤兵、人物与宝物状态重新复验和结算。目标失效时取消并返程。意见查询使用同一资格及三个实时阈值的最大值，不提交随机状态或世界变化。

宝物候选来自目标据点内人物持有的已发现宝物，按忠诚加成升序、稳定宝物身份升序取首项；独立50%运行随机门命中时才计算宝物阈值。人物候选只包括目标据点拘押的执行方所属俘虏；人物分支命中后从稳定排序候选中运行随机选择一名，复用俘虏恢复和返程服务，不能招募敌方在职人物。资金分支从目标当前根势力账户向执行者来源据点所属账户转移，数额同时受目标余额和接收容量限制，士兵与伤兵不扣减。

同一主骰严格按宝物、人物、资金顺序比较，第一个命中分支立即终止。任一成功分支独立尝试执行者基础武力成长；均未命中时，伤势为`max(原伤势, min(7, 原伤势+(主骰-资金阈值)/10))`，执行方与目标当前所属势力关系降低`1+rnd(3)`。所有分支均只给执行者策略类别7/8各增加基础熟练度2，随后返程。保存恢复与录像重放不得改变候选顺序、随机流位置或重复结算。

### 离间命令与行程

离间由单名可行动驻地武将执行。目标须为附属于有效他方据点或野战部队的在职非君主人物，当前所属忠诚为正；目标势力不得为异民族或受同一联盟保护，双方须存在关系记录。提交不预扣资源，只保存人物目标、出发时目的地（野战目标另存细坐标）和固定条件骰；来源与出发时目标位置决定每日行程。执行前按目标当前状态重新复验资格，但不要求目标仍在出发时位置；目标失去有效归属、成为己方／异民族／联盟成员、死亡或忠诚归零时取消并返程。

执行时按双方当前有效智力和目标义理重算阈值。成功按`4-义理/5+rnd(3)`降低目标对当前所属势力的忠诚并尝试增长执行者基础智力；失败不改忠诚。成功时，从执行方和目标方之外仍有效的普通势力中，选择与目标方关系最高者（同值按势力身份稳定排序），令其与目标方关系降低`1+rnd(3)`；没有这样的第三势力时回退为执行方。失败只令执行方与目标方关系降低同样数值。关系契约不隐式补造缺失记录，因此第三势力候选及执行方回退都要求相应关系记录存在。两分支均给执行者策略类别7/8各增加基础熟练度2，随后返程。意见查询、保存恢复与录像均复用公共计略确定性边界。
