# BEH-DUEL-0001：单挑触发与参战者选择

- 状态：已确认（陆战普通攻击机会、初始双方、追加参战者与先手）
- 负责人：项目开发者
- 最后更新：2026-09-19
- 关联证据：[RE-SAN9PK-0103](../../research/findings/RE-SAN9PK-0103.md)、[RE-SAN9PK-0107](../../research/findings/RE-SAN9PK-0107.md)
- 关联决策：[DEC-SIM-0001](../decisions/DEC-SIM-0001-determinism-and-saves.md)、[DEC-PROJECT-0002](../decisions/DEC-PROJECT-0002-selective-inheritance.md)
- 继承方式：关系保留

## 适用范围

适用于陆战部队在每日普通攻击事件中尝试创建单挑并构造双方参战名单。本规格定义单挑自身的触发骰、初始发起者和接受者、追加参战者以及首击方；逐刀伤害和战后处理分别由 `BEH-DUEL-0002/0003` 定义。

## 原作基线

发起方候选必须无伤、当前兵法间隔不大于零、尚未行动、位于前排且性格不是慎重。合格者按当前有效武力降序排列，只保留首名；后续任一门失败都不改试次名。

接受方候选必须无伤且位于前排，不检查当前兵法间隔或性格。合格者同样只保留当前有效武力最高者，后续失败不回退。

令发起方阵形倍率 `formation_multiplier` 在锋矢阵时为 `2`、其他阵形为 `1`，发起方全部前排人数为 `front_count`，则单挑自身概率为：

```text
chance = 3 * formation_multiplier * front_count
```

该计数不重新过滤伤势、间隔或性格。投骰成功后，令发起者性格编码 `C` 为莽撞 `0`、刚胆 `1`、冷静 `2`，双方当前有效武力为 `A` 与 `D`；只有 `A + 6 - 3*C >= D` 才创建单挑。普通兵法机会的随机判定与该触发骰相互独立，不能替代单挑自身概率。

初始配对创建后，对双方部队成员执行追加筛选；除已经固定的初始人物外，每个通过者成为追加参战者。筛选候选必须位于前排、当前兵法间隔不大于零、无伤，且人物的单挑排除标志未置位。

令本方初始人物为 `source`、追加候选为 `candidate`，两人的相性环距为 `d`；`d` 按 150 点环计算并封顶为 50。令阵形系数 `K` 在 `source` 所属部队为锥行阵时取 `3`，其他阵形取 `2`。关系加成为 `R`：

1. 关系规则未被场景状态抑制时，先读取双方关系表的配对加成；
2. 双方为兄弟且不属于关系排除表中的组合时，`R=20`；
3. 双方为父子时，`R=20`；
4. `candidate` 为赵云时，在以上结果上再加 `10`。该加成作用于候选追加者，不是初始人物。

每名合格候选使用：

```text
affinity_term = max(0, 5 * (5-d))
support_chance = R + trunc0(K * (affinity_term + 25) / 2)
```

除法在乘以 `K` 后向零截断，概率没有额外上限。判定按发起方成员原顺序逐人进行，再按接受方成员原顺序逐人进行；每名通过资格门者立即消费一次玩法随机。原作列表实现也会遍历本方初始人物：若其通过追加资格门，会消费一次不会改变名单的随机判定；随后无论该判定结果如何，初始人物都会被强制移至本方名单首位。其他成功者按当前有效武力稳定降序排列在其后。

主动发起方名单首项固定先攻击；接受方名单首项存活时才获得第一次还击。追加人物不能改变初始配对或首击方。

装备教谕／破陷不排除单挑资格。原作普通兵法候选的空任务提前终止发生在单挑尝试之后，不能解释为这两项装备阻断单挑；证据见[RE-0103补核](../../research/findings/RE-SAN9PK-0103.md#2026-09-19教谕破陷是否遮蔽单挑的回读)。

## 重制行为

重制版关系保留上述初始候选过滤、最高武力遮蔽、阵形与前排人数乘法、性格武力门、追加资格、关系概率、稳定排序和主动方首击顺序。所有玩法随机判定消费 `DEC-SIM-0001` 定义的显式稳定随机流；表现层不得改变资格、名单或首击方。

重制版从追加候选集合中显式排除已经固定的初始人物，不复制原作“对必定入场者进行无效随机判定”的列表实现偶然性。该差异由 `DEC-PROJECT-0002` 的选择性继承原则覆盖：它不改变任何人物能否入场或追加者各自的成功概率，只改变后续随机流位置。

追加资格中的原作人物bit12沿用已确认的命令占用语义，对应重制人物`Acted`，不另设单挑专用排除标志，证据见[人物字段记录](../../research/findings/RE-SAN9PK-0009.md)。发起方首发还须通过公共候选谓词的bit12检查，因此也排除`Acted`；接受方首发不检查该标志，见[RE-0103公共候选回读](../../research/findings/RE-SAN9PK-0103.md#2026-09-19教谕破陷是否遮蔽单挑的回读)。触发倍率通过阵型`DoublesDuelChance`表达，Importer将锋矢阵转换为该特性；追加关系复用兵法连携关系与阵型系数。按已采用的确定结果免抽骰选择，触发或追加概率达到100时直接成功，非正概率直接失败；其余先发起方、后接受方，各按人物ID升序抽取；首发固定首位，追加者按有效武力降序、ID升序出场，替代此前保留成员遍历顺序的选择。该选择改变随机流位置，不改变成功概率。

普通攻击完成伤害与溃灭处理后，双方仍有效才尝试后续机会。公共机会要求至少一名无伤、间隔为零且未行动的己方在职成员，不以是否装备主动兵法筛掉被动装备成员。先投普通兵法机会骰，再独立处理单挑，最后按原机会结果及当前资格尝试普通兵法；单挑写回的伤势、间隔和人物移除立即影响后续兵法候选。对方的反击机会还须先通过全局军事规则`DefensiveTacticChance`门，该门失败时既不尝试反击兵法，也不尝试反向单挑。

## 状态与不变量

- 输入与前置条件：一次有效的陆战普通攻击机会、交战双方部队、人物伤势/间隔/阵位/性格/当前有效武力/相性/关系、双方阵形和显式随机状态。
- 状态变化：失败时不创建单挑；成功时创建唯一初始配对，构造双方有序参战名单并把发起方标为首击方。
- 始终成立的不变量：两侧各恰有一个固定的初始人物；接受方间隔不参与初始过滤；初始候选失败不回退；追加者均排在本方初始人物之后；普通兵法骰不等于单挑骰。
- 失败或无效输入行为：任一侧无合格候选、单挑骰失败或武力门失败时，本次机会不创建单挑。

## 示例与边界

| 阵形 | 前排人数 | 单挑概率 |
| --- | ---: | ---: |
| 非锋矢 | 1 / 2 / 3 | 3% / 6% / 9% |
| 锋矢 | 1 / 2 / 3 | 6% / 12% / 18% |

当 `R=0` 时，追加概率的代表值为：

| 相性环距 `d` | 非锥行 `K=2` | 锥行 `K=3` |
| ---: | ---: | ---: |
| 0 | 50% | 75% |
| 1 | 45% | 67% |
| 5 或更大 | 25% | 37% |

- 莽撞允许比接受者低 6 点，刚胆允许低 3 点，冷静不得更低。
- 慎重人物不能主动发起，但可以成为接受者。
- 接受方当前间隔大于零仍可成为接受者。
- 接受者的当前间隔大于零时仍固定入场，但不通过追加资格门；重制版不会为其消费无效追加随机。
- 兄弟或父子关系通常把 `R` 置为 20；赵云作为追加候选时再加 10。最终概率不额外夹到 100。
