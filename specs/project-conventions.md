# 项目与文档约定

状态：已确认

## 权威边界

项目区分研究证据、产品要求与实现；这是职责边界，不是每个任务都要从研究重新开始的流程：

1. `research/` 保存原始来源的登记信息、可复现实验和分析结论。
2. `specs/` 保存采用的行为、数据和接口要求，依据可以是研究证据或明确的重制设计。
3. 产品实现依据重制规格和项目决策，不直接引用地址、反编译文本、旧 IDB 或黑盒工具内部实现。
4. 测试可使用从规格派生的自制夹具；不得把原版文件作为默认测试依赖。

BEH/DEC 的维护条件与状态统一见[规格索引](README.md#规格维护)。

## 原作基线与现代化设计

- 项目不追求完整复刻原版。体验支柱是旬制同步推进、大地图一体化、部署后自主执行，以及城市、势力、武将和部队之间的主要战略关系；原作研究是这些体验的设计输入，不是逐项实现清单，详见 [DEC-PROJECT-0002](decisions/DEC-PROJECT-0002-selective-inheritance.md)。
- 经验证的原作行为用于理解设计、建立比较基线和支持取舍，不自动成为必须照搬的产品要求。
- 核心公式只有在证据充分且被重制规格明确选用后才产生约束；默认保留变量关系、趋势、曲线和有设计意义的阈值，允许重新平衡参数与边界。
- 未知行为必须保持“未指定”，不能用直觉补全为原作结论。
- 每个子系统可以选择忠实保留、现代化调整或重新设计；选择应以整体策略体验、可理解性、可玩性和长期维护为依据。
- 当原作公式与目标体验冲突时默认体验优先，但重要玩法差异必须记录目标、理由和可执行验收场景，不能以体验为名进行无规格的任意修改。
- 现代技术实现不需要为“不同于原版内部实现”单独创建决策。实现应优先使用清晰、可测试、可维护的现代方案。
- 相关规格必须分别描述已知的“原作基线”和选择后的“重制行为”；原创设计可以把原作基线标为“不适用”或“未知”，但二者不得混写。
- 逆向研究按当前产品设计需要闭合；当前行为的完整依赖须先核对，与已明确重制行为无关的未知细节不阻塞实现。正式交付、阶段范围及完成判断统一见[路线图](roadmap.md#目标与范围)。项目不以代码行数、函数覆盖率或逆向完成率作为产品完成度指标。
- 修复重制实现偏离已确认规格不属于改良，不需要兼容错误行为。

## 文档规则

- [AGENTS.md](../AGENTS.md) 保存全仓库协作约束和按任务触发的入口；专题文档维护细节，入口只保留必要摘要，避免多处复制完整规则。
- 当前正文直接更新，普通修复历史交给 Git；重要决策保留替代关系，实验和阶段验收保留日期、版本、范围与证据。历史验证结果不表述为当前版本已通过。
- 不在专题文档追加逐提交版本流水、阅读进度、反复测试过程、临时失败排除过程或已失效的阶段待办；这些由提交与差异追溯。验收记录保留可复现条件、结果、反例和限制，审计报告保留问题、最终覆盖与未决项；同一证据只维护一处，其他入口链接引用。
- README 只概括当前能力、限制与运行入口，不累计逐次修复、完整命令 API 或事件清单；详细能力与验收链接对应专题。

- 文档使用简体中文；路径、标识符、代码符号和机器字段使用英文。
- 原作事实与研究推断链接相关 `SRC-*`、`EXP-*` 或 `RE-*`；项目设计和实现说明引用相关规格、代码或验证结果。
- 研究中的精确数值注明影响复现的单位、范围、样本版本和适用条件；共有信息可引用已有记录。
- 引用第三方原文应尽量短，并优先转述；不得复制大段受版权保护内容。
- 保留相互矛盾的证据，原作结论在解决前保持待验证；产品可明确选择重制行为，并说明与未决证据的关系。

## 目录职责

- 根 `README.md`：当前能力、限制、运行入口与导航。
- `docs/`：长期有效的实现与使用约定，以及明确标注版本和日期的专项验收记录。
- `tests/README.md`：测试职责、运行入口与覆盖取舍。
- `research/`：来源、实验与 RE 证据，不直接充当产品要求。
- `docs/ui/`：界面实现与通用约定，统一入口为 [UI 文档](../docs/ui/README.md)；关联规格和研究保留在各自目录，通过索引查找。
- `specs/behavior/`：面向实现的原作与重制行为规格。
- `specs/decisions/`：需要独立说明理由的重要长期取舍，不重复行为规格。
- `specs/templates/`：统一记录结构。
- `private/research/upstream/`：本地第三方资料快照；不进入版本库，也不继续无清单扩大。
- `research/experiments/`：可复现黑盒实验记录；大型中间产物统一放入被忽略的 `local/generated/research/`。
- `research/notes/`：尚未上升为规格的分析和证据链示例。
- `research/symbols/`：可公开、可追溯的符号映射导出；不保存 IDB。
- `private/`：当前本地私有样本区；研究文档统一使用其仓库相对路径，默认不入 Git。
