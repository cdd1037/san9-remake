## 约束词

- **必须**：不可省略；违反即不符合项目规范。
- **应该**：默认执行；偏离时必须记录原因。
- **可以**：可选做法，不构成要求。

## 文档状态

| 状态 | 含义 | 是否可作为实现依据 |
| --- | --- | --- |
| 草案 | 正在整理，内容可能变化 | 否 |
| 验证中 | 已有证据，仍需复验或解决矛盾 | 否 |
| 已确认 | 证据充分、边界明确并完成审查 | 是 |
| 已废弃 | 被新文档取代或结论被否定 | 否 |

状态必须写在每份行为规格或决策记录的元数据中。“已确认”只表示在已登记样本和条件下成立，不代表对所有版本普遍成立。

## 标识符

| 前缀 | 对象 | 示例 |
| --- | --- | --- |
| `SRC-` | 来源 | `SRC-KAODATA` |
| `EXP-` | 黑盒实验 | `EXP-EDITOR-0001` |
| `RE-` | 逆向记录 | `RE-SAN9PK-0001` |
| `BEH-` | 行为规格 | `BEH-SEARCH-0001` |
| `DEC-` | 改良决策 | `DEC-UI-0001` |

进入共享或发布基线的标识符一经引用不得复用。尚未对外使用的一批新增记录可在整理提交中整体重编号，但必须同步仓库内全部引用；被否定或废弃的既有记录保留原 ID，并链接替代项。
