## 适用范围

适用于伪报、扰乱、激励、救援、离间、烧夷、夺取和流言的玩家及 AI 命令提交、军师反馈、行动占用与阶段结算。不规定各命令的具体效果公式。

## 原作基线

每条计略只有一名选择执行者。界面更换执行者或目标时，以当前组合重新校验并刷新军师意见；军师意见以同种子百分概率布尔值比较成功门和准确度门；不是按成功率是否过半分类，见[RE-0171](../../research/findings/RE-SAN9PK-0171.md#2026-09-18-g08审核军师分类与概率包装器)。

提交阶段复验来源、人物、目标和命令特有资格，保存一个稳定的 `0..99` 结果并占用执行人物。执行阶段要求事件类型匹配并再次按当前世界状态复验，随后用保存结果与实时成功阈值结算。成功与失败最终都增加来源部队全员的策略熟练度；人物命令占用在旬清理释放。

## 重制行为

保留单执行者、选择变化重算意见、提交/执行双重复验、保存结果对实时阈值和旬末释放占用的关系。玩家与 AI 必须提交同一种类型化命令并走同一结算器。

“来源部队全员”指本次命令队伍的当前参与者，不是原驻地或原野战部队的全部人物；八类计略新建任务只有一名执行者，因而普通任务结算只给这名参与者增长熟练。对象链补证见 [RE-0116](../../research/findings/RE-SAN9PK-0116.md#2026-09-13-g08-来源队伍与全员成长边界)。

按[随机约定](../../docs/randomness.md)，八类计略提交百分骰采用固定条件随机：本局种子、判定用途、下令日期、执行者和类型化目标身份；流言包括相关目标势力。同条件下，无关操作顺序、命令序号、玩家读档和重启不会改变骰子。提交保存骰子，执行重算资格与阈值。证据见[RE-0171](../../research/findings/RE-SAN9PK-0171.md)，不复制原作身份求和碰撞。

夺取宝物额外概率门、烧夷资源分支、流言逐人物概率和随机效果数值采用独立用途的运行随机，不能因主骰固定而锁定整个命令。玩家读档保留任务骰，仅改变未来运行抽样；录像精确恢复完整种子、流状态和任务。

军师意见按当前条件确定性计算，不消费运行流、不写世界状态。重复查询、关闭重开和无关操作不刷新意见；外交普通意见沿用此约定。

### G08意见与行程实现选择

伪报期间的强制返城行为见[状态规格](BEH-STRATEGY-0002-unit-status-and-reinforcement.md#伪报持续移动)。伪报、扰乱、激励使用公共`UnitStrategyCommand`，来源为有效己方据点中的单名空闲执行者，目标为有在役成员的非嵌入、非人事野战部队。敌对目标使用公共禁战查询，友方激励要求同一势力。来源到目标的细坐标确定提交行程，目标身份保留至执行复验，返程从已保存的目的位置计算；地域身份仅用于没有归队据点时的地理安置，不以地域中心替代部队坐标。联盟成员（含盟主）之间及存在任一方向请求攻打约定的双方，不得使用伪报、扰乱、烧夷、夺取、离间或流言；流言只对来源与第一目标应用这项保护。已提交任务在执行前形成保护时取消效果并返程。原先中性记录的特殊配对谓词已核实为这两类语义，见[RE-0113补证](../../research/findings/RE-SAN9PK-0113.md#2026-09-17-联盟攻击请求配对资格补证)。

军师意见采用与提交相同用途、日期、执行者和类型化目标的固定百分骰，以当前成功阈值判断成功门，以`min(100,60+max(0,I-70)+max(0,I-90))`判断准确度门；两门布尔值相同为有利，不同为不利。智力100时，意见与当前条件的主成功门一致，包括低于50%的计略；50%不再特殊返回不确定。意见不读取已保存任务，不保证到达时资格、实时阈值或额外运行随机门不变。没有军师返回无军师，资格无效返回不可用。夺取仍用包含宝物独立门的总体成功率（保留半个百分点），外交复杂谈判仍按各自规格提供的当前阈值，不宣称预测全部分支。该关系替代此前固定50%分类的重制选择，依据为[RE-0171补证](../../research/findings/RE-SAN9PK-0171.md#2026-09-18-g08审核军师分类与概率包装器)。

## 状态与不变量

### G08 有限自动计略

`StrategyPlanner`是阶段集成策略，不复制原作完整AI。自动势力及自动军团在军事规划后、经营前最多提交一条公共计略命令；同一控制者已有计略去程时不重复派遣。CLI脚本也可调用同一只读入口。完整跨系统规划仍归G11。

候选按稳定身份排序，最多8名己方空闲驻地执行者，每类最多16个目标；以当前绝对旬数加势力身份对八类计略轮换首选，依次回退到首个通过公共验证的命令。无候选返回等待，不消费玩法随机、不窥读保存骰，也不把军师不利意见当作禁止施计的资格。敌对候选仅考虑关系低于40的势力；公共验证继续负责联盟、攻击请求、特殊势力、目标状态及行动权限。部队目标只含己方部队和己方当前接敌／攻击命令引用的敌军身份，不扫描隐藏敌军位置；人物只含已可见驻地人物及上述接触部队成员。规划不按敌方隐藏能力或资金排序。

救援额外保留来源至少3000驻军，并要求目标至少缺1000兵，避免小额补兵反复占用人物。己方资源、当前部队状态可用于规划；提交与到达仍由正式规则重新检查。预算限制候选搜索工作量，不限制内容身份或对象数量。

验收覆盖八种命令的实际选择与结算、无候选、权限、外交保护、在途预算、救援保留兵力、重复规划无副作用、自动调度及保存／录像恢复。事件系统未来通过同一公共命令入口接入，不在G08预建G10事件框架。

关系存储是否包含显式零项不属于计略资格。缺省关系按0查询；离间第三方排序和流言关系效果也使用统一关系服务，省略零项与显式零项具有相同行为。

- 输入与前置条件：计略类型、单名执行者、来源部队、类型化目标、当前资格、军师和显式随机上下文。
- 状态变化：提交命令、保存判定结果、设置执行者占用；执行时写效果、经验与事件；旬末释放占用。
- 始终成立的不变量：参与者恰好一人；军师反馈不写世界状态；玩家与 AI 共享结算；事件类型必须匹配命令；无效目标不得写回；占用最终释放。
- 失败或无效输入行为：提交复验失败不创建命令；执行复验失败不应用目标效果，并产生可诊断的失效事件。

## 示例与边界

- 更换执行人物但目标不变时，军师反馈按新组合重算。
- 提交后目标失效时，执行复验拒绝效果，不沿用提交时对象快照盲写。
- 保存结果等于实时阈值时判定失败；只有严格小于阈值才成功。
- 阈值为 0 时必定失败；阈值至少为 100 时，任意 `0..99` 保存结果均成功。

## 验收标准

- [x] 八类计略的玩家与 AI 路径产生相同类型化命令。
- [x] 执行者/目标变化会刷新意见，意见调用不改变状态哈希。
- [x] 固定命令日志和随机种子得到固定事件与状态哈希。
- [x] 提交后目标失效、人物占用及事件类型不匹配均有测试。
- [x] 成功和失败均给来源部队当前全员增加策略熟练度，且旬末无占用泄漏。
- [x] 测试夹具不依赖原版文件、机器地址或研究工具。

- [x] 相同条件下，改变无关操作顺序、命令序号、玩家读档或重启不改变提交骰；实时阈值变化仍可改变成败。
- [x] 军师重复查询稳定且不推进规则随机流；军师或有效条件变化会重算。
- [x] 玩家读档保留任务骰，混合流程仍有独立运行抽样；录像精确恢复完整事件与状态。
