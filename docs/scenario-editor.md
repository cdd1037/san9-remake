# 剧本编辑器

首版在已有内容目录中编辑单个剧本，入口为标题菜单的“剧本编辑”按钮。也可从仓库根目录独立启动，`--scenario`使用内容目录中的剧本ID，省略时选择首项。

```powershell
godot --path src/San9.Client.Godot -- --scenario-editor --scenario 0
```

`--content-root <目录>`选择转换内容根目录。独立启动与其他编辑器、直接内容包启动及世界验证互斥。

## 编辑范围

| 页面 | 可编辑内容 |
| --- | --- |
| 剧本 | 标题、简介、年份、月份、开局旬、默认玩家势力，以及登场、自然死亡、迁移、官职请求、叛变、都市独立、势力兴起与合并开关 |
| 势力 | 信望、基础信望、君主、军师、爵位、国号、休眠状态，以及各军团的资金和兵粮 |
| 据点 | 势力和军团归属、兵力、伤兵、士气、耐久、民心、商业、农业、人口、预备兵役和休眠状态 |
| 武将安置 | 势力、据点或地域、身份、官职、伤病、休眠、本旬行动、军团长标记和对所属势力的忠诚 |
| 宝物 | 未启用／未出土／已出土、持有武将和出土地域 |
| 完整初始状态 | 完整`ScenarioDocument`的JSON，可配置部队、宝物持有、外交、事件进度、额外人物、人物安置与显式资料差异等现有契约 |

势力、据点、武将和宝物页可按名称或ID搜索。表单中的人物、势力、军团、据点、地域、官职、爵位和国号引用共用可搜索选择弹窗，可按名称或ID筛选并选择“无”清空。修改归属时须同步相关人物、君主／军师、军团及其他引用。人物基础资料由共享默认值和剧本显式差异组合，未覆盖的字段继续继承共享资料。完整数据页可添加共享目录中人物的安置，或声明剧本额外人物。

宝物页列出当前有效定义中的全部宝物，包含未启用项；其基础效果归共享定义或剧本规则差异。发现状态、持有武将与出土地域分别编辑，持有武将和地域可选“无”清空。持有者使用共用人物选择组件，可按姓名或ID搜索本剧本全部人物，地域候选覆盖地图全部地域；未出土且无持有者的宝物可在指定地域通过探索获得。目录外的未启用状态记录随草稿完整保存。宝物页与完整数据页共用同一初始状态，随“保存剧本”发布。

完整数据应用前进行结构、引用和建世校验，拒绝未知字段、无效身份及地图布局修改；失败保留输入。切出完整数据页、保存时均先应用输入。首版使用原有剧本身份、分类、地图布局、据点集合、据点类型及外观；地图布局可在[地图编辑器](map-editor.md)中调整。新建／复制独立剧本与事件专用编辑界面留待后续实现。

## 保存与恢复

点击“保存剧本”或按`Ctrl+S`保存。发布文件位于原始文件旁，通常为`scenario.player.json`与`content.player.json`，分别保存完整初始状态和带预览的入口。两个副本共用现有文件锁、快照冲突检查和失败回滚事务。保存失败保留内存草稿。

玩家副本优先于对应基础文件。它保留共享资料引用与显式覆盖，初始状态为完整副本；基础剧本重建后，玩家副本仍保持自己的初始状态。玩家副本格式失效时明确报错。编辑器不改写已有对局，保存后新局使用修改后的数据；当前标题菜单的剧本名称、日期和城市归属预览同步更新。

开局日期须为1、11或21日。保存复用内容组合、文本格式和新局建世校验，保留有效对象与休眠状态。共享资料编辑器的引用检查同时读取玩家剧本，受初始状态引用的自建资料不能删除。

“恢复打开时的值”将整个当前剧本草稿恢复至本次打开时的状态，恢复后可再次保存。切换剧本、关闭编辑器或退出窗口时，有修改则提供保存、放弃和继续编辑选项。
