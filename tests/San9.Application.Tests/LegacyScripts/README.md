# 历史脚本基线

这些策略只编入 Application 测试程序集，AI-06 已将其从产品移出。旧军事用例保留攻击请求、地形与公共军令接线；旧外交用例保留正式谈判、保存及玩家暂停；旧计略用例保留公共任务、权限和返回等待。

生产能力证据由 `EconomicSessionTests`、`SharedAllocationTests`、`CampaignPlanningTests`、`DomainOpportunityTests` 和自主 Headless 对局承担。历史脚本不能用来证明统一生产策略的候选覆盖、协调或强度；调整生产 AI 不要求维护其评分或日历规则。移入测试不保留产品兼容入口。
