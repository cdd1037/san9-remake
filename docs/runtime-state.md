# 运行时状态与资源目录

## 当前结构

内容包提供支持范围内的完整定义、资源和初始状态，不按首屏或初始可见性删减对象。`GameSession.Start`复制初始记录，创建独立的`WorldState`；Core持有势力、据点、人物、宝物等当前状态。两个会话互不影响，改变导入对象也不会改变已启动会话。Core不依赖内容包、Godot或原版格式。

状态只能通过规则提交，成功事务更新世界版本。`WorldSnapshot`保留按ID排序的只读记录；旧快照不随新事务变化。状态摘要包含日级日期、起始日期、控制席位/当前位置、命令序号水位、持续任务、命名随机状态及全部当前领域记录，仅在录像、测试或诊断主动请求时计算，用于确定性对比。世界摘要不包含显示文本、图像或会话内容身份；会话诊断摘要覆盖当前世界、年表、最近记录与操作水位，二者均不写入普通快照；磁盘文件仅保留封套完整性校验和独立内容指纹。

`SimulationEngine`统一组织规则执行及事务提交：类型化命令经控制权限与业务终验后即时提交或建立持续任务；全部控制席位结束后逐日推进到下一旬，再完成前置更新。`DomesticDevelopmentHandler`检查业务前提并准备变更，`XunRecovery`负责旬行动恢复；二者都只修改候选事务，不自行发布世界。`GameSession`通过运行引擎执行用例，从成功提交返回的领域事件生成会话记录，再通知界面。

`WorldState`负责状态保存与发布。初始化显式拒绝全部七类集合的重复身份，包括同ID同内容的重复记录；初始化和提交共用`WorldInvariants`，校验现有领域数值、日期及对象关联约束。事务允许中间状态暂时不一致，在最终候选状态上统一校验，便于跨对象归属变更。校验失败不改变世界、随机状态、版本或缓存快照；成功只增加一次版本。此处保证单线程执行中的原子发布，不提供并发写入同步。新增规则须把公共状态不变量放入统一校验，业务可执行条件留在对应处理器。

Application把当前世界与复制后的名称/显示定义组合成`StrategySnapshot`，按世界版本缓存。HUD、标注、设施可用性和小地图读取同一视图。Rendering根据耐久、开发度、驻兵、归属选择组合和动画；客户端不再把初始精灵实例作为建筑真值。

当前700名内置人物保存在世界中，只有可见身份进入人物视图；宝物状态保留出土状态、持有人和发现地域，情报查询再筛选已出土且由可见人物持有的宝物。没有进入初始情报的对象仍有定义和资源。数据核对方法见[内容管线](client-content.md#接入前的数据核对)。

## 已接入规则

依据[BEH-DOMESTIC-0001](../specs/behavior/BEH-DOMESTIC-0001-base-development-effect.md)，首批接入单人商业和开垦。命令只传势力、据点、武将和项目；能力、费用及增量由Core从当前世界读取并计算。

执行前检查对象存在、同势力、武将在目标据点且未行动、项目本旬未用、开发度未满及资金足够。成功原子提交开发度、资金扣50、武将行动和城市项目使用状态，日期与随机流不变。拒绝不产生任何写回。

F3面板对选中玩家城市选择可用武将中当前政治最高者执行，展示成功增量或拒绝原因。它是实际用例的调试入口；正式内政菜单尚未制作。

## 内容与显示契约

当前包版本统一见[客户端内容契约](client-content.md#职责与文件)。旧包重新生成，没有兼容分支。当前默认包为`local/generated/content/scenario-190-live`。

- 地图建筑记录只保存稳定ID、位置和固定类型；类型目录提供耐久上限，30个已确认组合提供部件与旗帜/守兵锚点。
- 312项建筑源资源全部导出键色及调色板Alpha两种解释，共624张纹理，不再依赖初始剧本是否使用。三种城市外观及已确认耐久、开发档位都可选择。
- 动画目录共437片段：4种水面、8方向守兵、51种旗色、两套各186个旗字，以及前后旗杆。旗杆后层、旗面、旗字、旗杆前层独立叠加，运行时按归属选择；驻兵为零不生成守兵。
- 四季地貌仍全部导出；显示时钟独立于模拟时钟，F3季节预览不改变世界。未知建筑组合明确拒绝，不因纹理齐全就假定组合规则已确认。
- 图标、城池外观类别、地理位置和势力显示定义目前属于会话静态定义；当前没有改变这些定义的玩法。云层仍按初始建筑边界导出，尚不支持新建/拆除设施后的云遮挡重算。

`render-map --content-package`从剧本初始态派生建筑供离线静态导出；独立地图包没有据点运行数值，`render-map --package`必须指定`--terrain-only true`。

## 时间、命令与任务内核

`SimulationState`保存场景起始日期、初始种子、稳定/终局边界、控制席位与当前位置、单调命令序号水位、任务和命名随机。执行中标记由`WorldState`独占持有，不序列化；同一世界的多个引擎入口也不能重入。`GameClock`只有年月日可构造，旬与周期标志均派生。

`GameSession.Start`将玩家势力置于首席，其他势力按ID配置自动席位；请求携带由Application指定的控制者上下文。`Execute`和`Validate`共用类型化终验，`Develop`只是现有客户端内政调用的转换方法。`EndControl`推进席位；现有会话`AdvanceXun`显式结束剩余席位后推进，尚无自动规划器。命令拒绝不消耗序号、资金或随机，不发布事件。

任务记录是人物持续占用的唯一来源，名单和建筑可用人数也读取该状态；旬恢复清行动位时不清任务。内部编译规则决定任务时长、资格及完成效果，存档不能携带执行代码；未知任务规则恢复时拒绝。正式任务注册表当前为空，内核夹具验证真实事务、到期、取消与随机，不代表人事或战争已可执行。

`CaptureStableState`拒绝执行中取存档；`WorldState.Restore`验证稳定边界与不变量，保留版本且不执行首轮更新。`SaveEnvelope.Session.World`包含权威世界，初始种子只保存于`SimulationState`。Application的`SaveService`实现严格校验、同目录原子替换和新会话恢复；`CommandLogService`按会话序号重放，旧序号返回已处理且不产生事件、不验证旧载荷。`GameSession.Apply`在候选世界上执行，世界、最近128条内政记录和水位一起发布；玩家年表保留，完整操作与事件仅在显式录像时记录。协议、独立CLI和实际验收见[G02验收](g02-verification.md)。

## 战略全图运行态

[BEH-UI-0003](../specs/behavior/BEH-UI-0003-strategy-overview.md)引入独立面板状态。SettlementKind区分城市与设施；排行榜统计领域类别，不以纹理或标记是否存在推断城市。ForceState保存初始化派生的IsBarbarian。UnitState保存有效部队身份、根势力、位置及现役兵力，独立于据点驻兵；GameSession复制初始内容，WorldSnapshot含不可变部队列表。此入口没有实现出征、移动、战斗或部队内武将驻地迁移。

城市区域掩码、地形、排行榜背景及图层按钮属于皮肤schema7；面板显示和图层切换不修改世界版本。三项开关在本会话保留，重开不重置；点击全图、雷达及名单只改变详细地图相机目标，不改变命令起点。

情报扩展使用不可变目录投影和独立模态导航；军团的Treasury为空表示使用所属势力金库，非空表示其独立金库，避免资金副本。人物可具有据点位置或独立地域位置，在职人物才进入右侧行动名单；官爵、人口、宝物及关系值纳入内容校验。详见[情报界面](information-browser.md)。
