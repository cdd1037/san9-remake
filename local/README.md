# 本地生成目录

`local/generated/` 被 Git 忽略，保存转换包、缓存、验证报告和研究工作文件；原始私有输入放入 `private/`，可长期复用的生成方法和结论放入受版本管理的工具或文档。

| 内容 | 保留与清理边界 |
| --- | --- |
| `content/` | 当前客户端运行包；原位增量更新，由转换器清理失效资源 |
| `verification/`、`research/` | 保留仍被引用的报告、实验记录及独有截图；可再生的工作副本和构建缓存可清理 |
| 专项实验目录 | 待验收的交付物、生成脚本及依赖一起保留；完成后再清理中间产物 |
| 临时工程、旧验证副本、日志 | 确认无进程使用、无独有输入或未归档结论后清理；删除受限时移入回收站 |

清理只针对已核对的子路径，不整体删除 `local/`。原版样本、主 IDA 库和未整理的唯一证据不按缓存处理。已有文档中的本地产物路径是复现线索，不保证每个检出都存在；清理不改变历史验证结论，也不代表当前版本重新通过验证。

转换只使用已登记、合法持有且指纹匹配的样本；游戏、测试和工具不得依赖开发者机器绝对路径。默认测试使用 `content/dev-fixture/` 的自制数据。运行包生成命令见[快速开始](../README.md#转换客户端内容)，数据核对见[内容管线](../docs/client-content.md#接入前的数据核对)。
