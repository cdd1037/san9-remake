# 局内世界编辑器

- 状态：已确认。
- 证据：[RE-SAN9PK-0199](../../research/findings/RE-SAN9PK-0199.md)。

## 目标与字段

功能菜单的编辑武将、军团、都市、设施和障碍物均进入正式局内编辑流程。编辑玩家及其他势力的当前有效对象，不受普通命令的己方权限限制；终局、待答、推进和自动执行尚未完成时禁止编辑。无候选时禁用对应菜单。

| 类别 | 候选 | 可编辑内容 |
| --- | --- | --- |
| 武将 | 当前有效且可见的君主、都督、军师、一般、俘虏和在野人物 | 基础四维、四种性格、情义、野心、相性、负伤、有归属者当前忠诚、九类熟练／精通、个人兵法 |
| 军团 | 当前普通势力的全部军团 | 资金、兵粮，各0..1000000 |
| 都市 | 当前有效的有主都市 | 民心、收益／收获／耐久及各自上限、非兵役／兵役人口、士兵、士气、城防兵法 |
| 设施 | 有主、可驻人的已完成设施 | 耐久、士兵、士气 |
| 障碍物 | 不可驻人的已完成工作物 | 耐久 |

所有目录排除未启用、已毁灭及施工中的对象；武将排除未发现、未登场、死亡和特殊对象。对象数量与身份不使用原版固定槽位或编号边界。军团不编辑军团长、方针或隶属；都市与设施不编辑所有权、位置、类型或任务。

数值输入沿证据范围：四维1..100，情义／野心0..15，相性0..149，负伤0..7，忠诚0..100，熟练0..1000。都市人口3000..1000000、兵役人口0..500000，三项最大值100..1000；当前收益／收获不超过新上限，耐久1..新上限，民心0..1000，士兵不超过对象容量。兵力减为0使士气归0，从0增加使士气为70，士气输入1..100且零兵时隐藏。减少最大值同步夹取当前值，取消仍丢弃整份草稿。

个人兵法按规则语义提供可选个人兵法及阵形／建设技术，不把自动船舶攻击、派生陷阱或建筑专用效果作为个人学习项；TC101对应原作31项。已有合法的扩展字段值不因打开或修改其他字段而截断。新增修改遵守编辑范围，完整世界仍须满足领域不变量。移除已装备的个人兵法时同时清除该装备引用。

## 所有权与提交

Application持有编辑草稿；切换对象与筛选保留草稿，但不修改会话、不递增序号、不触发AI、不推进日期。列表或地图中的“决定”统一提交本次全部改动；有未提交改动时，通过关闭按钮、关闭图标、右键或Esc退出，先弹出原作“资料还没储存。您确定吗？”确认框，选择“是”丢弃全部草稿并退出，选择“否”留在原页并保留草稿，弹窗期间底页停止输入。详情页的“关闭”、右键或Esc回到来源列表／地图并保留草稿；“取消”恢复当前对象的会话初值并留在详情，当前对象没有改动时禁用。军团详情的取消恢复所选势力的军团资源。数字弹窗中止、右键或Esc只放弃此次数值输入并返回详情。无变化直接关闭，不产生空操作。

Core校验候选、类别、可修改字段和数值，所有改动在一个事务中提交；任一项失败则整批不生效。重算相关太守／部队主将与派生信望，保持既有任务、普通命令水位和随机流不变。Application仅允许玩家提交编辑操作，复用操作水位、未保存标记和Changed通知；失败保留草稿并提示。

`SettlementState.EnabledTacticIds`持有建筑可变城防兵法，新局由内容定义初始化，战斗和情报读取当前世界值；不修改共享MilitaryRulebook或作者定义。城防主动兵法与落石／射台分别单选，同组更换互斥。

编辑通过统一会话操作提交，状态进入普通存档；显式命令脚本可包含编辑操作，会话不累计历史。录像已延期并撤下，见[持久化边界](BEH-SAVE-0001-session-persistence-replay-and-headless.md#面向玩家交付前的后续要求)。保存122、日志129保持不变。旧格式明确拒绝，无隐式补值。剧本139保持现有契约；组合包204提供编辑提示与退出确认消息，皮肤60区分标题姓名框、静态分类底纹与数值读数背景，提供完整编辑页资源。编辑目录复用既有情报目录排序，不新增姓名排名元数据。当前190年转换包已原位更新。

## 明确的重制选择

- 菜单先进入一览，点击对象进入独立编辑页。军团入口为五页“势力一览”，都市复用五页“都市一览”，两者保留地图入口；设施为“工作物一览”的所属／战力两页，障碍物只有耐久页。武将与军团入口保留既有武将／势力目录的默认顺序，不在编辑器二次排序。
- 详情使用独立编辑皮肤：武将为头像／能力雷达、四维、个人属性、性格、九类兵法和20行姓名栏；军团上方显示君主头像／四维卡片，摘要为国号、官爵、信望、兵法、军师、军团数、资金和兵粮；下方按原作双列八张资源卡显示，空卡保留名称框与数值底图、禁用资金和兵粮按钮，超过八个时分页；都市为地图、内政、兵力、城防兵法，标题附状态与特征；设施和障碍物使用各自的小窗口，姓名栏分别为14行和13行。保留可扩展集合，不把八张卡片当作军团总量上限。
- 原作四维上限取决于内部99／100标志；重制统一允许100。
- 草稿完全隔离；没有原作编辑期间临时改世界、生成地图预览再恢复的行为。
- 城防主动兵法允许主动清空；选择新项仍保证同组互斥。

关闭及取消的底部提示直接消费转换包中的原作消息：关闭返回前一画面；取消按编辑类别及可用／无修改状态选择对应文本，不在客户端自行编写替代提示。组合包204包含这十条取消提示及退出确认消息，默认说明和帮助文案沿用现状。

都市与设施／障碍物的数值框显示当前值及当前上限，都市三个最大值按钮使用字段名称，并继续调整上限及夹取当前值；上限不由截图固定。都市标题显示一般／混乱及非空兵法类别修行。地图预览使用独立装饰框和512×256内容区，以含地形高度的建筑地面锚点定位；该布局需要皮肤60。

## 验收

五个菜单按范围进入对应目录；点击对象进入详情，返回保留目录分页与草稿。修改、切换对象、决定或关闭均有确定结果。自动验证覆盖草稿隔离、撤销、原子失败、权限／范围拒绝、数值联动、城防消费者以及真实保存／命令脚本往返。编译与自动化不代表最终画面验收。

本需求解决方案各项目合计5472项通过；Headless29项沿用前轮通过结果，本轮没有改变进程协议。190年包完整校验通过（31621逻辑图片／5272物理文件）。Godot实际渲染检查覆盖武将、军团、都市、设施列表与详情；190年初始世界没有障碍物，入口正确禁用，障碍物表结构由自动测试核对。画面检查不等于所有编辑值的人工交互验收。

补充交互检查：实际Godot探针确认修改武将数值后取消恢复初值，取消按钮随改动状态启用／禁用；数值弹窗期间详情输入禁用，Esc只关闭数值框，再按Esc返回列表；由地图进入详情后返回原地图。双按钮底框及地图入口位置已重新渲染核对，客户端构建通过。
