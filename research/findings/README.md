## 维护规则

- 同一对象的后续收窄记录链接基线记录；不要复制整张字段表，只记录新增证据、冲突和变化。
- 研究事实、推断和待验证项必须分层；成熟结论另行进入 `specs/behavior/`。
- 地址、IDA 写入和回读验证只留在 `RE-*` 与符号表，不进入产品代码注释。
