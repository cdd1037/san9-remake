# 三国志 IX PK 繁中版 `.s9` 文件清单

- 样本基线：`SRC-SAN9PK-TC-101`
- 最后更新：2026-08-16
- 游戏数据目录：`private/s9数据文件/`
- 编辑器截图目录：`private/剧本编辑器截图/`
- 范围：私有目录中的繁中 PK 1.0.1.0 游戏数据及已观察到的用户编辑文件
- 产品范围：教学剧本和挑战剧本保留为研究资料，但不属于最小可玩版本；范围决策见 [`DEC-SCOPE-0001`](../specs/decisions/DEC-SCOPE-0001-scenario-scope.md)

本清单记录文件用途线索，不直接构成产品实现规格。状态含义如下：

- **已确认**：已有容器检查、数据差分或目标程序加载链支持。
- **结构已观察**：文件头、记录数量或容器家族已确认，具体业务语义未确认。
- **名称推断**：只依据文件名、同组资源或 RPG Viewer 分类推测用途。
- **未解释**：当前没有足够证据。
