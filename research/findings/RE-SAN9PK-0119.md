## 对象、状态、输入、输出与不变量

对象是 50 条主势力记录、每条运行时记录中的 50 项关系数组、全局联盟剩余旬数、联盟目标、参与势力、盟主、季度事件 type 26、到期事件 type 27 以及联盟通知/清理链。输入包括剧本模式、开局经过日数、全局随机流、兵力汇总、基础/当前信望、势力关系、控制权及若干敌对与邻接谓词；输出包括联盟三类旗标、36 旬期限、盟主基础信望、成员与目标/成员彼此的关系值、内部冲突命令清理和通知。

不变量：普通关系值和联盟身份是两套状态；关系写入保持双边对称并限制在 `0..100`；同一时刻只有一组全局联盟期限和目标；形成成功才写持久联盟状态；目标不进入成员表，盟主必来自最终参与者；期限为正时每旬只减一，归零后统一清除所有势力的 bit 4/5/6 并把期限置零。

## 已确认事实

### 关系数组与关系档位

势力关系 getter 先把对方解析为有效主势力 ID，再读取本势力运行时记录 `+0x38+other_id`。底层 set/add/subtract 对单项写入，add 上限为 100、subtract 下限为 0；对外包装把同一最终值镜像给另一方，因此正常命令路径保持对称。

关系档位严格为 `0..19 → 0`、`20..39 → 1`、`40..59 → 2`、`60..79 → 3`、`80..100 → 4`，越界返回哨兵 5。数值变化会在跨档时生成相应关系通知，但通知不是另一个关系存储。

### 联盟形成门与目标候选

联盟形成事件 type 26 位于季度事件表，因此下列门按季度评估：当前样本模式不是 2/9、联盟期限为 0、开局至少经过 360 日、全局 `rnd(4)==0`，且至少存在一个目标候选拥有三名合格非目标成员。这里确认的是每次季度评估 1/4 门，不把它换算成独立年度概率。

主目标路径要求候选集合的合计兵力指标超过 300,000，并在一个尚未获得唯一玩家术语的集合/地域计数上取最大值；低信望后备路径要求合计兵力超过 200,000，并在基础信望小于 30 的候选中取最低值。两条路径都有效时，准备阶段以 `rnd(2)` 二选一。不能把主路径误称为“高信望目标”。

成员资格排除目标自身，并检查有效主势力、特殊/控制状态、与目标关系档不在 3/4（即数值低于 60）、君主相性排除及机器中的敌对/邻接条件。最后几个谓词的数据流已确认，但本批没有为它们猜测产品标签。

### 参与者、盟主与形成写回

准备阶段遍历 50 条势力。玩家控制势力通过消息链显式决定是否参加；AI 势力使用成员资格判定。最终至少需要两名参与者，否则只发失败消息，不写期限、联盟旗标或关系。成功候选中的盟主取当前信望 `+0x20` 最高者；这与成功后奖励写入的基础信望 `+0x1C` 是两个不同字段。

形成提交把全局期限设为 36 旬，把目标的 bit 6、盟主的 bit 5、所有参与者的 bit 4 置位，并给盟主基础信望增加 25。由此闭合 `RE-SAN9PK-0021/0045` 先前未定的三位标签：bit 4 是联盟成员，bit 5 是盟主，bit 6 是战争目标。

提交还取消参与势力之间的冲突命令，并规范化关系：每名成员对目标的新关系为 `min(max(old-20, 0), 35)`；每对成员的新关系为 `max(60, min(old+20, 100))`。两类变化均沿公共对称关系写入链执行。

### 期限递减、到期与提前解除

每旬世界更新直接调用此前误识别为数据的 `0x480980`。当联盟期限大于 0 且已过剧本起始日时，它调用有界减法把期限减一；结果不大于 0 时发出到期 case 3。通知链最终调用公共清理函数，遍历所有主势力清除 bit 6、5、4，把期限置 0 并刷新状态。

势力/君主死亡、劝降执行和势力对状态变化还会进入联盟通知或势力对处理链，因而联盟也可能提前解体。当前事实足以确认它们共用状态清理边界，但不足以为每个玩家消息 case 写最终中文名称。

### 外交状态与剧情事件的边界

联盟形成是季度事件系统中的周期事件，不是普通外交命令；关系数值数组、联盟三类旗标和消息事件分别承担数值关系、临时联盟身份和表现/清理触发。type 27 存在于事件工厂，但普通季度静态表不包含它；实际期限消费由旬世界更新直接完成。因此不能从某条剧情/通知消息反推出所有日常外交状态，也不能把联盟旗标当作关系档位的别名。

## 2026-09-13 主动宣战确认与背盟惩罚

### 样本与方法

沿用 `SRC-SAN9PK-TC-101` 的工具及环境登记。本轮主库 survey 确认繁中威力加强版、32位、映像基址 `0x400000`，EXE SHA-256 为 `d20794aeff67301ec2bf8c3becb1e9944c68c6c0588fbfd4bf04e8597f0e5028`。以反编译、交叉引用和只读指令解码追踪交互、命令集合、推进入口及属性写回，没有运行原游戏动态实验。

文案证据来自当前转换包 `local/generated/content/scenario-190-live/messages.json` 的源脚本字面文本和绑定；转换路径为 `San9MessageTable → OriginalMessageParser`。源文件 `private/s9数据文件/M_MsgPK.s9` 的 SHA-256 为 `3A8BB191DE1A9F17EA95E9EC6CDD1443D6EF44A524BA6DBB7CE977DF25900B5D`。消息编号与 EXE 调用立即数对应，不能只凭文案猜测触发条件。

**事实，高置信度：**原作允许确认后下达针对高关系势力或联盟成员的攻击命令。确认、普通宣战代价、联盟背信是不同环节。此前重制实现统一拒绝成员攻击，尚未覆盖这一入口，不能视为联盟玩法完整实现。

### 普通宣战处罚

令 `y` 为人物义理。关系名称由消息9867核对；消息9798说明对好意/信赖开战损失信望和属下信赖，与以下写回分支一致。

### 联盟附加处罚

**事实，高置信度：**普通关系分支之后，双方仍具成员/盟主身份时独立进入 `process_alliance_force_pair_state_change (0x458D70)`。内部要求期限非零、目标和盟主有效、双方成员位成立；形成链保证盟主同时具有成员位。效果为：

- 攻击方基础信望再减50，下限0。
- 攻击方与每名其他原成员的双边关系变为 `min(35, max(0, old-30))`；`old` 是本函数执行时的值。
- 攻击方所属非君主人物的当前势力忠诚再减各自义理，下限0。
- 攻击方是盟主，或原成员总数小于3，则整体解除；否则只清除攻击方成员身份，保留其他成员和原期限。

实际忠诚写回重新调用 `0x43DDE0(actor, list, null, 0)`，然后仅排除人物状态0，没有普通宣战的状态0..3过滤，不能与前面的消息提示人物集合混淆。归属谓词 `0x4716B0 → 0x44C0B0` 使用人物虚表 `+0x34` 比较根势力；`0x44DEE0` 对俘虏状态4返回 `+0xEC` 原归属引用，对状态0..3返回当前所属对象的归属，其余为空。因此还可覆盖原属于攻击方、现被俘的武将，并非攻击方拘押的全部俘虏。忠诚 getter `0x44DE00` 经虚表 `+0x30 → 0x44DE80 → 0x44BFF0` 同样解析俘虏原归属。俘虏边界为静态调用链事实，尚未做存档对照。

消息9407..9412分别对应与其他成员决裂、盟主背信解散、普通成员除名、人数不足解散、信用下降及属下不满。反编译在该函数存在栈参数/局部变量错配：本轮原始指令核对了 `0x459165` 的50常数、`0x45922D / 0x459237` 的状态/义理读取，以及 `0x459244` 后对保存的原盟主、原成员数的比较，未直接采信错配的伪代码表达式。

**由上述顺序推导的算例，非动态实验：**原关系70、基础信望100、普通在职非君主忠诚100、义理10，无请求约定时，攻击盟友后信望40、忠诚85；被攻击方关系先到35，再到5。其他成员与攻击方原关系70则到35。若原关系90，同样初值的信望为30、忠诚为80。两层处罚叠加，各层均受下限约束，不能以“背盟只减50”替代全过程。

同次推进的后续同势力对命令读取已变化的关系和联盟身份，通常不再满足两个处罚门；这来自状态变化，不是每支部队另设免罚计数。

### 请求约定与剩余证据边界

**事实：**联盟处理后还有独立的 `0x441EA0 → 0x440380` 配对检查，读取双方 `+0xC8` 引用；消息6070以及计略资格消息9017/9020/9023将其关联到约定/请求关系，不能未经核对就解释为宿敌。`0x50A733` 起的实参指令确认主动宣战传入空原因参数，进入 `0x4464F0 → 0x445FA0` 的主动毁约分支。
