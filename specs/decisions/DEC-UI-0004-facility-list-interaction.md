# DEC-UI-0004：设施名单按原作行为、用原生控件实现

- 状态：已接受
- 日期：2026-09-06
- 授权：用户要求完整核对并对齐，允许性价比更高的现代实现，但必须明确。
- 关联：[BEH-UI-0001](../behavior/BEH-UI-0001-initial-strategy-screen.md)、[RE-SAN9PK-0158](../../research/findings/RE-SAN9PK-0158.md)

废止名单与地图共享选择及黄色持久选中的旧重制约定。地图命令起点、键盘焦点、按钮按下、名单滚动是独立状态。名单激活仅定位镜头；有无可用武将只决定文字颜色。君主关联设施固定在首行，普通集合按直属军团过滤并去重，最多显示13项。

实现采用 Godot 控件焦点、输入派发和原生滚动条，应用层维护离散行索引，不复刻原作窗口消息、对象布局或位图文字引擎。行背景使用已确认的原图四帧三段纹理及标准 Alpha；文字沿用 DEC-UI-0002。滚动条保留现代原生输入，使用原作已确认的分段轨道、滑块及四帧箭头纹理；箭头一步、轨道一页、滑块拖动和滚轮一行保持原作语义。Tab 顺序按现代场景控件顺序，Enter 激活，方向键不切换名单焦点。

当前只实现设施页。部队、武将等已有禁用入口保持明确的“尚未实现”提示，不用虚假空页冒充完整名单。右键名单打开现代通用快捷菜单，进行、情报、储存、载入按当前能力禁用并注明未实现；Escape 关闭。尚无详图面板、军团切换用例或君主移动命令，不能宣称这些玩法已经实现；名单模型仍从当前会话关系派生并在刷新时裁剪滚动、重新确定君主行。

军团直属关系与根势力归属分别保存；不再从根势力反推军团。当前领域只保存设施的直属军团标识，军团的创建、层级管理和调动留给其对应领域用例。君主身份保存为人员引用，位置从运行时驻留人员派生，不硬编码洛阳或最小设施编号。导入时仅对本版已支持的初始驻留人员建立君主引用；无法建立时明确拒绝导入，不能静默选择替代设施。

验收覆盖君主固定/去重、直属过滤、空页与13项边界、刷新裁剪、滚动符号与页步长、焦点保留与转移、按下位移、拖出取消及移回、回车与双击、褐色可点击、地图选择隔离、右键菜单、实际 GPU 状态截图。实际操作系统输入与引擎派发测试分别记录。

2026-09-06范围更新：武将页现已按 [BEH-UI-0002](../behavior/BEH-UI-0002-officer-roster.md) 接入，与设施共用控件和分页模型；本文关于武将页未实现的早期限制由该规格替代。

2026-09-06外观更新：依据用户要求及RE-SAN9PK-0158滚动条复核，通用滚动组件接收皮肤与范围，不依赖设施或人物模型。主界面整体16×280、内滑道12×252，滑道相对原点(3,14)，滑块最小16；中心纹理平铺、端头固定，禁用箭头使用第四帧。无溢出显示侧栏装饰。原生滑块比例取整及焦点派发允许现代差异。未来人物界面按其规格传入皮肤，不假定原作各界面资源相同。
