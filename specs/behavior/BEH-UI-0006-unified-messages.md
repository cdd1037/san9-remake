# BEH-UI-0006：统一消息与图文显示

- 状态：已确认
- 原作证据：[RE-0026](../../research/findings/RE-SAN9PK-0026.md)、[RE-0159](../../research/findings/RE-SAN9PK-0159.md)

## 重制行为

原始文本字节只在版本Importer解析。转换包保存Godot原生BBCode显示片段及参数、条件、随机选择、消息引用节点；Content与Application不引用Godot程序集。普通参数转义后插入，不再次解析为标签。纯文本读取遇到富文本必须报错，不能丢弃图标后继续用于排序。

## 状态与不变量

消息求值采用调用方显式提供的值、查询与随机源；求值结果保留至消息替换，重绘不重抽。消息引用区分追加调用与尾部转移，循环、超深引用、缺少绑定和未确认语义均明确拒绝。原版01J采用尾部转移，01C采用返回调用；不把两者混为字符串追加。

源文和简体片段结构一致，OpenCC仅转换文字。普通文字使用现有现代字体，原作有效图标使用转换图片，按字号选择最近原生尺寸、同距优先大图并等比缩放。城市前缀成为普通行内图片，不使用私用Unicode或专用图片控件。

字体取舍（2026-09-11，项目所有者确认）：不为缺字增加补充字体，移除此前 BabelStone Han 回退；当前仍用 GB Lite。明确接受 U+20860、U+29166、U+2AEFA、U+2B623 缺字，保留原始和转换后 Unicode 内容，不替字、不丢字。覆盖报告必须列出这些缺字，已接受缺字不阻断验收，其他新增缺字仍需报告并阻断自检。用户补入的 GB 字体不自动成为主字体。

Godot负责排版，保留显式换行并支持容器自动换行。描边和阴影为未决项，不要求控件间强一致。

## 验收标准

运行时只发布PK消息与列传两个档案；研究审计可对照四个M_文本档案、被识别的EXE文本及运行时控制。逐记录报告字节消费、完整解析、语义确认、引用和绑定需求；部分解析与未确认结果保存诊断，不作为可执行消息发布。完整解析不等于已接入玩法。

验证城市图标与洛阳混排、扩展汉字、BBCode转义、参数、条件与随机、尾部转移与返回、循环和异常记录。执行跨层测试和客户端编译，画面检查12/16/24字号、图标基线、长列传与换行。原作证据保留，旧消息转换实现和生成物在引用迁移后删除，仅保留统一转换入口。

## 未决问题

描边和阴影的跨控件一致性尚未采用统一要求；保持上述已确认文字、图标与消息语义，不将此项计为已验收。

## 动态消息的领域接入（2026-09-27）

消息是一次业务事实的表现结果。Application提供基于不可变世界快照的消息生产入口，调用方明确传入人物、势力、据点、部队、宝物等类型化引用及数值、文字参数；不从当前选中对象猜测说话人或接受者。产生后保存正文、消息键与日期，重绘不重新查询或抽签。表现随机源由调用方显式提供，不能消耗领域随机流。

Content的表达式区分实体引用、属性读取、语义查询与普通值。Importer在发布组合包前将原版脚本降为此契约：正文名称与条件数值分开；列传编号身份判断改为人物引用；剧本编号及模式条件在转换阶段求值；世界标志改为具名事件历史查询。返回台词使用事件产生者提供的人事归队／自动撤退／主动返回原因，不能从事后状态猜测已销毁任务的类别。固定槽位上限、倒序编号、原版命令码不进入Application。原始语法与异常仍保留在研究导出，不作为运行时适配协议。

消息中未能降低的表达式记录明确的运行时拒绝原因，独立于原作语义确认；依赖链传播拒绝。缺少参数、类型错误、失效引用或查询未支持必须报错，不填零、不插入调试占位符。纯历史人物身份分支在当前剧本没有该人物时按不匹配处理，不能把不存在的人物绑定给调用方。

验收包括真实人物能力、忠诚与亲属关系、动态姓名与地点、事件历史、类型错误与缺失引用、名称转义、ID超出原版范围、消息产生后的状态隔离及随机隔离；转换报告分别给出语法确认、运行时可执行、调用所需参数和未支持原因。消息可求值不等于所有原版调用现场均已接线；事件到具体台词的选择必须有明确的事件参数契约。

### 已确认的原文异常取舍（2026-09-27）

原作容貌帮助的70／30数量暂时固定，数字使用淡黄色前景强调；用户截图支持该显示目标，不据此推定`ESC H`在所有宿主中的含义。发布转换按已审阅源记录核对，保留源文与简体版本。对已登记的四条PK消息，删除正常结束后残留的两字节无目标跳转，保留全部可解析正文和分支；未登记异常及正文错误继续拒绝。严格原文审计和发布内容决策分别记录，不把重制取舍标记成原作字节语义已闭合。条目与验收见[消息约定](../../docs/ui/messages.md#容貌帮助与异常尾部的发布策略2026-09-27)。
