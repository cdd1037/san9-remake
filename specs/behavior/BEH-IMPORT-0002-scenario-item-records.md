# BEH-IMPORT-0002：剧本宝物记录解析

- 状态：已确认
- 负责人：项目开发者
- 最后更新：2026-11-22
- 关联证据：[RE-SAN9PK-0006](../../research/findings/RE-SAN9PK-0006.md)、[RE-SAN9PK-0141](../../research/findings/RE-SAN9PK-0141.md)
- 关联决策：[DEC-DATA-0001](../decisions/DEC-DATA-0001-content-pipeline.md)

## 适用范围

本规格只约束繁中 PK 1.0.1.0 正式剧本 `item` chunk 的记录边界、已确认字段和引用校验。输入必须先通过 [BEH-IMPORT-0001](BEH-IMPORT-0001-source-container-validation.md)。

本规格不定义宝物名称文本、13 个类别的显示名称、地点编号到地图实体的映射或重制版宝物平衡。

## 原作基线

`item` chunk 包含 120 项，每项由 11 个小端 `u16` 组成，共 22 字节：

| 偏移 | 字段 | 已确认约束 |
| --- | --- | --- |
| `0x00` | serialized id | 正式样本等于记录序号 |
| `0x02` | resource id 1 | 名称资源编号 |
| `0x04` | resource id 2 | 说明资源编号 |
| `0x06` | image id | 0–99 |
| `0x08` | category id | 0–12；同时决定是否以及对哪项能力提供加成 |
| `0x0A` | loyalty change | 赏赐与没收使用的忠诚变化量 |
| `0x0C` | ability bonus | 与类别共同决定的独立能力加成量，不从忠诚字段派生 |
| `0x0E` | tactic code | 0–40；`0xFFFF` 表示无兵法 |
| `0x10` | holder person code | 0–849；`0xFFFF` 表示无持有者 |
| `0x12` | discovery state code | 正式剧本中只出现 0、1、2；0 表示无效且永不出土，1/2 分别对应未出土/已出土 |
| `0x14` | discovery location code | 0–249；`0xFFFF` 表示无地点 |

宝物 ID 取记录序号。正式样本的两个文本资源编号均等于记录序号，模组可分别引用其他宝物的名称和说明。前 100 项内置宝物可引用 0–99，后 20 个扩展槽可引用 0–119。启用扩展槽所需的独立文本来源尚未接入。

四维映射为：类别 2 → 统率，1 → 武力，5/9 → 智力，3/4/6 → 政治；其余类别不增加四维。同一人物持有多件作用于同一能力的宝物时取 `ability_bonus` 最大值，不累加。忠诚变化和能力加成是两个独立 `u16`；只有授予/没收忠诚路径对 `loyalty change` 使用动作特有算法。

## 重制行为

导入器必须无损保留 11 个原始字段，并为状态、兵法、持有者和发现地点提供显式解析结果。状态语义如下：

- `0`：无效宝物；`IsInvalid` 必须为 true，`CanBeUnearthed` 必须为 false，永远不能进入出土流程。
- `1`：有效且未出土；可以进入出土流程。
- `2`：有效且已出土；不再进入出土流程。

兵法、持有者和发现地点字段中的 `0xFFFF` 必须映射为空值，不得转换为有效实体 ID。

资源编号越界、图像/类别越界、无效兵法、无效持有者、未知状态码或无效地点必须拒绝整个 `item` chunk，不产生部分宝物列表。

### 转换为共享安置

上述状态码保留在源记录解析层。共享剧本与Core采用互斥宝物位置，契约见[共享创作规格](BEH-CONTENT-0001-shared-scenario-authoring.md)。转换先排除源状态0，其余优先选择内容中存在且存活的持有人。无有效持有人时，有有效地域则生成地域埋藏，其余省略投放。持有位置仅保存人物引用，埋藏位置仅保存地域引用。184剧本倚天剑、青釭剑的“未出土且由曹操持有”统一转换为曹操持有。此项为用户确认的重制选择，替代此前完整保留独立出土状态的转换行为。原作事实及源数据复核见[RE-0006](../../research/findings/RE-SAN9PK-0006.md#2026-11-17未出土且有持有人的正式记录与消费者)。

## 状态与不变量

- 输入与前置条件：已通过 `BEH-IMPORT-0001` 的完整剧本流，位置在文件起点。
- 状态变化：无；只生成 120 项只读记录。
- 始终成立的不变量：返回顺序等于原文件顺序；每项保留完整 22 字节语义值；状态码 0 的记录不可出土。
- 能力不变量：逐能力只取所持宝物最大加成；宝物忠诚值不得参与当前能力计算。
- 失败或无效输入行为：抛出格式错误，不猜测未知编号或截断引用。

## 示例与边界

- `tactic code = 3`：解析为兵法 ID 3。
- `tactic code = 0xFFFF`：解析为空。
- `holder person code = 326`：解析为武将 ID 326。
- `discovery state code = 0`：解析为无效宝物，永不出土。
- `discovery state code = 1`：解析为未出土且可出土。
- `discovery state code = 2`：解析为已出土。
- 记录序号 1 的 serialized id 被改为 99：保留原值 99，宝物定义和初始安置使用 ID 1。
- category id 为 13：拒绝整个列表。
