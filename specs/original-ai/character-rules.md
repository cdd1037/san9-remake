# 原版 AI 人物与家族规则

状态：已确认；2026-10-16采用。本文补充[行为B06](behavior.md#b06)，覆盖已确认的策略特判与相关公共自动规则，不新增一套人物能力或事件系统。原作身份域与证据分别见[AI研究](../../research/ai.md#strategy-groups)、[人物判别](../../research/findings/RE-SAN9PK-0106.md)和各项链接；未核实的历史动机不作为规则。

## 内容表达与边界

原版内容按下列名单和参数转换，规则消费语义属性、人物／家族引用、优先值及显式禁用条件，不比较姓名、实体编号区间或列传资源码。版本Importer负责源身份映射；作者只配置基础属性和引用，运行时按当前君主、归属及家族关系派生势力偏好。独立内容与Mod可以配置同类规则；没有配置时使用对应规则的普通分支，不从名字猜测特判。

策略分组、自动接受、继任、起兵、国号和登用分别表达，不能合并成一个“历史名将”标记。C01～C03属本次AI策略，C04～C09依其公共自动事件或命令职责接入；玩家与电脑共用的效果不能再叠加AI专属补偿。当前已实现的公共消费者继续复用，新策略接入不得重复结算。

<a id="c01"></a>
### C01：家族外交排序加权

君主属于曹操血缘时排序分加200，刘备／孙坚血缘加100，其余0；依据血缘引用，可作用于后代，不要求始祖存活。只增加外交排名的排序分，不改实际信望；排名生命周期按[B05](behavior.md#b05)。来源：[策略分组与排名](../../research/ai.md#strategy-groups)。

<a id="c02"></a>
### C02：特殊策略分组

刘备、曹操、曹丕、曹叡、孙坚、孙策、孙权作为君主，且普通主势力与玩家合计至少四家时，优先进入战略优待组（`Favored`，原版元数据bit7）；其余分组保留同根当前兵力（含驻军及同根子军团单位）的排序及兜底。该组继续影响原有攻击门和计略／在职登用的额外75%跳过门，不提供全面免疫或额外能力；玩家控制与根势力资格仍分别判断。来源：[策略分组](../../research/ai.md#strategy-groups)。

<a id="c03"></a>
### C03：吕布攻击强度偏好

吕布为君主时，普通攻击对应分支要求可派余兵严格大于目标估计兵力；保留该分支在联盟条件之后、一般策略分组门之前的次序。不绕过来源、选将、留兵、路线、预算及最终兵量门。来源：[攻击强度门](../../research/ai.md#re-0082-事实三处概率门)。

<a id="c04"></a>
### C04：特定君主自动劝降限制

刘备、曹操、曹丕、曹叡、孙坚、孙策、孙权作为目标君主时，自动接受阈值为0。作用于公共自动判断，不把玩家接收方的选择替换成自动拒绝；其他资格及[B17](behavior.md#b17)的高分修正不取消该限制。来源：[劝降资格](../../research/findings/RE-SAN9PK-0118.md#2026-09-17-劝降资格兵力与归并闭合)。

<a id="c05"></a>
### C05：自动势力合并的存续偏好

名单为刘备、曹操、曹丕、曹叡、孙坚、孙策、孙权、董卓、吕布、袁绍、张角。双方君主均在名单则不合并；仅一方在则其势力存续；均不在则兵力较大者存续，相等按既定候选顺序。仍先满足公共合并事件资格及概率；不是外交劝降规则。来源：[自动合并研究](../../research/findings/RE-SAN9PK-0071.md)。

<a id="c06"></a>
### C06：在野起兵资格与集团首领优先

一般候选需要野心大于9；下列人物可由特判取得候选资格，排序优先级依次递减且均高于普通野心键：袁术、袁绍、曹操、公孙瓒、曹丕、孙坚、孙策、孙权、张角、张鲁、董卓、刘表、刘备、吕布、马腾。保留原排序中相邻档次，多个候选／支持者合并排序后取首为君主，不保证最初收集者最终为君主。

空城、支持者、日期及场景资格继续沿公共起兵规格；低忠诚在职人物自立是另一事件。来源：[起兵研究](../../research/findings/RE-SAN9PK-0124.md)、[公共治理规格](../behavior/BEH-GOVERNANCE-0003-xun-personnel-and-territorial-transition.md#g10空城起兵)。

<a id="c07"></a>
### C07：自动继任优先值

| 优先值 | 原版人物 |
| --- | --- |
| 4 | 董卓、张角、何进 |
| 3 | 袁绍、马腾、袁术、公孙瓒、曹操、孙坚、孙策、刘表 |
| 2 | 刘备、曹丕、孙权 |
| 1 | 吕布、马超、张鲁 |
| 0 | 其余人物 |

依次按“与旧君主构成亲子且候选更年轻、同非空亲代、同血缘年龄、人物优先值、四项当前能力和”降序选择；不能把较年长的父母也提升到首项亲子优先级。沿用[公共继任规格](../behavior/BEH-PERSON-LIFECYCLE-0002-appearance-injury-and-death.md)以人物ID稳定破平的已采用规则，不由AI另设输入枚举次序。死亡来源不同不另造继任算法，玩家选择入口仍独立。该表与C06的起兵排序不同。来源：[继任研究](../../research/findings/RE-SAN9PK-0141.md)。

<a id="c08"></a>
### C08：国号偏好

袁术本人优先“成”；司马懿、曹操、孙坚、刘备的血缘分别优先“晋”“魏”“吴”“蜀”。按原有次序先人物特例再血缘，偏好项不可用时继续控州／剩余可用国号流程，不抢占其他势力已有国号。使用显式国号引用，不按显示名匹配。来源：[国号选择](../../research/findings/RE-SAN9PK-0016.md#9-g10国号自动选择与提交边界续核2026-09-20)。

<a id="c09"></a>
### C09：公共登用人物特例

刘备亲自执行登用时加`max(0,100−基础政治)`补偿，当前能力、伤病及其他公共条件仍有效；不把该项解释成政治固定100或保证成功。许攸为目标且公共特殊事件资格成立时阈值可直接为100，涉及曹操／袁绍的事件引用；这不等于曹操登用许攸必成。

两项均属公共登用规则，AI只消费其预测和结果。许攸分支已由[官渡专项研究](../../research/findings/RE-SAN9PK-0130.md#2026-09-20官渡专项登用前置的独立生产链)闭合，复用已有[公共官渡事件](../behavior/BEH-EVENT-0002-event-selection-and-commit.md#官渡之战)：曹操所属根势力必须为玩家，执行者同根；普通电脑曹操不能触发，玩家委任军团仍按公共资格判断。预测只读，到达时复验，事件效果先于普通成功转属；人物、关系、地域、兵粮、模式及一次性条件全部沿公共规格，不新增AI专用必成路径。刘备公式与身份依据仍见[登用公式](../../research/findings/RE-SAN9PK-0067.md)、[身份边界](../../research/findings/RE-SAN9PK-0106.md)。

## 不增加的特判

自动俘虏处置的能力保护仍按当前能力大于89判断，不扩成名将名单。野心、义理、相性、性格和异民族归属沿各自通用规则；单挑、兵法联动、历史剧情中的其他人物分支仍归公共战斗／事件规格，不因本次AI接入而追加或重复实施。
