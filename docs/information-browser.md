# 情报界面

情报按钮及右侧名单快捷菜单打开十项入口。行为依据[BEH-UI-0004](../specs/behavior/BEH-UI-0004-information-browser.md)，设计取舍见[DEC-UI-0007](../specs/decisions/DEC-UI-0007-information-browser.md)，原作调查及IDA同步见[RE-SAN9PK-0161](../research/findings/RE-SAN9PK-0161.md)。

## 当前行为

| 入口 | 内容 |
| --- | --- |
| 全官爵 | 八项官爵的指挥、信望与就任势力 |
| 全势力 | 状态、战力、资金、兵粮、相对玩家的外交关系数值，以及君主头像详情 |
| 全军团 | 归属、都督、驻兵、武将、金库及详情 |
| 全都市 | 驻防、内政、人口与详情，关联地域/武将 |
| 全地域 | 地域所属城市、已建设施与驻防，包括没有建筑的地域 |
| 全部队 | 活动部队兵力与坐标；190年初始无活动部队，入口禁用 |
| 全武将 | 通用目录的13页列组、表头排序、15行视口、头像联动；独立全屏武将详情 |
| 全宝物 | 可见宝物持有人、增益和图像详情 |
| 进行记录 | 本会话成功商业/开垦的日期、执行者、增量与费用 |
| 年表 | 开局统治、军师及玩家手工笔记 |

点击列头排序；滚轮、滚动条、方向键、PageUp/PageDown、Home/End浏览。点击行或Enter打开详情；其他情报详情可切换上一项/下一项并打开关联名单。武将详情使用右侧18人名单：移入只改变焦点，单击或回车换人；状态/兵法切页、宝物查看均保持当前人物上下文。Escape、右键或关闭按钮逐层返回，保留原名单状态。地图按钮关闭情报并定位，不改变地图命令起点。年表点击输入年表后输入文字，Enter保存，Escape取消。

这批窗口呈现已实现领域状态，未接入原作全部说明文本、经济预测、AI请求、人物生命周期及存档。记录和笔记随当前会话保存在内存；部队没有新增出征、移动或战斗规则。外交显示关系数值，不臆定文字等级阈值。

## 分层与数据

Core保存人物身份、人口、官爵归属、军团、宝物归属和关系值；Application的InformationQuery从同一只读快照投影，InformationBrowser保存模态导航。直属军团的Treasury为空，明确使用势力金库；子军团单独持有CorpsTreasury。领域不读取源格式或图像索引。

组合包schema12、地图schema8、初始态schema9、皮肤schema12；旧包重新导入。导入器转换官爵/官职/宝物定义、可见人物及图像，客户端只读取生成包。人物详情图像角色为information-person-{id}，目录使用原生64×80的catalog-person-{id}，宝物为information-treasure-{id}，包校验要求所有可见对象的图像与文本引用闭合。190年导出含210名可见人物（195在职、15在野）和14件宝物；隐藏人物不加入目录。

武将详情由OfficerDetailState保存进入时的候选顺序、查看人物、焦点、视口和页签；OfficerDetails投影数据，OfficerDetailView只显示和转发输入。240×240头像、表字、四维图、四列状态与列传、九类兵法和持有宝物已接入。表字/列传键属于内容定义；列传来自M_RtdnPK，保留原始文本并投影简体。未知命令字段仍显示不可用标记。

右侧名单的装饰与数据独立于地图侧栏；只复用滚动组件和目录皮肤。关闭返回原一览排序和视口。原作证据及主库注释见[RE-0162](../research/findings/RE-SAN9PK-0162.md)。宝物和帮助浮层沿用重制内容呈现，不宣称其布局已逐像素对齐原版。

## 显示与通用表格

十项菜单采用三段四帧原图，按状态应用文字颜色、描边和按下位移；九段外框按源尺寸平铺。十二条底部提示由原版消息目录转换，包含无部队、无宝物的禁用原因，移出后清除。文字统一通过GameTextPresenter绘制，效果方案与后续评估见[DEC-UI-0002](../specs/decisions/DEC-UI-0002-modern-text-effects.md)。

武将一览接入CatalogView，OfficerCatalog声明页面和列；其他目录尚未迁移。能力页九列，13个页签按7+6排列；行身份、排序、滚动与详情导航分别管理。本人习得、宝物/势力提供及九类熟练度来自转换后的运行时数据。

目录框架保留源调色板Alpha，头像使用原生64×80中档图。正文在24像素行内垂直居中；正文、表头和页签分别使用已确认的文字效果。共用状态和输入约定见[战略界面](strategy-ui.md)。

命令调度、大将/布阵及擢升等未建模字段显示“—”；缺少爵位时，指挥与俸禄未模拟原版派生规则，也显示“—”。帮助按钮展示重制操作说明。姓名使用现代中文排序，不等同于原版编码排序。标题及关闭按钮文字效果仍待原版核对。

四维图使用固定面板坐标的程序渐变与连续能力轮廓，放大时由着色器抗锯齿；只保留此实现。原版位图方式的取舍见[DEC-RENDER-0003](../specs/decisions/DEC-RENDER-0003-procedural-officer-radar.md)。

## 验证分工

自动测试覆盖目录、排序、关联返回、金库、记录和浏览不改变模拟等行为；按受影响范围运行。实际画面由用户验收，不自动启动Godot。已解决问题的试验截图、审计数量和逐轮修复经过不在本页累计。
