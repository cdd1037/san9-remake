# 寻路优化验收

2026-09-14，当前规则 `san9-core-g08-v7`。本轮未提交迭代统一为一个规则版本；原始测量产物中的临时v8/v9分别对应完整路线方案和分段计划方案，不作为发布版本。设计与状态语义见[行军规格](../specs/behavior/BEH-WAR-0001-movement-and-command-lifecycle.md#分段行军计划2026-09-14)。

## 当前实现

每日行军和建设推进改用持久短程计划。较近目标一次规划后跨日消费，长途用区域引导选择近期推进范围；每步仍验证占地、当前阻挡、费用和精确到达资格。路径耗尽后可以用剩余当日预算接续，实际移动目标在近处更新、远处跨区域变化时重规划。计划、失败输入和有限重试状态属于模拟状态，正常存档和记录重放完整保存。

世界变更入口维护按对象排序的占用矩形缓存，查询直接筛选本队规划范围与目标附近的矩形。持续失败会逐步扩大搜索范围及节点预算；Waiting与Unreachable分开，工作量上限不会伪装成无路。占用输入未变化时最多间隔3次日级调用重试，变化立即唤醒；直接比较位置和占地，没有增加世界哈希。

静态拓扑按地图共享，连通性只在区域图维护，费用和细格所属区域两份主要数组使用128MiB保留预算，区域引导仍各有8MiB预算。精细搜索工作区按执行线程隔离，以弱引用表关联地图，独立批次结束后不会被线程缓存永久持有。此项支持Core层同图并行，不代表新增了批量任务调度器。

## 固定100队独立导航负载

从同一真实剧本构造100队，每日逐队更新占用，接近目标后返回起点再往返，始终保留100队。固定10细单位接近范围，所有设施阻挡，关闭战斗、经济与AI。这是独立导航负载，不能代替上面的完整结算；设施通行口径也不同于正式会话按外交筛选的规则。

## 路线质量

同一100队初态分别独立执行完整旅程，保留所有其他队伍为固定阻挡，固定10细单位曼哈顿接近范围，逐日导航费用按地形费用累计。与提交 `2a3d227` 精确A*生成的相同100条固定输入基准比较：全部100条到达，1条初始已到达；其余99条平均代价增加0.57%，中位0%，最大10.29%，总地形代价增加1.35%。

这是实际地图样本，不是数学误差上界，也不是正式战斗中位置相关射程及固定步进费用下的行军天数对照。前期短前视方案出现过约58%的最差绕行，已通过增加前视、允许多个阶段出口及保留较近目标完整规划改善；最终数字取 `navigation-quality-final.txt`。
