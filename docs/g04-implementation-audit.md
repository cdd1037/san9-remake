当前人事代码是尚待规则对齐的原型。549项测试和190年年度脚本证明当前实现的约束、确定性、保存恢复和重放一致，不能证明原作耗时、完整搜索和调动生命周期正确。以下仍标为“待核实/待修正”的问题仍存在于代码中，不能因有文档记录而视为已修复或G04验收完成。

分类：**证据支持**表示有对应研究，但仍以列出的范围为限；**已决改良**须有既有DEC或用户明确指令；**工程选择**只说明实现机制，不冒充原作；**待核实/待修正**不作为最终玩法要求。
