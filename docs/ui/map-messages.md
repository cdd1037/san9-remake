## 当前可见范围

每次结算先由界面消费结果，已有对白和排队对白全部关闭后才推进下一阶段。获得宝物、探索资金、登用及任务完成等结果共用此顺序；旬末结果先于换季演出（如有）、战略面字图和旬开始下令／情境提示，普通日结果先于下一日推进。

伪报、扰乱、激励、救援的行动与回应在目标部队位置显示，行动立即出现，回应延迟一秒；烧夷及夺取人物／资金和失败分支在目标设施位置显示。结果留在左下即时记录，不再为这些无插图、无专用音效的结果弹普通模态对白。外交会谈、人事探索、插图及专用结果音效仍走已有叙述流程；日志由生产者独立提供并经同一记录入口发布，不依赖叙述回调，也不自动复制对白或喊话正文。

伪报／扰乱失败回应按原作优先级区分团结、识破、方圆阵和通常失败。部队结算事实保存发生位置、当时主将、势力、所属设施及状态／相关能力；不从推进之后的部队状态反猜。地图重绘、暂停和资源加载不重新选台词。

反馈生成由 Application 的 `OccurrenceFeedback` 统一组织，`ExecutionPublication` 发布即时结果，`BattlePresentationBuilder` 只选择反馈并安排时间、特效及对话阻塞。去重按本次发布的世界修订号、事实索引、反馈来源、消息／记录通道及条目序号标识具体反馈；播放一条对白不会连带吞掉同一事实的其他记录。单挑专用阵亡对白只替代通用阵亡播报，其他反馈仍独立发布。该标识属于内存中的发布／播放契约，不写入存档或录像。

## P2完成范围与使用限制
