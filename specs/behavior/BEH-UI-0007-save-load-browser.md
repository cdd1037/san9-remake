# BEH-UI-0007：存档与读档界面

- 状态：已确认
- 最后更新：2026-11-02
- 依据：[RE-SAN9PK-0180](../../research/findings/RE-SAN9PK-0180.md)

## 重制行为

存读档页号属于客户端界面偏好：主菜单载入与局内储存／载入共享最后浏览页，翻页即更新内存，中止不回滚，不按最新存档时间选页。正常关闭客户端时统一写入独立`ui-preferences.json`，下次启动恢复；切换场景、读取或写入战局本身不保存这份偏好。初始为第一页，恢复页超出当前容量时夹取；手动与自动页均可记忆。存储所有权与失败处理见[界面记忆](../../docs/user-settings.md#界面记忆)。

战略面右上角“功能”打开11项菜单，提供储存、载入、局内编辑、PK设定、设定环境、初始设定与结束游戏入口。初始设定返回开局主菜单；存在未保存修改时先确认，取消恢复地图，确认后释放当前游戏场景及其输入、纹理和音乐所有者。窗口打开期间阻止地图操作、阶段推进和快速存读档快捷键，关闭恢复原战略状态。

存读档页默认呈现40个栏位，每页5行、8个手动栏位页签及“自动1”“自动2”两个自动栏位页签，模式切换及关闭重开保留当前页。栏位摘要包含君主、头像引用、玩家数、史实／虚拟、难度、剧本起始日期及名称、当前日期、保存时间与备注。空位保留行底板及编号；载入空位不可选。选择后锁住当前槽位，确认期间不能翻页或替换待确认选择；取消不改变摘要。

储存选择弹出备注框，已有备注作为初值，已有资料明确询问覆盖。支持Unicode输入，不继承原版字节长度限制。确认产生包含模式、栏位和备注的界面请求；重复确认不再产生请求。载入已有栏位时先关闭栏位页、显示当前地图，仅有未保存修改才询问放弃当前进度；输入备注不能修改已存摘要。

备注框、帮助提示和栏位页按最上层响应Escape／右键。中止与页面关闭返回地图；菜单外左键关闭菜单。页签支持点击、键盘焦点激活和PageUp／PageDown翻页。

开局“载入游戏资料”复用同一栏位页、手动／自动目录和用户数据路径。关闭、右键与Esc返回开局并恢复该按钮焦点；没有活动会话，不询问放弃当前游戏。载入时按摘要中的剧本ID解析目录及对应转换包，校验包的剧本身份，再按玩家读档语义恢复正文；局内同剧本栏位读档复用已加载内容、地图资源及音乐播放器，只替换会话及其界面；跨剧本读档重新准备并替换完整游戏场景。成功不创建新局、不重发开局补偿或介绍、不生成新的旬首检查点。读取与准备期间锁定重复请求及返回；文件损坏、所需剧本或资源缺失时显示错误，开局仍可关闭提示、重选或取消，局内保留原游戏。旧栏位格式缺少剧本身份，明确拒绝，不推断剧本、不迁移或删除文件；Application封套和快速存档格式不变。

主菜单读档和局内返回主菜单复用宿主的黑屏转场：开始准备目标画面时同步以500ms连续淡出，已全黑且目标就绪后替换，再以500ms淡入；加载较慢时在全黑下等待，较快时也不能提前替换。期间阻止重复切换和界面操作，目标演出在淡入完成后开始。原作分档亮度与重制连续透明度的区别见[RE-0200](../../research/findings/RE-SAN9PK-0200.md#2026-10-23主菜单换景时序复核)。读档恢复原会话，不重复新游戏“战略”字图或开局介绍。准备失败保留原场景并淡入恢复，再显示错误；返回主菜单失败同样恢复原游戏。局内栏位读档和快速读档均无此转场：保留原地图，待新画面就绪后直接替换。

## 状态与不变量

客户端栏位目录为[用户数据目录](../../docs/user-settings.md#用户数据目录)下的`saves/slots/`，文件名为`slot-{slot:D2}.save.json`。容器版本6在单个UTF-8 JSON文件中按顺序保存`header`与`save`。摘要头包含剧本ID、显示摘要、旗色／旗字、协议版本；正文为Application存档封套。两者共同原子写入，不维护独立索引。目录仅增量读取文件前缀并校验摘要头，不解析世界、计算正文哈希或构造世界投影；正常读取量随摘要大小变化，与正文大小无关。目录读取不展示遮罩或提示页，完成后直接进入栏位页。缺失文件为空位；摘要头无效、版本不支持、访问失败仍占据栏位并显示错误。正文的结构或状态错误在实际载入时报告，预览可用不代表正文有效。允许手工修改存档，不保存或检查摘要及正文的完整性哈希；手工修改正文后，相关预览字段需同步修改，浏览不会从正文重建摘要。

手动栏位、自动及F1快速存档统一先在主线程捕获独立的稳定会话快照及所需摘要，再在工作线程编码完整JSON并执行原子写入；后台任务不访问活动`GameSession`，完成后回到主线程更新提示及保存标记。栏位与自动存档共用按请求顺序串行执行的后台队列，F1入口在写入完成前拒绝重复请求。手动栏位保存成功后直接关闭存档界面并返回大地图，不弹成功提示，保留原有详情／缩略视图、镜头与选择，不重建会话或战略界面。失败留在存档页并提示原因，原子替换失败保留原目标。下次打开存档页时重新读取目录。备注随世界状态一起持久化，重新启动后仍可展示。界面忙碌期间阻止重复操作和关闭。

载入在工作线程一次解析JSON，校验摘要头，再验证Application封套版本、会话状态及当前内容的对象引用，采用`SaveService.Load`的玩家读档语义，然后在主线程替换会话及战略界面并返回地图。玩家读档建立新的随机运行流，已保存任务结果保留；失败不替换当前会话。目录不以内容身份筛掉存档；当前内容的实际兼容性在载入正文时检查。

Application会话持有仅在内存存在的`HasUnsavedChanges`：新局为真，恢复／载入为假；统一操作提交成功后置真，查询、取消、拒绝及重复请求不改变标志。保存成功仅在当前操作序号仍等于保存捕获序号时清除，保存失败或落后的异步保存不清除新修改；不计算世界哈希，也不写入快照。

选中载入栏位后关闭栏位页、保留当前地图模式与镜头；有修改才显示“是否放弃当前进度”，选否、Escape或右键关闭后停留在原地图。无修改直接读取。实际读取期间不显示过渡页或遮罩，但阻止重复操作；失败在原地图提示，不替换会话、不清除修改标记。此处为低成本重制选择，原版标志证据见RE-0180。

现有F1／F2快速存读档继续使用独立路径，但在此窗口打开期间不执行；F2复用地图上的未保存修改确认与载入失败提示。未保存修改标记不改变Application存档格式，栏位封套属于客户端文件组织；不接入原版存档导入。

Godot客户端的旬开始自动存档默认启用，Application／Headless默认关闭自动检查点；客户端新局创建时显式启用，载入后只启用未来新旬检查点，不补存载入当旬。Application会话在新局首次进入稳定旬首、或实际推进到新的稳定旬首时生成独立的下令前检查点；初始待答交互结束后再生成，终局不生成。检查点只存在于内存，不进入存档协议；普通读档和精确恢复均不创建它。界面在完成交互及返回转场、交还玩家控制时仅提交已有检查点，不以窗口切换或转场完成推导新旬。单个检查点被请求领取后，同旬重复通知及界面重建不再捕获；写入失败归还仍属当前旬的检查点，下一次请求可重试，推进到下一旬则使用新检查点。保存内容固定为该检查点，之后下令、推进或切换会话不能改变已排队的正文、摘要及旗帜。

自动档使用栏位目录内独立的十个固定位置`auto-01.save.json`～`auto-10.save.json`，不占用40个手动栏位，也不覆盖F1快速档。位置为`floor((当前旬首日期−剧本开始日期) / 10) % 10 + 1`，按游戏经过旬数轮换；新局从位置1开始，十旬后复用同一位置，读回旧档重新推进时覆盖同日期对应位置，不按保存请求数增加文件。复用栏位封套、摘要与原子写入；替换失败保留该位置原文件及其他九个位置，不先删档。只有后台成功写入后，才按检查点捕获序号清除仍属当前会话且没有更新操作的未保存标记；旧会话回调不影响新会话。成功不显示提示，失败短暂提示原因并继续游戏，不弹确认框。原递增编号自动档不再由新自动页枚举，不迁移或删除这些旧文件。

页签区在“36–40”后显示“自动1”“自动2”两页，十个页签整体左扩，保留原有字号与按钮尺寸。自动档按固定物理槽号排列，第一页固定为A1～A5，第二页固定为A6～A10，编号与`auto-01.save.json`～`auto-10.save.json`一一对应，不因时间或空槽移动；两页复用完整摘要、头像和旗帜。普通自动槽号保留原有文字样式；可读取摘要的自动档中，捕获时间最近的一槽仅将编号文字改为金色，位置、字号与原有样式一致，不显示“最新”文字，同时间取槽号较小者；没有有效摘要时不显示金色编号。缺失行保留对应位置的空底板且不可载入，损坏行展示错误并允许尝试载入以报告失败。自动档载入请求直接使用所选文件的固定位置，读取该位置的存档。载入复用玩家读档语义、未保存修改确认与现有错误提示；储存模式仍可浏览“自动”页，但两页全部行禁用，不能手动覆盖。

## 呈现边界

摘要来自当前会话与转换后的内容包，不伪造原版设置。剧本名读取内容包必需词条`scenario.title`，TC101导入器按剧本头选择原始名称，独立作者可直接提供名称；史实／虚拟和初级／高级来自已保存的会话开局设置，电脑伤害加成独立于难度显示。头像与君主使用当前玩家势力资料。保存时从已加载的剧本插图映射解析君主头像，把共享头像资源ID写入摘要的`portraitAssetId`；不保存剧本内人物角色作为头像引用。主菜单与局内浏览都直接按该ID使用共享头像目录和Face裁切，仅请求当前页需要的图片，复用现有纹理缓存；不为显示头像读取剧本、人物映射或存档正文。同一人物编号在不同剧本中可以对应不同头像，摘要固定保存时的引用；没有君主时为null。旧栏位容器不支持该字段，明确拒绝且保留原文件，不在浏览时补查或迁移。

分页容量属于呈现模型，可扩展，不充当领域身份或文件格式约束。资源以语义角色进入内容皮肤，客户端只读转换包。

已有栏位左下角显示存档玩家势力的旗帜；旗色与旗字在保存时从同一稳定会话投影提取，包含国号或新建势力的显示规则，作为预览摘要写入头部；浏览时只读摘要头，不解析存档世界或使用当前运行会话。摘要与正文的依赖关系在正常保存时通过同次原子写入维护，不作为领域状态来源。旗帜复用转换包的组合图层，行内位置为`(-7,44)`、尺寸68×52，固定方向5、第4帧；空栏位与错误栏位不显示旗帜。

## 验收标准

- 战败或其他终局返回标题后，载入界面显示顺序与鼠标命中顺序一致，存档行可选择；取消后恢复标题菜单及其焦点。
- 备注确认、帮助和错误提示仅允许最上层窗口接收鼠标、键盘与Tab焦点，关闭后恢复下层操作。
- 右上角入口、两种底板、9页导航及备注输入可显示；空读档位保留底板但不可激活。
- 存档取消、重开、切换模式、目录替换及重复确认不产生意外请求或摘要修改。
- 打开界面、翻页和取消不改变世界日期、随机流、命令及当前会话；成功载入恢复保存状态并采用玩家读档语义。
- 自动化测试覆盖导航与请求状态、重启后目录重建、Unicode备注、合法手工修改、结构和状态错误、失效内容引用和原子写入失败。
- 自动档测试覆盖新旬检查点在操作成功发布后才可领取、同旬去重、界面重建及读档不创建检查点、独立于手动栏位、串行写入顺序、按经过旬数轮换十位置、跨月／跨年与非首月剧本、回读旧档同旬位置覆盖、写入失败保留原有文件及同检查点重试、自动页按固定位置载入和禁止手动覆盖。
- 三种保存路径的测试覆盖捕获后继续操作不改变待写快照、不清除新修改、后台编码／写入不在捕获线程执行，前一写入失败不阻断后续保存；现有Application和Headless存档／录像协议保持不变。
- Godot实际视口检查覆盖菜单、空页、备注框与已有存档行；临时脚本完成真实文件储存、读回备注、确认载入和会话替换的往返。脚本信号驱动不等同于完整人工鼠标验收。
